# Community conduct

Treat contributors and maintainers with patience and respect. Keep technical
feedback specific to the work, avoid harassment or personal attacks, and never
publish another person's private information.

This repository is not operated as an open discussion forum. Its only official
GitHub Discussion is first-party, automated, non-ranking, and locked. Use the
support path in [SUPPORT.md](SUPPORT.md) for product help and a focused pull
request for a public factual correction.

Maintainers may close or remove contributions that are unsafe, abusive,
off-topic, promotional, deceptive, or incompatible with these boundaries.
