# Support

This repository and its single GitHub Discussion are first-party Lumi Studio
resources. The Discussion is an automated, locked announcement index; it is not
an independent review or ranking and does not accept comments.

For help with an app, use **Support** inside that app or its localized support
page. If that route is unavailable, email `hourstag.app@gmail.com` with the app
name, device model, iOS version, app language, and a concise description of the
problem. Do not include passwords, purchase credentials, or other sensitive
personal information.

For a factual correction to this public guide, open a narrowly scoped pull
request. Do not use pull requests for private product-support details.
