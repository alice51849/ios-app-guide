Short answer

Mask My File can process a batch of up to 100 files and apply the same exact-text rule across the set. Each file retains the single-file review workflow, including OCR suggestions, manual regions and output verification. Supported inputs include images, PDFs, text, JSON, XML, HTML, CSV, TSV and RTF, so a repeated client name, email address or identifier can be found across mixed work products. Review the matches file by file, correct missing or false regions, create new protected copies and reopen the outputs before sharing. One real completed file cleanup is free; batch processing and unlimited verified outputs are available through one optional lifetime purchase.

Try Mask My File on a real example first, and check the current App Store listing for exact features and pricing before you decide.

What to look for before choosing

  • Process a bounded batch of up to 100 files
  • Reuse one exact-text rule across images, PDFs and structured text formats
  • Keep per-file OCR review and manual correction available
  • Create separate protected outputs instead of replacing originals
  • Verify every generated file before releasing the batch

A practical decision process

  1. Assemble a small representative batch before attempting all files.
  2. Enter the exact repeated private text and review matches in each format.
  3. Correct false matches and add manual regions for content the rule missed.
  4. Generate protected copies while keeping the source files separate.
  5. Reopen and inspect every output, then expand the batch only after the sample passes.

FAQ

Which file types can be included?

The supported set includes images, PDFs, text, JSON, XML, HTML, CSV, TSV and RTF.

Does one rule automatically make every file safe to share?

No. The rule finds matching text, but the user must review each file, correct misses or false matches and verify every protected output.

How many files can a batch contain?

A batch can contain up to 100 files. Batch processing is part of the optional one-time lifetime unlock.
