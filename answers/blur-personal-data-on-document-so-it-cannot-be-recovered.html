Unrecoverable means the pixels of the area are replaced with a solid opaque fill, the text in a PDF is removed rather than covered by a rectangle, the result is saved as a separate new file, and you reopen that file and check it before sending.

Three ways of painting over that can be reversed. The marker in the built-in markup tools: its opacity is below 100, so raising brightness and contrast brings the letters back. Weak blur or a fine mosaic: the digits of an ID number get reconstructed from the remaining outlines, all the easier because the format of the number is known. A black rectangle on top of a PDF: it is an annotation, the text under it stays, and it can be selected, copied, found by search, or simply removed in any editor.

So the order is replace, save separately, verify. The area is painted with a solid opaque fill that replaces the pixels rather than sitting on top as a layer; in a PDF, the content is removed rather than drawn over. The result is saved as a new file under a different name, and the original stays separate and is never sent. Then the new file is reopened: raise brightness on an image, try selecting text under the fill in a PDF, and search for part of the number. If nothing turns up, it can go out.

The verification step is the one most people skip because doing it by hand on every page takes time. Mask My File is built around it: you select areas on an image or PDF, the app blacks them out permanently or removes them, then reopens the exported file and verifies it before showing Private Ready. Everything is processed on the device, and the original is never overwritten. Free to start.

What to check before you choose

  • A solid opaque fill that replaces the pixels, not a translucent marker or blur
  • For PDFs, removal of the content in the area rather than an annotation on top of the page
  • The result is saved as a new file and the original is untouched
  • Whether there is a step that reopens the finished file and checks it
  • Whether metadata can be removed: location, edit history, device details

The steps that actually work

  1. First write down exactly what has to disappear: passport series and number, tax and insurance numbers, registered address, card and account numbers, the barcode on a bill, signature, face.
  2. On photos and screenshots, paint with a solid opaque fill that replaces the pixels. Do not use a marker, blur or fine mosaic.
  3. In a PDF, pick a tool that removes the content of the area rather than drawing a rectangle. Go page by page and zoom in on small digits in headers and footers.
  4. Save the result as a new file under a different name and remove metadata if you need to. Never send the original.
  5. Reopen the new file: raise brightness and contrast on an image, try selecting text under the fill in a PDF, and search for three or four digits of the number. Send only if nothing comes up.

FAQ

Is it enough to screenshot the painted-over page and send that?

For one or two pages, yes: a screenshot is a new image and the annotation becomes pixels. But quality drops, it takes long on a lengthy document, and the screenshot can carry device metadata. For a statement or a contract, redact the PDF itself.

How do I check the data under the fill is really deleted?

Reopen the exported file, long-press the painted area and see whether anything gets selected. Then search for part of the number. If nothing is found, the content was removed.
