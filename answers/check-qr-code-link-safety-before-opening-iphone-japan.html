The single most important QR safety habit is not opening the link the instant you scan. Read the domain (the host) first; if it does not match the business or official site, uses a confusing spelling, or hides behind a short link, do not open it and check with staff or the official app. QR Code Halo lets you turn off Run action after scanning, and its Security Check in History parses the code on the device into scheme, host, path and query and returns Safe, Caution or Blocked without any network reputation lookup. Codes such as javascript:, data: or file: are never opened.

Most fake QR codes are a sticker over the real one. They lead to pages that imitate a payment or sign-in screen to collect card numbers or passwords. When the browser opens the instant you scan, a convincing page is easy to trust. That is why one extra look at the URL before opening works so well, especially at the host, the part that says which site it really is.

By default QR Code Halo acts the moment it reads a code. When safety comes first, turn off Run action after scanning in Settings and decide after you see the result. In History, open a code and tap Security Check: the Local Payload Security Inspector parses the complete payload on the device into scheme, host, path, query and fragment, and returns Safe, Caution or Blocked with transparent findings.

For codes you use again at the same place, QR Verification helps. Save a result as a local reference, then compare a later scan by its complete SHA-256 fingerprint and URL components, so a swapped code stands out. No network reputation lookup or fuzzy score is used, and parsing uncertainty fails closed.

What to check before you choose

  • Can you stop codes from opening automatically and check first?
  • Is the URL's host shown clearly?
  • Are the reasons for the verdict listed item by item?
  • Are dangerous forms such as javascript: or data: refused?
  • Can you compare a code with the one you scanned last time?

The steps that actually work

  1. In QR Code Halo Settings, turn off Run action after scanning.
  2. Scan the code and check that the host matches the business or official site.
  3. Open the code in History and tap Security Check to see Safe, Caution or Blocked and why.
  4. If it says Caution or Blocked, or a short link hides the destination, do not open it; ask staff or use the official app.
  5. Save codes you use regularly as a QR Verification reference and compare future scans.
