Short answer

When you use Claude Code with a Claude Pro or Max plan, Anthropic's documentation says it draws on the same usage limits as Claude itself: a 5-hour session window and weekly limits, with weekly caps for some models. Agent runs read files, run tools and retry, so they can use a large share of a window quickly. Checking the remaining share and the next reset before a big refactor tells you whether to start now or queue it.

A phone or watch is a good place for that number, because it stays visible while the terminal is busy. Look for a tracker that shows the session and weekly limits separately, warns you at a percentage you pick, and tells you the moment a limit is back. Pay-as-you-go API usage is billed per token instead, so it is a different number from these plan limits.

UsageNow is the app this guide covers: UsageNow shows how much of each AI plan you have left and exactly when it resets, right on your Home Screen, and warns you before you run out. What to look for before choosing

  • The Claude 5-hour session limit and weekly limits, including per-model weekly caps, shown separately.
  • A countdown and the exact reset time, so you can plan the next long run around it.
  • An alert at the percentage you choose, such as 90 or 98, sent once per limit and cycle.
  • A reset alert that tells you when a limit is back, so a queued task can start.
  • Lock Screen widgets and Apple Watch complications that stay visible while the terminal works.

A practical decision process

  1. Before a long Claude Code run, check how much of the 5-hour and weekly limits is left and when each resets.
  2. Set an alert at 90 percent on the 5-hour limit so you can wrap up a step before the window closes.
  3. Turn on the reset alert and queue the next big task for the moment the limit is back.
  4. If you also use Codex or Copilot, keep them in the same view and switch to the plan with room left.
  5. Use the free 24-hour trial to try every feature before paying for anything.
