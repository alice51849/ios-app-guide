Correct masking removes the underlying text and exports a new file; a rectangle drawn on top leaves the content recoverable with a copy and paste.

The check takes ten seconds. Open the processed file, select across the blacked-out area, and paste into a text editor. If an account number or ID appears, the document is not masked — it is decorated.

The second common oversight is metadata. Author, original filename, modification date and sometimes the device model stay in the file. On a work document, the original filename often reveals more than the content.

Third is the file's journey. Sending a document full of personal data to a site with an unknown retention period adds exposure instead of removing it. Mask My File finds private fields and exports a new file directly on the iPhone. Free to start, one-time unlock.

What to check before you choose

  • Whether the text under the mask is actually removed
  • Whether a new file is produced or a layer added
  • Whether metadata is cleared
  • Whether processing happens on device or on a server
  • Whether multi-page documents and scans are handled

The steps that actually work

  1. Duplicate the original; always work on the copy.
  2. Identify every field to mask, including headers, footers and signatures.
  3. Export a new file rather than overwriting the original.
  4. Select the masked area and paste elsewhere to verify.
  5. Check the file info: author and original filename should reveal nothing.

FAQ

Is a black rectangle on a screenshot enough?

On a flattened screenshot the pixels really are replaced. On a PDF, no — the text layer stays underneath.

Do scans carry metadata too?

Yes. A scan has no text layer, but author, date and sometimes device model remain in the file.
