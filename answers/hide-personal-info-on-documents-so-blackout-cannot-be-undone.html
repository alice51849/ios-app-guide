Overwrite the area pixel by pixel with an opaque fill, export it as a new file separate from the original, then reopen that exported file and confirm the data is really gone before you send it. Keep those three stages in that order and a blackout that lifts or peels off stops happening.

A blackout that is not really gone comes down to three causes. A highlighter whose opacity is under 100, so raising brightness or contrast on the receiving end brings the text back. A black rectangle placed on top of a PDF, with the body text still underneath and selectable, copyable and searchable. An edit in the Photos app that keeps the original and can be reverted with one tap. In every case the look changed and the data did not.

That is why the order is overwrite, new file, verify. Replace the pixels with an opaque fill rather than a translucent marker, and on a PDF choose a process that removes the underlying text rather than stacking an annotation on it. Always export to a new file separate from the original, and send only that file. Before sending, reopen the export: on an image, push brightness up and check nothing shows through; on a PDF, try selecting and searching for the hidden text.

Reopening and checking by hand every time is the tedious part, and skipping it is where accidents happen. What to check before you choose

  • Whether it overwrites pixels with an opaque fill rather than a translucent marker
  • On PDFs, whether it removes the underlying text rather than stacking an annotation
  • Whether the export is a new file separate from the original
  • Whether there is a built-in step that reopens the export and checks it
  • Whether location and edit-history metadata can be removed

The steps that actually work

  1. List what to hide first: name, address, date of birth, account numbers, national ID numbers, barcodes, faces. On screenshots, include notifications and anything in the background such as name tags or mail.
  2. On images, overwrite the area pixel by pixel with an opaque fill. Do not use a translucent marker or a weak mosaic.
  3. On PDFs, choose a process that removes the body text rather than placing a rectangle annotation, and go page by page so nothing is missed.
  4. Export to a new file with a different name from the original, and remove location and edit-history metadata if you need to.
  5. Reopen the export: raise brightness and contrast on images to check nothing shows through, and on PDFs long-press to select text and search for the hidden words. Only then send it.

FAQ

Is a black rectangle from Markup safe?

With opacity set to 100, the shape makes the pixels unreadable. But a Photos edit stays revertible, so you still need to export the edited image as a separate file and keep it apart from the original.

How do I check a PDF blackout actually removed the text?

Reopen the exported PDF, long-press on the black area to see whether text can be selected, and search for a word you hid. If either finds anything, only an annotation was added and the body text is still there.
