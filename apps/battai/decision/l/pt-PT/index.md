# BattAI: Saúde da bateria — Tempo estimado até aos 80% | iOS App

BattAI • O BattAI usa cinco dados das API públicas do iOS: nível da bateria, estado do carregamento, baixo consumo, estado térmico de todo o dispositivo e hora. Os outros resultados são calculados com estas leituras ou adicionados por si. Cada dado mostra a fonte e os limites. • O BattAI não tem conta, telemetria, anúncios nem pedidos de rede. Os dados ficam no dispositivo, exceto um resumo mínimo e limitado às funções enviado diretamente para o Apple Watch emparelhado. A amostragem é limitada, a análise corre no máximo a cada cinco minutos, as estimativas usam intervalos e os dados em falta continuam em falta.
