# BattAI: คะแนนสุขภาพแบตเตอรี่ — กฎ แหล่งข้อมูล และข้อจำกัดที่ชัดเจน | iOS App

BattAI BattAI ใช้ข้อมูล 5 อย่างจาก API สาธารณะของ iOS: ระดับแบตเตอรี่ สถานะการชาร์จ โหมดประหยัดพลังงาน สถานะความร้อนของทั้งเครื่อง และเวลา ผลอื่นคำนวณจากข้อมูลเหล่านี้หรือคุณเป็นผู้เพิ่ม ทุกหัวข้อแสดงแหล่งข้อมูลและข้อจำกัด สุขภาพ • คะแนนสุขภาพแบตเตอรี่ • ปัจจัยที่สร้างคะแนน • แนวโน้มความจุสูงสุด • ความจุสูงสุด • จำนวนรอบชาร์จ การชาร์จ • การดูแลการชาร์จ • ช่วงการชาร์จ • อัตราการชาร์จ ส่งออกข้อมูล • สร้างไฟล์บนเครื่องนี้ ไม่มีการอัปโหลด • สร้างบนเครื่องนี้ ไม่มีการอัปโหลดข้อมูล ความเป็นส่วนตัว • ไม่มีโฆษณา การวิเคราะห์ การติดตาม SDK ภายนอก หรือคำขออินเทอร์เน็ต ข้อมูลอยู่ที่นี่ ยกเว้นสแนปช็อตขั้นต่ำที่ส่งตรงไปยัง Apple Watch ที่จับคู่ • BattAI อ่านเฉพาะจำนวนรอบชาร์จ ความจุประจุปกติ และความจุออกแบบ ข้อมูลอื่นจะถูกทิ้งทันที ไม่บันทึกและไม่ส่ง เข้าใจแบตเตอรี่ของคุณเมื่อเวลาผ่านไป • ปลดล็อกประวัติเชิงลึก การวางแผน และรายงาน • จ่ายครั้งเดียว ไม่มีการสมัครสมาชิก
