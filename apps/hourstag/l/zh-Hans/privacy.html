Detailed policy (English)

Data collection. HoursTag does not collect, transmit, sell or share salary, working-time, purchase, category, history or goal data. It has no developer-operated account, analytics, advertising or tracking service.

Storage and backup. App data is stored in the app's local container. Export Backup creates a local backup file and opens Apple's system share sheet; Restore Backup reads only the file the user explicitly selects. The developer cannot access either file.

Purchases and network use. HoursTag is a paid App Store download, not an in-app purchase or subscription. Apple processes the purchase. Core calculations work offline; the app does not upload user content.

Retention and deletion. Data remains until the user removes it or deletes the app. Deleting the app removes its local container, subject to any device backup the user controls through Apple.
