# Kumo 몸무게·GLP-1 주사 기록·간헐적 단식 — 귀여운 구름과 하루 10초 체중 관리·다이어트 일기 | iOS App

매일 오르내리는 체중계 숫자에 지쳤다면, Kumo는 하루 10초 기록과 7일 평균으로 흐름만 보여 줘요. GLP-1 주사를 맞든 안 맞든 쓸 수 있고, 기록하러 온 날만큼 구름이 자라요. iPhone Duo에 맞춰 설계: 열면 Kumo가 넉넉한 두 열 레이아웃으로 안쪽 화면 전체를 채웁니다. 이런 점이 달라요 • 열면 바로 오늘, 지난번 숫자가 들어 있어 ±0.1만 누르면 끝 • 7일 평균과 지난주 비교로 하루하루 오르내림에 흔들리지 않아요 • '오늘은 안 쟀어요'도 출석으로 인정, 연속 기록이 이어져요 • 단식, 주사, 물과 단백질은 원하는 것만 켜기 • 구름은 몸무게가 아니라 기록하러 온 날 수만큼 자라요 • Apple Watch, 위젯, Siri, 건강 앱 지원 • 계정 없음, 광고 없음, 추적 없음 이럴 때 써 보세요 • 아침에 체중계에 오른 뒤 숫자를 확인하고 한 번 탭 • GLP-1 주사 날짜와 부위, 몸 상태를 메모하고 내 주기에 맞춰 알림 받기 • 16:8 단식 중 남은 시간을 Apple Watch에서 확인 몸무게와 신체 데이터 • 단위는 kg, 파운드, 스톤 중에서 선택 • 매일 점과 7일 평균선, 최근 30일 추세와 기록 • 3개월·전체 기간 추세와 그 이전 기록(풀버전) • 바지가 헐렁해졌어요, 계단이 덜 힘들어요 같은 체중계 밖의 작은 승리도 기록 • 허리, 체지방률, 엉덩이, 가슴, 허벅지, 팔뚝, 목 둘레를 각각 추세로 (1개 무료, 전체는 풀버전) • 지금 속도로 목표에 닿는 날을 예상해요(참고용). 데이터가 적으면 며칠 더 기록해 달라고 알려 줘요 • 사진 비포 애프터 비교, 얼굴은 기본으로 흐리게(풀버전) • 매주 자동으로 만들어지는 비교 카드는 변화와 곡선만 보여 주고 몸무게 숫자는 숨겨요. 탭 한 번으로 공유 간헐적 단식 타이머 • 12:12, 14:10, 16:8. 18:6, 20:4, 직접 설정, 단식 차트는 풀버전 • 한 번 눌러 시작, 시작 시간은 나중에 고칠 수 있어요 • Apple Watch에서 남은 시간 확인. 잠금 화면과 Dynamic Island의 실시간 카운트다운은 풀버전 • 시간이 되면 든든하게 한 끼 먹으라고 알려 줘요. 단식을 더 길게 하라고 권하지 않으며 최대 23시간까지예요 • 임신 중이거나 수유 중인 분, 18세 미만인 분, 거식이나 폭식을 겪은 적이 있는 분, 만성 질환이 있는 분은 단식 전에 의사와 상담하세요 주사 카드(사용하는 분만 표시) • 날짜, 부위, 나만의 메모 기록 • 직접 정한 주기에 맞춰 알림, 다음 주사까지 카운트다운 • 최근 사용한 부위 지도와 몸 상태 체크 • 기록만 해요. 계산, 용량 기록이나 제안, 판단은 하지 않아요 물·단백질·함께 자라는 구름 • 한 번 눌러 물 +1잔, 단백질 +10／20／30g, 링으로 오늘 진행을 한눈에 • 건강 앱을 연결하면 오늘 걸음 수 표시(표시만 하고 저장하지 않아요) • 구름은 5단계로 자라요. 몸무게가 오르든 내리든 늘 반가워해요 • 기본 구름은 무료, 옷 갈아입히기와 맑음·무지개·비·눈·별밤 날씨 테마는 풀버전 Apple Watch·위젯·Siri • Apple Watch에서 Digital Crown을 돌리고 탭하면 기록 끝, iPhone이 곁에 없어도 돼요. 컴플리케이션으로 단식도 확인 • 홈 화면과 잠금 화면 위젯은 모두 무료(오늘 기록 여부, 연속 기록, 이번 주 평균, 구름, 빠른 기록), 제어 센터 버튼 • Siri와 단축어로 몸무게와 물 기록, 오늘 화면 열기 • 몸무게와 허리둘레를 건강 앱에 기록하거나 건강 앱의 몸무게 기록 가져오기(모두 선택 사항) • CSV와 PDF 월간 리포트 내보내기(풀버전) • 앱 화면은 50개 언어 지원 개인정보 데이터는 내 기기와 나의 iCloud에 저장되고 iPhone과 Apple Watch가 자동으로 동기화돼요. 계정이 필요 없고 광고와 추적도 없어요. 무료 몸무게 기록과 7일 평균, 최근 30일 추세와 기록, 원하는 모듈 1개(12:12·14:10·16:8 단식, 주사 카드, 물·단백질 중 선택), 신체 데이터 1개, 알림 1개, Apple Watch 기록과 컴플리케이션, 홈 화면과 잠금 화면 위젯 전체, 기본 구름, 계정 없음, iCloud 동기화. Kumo 풀버전 여러 모듈 동시 사용, 신체 데이터 전체, 18:6·20:4·직접 설정 단식과 단식 차트, 잠금 화면과 Dynamic Island 실시간 카운트다운, 3개월·전체 기간 추세와 30일 이전 기록, 사진 비포 애프터, CSV·PDF 내보내기, 여러 알림과 물 마시기 알림, 옷·날씨.
