# LED Moving Text — 画面がそのまま電光掲示板に | iOS App

文字を打つだけで、iPhone が明るく流れる大きな掲示板になります。ホールの後方でも、到着ロビーの向こうからでも、ひと目で読めます。 開いた瞬間からライブキャンバスです。プレビューがそのまま入力欄なので、文字も速度も大きさも色も、変えた瞬間に反映されます。仕上がったらワンタップで全画面へ。タップで操作ボタンの表示・非表示を切り替え、わかりやすい一時停止ボタンで表示を止め、左右のスワイプで速度と向き、ピンチで文字サイズ、さらに九十度回して画面の高さいっぱいに見せることもできます。 声が届かない場面のために作りました。ライブで喉をからさずに気持ちを伝える。到着ロビーで名前を掲げ、遠くからでも見つけてもらう。店先や路肩で受け取りやお迎えの合図を出す。話しづらい場所で、ゆっくり話してほしい、静かな席に替えてほしいとお願いする。撮影や配信の合間に、手元のカンペとして使う。 無料の範囲はずっと無料、登録もいりません。回数制限のない入力と全画面表示、静止とスクロールの二種類の動き、左右の移動、速度と文字サイズ、百八色すべての文字色、鏡文字（窓ガラスや車内から外に見せるとき）、九十度の縦向き大文字、点滅の速さ、直前に打った文章の呼び出し、ライトのパルス。さらにテンプレートの一つと LED フレームの一つは、そのまま試して保存できます。保存できるボードは一枚です。 買い切りのライフタイム解除で加わるもの。ボードの保存数と自作テンプレートが無制限、欧文フォント百種類以上（和文はゴシックと明朝、太さから選べます）、縁取り・影・発光・点滅・パルス・波・タイプライター・ドットマトリクスなど二十種類の効果、残り五十九枚の場面別ボード（六つの生活シーン）、ページ送り・スライドイン・往復・スウェイ・ドリフトの動き、上下の移動、レインボーとグラデーションの文字、残りの LED フレームとその色、文字間隔と繰り返し間隔、写真とオーロラの背景、音に反応する動き、カウントダウン、MP4 と GIF の書き出し。 すべて端末の中で動きます。アカウントもクラウドも広告も解析もトラッキングもありません。入力した文章も保存したボードも選んだ写真も、iPhone の中に留まります。マイクは音に反応する動きをオンにしているあいだだけ使い、録音も保存も行いません。 五十言語に対応。各言語の場面別ボードは直訳ではなく、その土地の言い回しで書き起こしています。iPhone と iPad に対応し、縦向き、横向き、Split View それぞれに専用のレイアウトを用意しています。
