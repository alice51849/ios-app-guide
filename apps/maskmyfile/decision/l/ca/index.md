# Mask My File — Oculta dades abans d'enviar | iOS App

Comparteix amb tranquil·litat sense perdre el context útil. Mask My File detecta les dades privades abans que enviïs un fitxer, oculta de manera permanent el que triïs i després torna a obrir i verifica la còpia nova abans de mostrar Private Ready. QUÈ POTS FER • Imatges i PDF: previsualització a tota l'amplada, zoom fins a 5×, arrossegament fluid i selecció manual precisa. • Fitxers visuals: ocultació opaca permanent o eliminació. La detecció de cares i codis de barres només marca zones perquè les revisis. • Text, JSON, XML, HTML, CSV, TSV i RTF: cerca cada coincidència i aplica màscara completa, màscara parcial, marcador, pseudònim o eliminació. • Elimina metadades quan el format ho permet. Treballa pàgina a pàgina als PDF o processa fins a 100 fitxers amb previsualització individual, cerca entre fitxers i selecció manual per a cadascun. QUAN DE VERITAT IMPORTA Abans d'enviar una sol·licitud de lloguer, compartir un informe mèdic o passar un expedient de client a un company, conserva el context que necessiten i amaga per sempre els detalls que no. PRIVADESA PER DISSENY Tot es processa al teu dispositiu. No hi ha cap compte, publicitat, seguiment, analítica ni pujada de contingut. L'Apple Vision i el Tesseract OCR integrat s'executen en local. La detecció de cares només crea zones: no identifica ningú, no crea cap plantilla i no comparteix ni conserva dades facials. Apple gestiona les compres amb StoreKit. Mask My File no utilitza cap VPN, NetworkExtension, servidor intermediari, túnel, filtre DNS ni encaminament de xarxa. Els originals mai no se sobreescriuen. UN SOL PAGAMENT. PER TOTA LA VIDA.
