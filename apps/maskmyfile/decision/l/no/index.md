# Mask My File: Fjern dine data — Skjul private data før deling | iOS App

Optimalisert for iPhone Duo. Appen er bygget med den nyeste SDK-en, fyller hele den indre skjermen og tilpasser oppsettet automatisk, både sammenbrettet og utbrettet. Sladd personopplysninger før du deler. Mask My File finner navn, telefonnumre, e-poster, adresser, konto- og betalingsopplysninger, og skjuler deretter permanent bare det du velger. Fungerer med PDF-er, bilder, skjermbilder og tekstfiler, og fjerner metadata der formatet tillater det. Originalen blir aldri overskrevet: Du får en ny kopi som åpnes på nytt og kontrolleres. Bruk den til leiesøknader, lønnsslipper, kundefiler og kopier av legitimasjon. DETTE KAN DU GJØRE • Visuelle filer: permanent, heldekkende sladding eller fjerning. Ansikts- og strekkodegjenkjenning markerer bare områder du selv skal se gjennom. • Tekst, JSON, XML, HTML, CSV, TSV og RTF: søk gjennom hvert treff, og bruk full maske, delvis maske, plassholder, pseudonym eller fjerning. • Fjern metadata der formatet tillater det. Jobb side for side i PDF, eller beskytt opptil 100 filer med egne forhåndsvisninger, søk på tvers av filer og manuelle merkinger for hver fil. • Hold arbeidet ryddig med privat økt, prosjektområder og plassholderhvelvet. • Bilder og PDF: forhåndsvisning i full bredde, opptil 5× zoom, jevn draing og presise manuelle merkinger. PRIVAT FRA BUNNEN Alt skjer på enheten din. Ingen konto, ingen annonser, ingen sporing, analyse eller opplasting av innhold. Apple Vision og innebygd Tesseract OCR kjører lokalt. Ansiktsgjenkjenning lager bare områder: den identifiserer ingen, lager ingen mal, deler ingen ansiktsdata og lagrer dem ikke. Apple håndterer kjøp med StoreKit. Mask My File bruker ikke VPN, NetworkExtension, proxy, tunnel, DNS-filter eller nettverksruting. Originaler blir aldri overskrevet; midlertidige arbeidsfiler, data fra privat økt og prosjekter blir liggende på enheten til du sletter dem. KJØP ÉN GANG. EI DET FOR ALLTID. Ett livstidskjøp låser opp ubegrenset antall verifiserte resultater og batchprosessering. Ingen abonnement. Gjenopprett kjøpet via App Store. Optimalisert for iPhone Duo.
