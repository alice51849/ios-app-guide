# Mask My File — 分享前遮蔽個資與私密資訊 | iOS App

安全分享，同時保留有用的脈絡。Mask My File 會在你送出檔案前找出私密資訊，永久遮蔽後，再重新開啟並驗證輸出的新檔案，確認無誤才顯示 Private Ready。 主要功能 • 圖片與 PDF：滿版預覽、最高 5× 縮放、跟手拖移，並可手動精準框選。 • 視覺檔案：只提供永久實心遮蔽或直接移除；人臉與條碼偵測僅標出可供你審查的區域。 • 文字、JSON、XML、HTML、CSV、TSV 與 RTF：逐項搜尋每個符合結果，並以星號套用完整遮罩、部分遮罩、佔位符、化名或移除。 • 在適用時移除中繼資料。PDF 可逐頁處理；批次一次最多 100 個檔案，每個檔案都能單獨預覽、跨檔搜尋文字並手動框選。 • 以私密工作階段、專案工作區與佔位符保管庫，讓工作井然有序。 在關鍵時刻派上用場 無論是遞出租屋申請、分享病歷文件，或把客戶檔案交給同事，都能在永久遮蔽私密資訊的同時，保留必要的脈絡。 以隱私為設計核心 所有處理都在你的裝置上完成，沒有帳號、廣告、追蹤、分析，也不會上傳任何內容。Apple Vision 與內建的 Tesseract OCR 皆在本機執行。人臉偵測只會建立區域，不會辨識身分、不建立範本，也不分享或保留任何人臉資料。購買由 Apple 透過 StoreKit 處理。Mask My File 不使用 VPN、NetworkExtension、代理伺服器、通道、DNS 過濾或任何網路轉送。原始檔永遠不會被覆寫；暫存工作區檔案、私密工作階段資料與專案都會留在裝置上，直到你自行刪除。 一次買斷，終身使用 只需一次付費解鎖，即可永久享有無限次的驗證輸出與批次處理功能。沒有任何訂閱制，日後可隨時透過 App Store 恢復購買。
