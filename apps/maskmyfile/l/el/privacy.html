Πολιτική απορρήτου του Mask My File

Το Mask My File σχεδιάστηκε για να προστατεύει αρχεία χωρίς να τα συλλέγει. Δεν απαιτείται λογαριασμός και η εφαρμογή δεν περιέχει διαφημίσεις, παρακολούθηση, αναλυτικά στοιχεία ή υπηρεσία μεταφόρτωσης περιεχομένου.

Η επεξεργασία παραμένει στη συσκευή σας

Το Apple Vision και το ενσωματωμένο Tesseract OCR αναλύουν το επιλεγμένο περιεχόμενο τοπικά. Η απόκρυψη, η μόνιμη μαύρη κάλυψη, η αφαίρεση μεταδεδομένων, η εξαγωγή και η επαλήθευση εκτελούνται επίσης στη συσκευή.

Περιοχές προσώπου, ποτέ προφίλ ταυτότητας

Η ανίχνευση προσώπων σημειώνει μόνο περιοχές εικόνας για τον έλεγχό σας. Το Mask My File δεν ταυτοποιεί άτομα, δεν δημιουργεί βιομετρικά ή ταυτοτικά πρότυπα, δεν μεταφορτώνει ούτε μοιράζεται δεδομένα προσώπου και δεν τα διατηρεί ξεχωριστά.

Οι αγορές είναι η μόνη υπηρεσία δικτύου

Η Apple διαχειρίζεται την προαιρετική εφάπαξ αγορά και την επαναφορά της μέσω StoreKit. Το Mask My File δεν χρησιμοποιεί VPN, NetworkExtension, διακομιστή μεσολάβησης, σήραγγα, φίλτρο DNS ούτε δρομολόγηση δικτύου.

Δεδομένα προσώπου (εφαρμογή iOS)

Ενότητα ενημερωμένη στις 2026-11-16. Αυτή η ενότητα ισχύει για την εφαρμογή iOS Mask My File στο App Store.

1. Ποια δεδομένα προσώπου χρησιμοποιεί η εφαρμογή

Όταν σαρώνετε μια εικόνα ή μια σελίδα PDF, μεμονωμένα ή σε παρτίδα, το Mask My File χρησιμοποιεί το πλαίσιο Vision της Apple, το οποίο εκτελείται στη συσκευή, για να ανιχνεύσει πρόσωπα. Για κάθε πρόσωπο, τα μόνα δεδομένα προσώπου που χρησιμοποιεί η εφαρμογή είναι η θέση του ορθογωνίου γύρω από το πρόσωπο στη σελίδα αυτή και η βεβαιότητα της ανίχνευσης. Όταν δημιουργείται το προστατευμένο αντίγραφο, η εφαρμογή εκτελεί την ίδια ανίχνευση άλλη μία φορά στο προστατευμένο αντίγραφο για να ελέγξει ότι κανένα επιλεγμένο πρόσωπο δεν είναι ακόμη ορατό· το αποτέλεσμα αυτό χρησιμοποιείται μόνο για τον έλεγχο. Η εφαρμογή δεν εκτελεί αναγνώριση ή ταυτοποίηση προσώπου, δεν δημιουργεί πρότυπο προσώπου, αποτύπωμα προσώπου (faceprint) ή οποιοδήποτε άλλο βιομετρικό αναγνωριστικό και δεν συγκρίνει πρόσωπα.

2. Πώς χρησιμοποιούνται τα δεδομένα προσώπου

Αυτά τα ορθογώνια χρησιμοποιούνται μόνο για να εμφανίζονται προτεινόμενες περιοχές προσώπων στην οθόνη ελέγχου, όπου μπορείτε να κρατήσετε, να αλλάξετε ή να αφαιρέσετε κάθε μία (τα πρόσωπα με υψηλότερη βεβαιότητα είναι προεπιλεγμένα), και για να καλύπτονται τα πρόσωπα που διατηρείτε επιλεγμένα στο προστατευμένο αντίγραφο που εξάγετε (από προεπιλογή με συμπαγές μπλοκ). Δεν χρησιμοποιούνται για διαφήμιση, αναλύσεις, παρακολούθηση, κατάρτιση προφίλ ή οποιονδήποτε άλλο σκοπό.

3. Κοινοποίηση και τρίτα μέρη

Τα δεδομένα προσώπου δεν μεταφορτώνονται, πωλούνται, κοινοποιούνται ή αποκαλύπτονται ποτέ στον προγραμματιστή ή σε οποιοδήποτε τρίτο μέρος. Η εφαρμογή δεν κάνει κανένα αίτημα δικτύου που να αφορά τα αρχεία σας, το περιεχόμενό τους ή τα αποτελέσματα ανίχνευσης· η μόνη υπηρεσία δικτύου της είναι το Apple StoreKit για αγορά και επαναφορά. Δεν περιέχει κανένα SDK τρίτων για διαφήμιση, αναλύσεις, παρακολούθηση ή δεδομένα.

4. Πού αποθηκεύονται τα δεδομένα προσώπου

Τα ορθογώνια προσώπων διατηρούνται μόνο στη μνήμη της συσκευής σας στον ενεργό χώρο εργασίας ελέγχου και δεν εγγράφονται ποτέ σε αποθηκευτικό χώρο ως δεδομένα προσώπου. Η Ιδιωτική συνεδρία είναι ενεργοποιημένη από προεπιλογή. Εάν την απενεργοποιήσετε, τα Έργα αποθηκεύουν το αρχικό αρχείο και το προστατευμένο αντίγραφο σε αυτή τη συσκευή, μαζί με τον αριθμό των προστατευμένων στοιχείων και τις κατηγορίες τους (για παράδειγμα «πρόσωπο» (face)), αλλά όχι τις θέσεις των προσώπων. Αυτά τα αρχεία είναι δικές σας εικόνες και μπορεί να εμφανίζουν πρόσωπα.

5. Για πόσο διάστημα διατηρούνται τα δεδομένα προσώπου

Τα ορθογώνια προσώπων απορρίπτονται όταν καθαρίζεται ο χώρος εργασίας ελέγχου ή παρτίδας, για παράδειγμα όταν ξεκινάτε από την αρχή με άλλο αρχείο, και κανένα δεν παραμένει μετά τον τερματισμό της εφαρμογής. Τα αποθηκευμένα έργα παραμένουν στη συσκευή σας μέχρι να τα διαγράψετε. Ο προγραμματιστής δεν λαμβάνει ούτε διατηρεί ποτέ δεδομένα προσώπου.

6. Διαγραφή

Επειδή τα ορθογώνια προσώπων δεν αποθηκεύονται ποτέ, δεν υπάρχουν αποθηκευμένα δεδομένα προσώπου προς διαγραφή. Μπορείτε να διαγράψετε ένα αποθηκευμένο έργο, να χρησιμοποιήσετε την Εκκαθάριση ιστορικού έργου για να αφαιρέσετε όλα τα διατηρημένα πρωτότυπα και προστατευμένα αντίγραφα ή να διαγράψετε την εφαρμογή για να αφαιρέσετε όλα τα τοπικά της δεδομένα από τη συσκευή σας.

Εσείς ελέγχετε τι παραμένει

Τα πρωτότυπα δεν αντικαθίστανται ποτέ. Τα προσωρινά αρχεία εργασίας, τα αποθηκευμένα έργα, οι αντιστοιχίσεις του θησαυροφυλακίου συμβόλων κράτησης θέσης και τα δεδομένα ιδιωτικής συνεδρίας παραμένουν μόνο όπως εξηγεί κάθε λειτουργία. Διαγράψτε τα στην εφαρμογή ή αφαιρέστε την εφαρμογή για να διαγράψετε το τοπικό της περιεχόμενο.
