Mask My File

જરૂર કરતાં વધુ જાહેર કર્યા વિના શેર કરો — Mask My File તમારા ઉપકરણ પર ખાનગી વિગતો શોધે છે અને કંઈ પણ તમારા હાથમાંથી નીકળે તે પહેલાં કાયમ માટે ઢાંકી દે છે.

Mask My File · App Store
ફોર્મેટ અને ઢાંકવાની રીતો

છબીઓ અને PDF, અથવા ટેક્સ્ટ, JSON, XML, HTML, CSV, TSV અને RTF ખોલો. દૃશ્ય ફાઇલોમાં ફક્ત કાયમી નક્કર આવરણ કે દૂર કરવું જ ઉપલબ્ધ છે, જ્યારે ટેક્સ્ટ અને સંરચિત ફાઇલોમાં તમે પસંદ કરેલા દરેક મેળ પર સંપૂર્ણ ઢાંકવું, આંશિક ઢાંકવું, સ્થાનધારક, ઉપનામ કે દૂર કરવું લાગુ થાય છે.

ભરોસો કરતાં પહેલાં ચકાસો

દરેક વખતે ઢાંકતાં એક તદ્દન નવી નકલ બને છે. App એ નકલ ફરી ખોલે છે, ફાઇલની સંરચના અને દરેક લાગુ ઢાંકણ તપાસે છે, અને પછી જ Private Ready બતાવે છે. શેર કરતાં પહેલાં પરિણામ એક વાર નજરે જોઈ લો.

એકસાથે 100 ફાઇલ સુધી

એક બેચમાં 100 ફાઇલ સુધી લોડ કરો, દરેક ફાઇલનું પૂર્વાવલોકન કરો, જ્યાં જરૂર હોય ત્યાં જાતે ચોકઠું દોરો, બધી ફાઇલોમાં ચોકસાઈથી ટેક્સ્ટ શોધો, અને પછી સુરક્ષિત આખો સેટ સાથે નિકાસ કરો.
