Kebijakan Privasi Mask My File

Mask My File dirancang untuk melindungi berkas tanpa mengumpulkannya. Tidak perlu akun, dan aplikasi tidak memuat iklan, pelacakan, analitik, atau layanan unggah konten.

Pemrosesan tetap di perangkat Anda

Apple Vision dan mesin Tesseract OCR bawaan memindai konten terpilih secara lokal. Penutupan, penyembunyian, penghapusan metadata, ekspor, dan verifikasi juga berjalan di perangkat.

Area wajah, bukan profil identitas

Deteksi wajah hanya menandai area gambar untuk Anda tinjau. Mask My File tidak mengenali orang, tidak membuat templat biometrik atau identitas, tidak mengunggah atau membagikan data wajah, dan tidak menyimpannya terpisah.

Pembelian adalah satu-satunya layanan jaringan

Apple memproses pembelian seumur hidup opsional dan pemulihannya melalui StoreKit. Mask My File tidak memakai VPN, NetworkExtension, proxy, tunnel, filter DNS, atau perutean jaringan.

Data wajah (aplikasi iOS)

Bagian ini diperbarui pada 2026-11-16. Bagian ini berlaku untuk aplikasi iOS Mask My File di App Store.

1. Data wajah yang digunakan aplikasi

Saat Anda memindai gambar atau halaman PDF, baik satu per satu maupun sekaligus, Mask My File menggunakan kerangka kerja Vision Apple di perangkat untuk mendeteksi wajah. Untuk setiap wajah, satu-satunya data wajah yang digunakan aplikasi adalah posisi persegi panjang di sekeliling wajah pada halaman tersebut dan tingkat keyakinan deteksi. Saat salinan terlindungi dibuat, aplikasi menjalankan deteksi yang sama sekali lagi pada salinan terlindungi tersebut untuk memeriksa bahwa tidak ada wajah terpilih yang masih terlihat; hasil itu hanya digunakan untuk pemeriksaan tersebut. Aplikasi tidak melakukan pengenalan atau identifikasi wajah, tidak membuat templat wajah, faceprint, atau pengenal biometrik lainnya, dan tidak membandingkan wajah.

2. Cara data wajah digunakan

Persegi panjang ini hanya digunakan untuk menampilkan area wajah yang disarankan pada layar tinjauan, tempat Anda dapat mempertahankan, mengubah, atau menghapus masing-masing area (wajah dengan keyakinan lebih tinggi dipilih terlebih dahulu), dan untuk menutupi wajah yang tetap Anda pilih dalam salinan terlindungi yang Anda ekspor (secara default dengan balok solid). Persegi panjang ini tidak digunakan untuk iklan, analitik, pelacakan, pembuatan profil, atau tujuan lainnya.

3. Berbagi dan pihak ketiga

Data wajah tidak pernah diunggah, dijual, dibagikan kepada, atau diungkapkan kepada pengembang maupun pihak ketiga mana pun. Aplikasi tidak membuat permintaan jaringan apa pun yang melibatkan file Anda, isinya, atau hasil deteksi; satu-satunya layanan jaringannya adalah StoreKit Apple untuk pembelian dan pemulihan. Aplikasi tidak memuat SDK iklan, analitik, pelacakan, atau data pihak ketiga.

4. Tempat data wajah disimpan

Persegi panjang wajah disimpan hanya di memori perangkat Anda dalam ruang kerja tinjauan yang aktif dan tidak pernah ditulis ke penyimpanan sebagai data wajah. Sesi Pribadi aktif secara default. Jika Anda menonaktifkannya, Proyek menyimpan file asli dan salinan terlindungi di perangkat ini, bersama jumlah item yang dilindungi dan kategorinya (misalnya "wajah" (face)), tetapi bukan posisi wajah. File tersebut adalah gambar Anda sendiri dan dapat menampilkan wajah.

5. Lama penyimpanan data wajah

Persegi panjang wajah dibuang saat ruang kerja tinjauan atau batch dikosongkan, misalnya saat Anda memulai ulang dengan file lain, dan tidak ada yang tersisa setelah aplikasi ditutup. Proyek yang disimpan tetap berada di perangkat Anda sampai Anda menghapusnya. Pengembang tidak pernah menerima atau menyimpan data wajah apa pun.

6. Penghapusan

Karena persegi panjang wajah tidak pernah disimpan, tidak ada data wajah tersimpan yang perlu dihapus. Anda dapat menghapus proyek yang tersimpan, menggunakan Bersihkan Riwayat Proyek untuk menghapus semua file asli dan salinan terlindungi yang disimpan, atau menghapus aplikasi untuk menghapus semua data lokalnya dari perangkat Anda.

Anda mengendalikan apa yang tersisa

Berkas asli tidak pernah ditimpa. Berkas ruang kerja sementara, proyek tersimpan, Placeholder Vault, dan data Private Session hanya bertahan seperti yang dijelaskan tiap fitur. Hapus di aplikasi atau copot aplikasi untuk mengosongkan kontainer lokalnya.
