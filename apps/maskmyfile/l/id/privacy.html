Kebijakan Privasi Mask My File

Mask My File dirancang untuk melindungi berkas tanpa mengumpulkannya. Tidak perlu akun, dan aplikasi tidak memuat iklan, pelacakan, analitik, atau layanan unggah konten.

Pemrosesan tetap di perangkat Anda

Apple Vision dan mesin Tesseract OCR bawaan memindai konten terpilih secara lokal. Penutupan, penyembunyian, penghapusan metadata, ekspor, dan verifikasi juga berjalan di perangkat.

Area wajah, bukan profil identitas

Deteksi wajah hanya menandai area gambar untuk Anda tinjau. Mask My File tidak mengenali orang, tidak membuat templat biometrik atau identitas, tidak mengunggah atau membagikan data wajah, dan tidak menyimpannya terpisah.

Pembelian adalah satu-satunya layanan jaringan

Apple memproses pembelian seumur hidup opsional dan pemulihannya melalui StoreKit. Mask My File tidak memakai VPN, NetworkExtension, proxy, tunnel, filter DNS, atau perutean jaringan.

Anda mengendalikan apa yang tersisa

Berkas asli tidak pernah ditimpa. Berkas ruang kerja sementara, proyek tersimpan, Placeholder Vault, dan data Private Session hanya bertahan seperti yang dijelaskan tiap fitur. Hapus di aplikasi atau copot aplikasi untuk mengosongkan kontainer lokalnya.
