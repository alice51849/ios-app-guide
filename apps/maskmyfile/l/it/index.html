Mask My File · App Store
Un flusso privato per ogni file

Visualizza immagini e PDF a tutta larghezza, ingrandisci fino a 5× e traccia aree precise a mano. Cerca ogni corrispondenza in Testo, JSON, XML, HTML, CSV, TSV e RTF, poi applica maschera completa, maschera parziale, segnaposto, pseudonimo o rimozione. I metadati vengono rimossi dove il formato lo consente.

Private Ready significa ricontrollato

Mask My File salva una nuova copia, la riapre e conferma che il file protetto sia ancora valido prima di mostrare Private Ready. Il tuo originale non viene mai sovrascritto.

Rivedi fino a 100 file insieme

Dai a ogni file la sua anteprima e le sue selezioni manuali, cerca lo stesso testo riservato in tutto il gruppo, poi esporta insieme le copie verificate.
