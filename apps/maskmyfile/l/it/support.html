Proteggi un file in tre passaggi

Usa Mask My File prima di inviare una domanda, un referto medico, la scheda di un cliente o uno screenshot che contiene dettagli che altri non devono vedere.

1

Scegli una foto, un PDF, un documento, un file di dati strutturati o del testo incollato. La scansione parte in locale sul tuo dispositivo.

2

Rivedi ogni risultato. Aggiungi il testo mancante o traccia un'area precisa, poi scegli uno stile di protezione supportato da quel tipo di file.

3

Crea la copia protetta. Condividi solo dopo che Private Ready conferma che il nuovo file si è riaperto e ha superato la verifica.

Cosa significa Private Ready?

Significa che la copia appena protetta è stata generata, riaperta e controllata per una struttura di file valida. Non sostituisce la tua revisione visiva finale prima di condividere.

Contatta l'assistenza

Scrivi a hourstag.app@gmail.com indicando il modello del dispositivo, la versione di iOS, il tipo di file e una breve descrizione.
