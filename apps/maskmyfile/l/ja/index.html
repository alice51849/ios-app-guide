Mask My File

共有はしても、過剰共有はしない。Mask My File は端末内で個人情報を見つけ、何かが手元を離れる前に恒久的に黒塗りします。

Mask My File · App Store
対応形式と保護スタイル

画像や PDF、またはテキスト、JSON、XML、HTML、CSV、TSV、RTF を開けます。視覚ファイルは恒久的な塗りつぶし（黒塗り）または削除のみ。テキストや構造化ファイルでは、選んだ一致箇所ごとに全体マスク・部分マスク・プレースホルダー・仮名化・削除を適用できます。

信頼する前に検証

保護のたびに新しいコピーを作成します。アプリはそのコピーを開き直し、ファイル構造と適用した黒塗りをすべて確認してから Private Ready を表示します。共有の直前に、もう一度目視で確認してください。

一度に最大100ファイル

1つのバッチに最大100ファイルを読み込み、各ファイルをプレビューし、必要な箇所に手動で枠を描き、全ファイルを横断して正確に文字検索し、保護後のセットをまとめて書き出せます。
