プライバシーの概要

Mask My File は、最初のスキャンから書き出しまで機密情報を端末内にとどめる設計です。以下では処理、顔データ、購入、保持について個別に説明します。

端末内処理

Apple Vision と組み込みの Tesseract OCR はローカルで動作し、スキャン・黒塗り・メタデータ削除・書き出し・検証もすべて端末内で行われます。アカウント、広告、トラッキング、分析、コンテンツのアップロードは一切ありません。

顔データの扱い

顔検出は確認用の領域を示すだけです。個人を特定したり、生体テンプレートを作成したり、顔データをアップロード・共有したり、編集中のファイルと別に保持したりすることはありません。

購入とネットワーク

買い切りの生涯アンロックと復元は Apple の StoreKit が処理します。Mask My File は VPN、NetworkExtension、プロキシ、トンネル、DNS フィルター、ネットワークルーティングを一切使用しません。

顔データ（iOS アプリ）

このセクションは 2026-11-16 に更新されました。このセクションは、App Store の Mask My File iOS アプリに適用されます。

1. アプリが使用する顔データ

画像や PDF のページを単独で、またはまとめてスキャンすると、Mask My File は Apple のオンデバイス Vision フレームワークを使用して顔を検出します。各顔について、アプリが使用する顔データは、そのページ上の顔を囲む矩形の位置と検出の信頼度のみです。保護されたコピーを作成する際、アプリは選択した顔がまだ見えていないことを確認するため、その保護されたコピーに対して同じ検出をもう一度実行します。その結果は、この確認にのみ使用されます。アプリは顔認識や個人の識別を行わず、顔テンプレート、フェイスプリント、その他の生体識別子を作成せず、顔の照合も行いません。

2. 顔データの使用方法

これらの矩形は、確認画面に顔の候補領域を表示し（信頼度の高い顔はあらかじめ選択されます）、各領域を保持、変更、削除できるようにするため、また、書き出す保護されたコピーで、選択したままにした顔を覆うため（既定では塗りつぶしのブロックで）にのみ使用されます。広告、分析、トラッキング、プロファイリング、その他の目的には使用されません。

3. 共有と第三者

顔データがアップロードされたり、販売されたり、開発者や第三者と共有・開示されたりすることはありません。アプリは、お客様のファイル、その内容、検出結果に関するネットワークリクエストを一切行いません。ネットワークサービスは、購入と復元のための Apple の StoreKit のみです。第三者の広告、分析、トラッキング、データの SDK は含まれていません。

4. 顔データの保存場所

顔の矩形は、現在の確認用ワークスペースにおいて、お使いのデバイスのメモリ内にのみ保持され、顔データとしてストレージに書き込まれることはありません。「プライベートセッション」は既定でオンです。これをオフにすると、「プロジェクト」には、元のファイルと保護されたコピーが、保護された項目の数とそのカテゴリ（例：「顔」（face））とともにこのデバイス上に保存されますが、顔の位置は保存されません。これらのファイルはご自身の画像であり、顔が写っている場合があります。

5. 顔データの保持期間

顔の矩形は、確認用または一括処理用のワークスペースがクリアされたとき（たとえば、別のファイルでやり直すとき）に破棄され、アプリの終了後に残ることはありません。保存したプロジェクトは、削除するまでお使いのデバイスに残ります。開発者が顔データを受け取ったり保持したりすることは一切ありません。

6. 削除

顔の矩形は保存されないため、削除すべき保存済みの顔データはありません。保存したプロジェクトを削除する、「プロジェクト履歴を消去」を使用して保持されているすべての元のファイルと保護されたコピーを削除する、またはアプリを削除してデバイスからすべてのローカルデータを消去することができます。

保持と削除

元のファイルは上書きされません。一時作業ファイル、プロジェクト、プレースホルダー保管庫、プライベートセッションのデータはそれぞれ保持も削除もあなたの操作次第で、アプリを削除するとコンテナは完全に消去されます。
