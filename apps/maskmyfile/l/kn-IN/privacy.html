Mask My File ಗೌಪ್ಯತಾ ನೀತಿ

Mask My File ಫೈಲ್‌ಗಳನ್ನು ಸಂಗ್ರಹಿಸದೆ ರಕ್ಷಿಸಲು ವಿನ್ಯಾಸಗೊಂಡಿದೆ. ಖಾತೆ ಬೇಕಿಲ್ಲ, ಮತ್ತು ಆ್ಯಪ್‌ನಲ್ಲಿ ಜಾಹೀರಾತು, ಟ್ರ್ಯಾಕಿಂಗ್, ವಿಶ್ಲೇಷಣೆ ಅಥವಾ ವಿಷಯ-ಅಪ್‌ಲೋಡ್ ಸೇವೆ ಇಲ್ಲ.

ಪ್ರಕ್ರಿಯೆ ನಿಮ್ಮ ಸಾಧನದಲ್ಲೇ ಉಳಿಯುತ್ತದೆ

Apple Vision ಮತ್ತು ಒಳಗೊಂಡ Tesseract OCR ಎಂಜಿನ್ ಆಯ್ದ ವಿಷಯವನ್ನು ಸ್ಥಳೀಯವಾಗಿ ಸ್ಕ್ಯಾನ್ ಮಾಡುತ್ತವೆ. ಮಾಸ್ಕಿಂಗ್, ಮರೆಮಾಚುವಿಕೆ, ಮೆಟಾಡೇಟಾ ತೆಗೆಯುವಿಕೆ, ರಫ್ತು ಮತ್ತು ಪರಿಶೀಲನೆಯೂ ಸಾಧನದಲ್ಲೇ ನಡೆಯುತ್ತವೆ.

ಮುಖ ಕ್ಷೇತ್ರಗಳು, ಗುರುತಿನ ಪ್ರೊಫೈಲ್ ಅಲ್ಲ

ಮುಖ ಪತ್ತೆ ಕೇವಲ ನಿಮ್ಮ ಪರಿಶೀಲನೆಗಾಗಿ ಚಿತ್ರ ಕ್ಷೇತ್ರಗಳನ್ನು ಗುರುತಿಸುತ್ತದೆ. Mask My File ವ್ಯಕ್ತಿಗಳನ್ನು ಗುರುತಿಸುವುದಿಲ್ಲ, ಜೈವಿಕ ಅಥವಾ ಗುರುತಿನ ಟೆಂಪ್ಲೇಟ್ ರಚಿಸುವುದಿಲ್ಲ, ಮುಖ ಡೇಟಾ ಅಪ್‌ಲೋಡ್ ಅಥವಾ ಹಂಚುವುದಿಲ್ಲ, ಪ್ರತ್ಯೇಕವಾಗಿ ಇಟ್ಟುಕೊಳ್ಳುವುದಿಲ್ಲ.

ಖರೀದಿ ಮಾತ್ರ ನೆಟ್‌ವರ್ಕ್ ಸೇವೆ

ಐಚ್ಛಿಕ ಜೀವಮಾನ ಖರೀದಿ ಮತ್ತು ಮರುಸ್ಥಾಪನೆ Apple StoreKit ಮೂಲಕ ನಡೆಯುತ್ತವೆ. Mask My File ಯಾವುದೇ VPN, NetworkExtension, ಪ್ರಾಕ್ಸಿ, ಟನಲ್, DNS ಫಿಲ್ಟರ್ ಅಥವಾ ನೆಟ್‌ವರ್ಕ್ ರೂಟಿಂಗ್ ಬಳಸುವುದಿಲ್ಲ.

ಮುಖ ಡೇಟಾ (iOS ಆ್ಯಪ್)

ಈ ವಿಭಾಗವನ್ನು 2026-11-16 ರಂದು ನವೀಕರಿಸಲಾಗಿದೆ. ಈ ವಿಭಾಗವು App Store ನಲ್ಲಿರುವ Mask My File iOS ಆ್ಯಪ್‌ಗೆ ಅನ್ವಯಿಸುತ್ತದೆ.

1. ಆ್ಯಪ್ ಬಳಸುವ ಮುಖ ಡೇಟಾ

ನೀವು ಒಂದು ಚಿತ್ರವನ್ನು ಅಥವಾ PDF ಪುಟವನ್ನು ಒಂಟಿಯಾಗಿ ಅಥವಾ ಬ್ಯಾಚ್ ಆಗಿ ಸ್ಕ್ಯಾನ್ ಮಾಡಿದಾಗ, Mask My File ಮುಖಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಲು Apple ನ ಸಾಧನದಲ್ಲೇ ಕಾರ್ಯನಿರ್ವಹಿಸುವ Vision framework ಅನ್ನು ಬಳಸುತ್ತದೆ. ಪ್ರತಿ ಮುಖಕ್ಕೆ, ಆ್ಯಪ್ ಬಳಸುವ ಮುಖ ಡೇಟಾ ಆ ಪುಟದಲ್ಲಿ ಮುಖದ ಸುತ್ತಲಿನ ಆಯತದ ಸ್ಥಾನ ಮತ್ತು ಪತ್ತೆಯ ವಿಶ್ವಾಸಾರ್ಹತೆ ಮಾತ್ರ. ರಕ್ಷಿತ ಪ್ರತಿಯನ್ನು ರಚಿಸಿದಾಗ, ಆಯ್ಕೆ ಮಾಡಿದ ಯಾವುದೇ ಮುಖ ಇನ್ನೂ ಕಾಣಿಸುತ್ತಿಲ್ಲ ಎಂಬುದನ್ನು ಪರಿಶೀಲಿಸಲು ಆ್ಯಪ್ ಅದೇ ಪತ್ತೆಯನ್ನು ರಕ್ಷಿತ ಪ್ರತಿಯ ಮೇಲೆ ಇನ್ನೊಮ್ಮೆ ಚಲಾಯಿಸುತ್ತದೆ; ಆ ಫಲಿತಾಂಶವನ್ನು ಆ ಪರಿಶೀಲನೆಗೆ ಮಾತ್ರ ಬಳಸಲಾಗುತ್ತದೆ. ಆ್ಯಪ್ ಮುಖ ಗುರುತಿಸುವಿಕೆ ಅಥವಾ ವ್ಯಕ್ತಿಯ ಗುರುತು ಪತ್ತೆಯನ್ನು ಮಾಡುವುದಿಲ್ಲ; ಮುಖ ಟೆಂಪ್ಲೇಟ್, ಮುಖ ಮುದ್ರೆ (faceprint) ಅಥವಾ ಬೇರೆ ಯಾವುದೇ ಬಯೋಮೆಟ್ರಿಕ್ ಗುರುತನ್ನು ರಚಿಸುವುದಿಲ್ಲ; ಮುಖಗಳನ್ನು ಹೋಲಿಸುವುದಿಲ್ಲ.

2. ಮುಖ ಡೇಟಾವನ್ನು ಹೇಗೆ ಬಳಸಲಾಗುತ್ತದೆ

ಈ ಆಯತಗಳನ್ನು ಪರಿಶೀಲನಾ ಪರದೆಯಲ್ಲಿ ಸೂಚಿತ ಮುಖ ಪ್ರದೇಶಗಳನ್ನು ತೋರಿಸಲು ಮಾತ್ರ ಬಳಸಲಾಗುತ್ತದೆ (ಅಲ್ಲಿ ನೀವು ಪ್ರತಿಯೊಂದನ್ನು ಉಳಿಸಿಕೊಳ್ಳಬಹುದು, ಬದಲಾಯಿಸಬಹುದು ಅಥವಾ ತೆಗೆದುಹಾಕಬಹುದು; ಹೆಚ್ಚಿನ ವಿಶ್ವಾಸಾರ್ಹತೆಯ ಮುಖಗಳನ್ನು ಮೊದಲೇ ಆಯ್ಕೆ ಮಾಡಲಾಗುತ್ತದೆ), ಮತ್ತು ನೀವು ರಫ್ತು ಮಾಡುವ ರಕ್ಷಿತ ಪ್ರತಿಯಲ್ಲಿ ನೀವು ಆಯ್ಕೆಯಲ್ಲಿ ಇರಿಸಿದ ಮುಖಗಳನ್ನು (ಡೀಫಾಲ್ಟ್ ಆಗಿ ಘನ ಬ್ಲಾಕ್‌ನಿಂದ) ಮುಚ್ಚಲು ಮಾತ್ರ. ಜಾಹೀರಾತು, ವಿಶ್ಲೇಷಣೆ, ಟ್ರ್ಯಾಕಿಂಗ್, ಪ್ರೊಫೈಲಿಂಗ್ ಅಥವಾ ಬೇರೆ ಯಾವುದೇ ಉದ್ದೇಶಕ್ಕೆ ಇವುಗಳನ್ನು ಬಳಸಲಾಗುವುದಿಲ್ಲ.

3. ಹಂಚಿಕೆ ಮತ್ತು ಮೂರನೇ ಪಕ್ಷಗಳು

ಮುಖ ಡೇಟಾವನ್ನು ಡೆವಲಪರ್‌ಗೆ ಅಥವಾ ಬೇರೆ ಯಾವುದೇ ಮೂರನೇ ಪಕ್ಷಕ್ಕೆ ಎಂದಿಗೂ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದಿಲ್ಲ, ಮಾರಾಟ ಮಾಡುವುದಿಲ್ಲ, ಹಂಚಿಕೊಳ್ಳುವುದಿಲ್ಲ, ಬಹಿರಂಗಪಡಿಸುವುದಿಲ್ಲ. ನಿಮ್ಮ ಫೈಲ್‌ಗಳು, ಅವುಗಳ ವಿಷಯ ಅಥವಾ ಪತ್ತೆ ಫಲಿತಾಂಶಗಳಿಗೆ ಸಂಬಂಧಿಸಿದ ಯಾವುದೇ ನೆಟ್‌ವರ್ಕ್ ವಿನಂತಿಯನ್ನು ಆ್ಯಪ್ ಮಾಡುವುದಿಲ್ಲ; ಇದರ ಏಕೈಕ ನೆಟ್‌ವರ್ಕ್ ಸೇವೆ ಖರೀದಿ ಮತ್ತು ಮರುಸ್ಥಾಪನೆಗಾಗಿ Apple ನ StoreKit. ಅದರಲ್ಲಿ ಮೂರನೇ ಪಕ್ಷದ ಜಾಹೀರಾತು, ವಿಶ್ಲೇಷಣೆ, ಟ್ರ್ಯಾಕಿಂಗ್ ಅಥವಾ ಡೇಟಾ SDK ಯಾವುದೂ ಇಲ್ಲ.

4. ಮುಖ ಡೇಟಾ ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತದೆ

ಮುಖದ ಆಯತಗಳನ್ನು ಸಕ್ರಿಯ ಪರಿಶೀಲನಾ ಕಾರ್ಯಸ್ಥಳದಲ್ಲಿ ನಿಮ್ಮ ಸಾಧನದ ಮೆಮೊರಿಯಲ್ಲಿ ಮಾತ್ರ ಇರಿಸಲಾಗುತ್ತದೆ; ಅವುಗಳನ್ನು ಮುಖ ಡೇಟಾವಾಗಿ ಸಂಗ್ರಹಣೆಗೆ ಎಂದಿಗೂ ಬರೆಯುವುದಿಲ್ಲ. "ಖಾಸಗಿ ಸೆಶನ್" (Private Session) ಡೀಫಾಲ್ಟ್ ಆಗಿ ಆನ್ ಆಗಿರುತ್ತದೆ. ನೀವು ಅದನ್ನು ಆಫ್ ಮಾಡಿದರೆ, "ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು" (Projects) ಮೂಲ ಫೈಲ್ ಮತ್ತು ರಕ್ಷಿತ ಪ್ರತಿಯನ್ನು, ರಕ್ಷಿಸಿದ ಅಂಶಗಳ ಸಂಖ್ಯೆ ಮತ್ತು ಅವುಗಳ ವರ್ಗಗಳೊಂದಿಗೆ (ಉದಾಹರಣೆಗೆ "ಮುಖ" ("face")) ಈ ಸಾಧನದಲ್ಲಿ ಉಳಿಸುತ್ತದೆ; ಮುಖಗಳ ಸ್ಥಾನಗಳನ್ನು ಉಳಿಸುವುದಿಲ್ಲ. ಆ ಫೈಲ್‌ಗಳು ನಿಮ್ಮ ಸ್ವಂತ ಚಿತ್ರಗಳು, ಮತ್ತು ಅವುಗಳಲ್ಲಿ ಮುಖಗಳು ಕಾಣಿಸಬಹುದು.

5. ಮುಖ ಡೇಟಾವನ್ನು ಎಷ್ಟು ಕಾಲ ಇರಿಸಿಕೊಳ್ಳಲಾಗುತ್ತದೆ

ಪರಿಶೀಲನೆ ಅಥವಾ ಬ್ಯಾಚ್ ಕಾರ್ಯಸ್ಥಳವನ್ನು ತೆರವುಗೊಳಿಸಿದಾಗ, ಉದಾಹರಣೆಗೆ ನೀವು ಬೇರೆ ಫೈಲ್‌ನೊಂದಿಗೆ ಮತ್ತೆ ಆರಂಭಿಸಿದಾಗ, ಮುಖದ ಆಯತಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ; ಆ್ಯಪ್ ಮುಚ್ಚಿದ ನಂತರ ಅವುಗಳಲ್ಲಿ ಯಾವುದೂ ಉಳಿಯುವುದಿಲ್ಲ. ಉಳಿಸಿದ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು ನೀವು ಅಳಿಸುವವರೆಗೆ ನಿಮ್ಮ ಸಾಧನದಲ್ಲೇ ಇರುತ್ತವೆ. ಡೆವಲಪರ್ ಎಂದಿಗೂ ಯಾವುದೇ ಮುಖ ಡೇಟಾವನ್ನು ಸ್ವೀಕರಿಸುವುದಿಲ್ಲ ಅಥವಾ ಇರಿಸಿಕೊಳ್ಳುವುದಿಲ್ಲ.

6. ಅಳಿಸುವಿಕೆ

ಮುಖದ ಆಯತಗಳನ್ನು ಎಂದಿಗೂ ಉಳಿಸದ ಕಾರಣ, ಅಳಿಸಲು ಸಂಗ್ರಹವಾದ ಮುಖ ಡೇಟಾ ಯಾವುದೂ ಇಲ್ಲ. ನೀವು ಉಳಿಸಿದ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ಅಳಿಸಬಹುದು, ಉಳಿಸಿಕೊಂಡ ಎಲ್ಲಾ ಮೂಲ ಫೈಲ್‌ಗಳು ಮತ್ತು ರಕ್ಷಿತ ಪ್ರತಿಗಳನ್ನು ತೆಗೆದುಹಾಕಲು "ಪ್ರಾಜೆಕ್ಟ್ ಇತಿಹಾಸ ತೆರವುಗೊಳಿಸಿ" (Clear Project History) ಬಳಸಬಹುದು, ಅಥವಾ ಆ್ಯಪ್ ಅನ್ನು ಅಳಿಸಿದರೆ ಅದರ ಎಲ್ಲಾ ಸ್ಥಳೀಯ ಡೇಟಾ ನಿಮ್ಮ ಸಾಧನದಿಂದ ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತದೆ.

ಏನು ಉಳಿಯುತ್ತದೆ ಎಂಬುದು ನಿಮ್ಮ ನಿಯಂತ್ರಣದಲ್ಲಿ

ಮೂಲ ಫೈಲ್ ಎಂದಿಗೂ ಬದಲಾಗುವುದಿಲ್ಲ. ತಾತ್ಕಾಲಿಕ ಕಾರ್ಯಕ್ಷೇತ್ರ ಫೈಲ್‌ಗಳು, ಉಳಿಸಿದ ಪ್ರಾಜೆಕ್ಟ್‌ಗಳು, ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್ ವಾಲ್ಟ್ ಮತ್ತು ಖಾಸಗಿ ಸೆಷನ್ ಡೇಟಾ ಪ್ರತಿ ವೈಶಿಷ್ಟ್ಯ ಹೇಳುವಷ್ಟೇ ಕಾಲ ಉಳಿಯುತ್ತವೆ. ಆ್ಯಪ್‌ನಲ್ಲಿ ಅಳಿಸಿ ಅಥವಾ ಆ್ಯಪ್ ತೆಗೆದು ಅದರ ಸ್ಥಳೀಯ ಕಂಟೇನರ್ ಅಳಿಸಿ.
