Mask My File

공유는 하되, 과잉 공유는 없이. Mask My File은 기기에서 개인정보를 찾아 무엇이든 손을 떠나기 전에 영구적으로 가립니다.

Mask My File · App Store
지원 형식과 보호 스타일

이미지와 PDF, 또는 텍스트, JSON, XML, HTML, CSV, TSV, RTF를 열 수 있습니다. 시각 파일은 영구 불투명 가리기 또는 제거만 지원하며, 텍스트·구조화 파일은 선택한 일치 항목마다 전체 마스크, 부분 마스크, 자리표시자, 가명, 제거를 적용할 수 있습니다.

믿기 전에 먼저 검증

보호할 때마다 완전히 새로운 사본을 만듭니다. 앱은 그 사본을 다시 열어 파일 구조와 적용된 가리기를 모두 확인한 뒤에야 Private Ready를 표시합니다. 공유 직전에 한 번 더 눈으로 확인하세요.

한 번에 최대 100개 파일

하나의 배치에 최대 100개 파일을 불러와 각 파일을 미리 보고, 필요한 곳에 수동으로 상자를 그리고, 모든 파일에서 정확하게 텍스트를 검색한 뒤 보호된 세트를 한꺼번에 내보냅니다.
