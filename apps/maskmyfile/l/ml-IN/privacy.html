Mask My File സ്വകാര്യതാ നയം

ഫയലുകൾ ശേഖരിക്കാതെ അവയെ സംരക്ഷിക്കാനാണ് Mask My File രൂപകൽപ്പന ചെയ്തിരിക്കുന്നത്. അക്കൗണ്ട് വേണ്ട, ആപ്പിൽ പരസ്യം, ട്രാക്കിംഗ്, വിശകലനം അല്ലെങ്കിൽ ഉള്ളടക്ക-അപ്‌ലോഡ് സേവനം ഇല്ല.

പ്രോസസ്സിംഗ് നിങ്ങളുടെ ഉപകരണത്തിൽ തുടരുന്നു

Apple Vision-ഉം ഉൾപ്പെടുത്തിയ Tesseract OCR എൻജിനും തിരഞ്ഞെടുത്ത ഉള്ളടക്കം പ്രാദേശികമായി സ്കാൻ ചെയ്യുന്നു. മാസ്കിംഗ്, മറയ്ക്കൽ, മെറ്റാഡേറ്റ നീക്കൽ, കയറ്റുമതി, പരിശോധന എന്നിവയും ഉപകരണത്തിൽ തന്നെ നടക്കുന്നു.

മുഖ മേഖലകൾ, ഐഡന്റിറ്റി പ്രൊഫൈൽ അല്ല

മുഖം കണ്ടെത്തൽ നിങ്ങളുടെ പരിശോധനയ്ക്കായി ചിത്ര മേഖലകൾ മാത്രം അടയാളപ്പെടുത്തുന്നു. Mask My File ആളുകളെ തിരിച്ചറിയുന്നില്ല, ബയോമെട്രിക് അല്ലെങ്കിൽ ഐഡന്റിറ്റി ടെംപ്ലേറ്റ് ഉണ്ടാക്കുന്നില്ല, മുഖ ഡാറ്റ അപ്‌ലോഡ് ചെയ്യുകയോ പങ്കിടുകയോ പ്രത്യേകം സൂക്ഷിക്കുകയോ ഇല്ല.

വാങ്ങൽ മാത്രമാണ് നെറ്റ്‌വർക്ക് സേവനം

ഐച്ഛിക ആയുഷ്‌കാല വാങ്ങലും പുനഃസ്ഥാപനവും Apple StoreKit വഴി നടക്കുന്നു. Mask My File ഒരു VPN, NetworkExtension, പ്രോക്സി, ടണൽ, DNS ഫിൽട്ടർ അല്ലെങ്കിൽ നെറ്റ്‌വർക്ക് റൂട്ടിംഗ് ഉപയോഗിക്കുന്നില്ല.

എന്ത് ശേഷിക്കണമെന്ന് നിങ്ങൾ തീരുമാനിക്കുന്നു

യഥാർത്ഥ ഫയൽ ഒരിക്കലും മാറ്റിയെഴുതില്ല. താൽക്കാലിക വർക്ക്‌സ്‌പേസ് ഫയലുകൾ, സേവ് ചെയ്ത പ്രോജക്ടുകൾ, പ്ലേസ്‌ഹോൾഡർ വോൾട്ട്, സ്വകാര്യ സെഷൻ ഡാറ്റ എന്നിവ ഓരോ സവിശേഷതയും പറയുന്നത്ര കാലം മാത്രം നിലനിൽക്കുന്നു. ആപ്പിൽ ഇല്ലാതാക്കുക അല്ലെങ്കിൽ ആപ്പ് നീക്കി അതിന്റെ പ്രാദേശിക കണ്ടെയ്‌നർ മായ്ക്കുക.
