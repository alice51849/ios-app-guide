Mask My File സ്വകാര്യതാ നയം

ഫയലുകൾ ശേഖരിക്കാതെ അവയെ സംരക്ഷിക്കാനാണ് Mask My File രൂപകൽപ്പന ചെയ്തിരിക്കുന്നത്. അക്കൗണ്ട് വേണ്ട, ആപ്പിൽ പരസ്യം, ട്രാക്കിംഗ്, വിശകലനം അല്ലെങ്കിൽ ഉള്ളടക്ക-അപ്‌ലോഡ് സേവനം ഇല്ല.

പ്രോസസ്സിംഗ് നിങ്ങളുടെ ഉപകരണത്തിൽ തുടരുന്നു

Apple Vision-ഉം ഉൾപ്പെടുത്തിയ Tesseract OCR എൻജിനും തിരഞ്ഞെടുത്ത ഉള്ളടക്കം പ്രാദേശികമായി സ്കാൻ ചെയ്യുന്നു. മാസ്കിംഗ്, മറയ്ക്കൽ, മെറ്റാഡേറ്റ നീക്കൽ, കയറ്റുമതി, പരിശോധന എന്നിവയും ഉപകരണത്തിൽ തന്നെ നടക്കുന്നു.

മുഖ മേഖലകൾ, ഐഡന്റിറ്റി പ്രൊഫൈൽ അല്ല

മുഖം കണ്ടെത്തൽ നിങ്ങളുടെ പരിശോധനയ്ക്കായി ചിത്ര മേഖലകൾ മാത്രം അടയാളപ്പെടുത്തുന്നു. Mask My File ആളുകളെ തിരിച്ചറിയുന്നില്ല, ബയോമെട്രിക് അല്ലെങ്കിൽ ഐഡന്റിറ്റി ടെംപ്ലേറ്റ് ഉണ്ടാക്കുന്നില്ല, മുഖ ഡാറ്റ അപ്‌ലോഡ് ചെയ്യുകയോ പങ്കിടുകയോ പ്രത്യേകം സൂക്ഷിക്കുകയോ ഇല്ല.

വാങ്ങൽ മാത്രമാണ് നെറ്റ്‌വർക്ക് സേവനം

ഐച്ഛിക ആയുഷ്‌കാല വാങ്ങലും പുനഃസ്ഥാപനവും Apple StoreKit വഴി നടക്കുന്നു. Mask My File ഒരു VPN, NetworkExtension, പ്രോക്സി, ടണൽ, DNS ഫിൽട്ടർ അല്ലെങ്കിൽ നെറ്റ്‌വർക്ക് റൂട്ടിംഗ് ഉപയോഗിക്കുന്നില്ല.

മുഖ ഡാറ്റ (iOS ആപ്പ്)

ഈ വിഭാഗം 2026-11-16-ന് അപ്ഡേറ്റ് ചെയ്തതാണ്. ഈ വിഭാഗം App Store-ലെ Mask My File iOS ആപ്പിന് ബാധകമാണ്.

1. ആപ്പ് ഉപയോഗിക്കുന്ന മുഖ ഡാറ്റ

നിങ്ങൾ ഒരു ചിത്രമോ PDF പേജോ ഒറ്റയ്ക്കോ ബാച്ചായോ സ്കാൻ ചെയ്യുമ്പോൾ, മുഖങ്ങൾ കണ്ടെത്താൻ Mask My File Apple-ന്റെ ഉപകരണത്തിൽ തന്നെ പ്രവർത്തിക്കുന്ന Vision framework ഉപയോഗിക്കുന്നു. ഓരോ മുഖത്തിനും, ആപ്പ് ഉപയോഗിക്കുന്ന മുഖ ഡാറ്റ ആ പേജിൽ മുഖത്തിന് ചുറ്റുമുള്ള ചതുരത്തിന്റെ സ്ഥാനവും കണ്ടെത്തലിന്റെ വിശ്വാസ്യതയും മാത്രമാണ്. സംരക്ഷിത പകർപ്പ് സൃഷ്ടിക്കുമ്പോൾ, തിരഞ്ഞെടുത്ത ഒരു മുഖവും ഇപ്പോഴും ദൃശ്യമല്ലെന്ന് ഉറപ്പാക്കാൻ ആപ്പ് അതേ കണ്ടെത്തൽ സംരക്ഷിത പകർപ്പിൽ ഒരിക്കൽ കൂടി പ്രവർത്തിപ്പിക്കുന്നു; ആ ഫലം ആ പരിശോധനയ്ക്ക് മാത്രമാണ് ഉപയോഗിക്കുന്നത്. ആപ്പ് മുഖം തിരിച്ചറിയലോ വ്യക്തിയെ തിരിച്ചറിയലോ നടത്തുന്നില്ല; മുഖ ടെംപ്ലേറ്റോ ഫേസ്പ്രിന്റോ (faceprint) മറ്റേതെങ്കിലും ബയോമെട്രിക് തിരിച്ചറിയൽ വിവരമോ സൃഷ്ടിക്കുന്നില്ല; മുഖങ്ങൾ താരതമ്യം ചെയ്യുന്നില്ല.

2. മുഖ ഡാറ്റ എങ്ങനെ ഉപയോഗിക്കുന്നു

ഈ ചതുരങ്ങൾ അവലോകന സ്ക്രീനിൽ നിർദ്ദേശിച്ച മുഖ മേഖലകൾ കാണിക്കാൻ മാത്രമാണ് ഉപയോഗിക്കുന്നത് (അവിടെ നിങ്ങൾക്ക് ഓരോന്നും നിലനിർത്താം, മാറ്റാം, അല്ലെങ്കിൽ നീക്കം ചെയ്യാം; ഉയർന്ന വിശ്വാസ്യതയുള്ള മുഖങ്ങൾ മുൻകൂട്ടി തിരഞ്ഞെടുക്കപ്പെടും), കൂടാതെ നിങ്ങൾ എക്സ്പോർട്ട് ചെയ്യുന്ന സംരക്ഷിത പകർപ്പിൽ നിങ്ങൾ തിരഞ്ഞെടുത്തിരിക്കുന്ന മുഖങ്ങൾ (സ്ഥിരമായി ഒരു ഖര ബ്ലോക്ക് ഉപയോഗിച്ച്) മറയ്ക്കാനും മാത്രം. പരസ്യം, അനലിറ്റിക്സ്, ട്രാക്കിംഗ്, പ്രൊഫൈലിംഗ്, മറ്റേതെങ്കിലും ആവശ്യം എന്നിവയ്ക്കായി ഇവ ഉപയോഗിക്കുന്നില്ല.

3. പങ്കിടലും മൂന്നാം കക്ഷികളും

മുഖ ഡാറ്റ ഡെവലപ്പർക്കോ മറ്റേതെങ്കിലും മൂന്നാം കക്ഷിക്കോ ഒരിക്കലും അപ്‌ലോഡ് ചെയ്യുകയോ വിൽക്കുകയോ പങ്കിടുകയോ വെളിപ്പെടുത്തുകയോ ചെയ്യുന്നില്ല. നിങ്ങളുടെ ഫയലുകൾ, അവയുടെ ഉള്ളടക്കം, അല്ലെങ്കിൽ കണ്ടെത്തൽ ഫലങ്ങൾ എന്നിവ ഉൾപ്പെടുന്ന ഒരു നെറ്റ്‌വർക്ക് അഭ്യർത്ഥനയും ആപ്പ് നടത്തുന്നില്ല; ഇതിന്റെ ഏക നെറ്റ്‌വർക്ക് സേവനം വാങ്ങലിനും പുനഃസ്ഥാപിക്കലിനുമുള്ള Apple-ന്റെ StoreKit ആണ്. അതിൽ മൂന്നാം കക്ഷി പരസ്യ, അനലിറ്റിക്സ്, ട്രാക്കിംഗ്, ഡാറ്റ SDK ഒന്നുമില്ല.

4. മുഖ ഡാറ്റ എവിടെ സംഭരിക്കുന്നു

മുഖ ചതുരങ്ങൾ സജീവമായ അവലോകന വർക്ക്‌സ്പേസിൽ നിങ്ങളുടെ ഉപകരണത്തിന്റെ മെമ്മറിയിൽ മാത്രം സൂക്ഷിക്കുന്നു, അവ മുഖ ഡാറ്റയായി സംഭരണത്തിലേക്ക് ഒരിക്കലും എഴുതുന്നില്ല. "സ്വകാര്യ സെഷൻ" (Private Session) സ്ഥിരമായി ഓണാണ്. നിങ്ങൾ അത് ഓഫാക്കിയാൽ, "പ്രോജക്റ്റുകൾ" (Projects) യഥാർത്ഥ ഫയലും സംരക്ഷിത പകർപ്പും, സംരക്ഷിച്ച ഇനങ്ങളുടെ എണ്ണവും അവയുടെ വിഭാഗങ്ങളും (ഉദാഹരണത്തിന് "മുഖം" ("face")) സഹിതം ഈ ഉപകരണത്തിൽ സേവ് ചെയ്യുന്നു, എന്നാൽ മുഖങ്ങളുടെ സ്ഥാനങ്ങൾ സേവ് ചെയ്യുന്നില്ല. ആ ഫയലുകൾ നിങ്ങളുടെ സ്വന്തം ചിത്രങ്ങളാണ്, അവയിൽ മുഖങ്ങൾ കാണാം.

5. മുഖ ഡാറ്റ എത്രകാലം സൂക്ഷിക്കുന്നു

അവലോകന അല്ലെങ്കിൽ ബാച്ച് വർക്ക്‌സ്പേസ് ക്ലിയർ ചെയ്യുമ്പോൾ, ഉദാഹരണത്തിന് മറ്റൊരു ഫയലുമായി നിങ്ങൾ വീണ്ടും ആരംഭിക്കുമ്പോൾ, മുഖ ചതുരങ്ങൾ ഒഴിവാക്കപ്പെടുന്നു, ആപ്പ് അടച്ചതിനുശേഷം അവയൊന്നും അവശേഷിക്കില്ല. സേവ് ചെയ്ത പ്രോജക്റ്റുകൾ നിങ്ങൾ ഇല്ലാതാക്കുന്നതുവരെ നിങ്ങളുടെ ഉപകരണത്തിൽ തുടരും. ഡെവലപ്പർ ഒരിക്കലും മുഖ ഡാറ്റ സ്വീകരിക്കുകയോ സൂക്ഷിക്കുകയോ ചെയ്യുന്നില്ല.

6. ഇല്ലാതാക്കൽ

മുഖ ചതുരങ്ങൾ ഒരിക്കലും സേവ് ചെയ്യാത്തതിനാൽ, ഇല്ലാതാക്കാൻ സംഭരിച്ച മുഖ ഡാറ്റയൊന്നുമില്ല. നിങ്ങൾക്ക് സേവ് ചെയ്ത ഒരു പ്രോജക്റ്റ് ഇല്ലാതാക്കാം, സൂക്ഷിച്ചിരിക്കുന്ന എല്ലാ യഥാർത്ഥ ഫയലുകളും സംരക്ഷിത പകർപ്പുകളും നീക്കം ചെയ്യാൻ "പ്രോജക്റ്റ് ചരിത്രം മായ്‌ക്കുക" (Clear Project History) ഉപയോഗിക്കാം, അല്ലെങ്കിൽ ആപ്പ് ഇല്ലാതാക്കിയാൽ അതിന്റെ എല്ലാ പ്രാദേശിക ഡാറ്റയും നിങ്ങളുടെ ഉപകരണത്തിൽ നിന്ന് നീക്കം ചെയ്യപ്പെടും.

എന്ത് ശേഷിക്കണമെന്ന് നിങ്ങൾ തീരുമാനിക്കുന്നു

യഥാർത്ഥ ഫയൽ ഒരിക്കലും മാറ്റിയെഴുതില്ല. താൽക്കാലിക വർക്ക്‌സ്‌പേസ് ഫയലുകൾ, സേവ് ചെയ്ത പ്രോജക്ടുകൾ, പ്ലേസ്‌ഹോൾഡർ വോൾട്ട്, സ്വകാര്യ സെഷൻ ഡാറ്റ എന്നിവ ഓരോ സവിശേഷതയും പറയുന്നത്ര കാലം മാത്രം നിലനിൽക്കുന്നു. ആപ്പിൽ ഇല്ലാതാക്കുക അല്ലെങ്കിൽ ആപ്പ് നീക്കി അതിന്റെ പ്രാദേശിക കണ്ടെയ്‌നർ മായ്ക്കുക.
