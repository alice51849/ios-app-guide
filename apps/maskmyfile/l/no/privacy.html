Personvernerklæring for Mask My File

Mask My File er laget for å beskytte filer uten å samle dem inn. Ingen konto kreves, og appen har ingen annonsering, sporing, analyse eller innholdsopplasting.

Behandlingen skjer på enheten din

Apple Vision og den innebygde Tesseract OCR-motoren skanner det valgte innholdet lokalt. Maskering, sladding, fjerning av metadata, eksport og verifisering skjer også på enheten.

Ansiktsområder, aldri identitetsprofiler

Ansiktsgjenkjenning markerer bare bildeområder til gjennomgangen din. Mask My File identifiserer ikke personer, lager ingen biometriske eller identitetsmaler, laster ikke opp eller deler ansiktsdata og beholder ingen egne ansiktsdata.

Kjøp er den eneste nettverkstjenesten

Apple håndterer det valgfrie livstidskjøpet og gjenoppretting via StoreKit. Mask My File bruker ikke VPN, NetworkExtension, proxy, tunnel, DNS-filter eller nettverksruting.

Du bestemmer hva som blir igjen

Originaler blir aldri overskrevet. Midlertidige arbeidsfiler, lagrede prosjekter, koblinger i plassholderhvelvet og data fra privat økt blir bare igjen slik hver funksjon forklarer. Slett dem i appen, eller fjern appen for å slette den lokale beholderen.
