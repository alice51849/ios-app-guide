Polityka prywatności Mask My File

Mask My File powstał, aby chronić pliki bez ich zbierania. Nie wymaga konta, a aplikacja nie zawiera reklam, śledzenia, analityki ani przesyłania treści.

Przetwarzanie zostaje na Twoim urządzeniu

Apple Vision oraz wbudowany silnik Tesseract OCR skanują wybraną treść lokalnie. Maskowanie, zaczernianie, usuwanie metadanych, eksport i weryfikacja również działają na urządzeniu.

Obszary twarzy, nigdy profile tożsamości

Wykrywanie twarzy zaznacza jedynie obszary obrazu do Twojego przeglądu. Mask My File nie identyfikuje osób, nie tworzy szablonów biometrycznych ani tożsamości, nie przesyła i nie udostępnia danych twarzy oraz nie przechowuje osobnych danych twarzy.

Zakup to jedyna usługa sieciowa

Apple obsługuje opcjonalny zakup na całe życie i przywracanie przez StoreKit. Mask My File nie używa VPN, NetworkExtension, serwera proxy, tunelu, filtra DNS ani przekierowań sieciowych.

To Ty decydujesz, co zostaje

Oryginały nigdy nie są nadpisywane. Tymczasowe pliki robocze, zapisane projekty, powiązania w skarbcu symboli zastępczych i dane sesji prywatnej pozostają tylko tak, jak opisuje to każda funkcja. Usuń je w aplikacji lub usuń aplikację, aby wymazać jej lokalny kontener.
