Política de Privacidade do Mask My File

O Mask My File foi feito para proteger arquivos sem coletá-los. Nenhuma conta é necessária, e o app não tem publicidade, rastreamento, análise ou envio de conteúdo.

O processamento fica no seu dispositivo

O Apple Vision e o mecanismo Tesseract OCR integrado analisam o conteúdo selecionado localmente. Mascaramento, tarja, remoção de metadados, exportação e verificação também funcionam no dispositivo.

Áreas de rosto, nunca perfis de identidade

A detecção de rosto apenas marca áreas da imagem para a sua revisão. O Mask My File não identifica pessoas, não cria modelos biométricos ou de identidade, não envia nem compartilha dados faciais e não guarda dados faciais separados.

A compra é o único serviço de rede

A Apple processa a compra vitalícia opcional e a restauração pelo StoreKit. O Mask My File não usa VPN, NetworkExtension, proxy, túnel, filtro DNS ou roteamento de rede.

Dados faciais (app iOS)

Seção atualizada em 2026-11-16. Esta seção se aplica ao app Mask My File para iOS na App Store.

1. Quais dados faciais o app usa

Quando você escaneia uma imagem ou uma página de PDF, individualmente ou em lote, o Mask My File usa o framework Vision da Apple, executado no dispositivo, para detectar rostos. Para cada rosto, os únicos dados faciais que o app utiliza são a posição do retângulo ao redor do rosto nessa página e a confiança da detecção. Quando a cópia protegida é criada, o app executa a mesma detecção mais uma vez na cópia protegida para verificar se nenhum rosto selecionado ainda está visível; esse resultado é usado somente para a verificação. O app não realiza reconhecimento nem identificação facial, não cria modelo facial, impressão facial (faceprint) nem qualquer outro identificador biométrico e não compara rostos.

2. Como os dados faciais são usados

Esses retângulos são usados somente para mostrar regiões de rosto sugeridas na tela de revisão, onde você pode manter, alterar ou remover cada uma (os rostos com maior confiança vêm pré-selecionados), e para cobrir os rostos que você mantém selecionados na cópia protegida que você exporta (por padrão, com um bloco sólido). Eles não são usados para publicidade, análises, rastreamento, criação de perfis nem qualquer outra finalidade.

3. Compartilhamento e terceiros

Os dados faciais nunca são enviados, vendidos, compartilhados com o desenvolvedor ou com qualquer terceiro, nem divulgados a eles. O app não faz nenhuma solicitação de rede envolvendo seus arquivos, o conteúdo deles ou os resultados da detecção; seu único serviço de rede é o StoreKit da Apple para compra e restauração. Ele não contém nenhum SDK de terceiros de publicidade, análises, rastreamento ou dados.

4. Onde os dados faciais são armazenados

Os retângulos de rosto são mantidos apenas na memória do seu dispositivo, no espaço de trabalho de revisão ativo, e nunca são gravados no armazenamento como dados faciais. Sessão Privada vem ativada por padrão. Se você a desativar, Projetos salva neste dispositivo o arquivo original e a cópia protegida, junto com o número de itens protegidos e suas categorias (por exemplo, "rosto (face)"), mas não as posições dos rostos. Esses arquivos são suas próprias imagens e podem mostrar rostos.

5. Por quanto tempo os dados faciais são retidos

Os retângulos de rosto são descartados quando o espaço de trabalho de revisão ou de lote é limpo, por exemplo, quando você recomeça com outro arquivo, e nenhum permanece depois que o app é encerrado. Os projetos salvos permanecem no seu dispositivo até que você os exclua. O desenvolvedor nunca recebe nem retém dados faciais.

6. Exclusão

Como os retângulos de rosto nunca são salvos, não há dados faciais armazenados para excluir. Você pode excluir um projeto salvo, usar Limpar Histórico de Projetos para remover todos os originais e cópias protegidas retidos ou excluir o app para remover todos os dados locais dele do seu dispositivo.

Você controla o que permanece

Os originais nunca são sobrescritos. Arquivos temporários de trabalho, projetos salvos, os vínculos do cofre de marcadores e os dados da sessão privada permanecem apenas conforme cada recurso explica. Apague-os no app ou remova o app para apagar o container local.
