Mask My File தனியுரிமைக் கொள்கை

Mask My File கோப்புகளைச் சேகரிக்காமல் அவற்றைப் பாதுகாக்க வடிவமைக்கப்பட்டது. கணக்கு தேவையில்லை, செயலியில் விளம்பரம், கண்காணிப்பு, பகுப்பாய்வு அல்லது உள்ளடக்க-பதிவேற்ற சேவை இல்லை.

செயலாக்கம் உங்கள் சாதனத்திலேயே இருக்கும்

Apple Vision மற்றும் உள்ளடங்கிய Tesseract OCR இயந்திரம் தேர்ந்தெடுத்த உள்ளடக்கத்தை உள்ளூரில் ஸ்கேன் செய்கின்றன. மாஸ்கிங், மறைப்பு, மெட்டாடேட்டா நீக்கம், ஏற்றுமதி மற்றும் சரிபார்ப்பும் சாதனத்திலேயே இயங்கும்.

முகப் பகுதிகள், அடையாள விவரக்குறிப்பு அல்ல

முகம் கண்டறிதல் உங்கள் பரிசீலனைக்காக படப் பகுதிகளை மட்டுமே குறிக்கும். Mask My File மக்களை அடையாளம் காணாது, பயோமெட்ரிக் அல்லது அடையாள டெம்ப்ளேட் உருவாக்காது, முக தரவைப் பதிவேற்றாது அல்லது பகிராது, தனியாக வைத்திருக்காது.

வாங்குதல் மட்டுமே நெட்வொர்க் சேவை

விருப்பத் தேர்வான வாழ்நாள் வாங்குதலும் மீட்டமைப்பும் Apple StoreKit மூலம் நடக்கின்றன. Mask My File எந்த VPN, NetworkExtension, ப்ராக்ஸி, டன்னல், DNS வடிகட்டி அல்லது நெட்வொர்க் ரூட்டிங்கையும் பயன்படுத்தாது.

எது இருக்கும் என்பதை நீங்கள் கட்டுப்படுத்துகிறீர்கள்

மூலக் கோப்பு ஒருபோதும் மேலெழுதப்படாது. தற்காலிக பணியிட கோப்புகள், சேமித்த திட்டங்கள், பிளேஸ்ஹோல்டர் வால்ட் மற்றும் தனிப்பட்ட அமர்வு தரவு ஒவ்வொரு அம்சமும் விளக்கும் அளவுக்கே இருக்கும். செயலியில் நீக்குங்கள் அல்லது செயலியை அகற்றி அதன் உள்ளூர் கண்டெய்னரை அழியுங்கள்.
