Mask My File தனியுரிமைக் கொள்கை

Mask My File கோப்புகளைச் சேகரிக்காமல் அவற்றைப் பாதுகாக்க வடிவமைக்கப்பட்டது. கணக்கு தேவையில்லை, செயலியில் விளம்பரம், கண்காணிப்பு, பகுப்பாய்வு அல்லது உள்ளடக்க-பதிவேற்ற சேவை இல்லை.

செயலாக்கம் உங்கள் சாதனத்திலேயே இருக்கும்

Apple Vision மற்றும் உள்ளடங்கிய Tesseract OCR இயந்திரம் தேர்ந்தெடுத்த உள்ளடக்கத்தை உள்ளூரில் ஸ்கேன் செய்கின்றன. மாஸ்கிங், மறைப்பு, மெட்டாடேட்டா நீக்கம், ஏற்றுமதி மற்றும் சரிபார்ப்பும் சாதனத்திலேயே இயங்கும்.

முகப் பகுதிகள், அடையாள விவரக்குறிப்பு அல்ல

முகம் கண்டறிதல் உங்கள் பரிசீலனைக்காக படப் பகுதிகளை மட்டுமே குறிக்கும். Mask My File மக்களை அடையாளம் காணாது, பயோமெட்ரிக் அல்லது அடையாள டெம்ப்ளேட் உருவாக்காது, முக தரவைப் பதிவேற்றாது அல்லது பகிராது, தனியாக வைத்திருக்காது.

வாங்குதல் மட்டுமே நெட்வொர்க் சேவை

விருப்பத் தேர்வான வாழ்நாள் வாங்குதலும் மீட்டமைப்பும் Apple StoreKit மூலம் நடக்கின்றன. Mask My File எந்த VPN, NetworkExtension, ப்ராக்ஸி, டன்னல், DNS வடிகட்டி அல்லது நெட்வொர்க் ரூட்டிங்கையும் பயன்படுத்தாது.

முகத் தரவு (iOS செயலி)

இந்தப் பிரிவு 2026-11-16 அன்று புதுப்பிக்கப்பட்டது. இந்தப் பிரிவு App Store-இல் உள்ள Mask My File iOS செயலிக்குப் பொருந்தும்.

1. செயலி பயன்படுத்தும் முகத் தரவு

நீங்கள் ஒரு படத்தையோ PDF பக்கத்தையோ தனியாகவோ தொகுதியாகவோ ஸ்கேன் செய்யும்போது, Mask My File முகங்களைக் கண்டறிய Apple-இன் சாதனத்திலேயே இயங்கும் Vision framework-ஐப் பயன்படுத்துகிறது. ஒவ்வொரு முகத்திற்கும், செயலி பயன்படுத்தும் முகத் தரவு அந்தப் பக்கத்தில் முகத்தைச் சுற்றியுள்ள செவ்வகத்தின் இடமும் கண்டறிதல் உறுதிநிலையும் மட்டுமே. பாதுகாக்கப்பட்ட நகல் உருவாக்கப்படும்போது, தேர்ந்தெடுக்கப்பட்ட எந்த முகமும் இன்னும் தெரியவில்லை என்பதை உறுதிசெய்ய, செயலி அதே கண்டறிதலைப் பாதுகாக்கப்பட்ட நகலில் ஒரு முறை மீண்டும் இயக்குகிறது; அந்த முடிவு அந்தச் சரிபார்ப்புக்கு மட்டுமே பயன்படுத்தப்படுகிறது. செயலி முக அங்கீகாரத்தையோ அடையாளம் காணுதலையோ செய்வதில்லை; முக டெம்ப்ளேட், முக அச்சு (faceprint) அல்லது வேறு எந்த உயிரியல் அடையாளங்காட்டியையும் உருவாக்குவதில்லை; முகங்களை ஒப்பிடுவதில்லை.

2. முகத் தரவு எவ்வாறு பயன்படுத்தப்படுகிறது

இந்தச் செவ்வகங்கள், மதிப்பாய்வுத் திரையில் பரிந்துரைக்கப்பட்ட முகப் பகுதிகளைக் காட்ட மட்டுமே (அங்கே ஒவ்வொன்றையும் வைத்திருக்கவோ மாற்றவோ நீக்கவோ முடியும்; அதிக உறுதிநிலை உள்ள முகங்கள் முன்கூட்டியே தேர்ந்தெடுக்கப்படும்), மேலும் நீங்கள் ஏற்றுமதி செய்யும் பாதுகாக்கப்பட்ட நகலில் நீங்கள் தேர்ந்தெடுத்து வைத்துள்ள முகங்களை (இயல்பாக ஒரு திடமான தொகுதியால்) மூடவும் மட்டுமே பயன்படுத்தப்படுகின்றன. விளம்பரம், பகுப்பாய்வு, கண்காணிப்பு, விவரக்குறிப்பு உருவாக்கம் அல்லது வேறு எந்த நோக்கத்திற்கும் இவை பயன்படுத்தப்படுவதில்லை.

3. பகிர்வும் மூன்றாம் தரப்பினரும்

முகத் தரவு டெவலப்பருக்கோ வேறு எந்த மூன்றாம் தரப்பினருக்கோ ஒருபோதும் பதிவேற்றப்படுவதில்லை, விற்கப்படுவதில்லை, பகிரப்படுவதில்லை, வெளிப்படுத்தப்படுவதில்லை. உங்கள் கோப்புகள், அவற்றின் உள்ளடக்கம் அல்லது கண்டறிதல் முடிவுகள் தொடர்பான எந்த நெட்வொர்க் கோரிக்கையையும் செயலி செய்வதில்லை; அதன் ஒரே நெட்வொர்க் சேவை வாங்குதல் மற்றும் மீட்டெடுப்புக்கான Apple-இன் StoreKit மட்டுமே. அதில் மூன்றாம் தரப்பு விளம்பரம், பகுப்பாய்வு, கண்காணிப்பு அல்லது தரவு SDK எதுவும் இல்லை.

4. முகத் தரவு எங்கே சேமிக்கப்படுகிறது

முகச் செவ்வகங்கள் செயலில் உள்ள மதிப்பாய்வுப் பணியிடத்தில் உங்கள் சாதனத்தின் நினைவகத்தில் மட்டுமே வைக்கப்படுகின்றன; அவை முகத் தரவாகச் சேமிப்பகத்தில் ஒருபோதும் எழுதப்படுவதில்லை. “தனிப்பட்ட அமர்வு” (Private Session) இயல்பாக இயக்கத்தில் இருக்கும். நீங்கள் அதை அணைத்தால், “திட்டங்கள்” (Projects) அசல் கோப்பையும் பாதுகாக்கப்பட்ட நகலையும், பாதுகாக்கப்பட்ட உருப்படிகளின் எண்ணிக்கையுடனும் அவற்றின் வகைகளுடனும் (எடுத்துக்காட்டாக "முகம்" ("face")) இந்தச் சாதனத்தில் சேமிக்கிறது; முகங்களின் இடங்களைச் சேமிப்பதில்லை. அந்தக் கோப்புகள் உங்கள் சொந்தப் படங்கள்; அவற்றில் முகங்கள் தெரியக்கூடும்.

5. முகத் தரவு எவ்வளவு காலம் வைத்திருக்கப்படுகிறது

மதிப்பாய்வு அல்லது தொகுதிப் பணியிடம் அழிக்கப்படும்போது, எடுத்துக்காட்டாக வேறொரு கோப்புடன் மீண்டும் தொடங்கும்போது, முகச் செவ்வகங்கள் நீக்கப்படுகின்றன; செயலி மூடப்பட்ட பிறகு அவற்றில் எதுவும் மிஞ்சுவதில்லை. சேமித்த திட்டங்கள் நீங்கள் நீக்கும் வரை உங்கள் சாதனத்தில் இருக்கும். டெவலப்பர் எந்த முகத் தரவையும் பெறுவதோ வைத்திருப்பதோ இல்லை.

6. நீக்குதல்

முகச் செவ்வகங்கள் ஒருபோதும் சேமிக்கப்படாததால், நீக்குவதற்குச் சேமிக்கப்பட்ட முகத் தரவு எதுவும் இல்லை. சேமித்த திட்டத்தை நீக்கலாம்; வைத்திருக்கப்பட்ட அனைத்து அசல் கோப்புகளையும் பாதுகாக்கப்பட்ட நகல்களையும் நீக்க “திட்ட வரலாற்றை அழிக்கவும்” (Clear Project History) என்பதைப் பயன்படுத்தலாம்; அல்லது செயலியை நீக்கினால் அதன் அனைத்து உள்ளூர்த் தரவும் உங்கள் சாதனத்திலிருந்து நீக்கப்படும்.

எது இருக்கும் என்பதை நீங்கள் கட்டுப்படுத்துகிறீர்கள்

மூலக் கோப்பு ஒருபோதும் மேலெழுதப்படாது. தற்காலிக பணியிட கோப்புகள், சேமித்த திட்டங்கள், பிளேஸ்ஹோல்டர் வால்ட் மற்றும் தனிப்பட்ட அமர்வு தரவு ஒவ்வொரு அம்சமும் விளக்கும் அளவுக்கே இருக்கும். செயலியில் நீக்குங்கள் அல்லது செயலியை அகற்றி அதன் உள்ளூர் கண்டெய்னரை அழியுங்கள்.
