隐私一览

Mask My File 的设计，是让隐私内容从首次扫描到最终导出都留在你的设备上。以下各段分别说明处理方式、人脸数据、购买与数据保留。

设备端处理

Apple Vision 与内置的 Tesseract OCR 均在本地运行，扫描、遮挡、移除元数据、导出与验证也全部在你的设备上进行。没有账户、广告、跟踪、分析，也不会上传任何内容。

人脸数据如何处理

人脸检测只会标出供你复核的区域，绝不识别身份、不创建生物特征模板、不上传或分享人脸数据，也不会与你正在编辑的文件分开另行保留。

购买与网络

一次性终身解锁与恢复购买均由 Apple 通过 StoreKit 处理。Mask My File 不使用任何 VPN、NetworkExtension、代理服务器、隧道、DNS 过滤或网络路由。

面部数据（iOS App）

本部分于 2026-11-16 更新。本部分适用于 App Store 上的 Mask My File iOS App。

1. App 使用哪些面部数据

当您单独或批量扫描图像或 PDF 页面时，Mask My File 会使用 Apple 的设备端 Vision 框架检测面部。对于每张面部，App 使用的面部数据仅限该面部在该页面上矩形范围的位置和检测置信度。创建受保护的副本时，App 会在该受保护副本上再运行一次相同的检测，以确认所选的面部是否仍然可见；该结果仅用于此项检查。App 不会进行面部识别或身份识别，不会创建面部模板、面部特征码或任何其他生物识别标识符，也不会比对面部。

2. 面部数据的使用方式

这些矩形仅用于在审阅界面上显示建议的面部区域（置信度较高的面部会预先选中），让您可以保留、更改或移除每一个区域；并用于在您导出的受保护副本中遮盖您保持选中的面部（默认为实心色块）。这些矩形不会用于广告、分析、跟踪、用户画像或任何其他用途。

3. 共享与第三方

面部数据绝不会上传，也绝不会出售、共享或披露给开发者或任何第三方。App 不会发出任何涉及您的文件、其内容或检测结果的网络请求；其唯一的网络服务是 Apple StoreKit 的购买与恢复。App 不含任何第三方广告、分析、跟踪或数据 SDK。

4. 面部数据的存储位置

面部矩形仅保存在您设备内存中当前的审阅工作区内，绝不会以面部数据的形式写入存储空间。“隐私工作会话”默认为开启。如果您将其关闭，“项目”会在此设备上保存原始文件和受保护的副本，以及受保护项目的数量及其类别（例如“面部”（face）），但不会保存面部位置。这些文件是您自己的图像，可能显示面部。

5. 面部数据的保留期限

当审阅或批量工作区被清除时（例如您改用另一个文件重新开始），面部矩形即被丢弃，App 退出后也不会残留任何面部矩形。已保存的项目会保留在您的设备上，直到您将其删除。开发者绝不会接收或保留任何面部数据。

6. 删除

由于面部矩形从不保存，因此没有任何已保存的面部数据需要删除。您可以删除已保存的项目、使用“清除项目历史记录”移除所有保留的原始文件和受保护的副本，或删除 App 以从您的设备中移除其所有本地数据。

保留与删除

你的原始文件永不被覆盖。临时工作区文件、项目、占位符保管库与私密会话数据，各自都由你决定保留或删除；卸载 App 会完全清除其容器。
