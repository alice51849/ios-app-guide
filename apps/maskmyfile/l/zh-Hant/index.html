Mask My File

分享檔案而不過度分享——Mask My File 會在你的裝置上找出私密資訊，並在任何內容離手前永久遮蔽。

Mask My File · App Store
支援格式與遮蔽方式

可開啟圖片與 PDF，或文字、JSON、XML、HTML、CSV、TSV 與 RTF。視覺檔只提供永久實心遮蔽或直接移除；文字與結構化檔則可對每個選定的符合項套用完整遮罩、部分遮罩、佔位符、化名或移除。

先驗證，再信任

每次遮蔽都會另存一份全新副本。App 會重新開啟該副本，檢查檔案結構與每一處遮蔽，確認無誤才顯示 Private Ready；最終分享前仍請自行目視確認一次。

一次最多 100 個檔案

單一批次最多載入 100 個檔案，逐檔預覽、依需要手動畫框、跨檔進行精準文字搜尋，最後把整批受保護的檔案一起輸出。
