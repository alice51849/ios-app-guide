# Mochi DoneStamp: છેલ્લી વાર — તમે ક્યારે કર્યું તે યાદ રાખો | iOS App

તમે છેલ્લી વાર ચાદર ક્યારે બદલી, છોડને પાણી ક્યારે આપ્યું, પરિવારને ફોન, ફોટાનો બૅકઅપ કે ફિલ્ટર ક્યારે બદલ્યું? Mochi DoneStamp જીવનની ઘટનાઓની યાદ છે, બીજી ટુ-ડુ યાદી નથી. કામ પૂરું થાય ત્યારે એક ટૅપ ચોક્કસ સમયને સરળ ઇતિહાસમાં સાચવે છે. જરૂર હોય ત્યારે અંદાજિત અથવા ચોક્કસ ચક્ર ઉમેરો. આગામી તારીખ હંમેશા વાસ્તવિક પૂર્ણ થયેલા સમયથી ફરી ગણાય છે. • એક ટૅપમાં નોંધ અને Undo • જૂનો સમય ઉમેરો, બદલો અથવા કાઢો • મિનિટથી વર્ષ સુધી લવચીક અને ચોક્કસ ચક્ર • Done અને Snooze સાથે સ્થાનિક સૂચનાઓ • હોમ અને લૉક સ્ક્રીનના ઇન્ટરેક્ટિવ વિજેટ • Siri, Shortcuts, વૈકલ્પિક નોંધ અને ફોટા • અંતર આંકડા, સંપૂર્ણ બૅકઅપ અને JSON નિકાસ • Dark Mode, iPad, VoiceOver અને Dynamic Type મફતમાં એક સક્રિય ઘટના અને અમર્યાદિત ઇતિહાસ. Lifetime Pro એક વખત ખરીદીને અમર્યાદિત ઘટનાઓ અને તમામ સુવિધાઓ ખોલો. એકાઉન્ટ, જાહેરાત, વિશ્લેષણ કે ટ્રૅકિંગ નથી. મુખ્ય ડેટા ઉપકરણ પર રહે છે. કોઈ સબ્સ્ક્રિપ્શન નથી.
