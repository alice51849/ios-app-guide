# Mochi DoneStamp: അവസാനമായി — എപ്പോൾ ചെയ്തു? വീട്ടുജോലി | iOS App

iPhone Duo ഉപകരണത്തിനായി ഒപ്റ്റിമൈസ് ചെയ്തത്. ഏറ്റവും പുതിയ SDK ഉപയോഗിച്ച് നിർമ്മിച്ച ഈ ആപ്പ് ഉള്ളിലെ സ്ക്രീൻ മുഴുവൻ നിറയ്ക്കുന്നു, ഉപകരണം മടക്കിയാലും തുറന്നാലും ലേഔട്ട് സ്വയം ക്രമീകരിക്കുന്നു. അവസാനമായി കിടക്കവിരി മാറ്റിയത്, എസി ഫിൽട്ടർ വൃത്തിയാക്കിയത്, വണ്ടിയുടെ ഓയിൽ മാറ്റിയത് എപ്പോഴാണ്? ജോലി കഴിഞ്ഞാൽ ഒരിക്കൽ ടാപ്പ് ചെയ്യൂ; Mochi DoneStamp കൃത്യമായ സമയം രേഖപ്പെടുത്തും, കഴിഞ്ഞ തവണ മുതൽ എത്ര ദിവസമായെന്ന് എപ്പോഴും കാണാം. ഒരു ഇടവേള സജ്ജമാക്കിയാൽ സമയമാകുമ്പോൾ ഓർമ്മപ്പെടുത്തൽ ലഭിക്കും; അടുത്ത തീയതി എപ്പോഴും നിങ്ങൾ യഥാർഥത്തിൽ ചെയ്ത ദിവസം മുതലാണ് കണക്കാക്കുന്നത്. • ഒറ്റ ടാപ്പ് രേഖയും Undoയും • പഴയ സമയം ചേർക്കുക, തിരുത്തുക, നീക്കുക • മിനിറ്റു മുതൽ വർഷം വരെ വഴങ്ങുന്ന കൃത്യമായ താളങ്ങൾ • Done, Snooze പ്രവർത്തനങ്ങളുള്ള പ്രാദേശിക അറിയിപ്പുകൾ • ഹോം, ലോക്ക് സ്ക്രീൻ ഇന്ററാക്ടീവ് വിജറ്റുകൾ • Siri, Shortcuts, ഐച്ഛിക കുറിപ്പും ഫോട്ടോയും • ഇടവേള കണക്കുകൾ, പൂർണ്ണ ബാക്കപ്പ്, JSON കയറ്റുമതി • Dark Mode, iPad, VoiceOver, Dynamic Type • Apple Watch: കൈത്തണ്ടയിൽ നിന്നുതന്നെ അവസാന സമയം കാണാം, രേഖപ്പെടുത്താം സൗജന്യമായി ഒരു സജീവ സംഭവവും പരിധിയില്ലാത്ത ചരിത്രവും. Lifetime Pro ഒരിക്കൽ വാങ്ങി പരിധിയില്ലാത്ത സംഭവങ്ങളും എല്ലാ സവിശേഷതകളും തുറക്കുക. അക്കൗണ്ട്, പരസ്യം, അനലിറ്റിക്സ്, ട്രാക്കിംഗ് ഒന്നുമില്ല. പ്രധാന ഡാറ്റ ഉപകരണത്തിൽ തന്നെ. സബ്‌സ്‌ക്രിപ്ഷൻ ഇല്ല. iPhone Duo-യ്ക്കായി ഒപ്റ്റിമൈസ് ചെയ്തത്.
