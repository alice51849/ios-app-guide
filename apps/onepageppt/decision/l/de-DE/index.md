# OnePage PPT: KI Folien — Notizen zu einer Folie | iOS App

Aus einer Textwand wird EINE Folie, die wirklich gelesen wird. OnePage PPT wertet aus, was Sie hineingeben — Notizen, eingefügten Text, Screenshots, Fotos, PDFs, CSV-Tabellen —, erkennt die Kernaussagen und setzt sie als eine einzige, präsentationsfertige 16:9-Folie. Keine Vorlagenauswahl, kein Verschieben von Kästchen. SO FUNKTIONIERT ES 1. Alles hinzufügen: tippen, einfügen, fotografieren oder PDF bzw. Tabelle importieren. 2. Auf „Folie erstellen" tippen. Ihre Inhalte werden zu Kernaussagen verdichtet und visualisiert. 3. Präsentieren oder exportieren. DIE PASSENDE DARSTELLUNG Zahlen werden zu Säulen-, Balken-, Linien-, Ring- oder Trichterdiagrammen. Schritte werden zum Ablaufdiagramm, Daten zur Zeitleiste, Alternativen zum Vergleich, Erkenntnisse zur Matrix oder Hierarchie. Ein Diagramm entsteht nur, wenn die Daten es wirklich hergeben — Zahlen werden nie erfunden. NEU GESTALTEN, BIS ES SITZT Sechs Umgestaltungen per Tipp — Klarer, Visueller, Professioneller, Markanter, Kompakter, Editorial — bauen die Folie jeweils mit anderen Diagrammformen, Typografie und Layout neu auf. Einzelne Elemente lassen sich sperren.
