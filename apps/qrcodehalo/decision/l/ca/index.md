# QR Code Halo: Escàner — Obre a l'acte, revisa després | iOS App

Optimitzada per a l’iPhone Duo. Creada amb l’SDK més recent, l’app ocupa tota la pantalla interior i n’ajusta el disseny automàticament, tant amb el dispositiu plegat com obert. Escaneja codis QR i de barres en 20 formats, amb la càmera o des d'una foto, i actua a l'instant: els enllaços s'obren i els codis Wi-Fi mostren l'avís per connectar-s'hi. Et preocupa que un codi sigui una estafa? Obre'l a l'Historial i toca «Revisió de seguretat». Al mateix dispositiu, QR Code Halo descompon l'enllaç i marca els URL sospitosos, els enllaços sense HTTPS i els dominis que barregen alfabets com a segurs, amb precaució o bloquejats. Els codis javascript:, data: i file: no s'obren mai, i pots desactivar «Executa l'acció en escanejar» per revisar cada codi abans. També pots crear 9 tipus de codis QR, com ara de Wi-Fi, contactes i esdeveniments. Revisió de seguretat a l'historial Cada escaneig fora del mode per lots es desa en aquest dispositiu, tret que activis «No desar a l’historial». Obre un codi a l'Historial i toca Revisió de seguretat per revisar-lo amb dues eines locals. Local Payload Security Inspector Analitza al dispositiu el payload complet i separa scheme, host, path, query i fragment. Les regles deterministes mostren Safe, Caution o Blocked, findings transparents i una action disposition clara. No consulta reputació en línia ni fa servir puntuacions difuses; si no pot interpretar una acció, la manté bloquejada. QR Verification Desa un resultat com a referència local i compara un escaneig posterior per l'empremta SHA-256 completa, el format QR, el tipus de contingut, els components URL, el nivell de seguretat i l'acció. Batch Risk & Difference Audit Agrupa els duplicats exactes i els resultats amb el mateix host, i després compara dins d'un abast limitat els host que es poden confondre. El resum, el risc de cada element i tots els payload complets continuen llegibles. L'auditoria sencera es pot consultar. Què fa QR Code Halo Escaneja amb la càmera o reconeix codis a les fotos, diversos codis en un sol quadre 20 formats de codis de barres: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar i MSI Plessey Escaneig per lots amb supressió de duplicats, zoom i llanterna Crea codis QR de text, enllaç, Wi-Fi, contacte, correu, telèfon, SMS, ubicació i esdeveniment de calendari Historial il·limitat, sense cap límit d'entrades: preferits, cerca, filtres i ordenació per tipus, data, format, etiqueta o categoria Classificació automàtica al dispositiu, modificable a mà, i exportació de l'historial en CSV La còpia de seguretat i la restauració mostren el nombre real d'entrades, la mida i el període abans que decideixis Mode de privadesa amb neteja automàtica, desar a Fotos, imprimir, Share Extension i Dreceres de Siri QR Code Halo és una descàrrega gratuïta a l'App Store: tres escanejos gratuïts, els nou tipus de QR i un historial il·limitat amb preferits, cerca i filtres, sense cap límit d'entrades, sense anuncis i sense compte.
