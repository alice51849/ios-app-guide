# QR Code Halo: Scanner — Sofort öffnen, danach prüfen | iOS App

QR Code Halo handelt, sobald ein Code gelesen ist. Scanne mit der Kamera oder wähle ein Foto: Links öffnen sich im Browser, Codes für die Anmeldung mit Passkey und App-Links gehen direkt an iOS, Wi-Fi-Codes zeigen die iOS-Abfrage zum Verbinden, und Anrufe, Nachrichten, E-Mails und Orte öffnen sich in der passenden App. Kontakte und Termine öffnen den Hinzufügen-Bildschirm von iOS, den du bestätigst. Text wird mit einem kurzen Hinweis kopiert, und Codes mit javascript:, data: oder file: werden nie geöffnet. Willst du jeden Code zuerst prüfen, schalte in den Optionen „Nach Scan ausführen“ aus; der Stapel-Scan sammelt nur. Sicherheitscheck im Verlauf Jeder Scan außerhalb des Stapel-Scans wird auf diesem Gerät gesichert, außer „Nicht im Verlauf sichern“ ist aktiv. Öffne einen Code im Verlauf und tippe auf Sicherheitscheck, um ihn mit zwei lokalen Werkzeugen zu prüfen. Local Payload Security Inspector Zerlegt den vollständigen Payload direkt auf dem Gerät in scheme, host, path, query und fragment. Feste Regeln liefern Safe, Caution oder Blocked, nachvollziehbare findings und eine action disposition. Es gibt weder eine Online-Reputationsabfrage noch einen unscharfen Punktwert; eine nicht sicher interpretierbare Aktion bleibt blockiert. QR Verification Sichere ein Ergebnis als lokale Referenz und vergleiche einen späteren Scan anhand des vollständigen SHA-256-Fingerabdrucks, des QR-Formats, Inhaltstyps, der URL-Komponenten, Sicherheitsstufe und Aktion. Batch Risk & Difference Audit Bildet Gruppen aus exakt gleichen Inhalten und gemeinsamen host, danach werden leicht verwechselbare host in einem klar begrenzten Rahmen verglichen. Zusammenfassung, Einzelrisiko und jeder vollständige Payload bleiben gleichzeitig lesbar. Der komplette Audit kann eingesehen werden.
