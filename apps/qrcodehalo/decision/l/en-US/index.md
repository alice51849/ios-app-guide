# QR Code Halo: Scan & Create — Inspect. Decide. Act. | iOS App

QR Code Halo is built around Inspect, Decide, Act. It exposes what a code contains, explains the local finding, and leaves the final action to you. Scanning never auto-opens a destination. Local Payload Security Inspector Parses the complete payload on device into scheme, host, path, query and fragment. Deterministic rules return Safe, Caution or Blocked, transparent findings and an action disposition. No network reputation lookup and no fuzzy score are used; parsing uncertainty fails closed instead of enabling an action. QR Verification Save a result as a local reference, then compare a later scan by its complete SHA-256 fingerprint, QR format, content type, URL components, security level and action disposition. Batch Risk & Difference Audit Finds exact duplicate groups and host groups across a batch, then checks bounded lookalike hosts rather than claiming unlimited similarity detection. It shows the overall risk, each item's risk and every full decoded payload together. Reading the complete audit is available without an unlock.
