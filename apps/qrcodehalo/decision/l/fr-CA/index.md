# QR Code Halo : Scan sécurisé — Ouvre vite, vérifie ensuite | iOS App

QR Code Halo agit dès qu'un code est lu. Numérisez avec la caméra ou choisissez une photo : les liens s'ouvrent dans votre navigateur, les codes de connexion par clé d'accès et les liens d'app sont transmis directement à iOS, les codes Wi-Fi affichent la demande d'iOS pour se joindre au réseau, et les appels, messages, courriels et lieux s'ouvrent dans leur appli. Les contacts et les événements ouvrent l'écran d'ajout d'iOS pour que vous confirmiez. Le texte est copié avec une courte note, et les codes javascript:, data: ou file: ne sont jamais ouverts. Pour examiner chaque code d'abord, désactivez « Exécuter dès la lecture » dans Réglages; la numérisation par lot ne fait que collecter. Contrôle de sécurité dans l'historique Chaque code numérisé hors du mode par lot est enregistré sur cet appareil, sauf si « Ne pas enregistrer » est activé. Ouvrez un code dans l'Historique et touchez Contrôle de sécurité pour l'examiner avec deux outils locaux. Local Payload Security Inspector Décompose entièrement le payload sur l'appareil en scheme, host, path, query et fragment. Le résultat déterministe Safe, Caution ou Blocked vient avec des findings compréhensibles et une action disposition. Aucune réputation en ligne ni note imprécise n'est utilisée ; en cas d'analyse incomplète, l'action demeure bloquée. QR Verification Enregistrez un résultat comme référence locale, puis comparez une analyse ultérieure selon l'empreinte SHA-256 complète, le format QR, le type de contenu, les composants URL, le niveau de sécurité et l'action. Batch Risk & Difference Audit Classe un lot par doublons identiques et par host, puis vérifie les host ressemblants dans une portée volontairement limitée. Le sommaire des risques, le risque propre à chaque entrée et tous les payload complets restent visibles, et l'audit entier peut être consulté. Un parcours local, de la lecture du code à l'action Ce que fait QR Code Halo Numérisez à la caméra ou reconnaissez les codes sur vos photos, plusieurs codes par image 20 formats de codes-barres : QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar et MSI Plessey Scan par lot avec suppression des doublons, zoom et lampe de poche Créez des QR texte, lien, Wi-Fi, contact, courriel, téléphone, SMS, position et événement de calendrier Historique illimité, sans plafond : favoris, recherche, filtres et tri par type, date, format, étiquette ou catégorie Classement automatique sur l'appareil, modifiable à la main, et export de l'historique en CSV La sauvegarde comme la restauration affichent le nombre réel d'éléments, la taille et la période avant que vous décidiez Mode confidentiel avec effacement automatique, enregistrement dans Photos, impression, extension de partage et raccourcis Siri Chaque appareil offre trois lectures réussies partagées entre la caméra et les photos; un échec, une annulation ou une permission refusée ne compte pas. Les neuf types de création QR, l'historique local illimité et la consultation complète de l'audit restent accessibles. L'achat unique et optionnel Lifetime Pro ajoute les lectures illimitées, l'enregistrement et les actions par lot, la création par lot et le CSV, la confirmation des sauvegardes et restaurations, les exports PNG, PDF et SVG haute résolution et les styles Aurora personnalisés. Il n'y a aucun abonnement. Pour du soutien : hourstag.app@gmail.com Ce n'est pas une appli de numérisation de documents. QR Code Halo ne numérise pas des pages, ne fait pas d'OCR et ne tient pas de bibliothèque de documents PDF; le PDF exporté contient seulement le visuel QR. Share Extension accepte une URL ou du texte brut pour créer un QR. Optimisée pour iPhone Duo.
