# QR Code Halo : Scan sécurisé — Ouvre aussitôt, contrôle après | iOS App

QR Code Halo agit dès qu'il lit un code. Scannez avec la caméra ou choisissez une photo : les liens s'ouvrent dans votre navigateur, les codes de connexion par clé d'accès et les liens d'app passent directement à iOS, les codes Wi-Fi affichent la demande d'iOS pour rejoindre le réseau, et appels, messages, e-mails et lieux s'ouvrent dans leur app. Les contacts et les événements ouvrent l'écran d'ajout d'iOS, que vous validez. Le texte est copié avec une courte note, et les codes javascript:, data: ou file: ne sont jamais ouverts. Pour vérifier chaque code d'abord, désactivez « Exécuter dès la lecture » dans Réglages ; le scan par lot se contente de collecter. Contrôle de sécurité dans l'historique Chaque scan hors mode par lot est enregistré sur cet appareil, sauf si « Ne pas enregistrer » est activé. Ouvrez un code dans l'Historique et touchez Contrôle de sécurité pour le revoir avec deux outils locaux. Local Payload Security Inspector Analyse localement le payload complet et détaille scheme, host, path, query et fragment. Des règles déterministes affichent Safe, Caution ou Blocked, des findings transparents et l'action disposition. Aucun service de réputation en ligne ni score flou n'intervient ; une action impossible à interpréter reste bloquée. QR Verification Enregistrez un résultat comme référence locale, puis comparez une analyse ultérieure selon l'empreinte SHA-256 complète, le format QR, le type de contenu, les composants URL, le niveau de sécurité et l'action. Batch Risk & Difference Audit Regroupe les doublons exacts et les résultats partageant le même host, puis compare dans un périmètre borné les host qui peuvent se ressembler. Le résumé, le risque de chaque élément et chaque payload intégral restent lisibles. La consultation complète de l'audit est accessible. Un parcours local, du scan à l'action Ce que fait QR Code Halo Scannez à la caméra ou reconnaissez les codes sur vos photos, plusieurs codes par image 20 formats de codes-barres : QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar et MSI Plessey Scan par lot avec suppression des doublons, zoom et lampe torche Créez des QR texte, lien, Wi-Fi, contact, e-mail, téléphone, SMS, position et événement de calendrier Historique illimité, sans plafond : favoris, recherche, filtres et tri par type, date, format, étiquette ou catégorie Classement automatique sur l'appareil, modifiable à la main, et export de l'historique en CSV La sauvegarde comme la restauration affichent le nombre réel d'éléments, la taille et la période avant que vous décidiez Mode confidentiel avec effacement automatique, enregistrement dans Photos, impression, extension de partage et raccourcis Siri Commencez avec trois scans réussis par appareil, partagés entre l'appareil photo et l'importation d'images. Un échec, une annulation ou un refus d'autorisation n'est pas décompté. Les neuf créations de QR, l'historique local sans limite et la lecture complète de l'audit sont disponibles.
