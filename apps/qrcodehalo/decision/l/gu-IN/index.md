# QR Code Halo: સ્કેન અને બનાવો — તરત ખોલો, પછી તપાસો | iOS App

QR Code Halo કોડ વાંચતાં જ કામ કરી દે છે. કૅમેરાથી સ્કૅન કરો અથવા ફોટો પસંદ કરો: લિંક તમારા બ્રાઉઝરમાં ખૂલે છે, પાસકીથી સાઇન ઇન કરવાના કોડ અને ઍપ લિંક સીધા iOS પાસે જાય છે, Wi-Fi કોડ પર iOS નો જોડાવાનો સંદેશ દેખાય છે, અને કૉલ, મેસેજ, ઇમેઇલ તથા સ્થળો પોતપોતાની ઍપમાં ખૂલે છે. સંપર્કો અને ઇવેન્ટ iOS ની ઉમેરવાની સ્ક્રીન ખોલે છે, જ્યાં તમે જાતે પુષ્ટિ કરો છો. ટેક્સ્ટ ટૂંકી નોંધ સાથે કૉપિ થાય છે, અને javascript:, data: કે file: વાળા કોડ ક્યારેય ખોલાતા નથી. દરેક કોડ પહેલાં તપાસવો હોય તો સેટિંગ્સમાં ‘સ્કૅન પછી સીધું ચલાવો’ બંધ કરો; બેચ સ્કેન ફક્ત એકત્ર કરે છે. ઇતિહાસમાં સુરક્ષા તપાસ ‘ઇતિહાસમાં સાચવશો નહીં’ ચાલુ ન હોય તો બેચ સ્કેન સિવાયનો દરેક સ્કૅન આ જ ડિવાઇસ પર સચવાય છે. ઇતિહાસમાં કોઈ પણ કોડ ખોલો અને સુરક્ષા તપાસ પર ટૅપ કરો, જેથી બે લોકલ ટૂલથી તેને ફરી જોઈ શકો. Local Payload Security Inspector આખું payload ઉપકરણ પર જ વિશ્લેષિત કરીને scheme, host, path, query અને fragment અલગ બતાવે છે. નક્કી નિયમો Safe, Caution અથવા Blocked, પારદર્શક findings અને action disposition આપે છે. Online reputation કે અસ્પષ્ટ score વપરાતો નથી; સુરક્ષિત રીતે સમજાય નહીં એવી ક્રિયા blocked રહે છે. QR Verification પરિણામને સ્થાનિક સંદર્ભ તરીકે સાચવો, પછી સંપૂર્ણ SHA-256 ફિંગરપ્રિન્ટ, QR ફોર્મેટ, સામગ્રી પ્રકાર, URL ઘટકો, સુરક્ષા સ્તર અને ક્રિયા પ્રમાણે પછીનું સ્કૅન સરખાવો. Batch Risk & Difference Audit ચોક્કસ સમાન પરિણામો અને સમાન host ધરાવતા પરિણામોના જૂથ બનાવે છે, પછી સ્પષ્ટ મર્યાદામાં ગૂંચવણ પેદા કરી શકે એવા host સરખાવે છે. સારાંશ, દરેક itemનું જોખમ અને બધા સંપૂર્ણ payload વાંચી શકાય છે. આખું audit જોઈ શકાય છે. QR Code Halo શું કરે છે કૅમેરાથી સ્કેન કરો કે ફોટામાંના કોડ ઓળખો, એક જ ફ્રેમમાં અનેક કોડ 20 બારકોડ ફોર્મેટ: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar અને MSI Plessey ડુપ્લિકેટ અટકાવ, ઝૂમ અને ફ્લેશલાઇટ સાથે બેચ સ્કેનિંગ ટેક્સ્ટ, લિંક, Wi-Fi, સંપર્ક, ઈમેલ, ફોન, SMS, સ્થાન અને કૅલેન્ડર ઇવેન્ટના QR કોડ બનાવો અમર્યાદિત ઇતિહાસ, એન્ટ્રીની કોઈ મર્યાદા નથી: મનપસંદ, શોધ, પ્રકાર, તારીખ, ફોર્મેટ, ટૅગ કે શ્રેણી પ્રમાણે ફિલ્ટર અને સૉર્ટિંગ ડિવાઇસ પર જ આપોઆપ વર્ગીકરણ, જે હાથે બદલી શકાય, અને ઇતિહાસનું CSV એક્સપોર્ટ બેકઅપ અને રિસ્ટોર બંને નિર્ણય લેતાં પહેલાં ખરી સંખ્યા, કદ અને તારીખની અવધિ બતાવે છે ઑટોમૅટિક ક્લિયરિંગ સાથેનો પ્રાઇવસી મોડ, Photos માં સેવ, પ્રિન્ટ, Share Extension અને Siri Shortcuts QR Code Halo એ App Store પરથી મફત ડાઉનલોડ છે: ત્રણ મફત સ્કેન, બધા નવ QR પ્રકાર અને મનપસંદ, શોધ તથા ફિલ્ટર સાથે અમર્યાદિત ઇતિહાસ, એન્ટ્રીની કોઈ મર્યાદા વગર, જાહેરાત અને એકાઉન્ટ વગર. એક વૈકલ્પિક Lifetime Pro ખરીદી અમર્યાદિત સ્કેનિંગ, સ્કેન કરેલા બેચને સાચવવાનું અને ખોલવાનું, બેચ ક્રિએશન અને બેચ CSV, બેકઅપ અને રિસ્ટોર, હાઈ રિઝોલ્યુશન એક્સપોર્ટ અને કસ્ટમ Aurora સ્ટાઇલ ઉમેરે છે, અને તે કાયમ માટે તમારી રહે છે. કોઈ સબ્સ્ક્રિપ્શન નથી. કોઈ કોડ સ્કેન ન થાય, કે કોઈ ફીચરની ઇચ્છા હોય: hourstag.app@gmail.com આ document scanner નથી. તે પાનાં scan કરતું નથી, OCR ચલાવતું નથી અને PDF document library રાખતું નથી; PDF exportમાં ફક્ત QR artwork હોય છે.
