# QR Code Halo: סריקה ויצירה — פותחים מיד, בודקים אחר כך | iOS App

מותאם למכשיר iPhone Duo. האפליקציה נבנתה עם ערכת הפיתוח העדכנית ביותר, ממלאת את כל המסך הפנימי ומתאימה את הפריסה אוטומטית, כשהמכשיר מקופל או פתוח. סורקים קודי QR וברקודים ב-20 פורמטים, במצלמה או מתמונה, והפעולה מתבצעת מיד: קישורים נפתחים, וקודי Wi-Fi מציגים את בקשת ההצטרפות לרשת. חוששים שקוד הוא הונאה? פותחים אותו בהיסטוריה ומקישים על "בדיקת אבטחה". במכשיר עצמו QR Code Halo מפרק את הקישור לחלקיו ומסמן כתובות URL חשודות, קישורים בלי HTTPS ודומיינים שמערבבים אלפביתים כבטוחים, דורשים זהירות או חסומים. קודים מסוג javascript:, data: ו-file: אף פעם לא נפתחים, ואפשר לכבות את "ביצוע הפעולה אחרי הסריקה" כדי לבדוק כל קוד קודם. אפשר גם ליצור 9 סוגים של קודי QR, כמו Wi-Fi, אנשי קשר ואירועים. בדיקת אבטחה בהיסטוריה כל סריקה שאינה באצווה נשמרת במכשיר הזה, אלא אם "לא לשמור בהיסטוריה" מופעל. פתחו קוד בהיסטוריה והקישו על בדיקת אבטחה כדי לבחון אותו בשני כלים מקומיים. Local Payload Security Inspector מנתח במכשיר את כל ה-payload ומציג בנפרד scheme, host, path, query ו-fragment. כללים דטרמיניסטיים מחזירים Safe, Caution או Blocked, לצד findings שקופים ו-action disposition. אין שימוש במוניטין מקוון או בציון עמום; פעולה שלא ניתן לפרש בבטחה נשארת חסומה. QR Verification שמרו תוצאה כהפניה מקומית, ולאחר מכן השוו סריקה מאוחרת לפי טביעת האצבע המלאה מסוג SHA-256, פורמט QR, סוג התוכן, רכיבי ה-URL, רמת האבטחה והפעולה. Batch Risk & Difference Audit מקבץ תוצאות זהות לחלוטין ותוצאות בעלות אותו host, ואז משווה host שעלולים להיראות דומים בטווח מוגדר ומוגבל. הסיכום, הסיכון של כל פריט וכל payload מלא נשארים קריאים. אפשר לעיין בביקורת כולה. מה QR Code Halo עושה סריקה במצלמה או זיהוי קודים בתמונות, כמה קודים בפריים אחד 20 פורמטים של ברקוד: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar ו-MSI Plessey סריקה באצווה עם סינון כפילויות, זום ופנס יצירת קודי QR של טקסט, קישור, Wi-Fi, איש קשר, אימייל, טלפון, SMS, מיקום ואירוע ביומן היסטוריה ללא הגבלה ובלי תקרת רשומות: מועדפים, חיפוש, סינון ומיון לפי סוג, תאריך, פורמט, תגית או קטגוריה סיווג אוטומטי במכשיר שאפשר לשנות ידנית, וייצוא ההיסטוריה ל-CSV גיבוי ושחזור מציגים את מספר הרשומות האמיתי, הגודל וטווח התאריכים לפני שמחליטים מצב פרטיות עם ניקוי אוטומטי, שמירה לתמונות, הדפסה, Share Extension וקיצורי Siri QR Code Halo היא הורדה חינמית מה-App Store: שלוש סריקות חינם, כל תשעת סוגי ה-QR והיסטוריה ללא הגבלה עם מועדפים, חיפוש וסינון, בלי תקרת רשומות, בלי פרסומות ובלי חשבון. רכישת Lifetime Pro אופציונלית אחת מוסיפה סריקה ללא הגבלה, שמירה ופתיחה של אצוות סרוקות, יצירה באצווה ו-CSV של אצווה, גיבוי ושחזור, ייצוא ברזולוציה גבוהה ועיצובי Aurora מותאמים, והיא שלכם לתמיד. בלי מינוי. קוד שלא נסרק, או פיצ'ר שהייתם רוצים: hourstag.app@gmail.com זה אינו סורק מסמכים. האפליקציה לא סורקת דפים, לא מפעילה OCR ולא מנהלת ספריית מסמכי PDF; ייצוא PDF כולל רק גרפיקת QR. ‏Share Extension יוצר קוד מ-URL או מטקסט פשוט. מותאם ל-iPhone Duo.
