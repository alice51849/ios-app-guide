# QR Code Halo: סריקה ויצירה — בודקים לפני שפועלים | iOS App

QR Code Halo שומר על סדר מכוון: בודקים את התוכן שפוענח, שוקלים את הממצאים הגלויים ורק אז בוחרים פעולה. עצם זיהוי הקוד לעולם לא פותח יעד אוטומטית. Local Payload Security Inspector מנתח במכשיר את כל ה-payload ומציג בנפרד scheme, host, path, query ו-fragment. כללים דטרמיניסטיים מחזירים Safe, Caution או Blocked, לצד findings שקופים ו-action disposition. אין שימוש במוניטין מקוון או בציון עמום; פעולה שלא ניתן לפרש בבטחה נשארת חסומה. QR Verification שמרו תוצאה כהפניה מקומית, ולאחר מכן השוו סריקה מאוחרת לפי טביעת האצבע המלאה מסוג SHA-256, פורמט QR, סוג התוכן, רכיבי ה-URL, רמת האבטחה והפעולה. Batch Risk & Difference Audit מקבץ תוצאות זהות לחלוטין ותוצאות בעלות אותו host, ואז משווה host שעלולים להיראות דומים בטווח מוגדר ומוגבל. הסיכום, הסיכון של כל פריט וכל payload מלא נשארים קריאים. אפשר לעיין בביקורת כולה. מה QR Code Halo עושה סריקה במצלמה או זיהוי קודים בתמונות, כמה קודים בפריים אחד תצוגה מקדימה בטוחה לכל תוצאה: התוכן המלא, סכימת הקישור והדומיין, ורמזים לפורמטים חשודים 20 פורמטים של ברקוד: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar ו-MSI Plessey סריקה באצווה עם סינון כפילויות, זום ופנס יצירת קודי QR של טקסט, קישור, Wi-Fi, איש קשר, אימייל, טלפון, SMS, מיקום ואירוע ביומן היסטוריה ללא הגבלה ובלי תקרת רשומות: מועדפים, חיפוש, סינון ומיון לפי סוג, תאריך, פורמט, תגית או קטגוריה סיווג אוטומטי במכשיר שאפשר לשנות ידנית, וייצוא ההיסטוריה ל-CSV גיבוי ושחזור מציגים את מספר הרשומות האמיתי, הגודל וטווח התאריכים לפני שמחליטים Lifetime Pro: סריקה ללא הגבלה, שמירת אצווה סרוקה בהיסטוריה ופתיחת התוצאות שלה, יצירה באצווה ו-CSV של אצווה, ביצוע גיבוי או שחזור, ייצוא PNG, PDF ו-SVG ברזולוציה גבוהה ועיצובי Aurora מותאמים מצב פרטיות עם ניקוי אוטומטי, שמירה לתמונות, הדפסה, Share Extension וקיצורי Siri QR Code Halo היא הורדה חינמית מה-App Store: שלוש סריקות חינם, כל תשעת סוגי ה-QR והיסטוריה ללא הגבלה עם מועדפים, חיפוש וסינון, בלי תקרת רשומות, בלי פרסומות ובלי חשבון. רכישת Lifetime Pro אופציונלית אחת מוסיפה סריקה ללא הגבלה, שמירה ופתיחה של אצוות סרוקות, יצירה באצווה ו-CSV של אצווה, גיבוי ושחזור, ייצוא ברזולוציה גבוהה ועיצובי Aurora מותאמים, והיא שלכם לתמיד. בלי מינוי. קוד שלא נסרק, או פיצ'ר שהייתם רוצים: hourstag.app@gmail.com זה אינו סורק מסמכים. האפליקציה לא סורקת דפים, לא מפעילה OCR ולא מנהלת ספריית מסמכי PDF; ייצוא PDF כולל רק גרפיקת QR. ‏Share Extension יוצר קוד מ-URL או מטקסט פשוט. נתוני Wi-Fi, איש קשר ויומן ללא actionURL בטוח נשארים בתצוגה מקדימה ואינם מוצגים כפעולה ישירה.
