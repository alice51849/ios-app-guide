Inspector पूरा payload डिवाइस पर ही समझकर scheme, host, path, query और fragment अलग-अलग दिखाता है। तय नियम Safe, Caution या Blocked, साफ़ findings और action disposition देते हैं। Online reputation या धुँधला score उपयोग नहीं होता; सुरक्षित रूप से न समझ आने वाली कार्रवाई blocked रहती है। QR Verification किसी परिणाम को स्थानीय संदर्भ के रूप में सहेजें, फिर पूरे SHA-256 फ़िंगरप्रिंट, QR फ़ॉर्मैट, कॉन्टेंट प्रकार, URL घटकों, सुरक्षा स्तर और कार्रवाई के आधार पर अगला स्कैन मिलाएँ। Batch Risk & Difference Audit बिल्कुल समान नतीजों और एक ही host वाले नतीजों के समूह बनाता है, फिर निश्चित सीमा में भ्रम पैदा करने वाले समान host की तुलना करता है। सारांश, हर item का जोखिम और सभी पूरे payload पढ़े जा सकते हैं। पूरा audit देखने के लिए उपलब्ध रहता है। QR Code Halo क्या करता है कैमरे से स्कैन कीजिए या PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar और MSI Plessey डुप्लिकेट रोक, ज़ूम और फ़्लैशलाइट के साथ बैच स्कैनिंग
