# QR Code Halo: QR코드 바로 실행 — 저장된 링크, 기기 안에서 보안 검사 | iOS App

iPhone Duo에 최적화되었습니다. 최신 개발 도구로 빌드되어 안쪽 디스플레이 전체를 가득 채우며, 접거나 펼쳐도 레이아웃이 자동으로 조정됩니다. QR코드와 바코드를 20가지 형식으로 읽고 바로 실행합니다. 카메라나 사진으로 스캔하면 링크는 바로 열리고, Wi-Fi 코드는 네트워크 연결 안내가 뜹니다. 혹시 사기 코드일까 걱정된다면 기록에서 열고 ‘보안 검사’를 누르세요. QR Code Halo가 기기 안에서 링크를 나눠 살펴보고 의심스러운 URL, HTTPS가 아닌 링크, 서로 다른 문자를 섞은 도메인을 찾아 안전·주의·차단으로 알려 줍니다. javascript:, data:, file: 코드는 절대 열지 않으며, ‘스캔 후 바로 실행’을 끄면 모든 코드를 먼저 확인하고 열 수 있습니다. Wi-Fi, 연락처, 일정 등 9가지 QR코드도 만들 수 있습니다. 기록에서 보안 검사 ‘기록에 저장 안 함’을 켜지 않았다면 일괄 스캔을 제외한 모든 스캔은 이 기기에 저장됩니다. 기록에서 코드를 열고 ‘보안 검사’를 탭하면 아래 두 가지 로컬 도구로 다시 확인할 수 있습니다. Local Payload Security Inspector 전체 payload를 기기에서 분석해 scheme, host, path, query, fragment를 각각 보여 줍니다. Safe, Caution, Blocked의 재현 가능한 판정과 투명한 findings, action disposition도 함께 표시합니다. 인터넷 평판이나 모호한 점수는 쓰지 않으며, 해석에 실패한 동작은 차단 상태로 둡니다. QR Verification 결과를 기기 내 참조로 저장한 다음 전체 SHA-256 지문, QR 형식, 콘텐츠 유형, URL 구성 요소, 보안 수준 및 동작을 기준으로 이후 스캔과 비교합니다. Batch Risk & Difference Audit 여러 결과를 완전히 같은 내용과 host별로 묶고, 정해진 범위 안에서 혼동하기 쉬운 유사 host를 비교합니다. 전체 위험 요약과 각 항목의 위험, 원문 payload를 모두 읽을 수 있으며 감사 결과 열람은 제한하지 않습니다. QR Code Halo가 하는 일 카메라로 스캔하거나 사진 속 코드를 인식, 한 화면의 여러 코드도 한 번에 20가지 바코드 형식: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar, MSI Plessey 중복을 자동으로 거르는 일괄 스캔, 줌과 손전등 텍스트, 링크, Wi-Fi, 연락처, 이메일, 전화, SMS, 위치, 캘린더 일정 QR 코드 생성 개수 제한 없는 무제한 기록: 즐겨찾기, 검색, 유형·날짜·형식·태그·분류별 필터와 정렬 기기 안에서 자동으로 분류하고 직접 바꿀 수도 있으며, 기록을 CSV로 내보내기 백업도 복원도 실제 개수와 용량, 기간을 먼저 미리 보고 결정 기록을 자동으로 지우는 프라이버시 모드, 사진 앱 저장, 프린트, 공유 확장, Siri 단축어 QR Code Halo는 App Store에서 무료로 내려받을 수 있습니다. 스캔은 무료로 3회, 9가지 QR 코드 생성은 전부 사용할 수 있고 기록은 개수 제한 없이 즐겨찾기와 검색, 필터까지 그대로 쓸 수 있으며, 광고도 계정도 없습니다. 선택 사항인 Lifetime Pro는 한 번 결제하면 무제한 스캔, 일괄 저장과 결과 열기, CSV 일괄 생성과 일괄 내보내기, 백업과 복원, 고해상도 내보내기, 커스텀 Aurora 스타일이 영원히 내 것이 됩니다. 구독은 없습니다. 안 읽히는 코드가 있거나 바라는 기능이 있다면 알려주세요: hourstag.app@gmail.com 문서 스캐너가 아닙니다. 종이를 스캔하거나 OCR을 수행하거나 PDF 문서 보관함을 관리하지 않습니다.
