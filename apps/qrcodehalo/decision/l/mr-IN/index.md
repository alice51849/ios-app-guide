# QR Code Halo: स्कॅन, तयार करा — कृतीपूर्वी धोका तपासा | iOS App

QR Code Halo क्रम तुमच्या हातात ठेवतो: decode केलेला मजकूर पाहा, दिसणारे findings समजा आणि मगच कृती निवडा. Code ओळखला म्हणून काहीही आपोआप उघडत नाही. Local Payload Security Inspector संपूर्ण payload डिव्हाइसवरच विश्लेषित करून scheme, host, path, query आणि fragment वेगळे दाखवतो. ठरावीक नियम Safe, Caution किंवा Blocked, स्पष्ट findings आणि action disposition देतात. Online reputation किंवा धूसर score वापरला जात नाही; सुरक्षितरीत्या न समजणारी कृती blocked राहते. QR Verification निकाल स्थानिक संदर्भ म्हणून सेव्ह करा, नंतर संपूर्ण SHA-256 फिंगरप्रिंट, QR फॉरमॅट, कॉन्टेंट प्रकार, URL घटक, सुरक्षा स्तर आणि कृतीनुसार पुढील स्कॅनची तुलना करा. Batch Risk & Difference Audit अगदी समान निकाल आणि समान host असलेले निकाल गटात ठेवतो, नंतर ठरावीक मर्यादेत गोंधळात टाकणाऱ्या सारख्या host ची तुलना करतो. सारांश, प्रत्येक item चा धोका आणि सर्व पूर्ण payload वाचता येतात. संपूर्ण audit पाहता येतो.
