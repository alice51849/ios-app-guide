# QR Code Halo: ஸ்கேன் உருவாக்கு — உடனே திறக்கும், பிறகு சோதனை | iOS App

QR Code Halo குறியீட்டைப் படித்த உடனே செயல்படுகிறது. கேமராவில் ஸ்கேன் செய்யுங்கள் அல்லது படத்தைத் தேர்ந்தெடுங்கள்: இணைப்புகள் உங்கள் உலாவியில் திறக்கும், கடவுச்சாவி மூலம் உள்நுழையும் குறியீடுகளும் ஆப் இணைப்புகளும் நேராக iOS-க்குச் செல்லும், Wi-Fi குறியீடுகள் iOS-இன் இணைவுக் கோரிக்கையைக் காட்டும், அழைப்புகள், செய்திகள், மின்னஞ்சல், இடங்கள் அவற்றின் ஆப்களில் திறக்கும். தொடர்புகளும் நிகழ்வுகளும் iOS-இன் சேர்க்கும் திரையைத் திறக்கும், அங்கே நீங்களே உறுதிசெய்வீர்கள். உரை ஒரு சிறு குறிப்புடன் நகலெடுக்கப்படும்; javascript:, data:, file: குறியீடுகள் ஒருபோதும் திறக்கப்படாது. ஒவ்வொரு குறியீட்டையும் முதலில் சரிபார்க்க விரும்பினால், அமைப்புகளில் ‘ஸ்கேன் செய்ததும் இயக்கு’ என்பதை அணையுங்கள்; தொகுதி ஸ்கேன் சேகரிக்க மட்டுமே செய்யும். வரலாற்றில் பாதுகாப்புச் சோதனை ‘வரலாறு சேமிக்க வேண்டாம்’ இயக்கத்தில் இல்லையெனில், தொகுதி ஸ்கேன் தவிர ஒவ்வொரு ஸ்கேனும் இந்தச் சாதனத்திலேயே சேமிக்கப்படும். வரலாற்றில் எந்தக் குறியீட்டையும் திறந்து பாதுகாப்புச் சோதனையைத் தட்டினால், இரண்டு உள்ளூர் கருவிகளால் அதை மீண்டும் பார்க்கலாம். Local Payload Security Inspector முழு payload-ஐ சாதனத்திலேயே ஆய்வு செய்து scheme, host, path, query, fragment ஆகியவற்றைத் தனித்தனியாகக் காட்டுகிறது. நிலையான விதிகள் Safe, Caution அல்லது Blocked, தெளிவான findings, action disposition ஆகியவற்றை வழங்குகின்றன. Online reputation அல்லது தெளிவற்ற score பயன்படுத்தப்படாது; பாதுகாப்பாகப் புரியாத செயல் blocked ஆகவே இருக்கும். QR Verification ஒரு முடிவை உள்ளூர் மேற்கோளாகச் சேமித்து, பின்னர் முழு SHA-256 கைரேகை, QR வடிவம், உள்ளடக்க வகை, URL கூறுகள், பாதுகாப்பு நிலை மற்றும் செயல் ஆகியவற்றின் அடிப்படையில் அடுத்த ஸ்கேனை ஒப்பிடவும். Batch Risk & Difference Audit முற்றிலும் ஒரே முடிவுகளையும் ஒரே host கொண்ட முடிவுகளையும் குழுவாக்கி, பின்னர் தெளிவான எல்லைக்குள் குழப்பமளிக்கும் ஒத்த host-களை ஒப்பிடுகிறது. சுருக்கம், ஒவ்வொரு item-இன் ஆபத்து, எல்லா முழு payload-களும் படிக்க முடியும். முழு audit-ஐ பார்க்கலாம். QR Code Halo என்ன செய்கிறது கேமராவில் ஸ்கேன் செய்யுங்கள் அல்லது புகைப்படங்களில் code-களை அடையாளம் காணுங்கள், ஒரே ஃப்ரேமில் பல code-கள் 20 பார்கோடு வடிவங்கள்: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar மற்றும் MSI Plessey நகல் தவிர்ப்பு, zoom மற்றும் டார்ச் உடன் batch ஸ்கேன் உரை, லிங்க், Wi-Fi, தொடர்பு, மின்னஞ்சல், தொலைபேசி, SMS, இருப்பிடம் மற்றும் காலெண்டர் நிகழ்வு QR உருவாக்குங்கள் வரம்பற்ற வரலாறு, பதிவுகளுக்கு உச்சவரம்பு இல்லை: பிடித்தவை, தேடல், வகை, தேதி, வடிவம், டேக் அல்லது பிரிவு அடிப்படையில் வடிகட்டலும் வரிசைப்படுத்தலும் சாதனத்திலேயே தானியங்கி வகைப்படுத்தல், கையால் மாற்றவும் முடியும், மேலும் வரலாற்றை CSV ஆக எக்ஸ்போர்ட் பேக்கப்பும் மீட்டமைப்பும் முடிவெடுக்கும் முன் உண்மையான எண்ணிக்கை, அளவு மற்றும் தேதி வரம்பைக் காட்டுகின்றன தானியங்கி அழிப்புடன் privacy mode, Photos-இல் சேமிப்பு, பிரிண்ட், Share Extension மற்றும் Siri Shortcuts QR Code Halo App Store-இல் இலவச பதிவிறக்கம்: மூன்று இலவச ஸ்கேன்கள், ஒன்பது QR வகைகள் அனைத்தும், பிடித்தவை, தேடல் மற்றும் வடிகட்டிகளுடன் வரம்பற்ற வரலாறு, பதிவுகளுக்கு எந்த உச்சவரம்பும் இல்லாமல், விளம்பரமும் கணக்கும் இல்லாமல். விருப்பப்பட்ட ஒரே ஒரு Lifetime Pro வாங்குதல் வரம்பற்ற ஸ்கேனிங்கையும், ஸ்கேன் செய்த batch-ஐச் சேமிப்பதையும் திறப்பதையும், batch உருவாக்கம் மற்றும் batch CSV, பேக்கப் மற்றும் மீட்டமைப்பு, உயர் தெளிவுத்திறன் எக்ஸ்போர்ட் மற்றும் custom Aurora ஸ்டைல்களைச் சேர்க்கிறது; அது என்றென்றும் உங்களுடையது. சந்தா இல்லை. ஸ்கேன் ஆகாத ஒரு code, அல்லது இருந்தால் நன்றாக இருக்கும் என நினைக்கும் அம்சம்: hourstag.app@gmail.com இது document scanner அல்ல. பக்கங்களை scan செய்யாது, OCR செய்யாது, PDF document library-ஐ பராமரிக்காது; PDF export-ல் QR artwork மட்டும் இருக்கும்.
