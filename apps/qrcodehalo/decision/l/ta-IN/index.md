Code அறியப்பட்டதால் மட்டும் எதுவும் தானாகத் திறக்காது. Local Payload Security Inspector முழு payload-ஐ சாதனத்திலேயே ஆய்வு செய்து scheme, host, path, query, fragment ஆகியவற்றைத் தனித்தனியாகக் காட்டுகிறது. நிலையான விதிகள் Safe, Caution அல்லது Blocked, தெளிவான findings, action disposition ஆகியவற்றை வழங்குகின்றன. Online reputation அல்லது தெளிவற்ற score பயன்படுத்தப்படாது; பாதுகாப்பாகப் புரியாத செயல் blocked ஆகவே இருக்கும். Batch Risk & Difference Audit முற்றிலும் ஒரே முடிவுகளையும் ஒரே host கொண்ட முடிவுகளையும் குழுவாக்கி, பின்னர் தெளிவான எல்லைக்குள் குழப்பமளிக்கும் ஒத்த host-களை ஒப்பிடுகிறது. சுருக்கம், ஒவ்வொரு item-இன் ஆபத்து, எல்லா முழு payload-களும் படிக்க முடியும். முழு audit-ஐ பார்க்கலாம்.
