# QR Code Halo: స్కాన్, సృష్టి — వెంటనే తెరవండి, తర్వాత తనిఖీ | iOS App

QR Code Halo కోడ్ చదవగానే పని చేసేస్తుంది. కెమెరాతో స్కాన్ చేయండి లేదా ఫోటో ఎంచుకోండి: లింక్‌లు మీ బ్రౌజర్‌లో తెరుచుకుంటాయి, పాస్‌కీతో సైన్ ఇన్ కోడ్‌లు, యాప్ లింక్‌లు నేరుగా iOSకు వెళ్తాయి, Wi-Fi కోడ్‌లకు iOS చేరిక అభ్యర్థన కనిపిస్తుంది, కాల్‌లు, మెసేజ్‌లు, ఈమెయిల్, ప్రదేశాలు వాటి యాప్‌లలో తెరుచుకుంటాయి. కాంటాక్ట్‌లు, ఈవెంట్‌లు iOS జోడింపు స్క్రీన్‌ను తెరుస్తాయి, అక్కడ మీరే నిర్ధారిస్తారు. టెక్స్ట్ ఒక చిన్న నోట్‌తో కాపీ అవుతుంది, javascript:, data: లేదా file: కోడ్‌లు ఎప్పుడూ తెరవబడవు. ప్రతి కోడ్‌ను ముందుగా చూడాలనుకుంటే సెట్టింగ్‌లలో ‘స్కాన్ తర్వాత అమలు’ ఆఫ్ చేయండి; బ్యాచ్ స్కాన్ సేకరిస్తుంది మాత్రమే. చరిత్రలో భద్రతా తనిఖీ ‘చరిత్రలో సేవ్ చేయవద్దు’ ఆన్‌లో లేకపోతే బ్యాచ్ స్కాన్ కాకుండా ప్రతి స్కాన్ ఈ పరికరంలోనే సేవ్ అవుతుంది. చరిత్రలో ఏ కోడ్‌నైనా తెరిచి భద్రతా తనిఖీని నొక్కితే, రెండు లోకల్ టూల్‌లతో దాన్ని మళ్లీ పరిశీలించవచ్చు. Local Payload Security Inspector పూర్తి payloadను పరికరంలోనే విశ్లేషించి scheme, host, path, query, fragmentలను విడిగా చూపుతుంది. స్థిర నియమాలు Safe, Caution లేదా Blocked, స్పష్టమైన findings, action dispositionను ఇస్తాయి. Online reputation లేదా అస్పష్ట score ఉపయోగించదు; సురక్షితంగా అర్థం కాని చర్య blockedగానే ఉంటుంది. QR Verification ఫలితాన్ని స్థానిక సూచనగా సేవ్ చేసి, తర్వాతి స్కాన్‌ను పూర్తి SHA-256 ఫింగర్‌ప్రింట్, QR ఫార్మాట్, కంటెంట్ రకం, URL భాగాలు, భద్రతా స్థాయి మరియు చర్య ఆధారంగా పోల్చండి. Batch Risk & Difference Audit అచ్చంగా ఒకే ఫలితాలను, ఒకే host ఉన్న ఫలితాలను group చేసి, తర్వాత స్పష్టమైన పరిమితిలో గందరగోళం కలిగించే పోలిన hostలను సరిపోలుస్తుంది. సారాంశం, ప్రతి item ప్రమాదం, అన్ని పూర్తి payloadలు చదవవచ్చు. పూర్తి auditను చూడవచ్చు. QR Code Halo ఏమి చేస్తుంది కెమెరాతో స్కాన్ చేయండి లేదా ఫొటోల్లో code లను గుర్తించండి, ఒకే ఫ్రేమ్‌లో అనేక code లు 20 బార్‌కోడ్ ఫార్మాట్లు: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar మరియు MSI Plessey డూప్లికేట్ నివారణ, జూమ్ మరియు ఫ్లాష్‌లైట్‌తో batch స్కానింగ్ టెక్స్ట్, లింక్, Wi-Fi, కాంటాక్ట్, ఇమెయిల్, ఫోన్, SMS, లొకేషన్ మరియు క్యాలెండర్ ఈవెంట్ QR లను సృష్టించండి అపరిమిత చరిత్ర, ఎంట్రీలకు పరిమితి లేదు: ఇష్టమైనవి, శోధన, రకం, తేదీ, ఫార్మాట్, ట్యాగ్ లేదా వర్గం ప్రకారం ఫిల్టర్లు మరియు సార్టింగ్ పరికరంలోనే స్వయంచాలక వర్గీకరణ, చేతితో మార్చుకోవచ్చు, మరియు చరిత్రను CSV గా ఎక్స్‌పోర్ట్ బ్యాకప్, రీస్టోర్ రెండూ నిర్ణయం తీసుకునే ముందు అసలు సంఖ్య, పరిమాణం, తేదీల పరిధిని చూపిస్తాయి ఆటోమేటిక్ క్లియరింగ్‌తో ప్రైవసీ మోడ్, Photos లో సేవ్, ప్రింట్, Share Extension మరియు Siri Shortcuts QR Code Halo App Store లో ఉచిత డౌన్‌లోడ్: మూడు ఉచిత స్కాన్‌లు, తొమ్మిది QR రకాలు అన్నీ, ఇష్టమైనవి, శోధన, ఫిల్టర్లతో అపరిమిత చరిత్ర, ఎంట్రీలకు ఎలాంటి పరిమితీ లేకుండా, ప్రకటనలు మరియు ఖాతా లేకుండా. ఒకే ఐచ్ఛిక Lifetime Pro కొనుగోలు అపరిమిత స్కానింగ్, స్కాన్ చేసిన batch ను సేవ్ చేయడం, తెరవడం, batch సృష్టి మరియు batch CSV, బ్యాకప్ మరియు రీస్టోర్, హై రిజల్యూషన్ ఎక్స్‌పోర్ట్, custom Aurora స్టైల్స్ జోడిస్తుంది; అది ఎప్పటికీ మీదే. సబ్‌స్క్రిప్షన్ లేదు. స్కాన్ కాని code, లేదా ఉంటే బాగుండేదని అనిపించే ఫీచర్: hourstag.app@gmail.com ఇది document scanner కాదు. పేజీలను scan చేయదు, OCR చేయదు, PDF document libraryను నిర్వహించదు; PDF exportలో QR artwork మాత్రమే ఉంటుంది.
