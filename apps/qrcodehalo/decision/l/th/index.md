# QR Code Halo สแกน & สร้าง — เปิดทันที ตรวจทีหลังได้ | iOS App

ปรับให้เหมาะกับ iPhone Duo แอปนี้สร้างด้วยชุดพัฒนาซอฟต์แวร์รุ่นล่าสุด แสดงเต็มหน้าจอด้านในทั้งหมด และปรับเลย์เอาต์ให้อัตโนมัติทั้งตอนพับและตอนกาง สแกน QR โค้ดและบาร์โค้ดได้ 20 รูปแบบ จากกล้องหรือจากรูปภาพ แล้วทำงานทันที ลิงก์เปิดขึ้นเลย ส่วนโค้ด Wi-Fi จะขึ้นข้อความให้เข้าร่วมเครือข่าย กังวลว่าเป็นโค้ดหลอกลวงหรือเปล่า เปิดโค้ดนั้นใน “ประวัติ” แล้วแตะ “ตรวจสอบความปลอดภัย” QR Code Halo จะแยกลิงก์ออกเป็นส่วน ๆ บนเครื่อง แล้วชี้ URL ที่น่าสงสัย ลิงก์ที่ไม่ใช่ HTTPS และโดเมนที่ปนตัวอักษรหลายระบบ โดยจัดเป็นปลอดภัย ระวัง หรือถูกบล็อก โค้ด javascript:, data: และ file: จะไม่ถูกเปิดเลย และถ้าอยากตรวจทุกโค้ดก่อนเปิด ก็ปิด “ทำงานทันทีหลังสแกน” ได้ สร้าง QR โค้ดได้อีก 9 แบบ เช่น Wi-Fi รายชื่อติดต่อ และกิจกรรม ตรวจสอบความปลอดภัยในประวัติ ทุกการสแกนที่ไม่ใช่การสแกนเป็นชุดจะถูกบันทึกไว้ในอุปกรณ์นี้ เว้นแต่จะเปิด "ไม่บันทึกลงประวัติ" ไว้ เปิดโค้ดในประวัติแล้วแตะ ตรวจสอบความปลอดภัย เพื่อดูซ้ำด้วยเครื่องมือในเครื่องสองอย่าง Local Payload Security Inspector วิเคราะห์ payload ทั้งหมดบนอุปกรณ์และแยกแสดง scheme, host, path, query และ fragment กฎที่ให้ผลแน่นอนจะแสดง Safe, Caution หรือ Blocked พร้อม findings ที่โปร่งใสและ action disposition ไม่ใช้ชื่อเสียงจากอินเทอร์เน็ตหรือคะแนนกำกวม หากตีความการทำงานไม่ได้อย่างปลอดภัยจะคงสถานะบล็อกไว้ QR Verification บันทึกผลลัพธ์เป็นข้อมูลอ้างอิงในเครื่อง แล้วเปรียบเทียบการสแกนครั้งถัดไปด้วยลายนิ้วมือ SHA-256 แบบเต็ม รูปแบบ QR ประเภทเนื้อหา องค์ประกอบ URL ระดับความปลอดภัย และการทำงาน Batch Risk & Difference Audit จัดกลุ่มผลที่เหมือนกันทุกประการและผลที่มี host เดียวกัน จากนั้นเปรียบเทียบ host ที่อาจสับสนกันภายในขอบเขตจำกัดที่ชัดเจน สรุปความเสี่ยง ความเสี่ยงของแต่ละรายการ และ payload ฉบับเต็มยังอ่านได้ทั้งหมด การอ่านรายงานทั้งชุดเปิดให้ใช้งาน QR Code Halo ทำอะไรได้บ้าง สแกนด้วยกล้องหรือรู้จำโค้ดในรูปภาพ อ่านได้หลายโค้ดในเฟรมเดียว บาร์โค้ด 20 รูปแบบ: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar และ MSI Plessey สแกนเป็นชุดพร้อมตัดรายการซ้ำ ซูม และไฟฉาย สร้างโค้ด QR แบบข้อความ ลิงก์ Wi-Fi รายชื่อผู้ติดต่อ อีเมล โทรศัพท์ SMS ตำแหน่งที่ตั้ง และกิจกรรมในปฏิทิน ประวัติไม่จำกัด ไม่มีเพดานจำนวนรายการ พร้อมรายการโปรด การค้นหา ตัวกรองและการเรียงลำดับตามประเภท วันที่ ฟอร์แมต แท็ก หรือหมวดหมู่ จัดหมวดหมู่อัตโนมัติบนเครื่องและแก้ไขเองได้ พร้อมส่งออกประวัติเป็น CSV ทั้งการสำรองและการกู้คืนแสดงจำนวน ขนาด และช่วงวันที่จริงก่อนที่คุณจะตัดสินใจ โหมดความเป็นส่วนตัวพร้อมล้างอัตโนมัติ บันทึกลงรูปภาพ พิมพ์ Share Extension และคำสั่งลัด Siri QR Code Halo ดาวน์โหลดฟรีบน App Store: สแกนฟรีสามครั้ง สร้าง QR ได้ครบเก้าประเภท และประวัติไม่จำกัดพร้อมรายการโปรด การค้นหาและตัวกรอง โดยไม่มีเพดานจำนวนรายการ ไม่มีโฆษณาและไม่ต้องมีบัญชี การซื้อ Lifetime Pro เพียงครั้งเดียวเพิ่มการสแกนไม่จำกัด การบันทึกและเปิดผลลัพธ์ของชุดที่สแกน การสร้างเป็นชุดและ CSV ของชุด การสำรองและกู้คืนข้อมูล การส่งออกความละเอียดสูง และสไตล์ Aurora แบบกำหนดเอง เป็นของคุณตลอดไป
