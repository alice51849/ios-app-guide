# QR Code Halo：安全扫码与制作 — 扫完直接打开，稍后本机查风险 | iOS App

QR Code Halo 扫到就直接执行。用相机扫描或选择照片：网址直接在浏览器中打开，通行密钥登录码和 App 链接直接交给 iOS，Wi-Fi 码会弹出 iOS 的加入网络提示，电话、短信、邮件和地点则交给相应的 App。联系人和日程会打开 iOS 的添加界面，由你确认后才会添加。纯文本会直接复制并显示一行提示；javascript:、data:、file: 这类内容一律不会打开。想先检查再决定，可在设置中关闭“扫描后自动执行”；批量扫描只收集、不执行。 历史记录里的安全检查 除非开启“不保存到历史记录”，批量扫描以外的每次扫描都会保存在这台设备上。在历史记录中点开任意一条，再点“安全检查”，即可用下面两个本地工具重新查看。 Local Payload Security Inspector 在设备端解析完整 payload，逐项显示 scheme、host、path、query 和 fragment，并给出 Safe、Caution 或 Blocked、透明 findings 与 action disposition。规则固定且可复现，不查询网络信誉，也不生成含糊分数；解析失败时禁止外部操作。 QR Verification 将结果保存为本机参照，再按完整 SHA-256 指纹、二维码格式、内容类型、URL 组成项、安全级别和操作状态比较后续扫描。 Batch Risk & Difference Audit 把一批结果按完全相同内容和 host 分组，有限度比较容易混淆的相似 host，并显示总体风险和每一项风险。所有完整 payload 都可阅读，审计阅读本身不设付费限制。 QR Code Halo 能做什么 用相机扫描，或识别照片中的码，同一画面可含多个码 20 种条码格式：QR、Micro QR、Aztec、Data Matrix、PDF417、Micro PDF417、EAN-8、EAN-13、UPC-A、UPC-E、Code 39、Code 93、Code 128、Interleaved 2 of 5、ITF-14、Codabar、GS1 DataBar 与 MSI Plessey 批量扫描自动去重，支持变焦与手电筒 生成文本、链接、Wi-Fi、联系人、邮件、电话、短信、位置与日历事件二维码 历史记录不限条数：收藏、搜索，可按类型、日期、格式、标签或分类筛选与排序 在设备本地自动归类，也可以自己改，并能把历史导出成 CSV 备份与恢复都会先预览真实的条数、大小与日期范围，再由你决定 隐私模式自动清空历史，支持存入相册、打印、分享扩展与 Siri 快捷指令 QR Code Halo 在 App Store 免费下载：免费 3 次扫描、9 种二维码全部可用、历史记录不限条数，收藏、搜索与筛选都在其中，无广告、无账号。可选的 Lifetime Pro 一次买断即永久拥有，增加无限次扫描、批量保存与打开结果、CSV 批量生成与批量导出、备份与恢复、高分辨率导出与自定义 Aurora 样式。绝无订阅。 遇到扫不出的码，或希望增加的功能：hourstag.app@gmail.com 它不是文档扫描器：不扫描纸张，不做 OCR，也不管理 PDF 文档库。PDF 只导出 QR 图稿。Share Extension 仅把 URL 或纯文本制成 QR。 针对 iPhone Duo 优化。
