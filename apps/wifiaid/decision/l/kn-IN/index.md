# WiFi Aid: ನೆಟ್ವರ್ಕ್ ಸಮಸ್ಯೆ — ರೌಟರ್, ಮೆಶ್ ಮತ್ತು DNS ಪರಿಶೀಲನೆ | iOS App

ಒಂದು ಟ್ಯಾಪ್‌ನಲ್ಲಿ Wi‑Fi ಮತ್ತು ಇಂಟರ್ನೆಟ್ ಸಮಸ್ಯೆ ಪರಿಶೀಲಿಸಿ. DNS, TCP, TLS, ವೇಗ, ಜಿಟ್ಟರ್, IPv4 ಮತ್ತು IPv6 ಸಾಕ್ಷ್ಯ ನೋಡಿ ಸರಿಯಾದ ಪರಿಹಾರ ಕೈಗೊಳ್ಳಿ—ಜಾಹೀರಾತು ಅಥವಾ ಚಂದಾ ಇಲ್ಲ. • ಪರಿಶೀಲನೆ ನಡೆಸು — ಒಂದೇ ಟ್ಯಾಪ್‌ನಲ್ಲಿ Wi-Fi, DNS ಮತ್ತು ಇಂಟರ್ನೆಟ್ ಪರಿಶೀಲನೆ • ಡೀಪ್ ಚೆಕ್ — ಹೆಚ್ಚಿನ ಪುರಾವೆ ಮತ್ತು ಸ್ಥಿರತೆಯ ಮಾದರಿಗಳು • ವೆಬ್‌ಸೈಟ್ ಪರಿಶೀಲಿಸಿ — ಒಂದು ತಾಣ ಅಥವಾ ಇಡೀ ಇಂಟರ್ನೆಟ್ ವಿಫಲವಾಗುತ್ತಿದೆಯೇ ಎಂದು ನೋಡಿ • ಪುರಾವೆ — DNS · TCP · TLS · TTFB · HTTP · Direct IP · IPv4 · IPv6 • ಸಂಪರ್ಕ ಅಸ್ಥಿರವಾಗಿದೆ — ವ್ಯತ್ಯಾಸ • ಪರಿಶೀಲನೆ ಇತಿಹಾಸ — ಖಾಸಗಿ ದಾಖಲೆಗಳು ಈ ಸಾಧನದಲ್ಲಿ ಮಾತ್ರ ಉಳಿಯುತ್ತವೆ • Apple Watch — ಪರಿಶೀಲನೆ ನಡೆಸು • Widget · iPad — ಸಂಪರ್ಕಗೊಂಡಿದೆ · ಪರಿಶೀಲನೆ ನಡೆಸು ಯಾವುದೇ ಖಾತೆ, ಜಾಹೀರಾತುಗಳು ಅಥವಾ ಟ್ರ್ಯಾಕಿಂಗ್ ಇಲ್ಲ. ಖಾಸಗಿ ದಾಖಲೆಗಳು ಈ ಸಾಧನದಲ್ಲಿ ಮಾತ್ರ ಉಳಿಯುತ್ತವೆ. WiFi Aid ಒಂದೇ ಬಾರಿಯ ಪಾವತಿಯ ಸಂಪೂರ್ಣ ಆಪ್. ಜಾಹೀರಾತು, ಇನ್‑ಆಪ್ ಖರೀದಿ ಅಥವಾ ಚಂದಾ ಇಲ್ಲ. iPhone Duo ಗಾಗಿ ಆಪ್ಟಿಮೈಸ್ ಮಾಡಲಾಗಿದೆ.
