# WiFi Aid: Finn nettverksfeil — Ruter-, mesh- og DNS-diagnose | iOS App

Optimalisert for iPhone Duo. Appen er bygget med den nyeste SDK-en, fyller hele den indre skjermen og tilpasser oppsettet automatisk, både sammenbrettet og utbrettet. Er Wi-Fi-en treg eller ustabil igjen? WiFi Aid tester Wi-Fi, DNS og internett med ett trykk og forteller om problemet mest sannsynlig ligger i Wi-Fi-en, DNS, hos internettleverandøren eller på ett enkelt nettsted – med bevisene bak hver konklusjon. Deep Check fortsetter å måle for å avsløre ustabile tilkoblinger som ser tilkoblet ut, men henger. På mesh-Wi-Fi viser den hvilken node du er koblet til, og om den har byttet siden forrige test. Test også fra Apple Watch eller en widget på Hjem-skjermen; testhistorikken blir bare på denne enheten. • Start test — test Wi-Fi, DNS og internett med ett trykk og få svar på sekunder • Deep Check — flere stabilitetsmålinger for problemer som kommer og går • Sjekk nettside — se om bare ett nettsted er nede eller hele tilkoblingen • Alle bevis — DNS, TCP, TLS, TTFB, HTTP, direkte IP, IPv4 og IPv6, punkt for punkt • Mesh-node — se hvilken node du er koblet til, og om du har byttet • Testhistorikk — sammenlign tidligere resultater, lagret kun på denne enheten • Apple Watch — kjør en test fra håndleddet • Widget og iPad — tilkoblingsstatus på Hjem-skjermen og fullt iPad-oppsett Ingen konto, annonser, analyse eller sporing. Ett engangskjøp i App Store. Ingen abonnement. Optimalisert for iPhone Duo.
