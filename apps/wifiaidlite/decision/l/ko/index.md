# WiFi Aid Lite — 네트워크 진단과 원인 분석 | iOS App

"또 인터넷이 느려졌다" — 원인은 공유기일까요, DNS일까요, 통신사일까요, 아니면 사이트 자체일까요? WiFi Aid Lite는 여러 독립 경로로 DNS, TCP, TLS, 응답 시간, 안정성을 동시에 검사하고 증거를 교차 비교해 가장 가능성 높은 원인을 알려 줍니다. 감으로 재부팅을 반복할 필요가 없습니다. • 검사 실행: 한 번의 탭으로 Wi-Fi, DNS, 인터넷 연결을 한꺼번에 진단하고 몇 초 만에 결과와 결론을 확인하세요. • 정밀 검사: 더 많은 증거와 안정성 샘플을 수집합니다. 됐다 안 됐다 하는 간헐적 문제를 가려내는 데 좋습니다. • 웹사이트 검사: 특정 사이트만 문제인지, 인터넷 전체에 장애가 있는지 바로 판별합니다. • 증거: DNS, TCP, TLS, TTFB, HTTP, 직접 IP, IPv4, IPv6 결과를 항목별로 보여 주므로 모든 결론에 근거가 있습니다. • 안정성 분석: 연속 샘플링으로 지연 시간의 변동(지터)을 관찰해 "연결은 됐는데 자꾸 끊기는" 불안정한 상태를 찾아냅니다. • 검사 기록: 지난 결과를 자동 저장해 네트워크 상태의 변화를 비교할 수 있습니다. 기록은 이 기기에만 저장됩니다. • 연결된 노드: 정확한 위치를 사용해 현재 연결된 Wi-Fi와 노드를 식별합니다. 위치 정보는 이 용도로만, 기기 안에서만 사용됩니다. 먼저 무료로 써 보세요: 각 도구는 한 번씩 제한 없이 완전하게 무료로 사용할 수 있습니다. 마음에 들면 1회 결제로 평생 잠금을 해제해 모든 도구를 무제한으로 사용하세요. 구독은 없습니다. 계정이 필요 없고 광고, 분석 도구, 추적이 전혀 없습니다. 모든 기록은 이 기기에만 저장되며 클라우드로 전송되지 않습니다.
