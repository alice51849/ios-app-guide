# WiFi Aid Lite：网络故障检测 — 上不了网？一键找出原因 | iOS App

已针对 iPhone Duo 优化。本应用使用最新开发工具包构建，铺满整块内屏，无论折叠还是展开都会自动调整布局。 “网络又卡了”——问题出在 Wi-Fi、路由器、DNS，还是网站本身？ 一键依次检查 Wi-Fi、DNS 与互联网，直接告诉你卡在哪一段、最可能的原因，以及下一步该怎么做。 酒店、咖啡馆 Wi-Fi 连上了却用不了、网页打不开、时好时坏，都能用网站检查和深度检查分辨清楚。 • 登录页检测：酒店、咖啡馆、机场的 Wi-Fi 明明连上了，却还要先在浏览器里认证登录，也会直接告诉你。 • 网站检查：输入任意网址，立刻判断是单个网站出问题，还是整个网络都有故障。 • 深度检查：连续采样观察延迟抖动，找出“看着连上了、用起来却很卡”的不稳定连接。 • 完整证据：DNS、TCP、TLS、TTFB、HTTP、直连 IP、IPv4 与 IPv6 逐项列出，每个结论都有依据。 • 下一步建议：例如打开登录页、换用可信的 DNS 服务、靠近路由器再测一次。 • 检查记录：历次结果自动保存，方便对比网络状况的变化；记录只保存在你的设备上。 • 当前节点：允许精确位置后，可识别当前连接的 Wi-Fi 与节点。 无需购买即可完整体验：所有工具合计可完整检查一次，任选一项工具即可，不是限时试用。觉得好用，再通过一次性 App 内购买解锁，即可不限次数使用全部工具、查看完整记录，以及修复前后对照——一次解锁，没有订阅。 无需账号，没有广告、没有分析工具、没有任何跟踪。位置信息只用于识别 Wi-Fi 与节点，并只在本机处理；检查记录只存本机，不上传云端。
