المعادلة والحدود

المجموع الفرعي = مجموع كل ما طُلب. الضريبة = المجموع الفرعي × نسبة الضريبة. البقشيش = المجموع الفرعي × نسبة البقشيش. حصة كل شخص = طلبه ÷ المجموع الفرعي، والهللات المتبقية تذهب أولاً لأكبر الكسور، فتتطابق مجموع الحصص مع الفاتورة تمامًا.

المجموع الفرعي = 32.40 + 18.90 + 25.00 = 76.30
الضريبة = 76.30 × 8.25% = 6.29
البقشيش = 76.30 × 15.00% = 11.45
الشخص 1: 32.40 + 2.67 + 4.86 = 39.93
الشخص 2: 18.90 + 1.56 + 2.84 = 23.30
الشخص 3: 25.00 + 2.06 + 3.75 = 30.81
إجمالي الفاتورة = 94.04

استخدم عملة واحدة، وأدخل الضريبة والبقشيش كنسبة من المجموع الفرعي. لا تحويل عملات، ولا قواعد لرسوم الخدمة، ولا نصيحة عن مقدار البقشيش، ولا أي عملية دفع. العرض يقرّب إلى منزلتين، والحساب نفسه يجري بوحدات صحيحة.

  • قيمة طلبه: 0 ≤ n ≤ 100,000,000
  • الضريبة % / البقشيش %: 0 ≤ % ≤ 100
  • الشخص: 1 ≤ n ≤ 20
