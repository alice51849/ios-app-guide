المعادلة والحدود

الربح = إجمالي الإيرادات − إجمالي المصروفات. هامش الربح = الربح ÷ إجمالي الإيرادات. صافي الساعة = الربح ÷ الساعات المستغرقة. تُجمع المبالغ بالهللات الصحيحة فلا تنحرف الإجماليات.

إجمالي الإيرادات = 1500.00
إجمالي المصروفات = 400.39
الربح = 1500.00 − 400.39 = 1099.61
هامش الربح = 1099.61 ÷ 1500.00 = 73.3%
صافي الساعة = 1099.61 ÷ 12.5 = 87.97

مبالغ من 0 إلى 100,000,000 بخانتَين عشريتَين على الأكثر، حتى 20 صف إيراد و20 صف مصروف، وساعات من 0.25 إلى 2000 بخطوات ربع ساعة. عملة واحدة، بلا تحويل عملات، وبلا نصائح ضريبية أو محاسبية.

  • المبلغ: 0 ≤ x ≤ 100,000,000
  • الساعات المستغرقة: 0.25 ≤ h ≤ 2000
  • إيراد / مصروف: 1 ≤ n ≤ 20
