المعادلة والحدود

الإجمالي = الكمية × السعر النهائي. ساعات العمل = الإجمالي ÷ صافي الدخل في الساعة. أيام العمل = الساعات ÷ ساعات يوم العمل.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

أدخل أسعارًا شاملة للضريبة. لا تحويل عملات ولا حساب رواتب ولا توقع للادخار ولا نصيحة شراء. العرض بمنزلتين عشريتين، والإجماليات تُحسب بالقيم غير المقرّبة.

  • صافي الدخل في الساعة: 0 < x ≤ 100000000
  • السعر النهائي للوحدة: 0 ≤ x ≤ 100000000
  • ساعات يوم العمل: 0 < x ≤ 24
  • الكمية: 1 ≤ x ≤ 999
