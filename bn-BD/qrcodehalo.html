QR Code Halo সচেতন ধাপ বজায় রাখে: ডিকোড করা বিষয় দেখুন, দৃশ্যমান findings বিচার করুন, তারপর কাজ বেছে নিন। শুধু কোড শনাক্ত হলেই কিছু স্বয়ংক্রিয়ভাবে খুলবে না।

Local Payload Security Inspector

পুরো payload ডিভাইসেই বিশ্লেষণ করে scheme, host, path, query ও fragment আলাদা দেখায়। নির্ধারিত নিয়মে Safe, Caution বা Blocked, স্বচ্ছ findings এবং action disposition পাওয়া যায়। অনলাইন reputation বা অস্পষ্ট স্কোর ব্যবহার হয় না; নিরাপদভাবে বোঝা না গেলে কাজটি বন্ধ থাকে।

QR Code Halo যা যা করে

20টি barcode ফরম্যাট: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar ও MSI Plessey

ডুপ্লিকেট আটকানো, জুম ও ফ্ল্যাশলাইটসহ ব্যাচ স্ক্যানিং

টেক্সট, লিংক, Wi-Fi, কন্টাক্ট, ইমেইল, ফোন, SMS, লোকেশন ও ক্যালেন্ডার ইভেন্টের QR বানান

নিজে নিজে মুছে যাওয়া প্রাইভেসি মোড, Photos-এ সেভ, প্রিন্ট, Share Extension ও Siri Shortcuts
