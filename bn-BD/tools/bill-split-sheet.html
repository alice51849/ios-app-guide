সূত্র ও সীমা

উপমোট = সবার অর্ডারের যোগফল। কর = উপমোট × করের হার। বকশিশ = উপমোট × বকশিশের হার। প্রত্যেকের ভাগ হলো নিজের অর্ডার ÷ উপমোট; বাকি থাকা পয়সা আগে সবচেয়ে বড় দশমিক অংশে যায়, তাই সবার ভাগ যোগ করলে বিলের অঙ্ক হুবহু মেলে।

উপমোট = 32.40 + 18.90 + 25.00 = 76.30
কর = 76.30 × 8.25% = 6.29
বকশিশ = 76.30 × 15.00% = 11.45
ব্যক্তি 1: 32.40 + 2.67 + 4.86 = 39.93
ব্যক্তি 2: 18.90 + 1.56 + 2.84 = 23.30
ব্যক্তি 3: 25.00 + 2.06 + 3.75 = 30.81
বিলের মোট = 94.04

একই মুদ্রা ব্যবহার করুন এবং কর ও বকশিশ উপমোটের শতাংশ হিসেবে লিখুন। মুদ্রা রূপান্তর নেই, সার্ভিস চার্জের নিয়ম নেই, কত বকশিশ দেবেন সেই পরামর্শ নেই, কোনো পরিশোধও নেই। পর্দায় দুই দশমিক ঘর দেখানো হয়; হিসাব হয় পূর্ণ পয়সায়।

  • কর % / বকশিশ %: 0 ≤ % ≤ 100
  • ব্যক্তি: 1 ≤ n ≤ 20
