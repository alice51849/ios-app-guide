সূত্র ও সীমা

শিট আপনার কথা যেমন আছে তেমনই রাখে: শিরোনাম, তারপর আপনার লেখা ক্রমে পয়েন্ট, তারপর পরবর্তী পদক্ষেপ, তারপর মেট্রিক। এটি পয়েন্ট গোনে ও দুই পাশের ফাঁকা জায়গা বাদ দেয়; কিছুই নতুন করে লেখা, সংক্ষিপ্ত বা স্কোর করা হয় না।

শিরোনাম ≤ 80 · পয়েন্ট × 3 ≤ 160 · পরবর্তী পদক্ষেপ ≤ 160 · মেট্রিক ≤ 60
অংশ: শিরোনাম → পয়েন্ট 1…3 → পরবর্তী পদক্ষেপ → মেট্রিক

শিরোনাম সর্বোচ্চ 80 অক্ষর, 3 থেকে 12টি পয়েন্ট প্রতিটি সর্বোচ্চ 160 অক্ষর, পরবর্তী পদক্ষেপ সর্বোচ্চ 160 অক্ষর, মেট্রিক সর্বোচ্চ 60 অক্ষর। প্রতিটি লাইন এক লাইনের লেখা হতে হবে। শিট ফাইল, রেকর্ডিং বা ক্যালেন্ডার পড়ে না।

  • শিরোনাম: ≤ 80
  • পয়েন্ট: 3 ≤ n ≤ 12, ≤ 160
  • পরবর্তী পদক্ষেপ: ≤ 160
  • মেট্রিক: ≤ 60
