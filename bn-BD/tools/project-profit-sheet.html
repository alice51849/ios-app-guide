সূত্র ও সীমা

লাভ = মোট আয় − মোট ব্যয়। মার্জিন = লাভ ÷ মোট আয়। ঘণ্টাপ্রতি নিট = লাভ ÷ ব্যয়িত ঘণ্টা। পরিমাণ পূর্ণ পয়সায় যোগ হয়, তাই যোগফল সরে যায় না।

মোট আয় = 1500.00
মোট ব্যয় = 400.39
লাভ = 1500.00 − 400.39 = 1099.61
মার্জিন = 1099.61 ÷ 1500.00 = 73.3%
ঘণ্টাপ্রতি নিট = 1099.61 ÷ 12.5 = 87.97

পরিমাণ 0 থেকে 100,000,000, সর্বোচ্চ দুই দশমিক; সর্বোচ্চ 20টি আয় ও 20টি ব্যয়ের সারি; ঘণ্টা 0.25 থেকে 2000, সিকি ঘণ্টার ধাপে। একই মুদ্রা, বিনিময় নেই, কর বা হিসাবরক্ষণ পরামর্শ নেই।

  • পরিমাণ: 0 ≤ x ≤ 100,000,000
  • ব্যয়িত ঘণ্টা: 0.25 ≤ h ≤ 2000
  • আয় / ব্যয়: 1 ≤ n ≤ 20
