সূত্র ও সীমা

মোট = পরিমাণ × চূড়ান্ত একক মূল্য। কাজের ঘণ্টা = মোট ÷ ঘণ্টাপ্রতি নিট আয়। কর্মদিবস = কাজের ঘণ্টা ÷ প্রতিদিন কাজের ঘণ্টা।

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

দামের মধ্যে কর অন্তর্ভুক্ত করুন। মুদ্রা রূপান্তর, বেতন হিসাব, সঞ্চয়ের পূর্বাভাস বা কেনার পরামর্শ দেওয়া হয় না। দুই দশমিক দেখানো হয়; মোট হিসাব অপরিবর্তিত মান দিয়ে করা হয়।

  • ঘণ্টাপ্রতি নিট আয়: 0 < x ≤ 100000000
  • করসহ একক মূল্য: 0 ≤ x ≤ 100000000
  • প্রতি কর্মদিবসের ঘণ্টা: 0 < x ≤ 24
  • পরিমাণ: 1 ≤ x ≤ 999
