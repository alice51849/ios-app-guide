Què és QR Code Halo: Escàner?

QR Code Halo: Escàner és una app per a iOS. Inspecciona abans d'actuar

QR Code Halo ordena el procés perquè tinguis el control: inspecciona el contingut, decideix amb indicis visibles i només després tria una acció. Detectar un codi no obre res automàticament.

Local Payload Security Inspector

Analitza al dispositiu el payload complet i separa scheme, host, path, query i fragment. Les regles deterministes mostren Safe, Caution o Blocked, findings transparents i una action disposition clara. No consulta reputació en línia ni fa servir puntuacions difuses; si no pot interpretar una acció, la manté bloquejada.

QR Verification

Desa un resultat com a referència local i compara un escaneig posterior per l'empremta SHA-256 completa, el format QR, el tipus de contingut, els components URL, el nivell de seguretat i l'acció.

Batch Risk & Difference Audit

Agrupa els duplicats exactes i els resultats amb el mateix host, i després compara dins d'un abast limitat els host que es poden confondre. El resum, el risc de cada element i tots els payload complets continuen llegibles. L'auditoria sencera es pot consultar.

Què fa QR Code Halo

Escaneja amb la càmera o reconeix codis a les fotos, diversos codis en un sol quadre

Previsualització segura per a cada resultat: contingut complet, esquema i host dels enllaços, i avisos de formats sospitosos

20 formats de codis de barres: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar i MSI Plessey

Escaneig per lots amb supressió de duplicats, zoom i llanterna

Crea codis QR de text, enllaç, Wi-Fi, contacte, correu, telèfon, SMS, ubicació i esdeveniment de calendari

Historial il·limitat, sense cap límit d'entrades: preferits, cerca, filtres i ordenació per tipus, data, format, etiqueta o categoria

Classificació automàtica al dispositiu, modificable a mà, i exportació de l'historial en CSV

La còpia de seguretat i la restauració mostren el nombre real d'entrades, la mida i el període abans que decideixis

Lifetime Pro: Escaneig il·limitat, desar un lot escanejat a l'historial i obrir-ne els resultats, creació per lots i CSV del lot, executar una còpia de seguretat o una restauració, exportació PNG, PDF i SVG en alta resolució, i estils Aurora propis

Mode de privadesa amb neteja automàtica, desar a Fotos, imprimir, Share Extension i Dreceres de Siri
