Fórmula i límits

Subtotal = la suma de tot el que s'ha demanat. Impostos = subtotal × percentatge d'impostos. Propina = subtotal × percentatge de propina. La part de cadascú és la seva comanda ÷ subtotal; els cèntims que sobren van primer als decimals més grans, de manera que la suma de les parts dona exactament el compte.

Subtotal = 32.40 + 18.90 + 25.00 = 76.30
Impostos = 76.30 × 8.25% = 6.29
Propina = 76.30 × 15.00% = 11.45
Persona 1: 32.40 + 2.67 + 4.86 = 39.93
Persona 2: 18.90 + 1.56 + 2.84 = 23.30
Persona 3: 25.00 + 2.06 + 3.75 = 30.81
Total del compte = 94.04

Fes servir una sola moneda i posa impostos i propina com a percentatge del subtotal. Sense conversió de divises, sense regles de servei inclòs, sense consells sobre quanta propina deixar i sense cobraments. A la pantalla s'arrodoneix a dos decimals; el repartiment es calcula en cèntims sencers.

  • Ha demanat per: 0 ≤ n ≤ 100,000,000
  • Impostos % / Propina %: 0 ≤ % ≤ 100
  • Persona: 1 ≤ n ≤ 20
