Fórmula i límits

Total = quantitat × preu final. Hores = total ÷ ingressos nets per hora. Jornades = hores ÷ hores per jornada.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Inclou els impostos en els preus. Sense canvi de divises, nòmines, previsions d’estalvi ni consells de compra. Es mostren dos decimals; els totals fan servir valors sense arrodonir.

  • Ingressos nets per hora: 0 < x ≤ 100000000
  • Preu unitari final: 0 ≤ x ≤ 100000000
  • Hores per jornada: 0 < x ≤ 24
  • Quantitat: 1 ≤ x ≤ 999
