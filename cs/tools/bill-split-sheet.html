Vzorec a omezení

Mezisoučet = všechny objednávky sečtené. Daň = mezisoučet × sazba daně. Spropitné = mezisoučet × sazba spropitného. Podíl každého je jeho objednávka ÷ mezisoučet; zbylé haléře připadnou nejdřív největším desetinným zbytkům, takže podíly vždy dají přesně částku účtu.

Mezisoučet = 32.40 + 18.90 + 25.00 = 76.30
Daň = 76.30 × 8.25% = 6.29
Spropitné = 76.30 × 15.00% = 11.45
Osoba 1: 32.40 + 2.67 + 4.86 = 39.93
Osoba 2: 18.90 + 1.56 + 2.84 = 23.30
Osoba 3: 25.00 + 2.06 + 3.75 = 30.81
Účet celkem = 94.04

Používej jednu měnu a daň i spropitné zadávej jako procento z mezisoučtu. Žádný převod měn, žádná pravidla pro servisní poplatek, žádné doporučení, kolik dát, a žádné placení. Na obrazovce se zaokrouhluje na dvě desetinná místa; samotné dělení počítá v celých haléřích.

  • Objednal(a) za: 0 ≤ n ≤ 100,000,000
  • Daň % / Spropitné %: 0 ≤ % ≤ 100
  • Osoba: 1 ≤ n ≤ 20
