Vzorec a omezení

Příjezd = předchozí odjezd + cesta. Odjezd = příjezd + pobyt. Celkem = všechny pobyty + všechny cesty. K dispozici = konec − začátek; konec dřívější než začátek se počítá jako další den. Přesah = celkem − k dispozici; cokoli nad nulou přetahuje. Čistá minutová aritmetika, žádná časová pásma.

1. Místo 1: 09:00 + 120 = 11:00 + 25 →
2. Místo 2: 11:25 + 60 = 12:25 + 40 →
3. Místo 3: 13:05 + 180 = 16:05 + 30 →
Celkem (min) = 455; K dispozici (min) = 09:00–18:00 = 540
Přesah (min) = 455 − 540 = -85 → Vejde se

Časy ve 24hodinovém formátu HH:MM, pobyty 5 až 720 minut, cesty 0 až 600 minut, nejvýše 25 míst. Otevírací doby, skutečný provoz, mapy, trasování a rezervace do tabulky nepatří.

  • Začátek / Konec: HH:MM
  • Pobyt (min): 5 ≤ m ≤ 720
  • Cesta k dalšímu (min): 0 ≤ m ≤ 600
  • Místo: 1 ≤ n ≤ 25
