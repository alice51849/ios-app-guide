Vzorec a omezení

Další termín = naposledy + interval. U měsíců zůstává stejný den; pokud neexistuje, použije se poslední den měsíce (včetně přestupných let). Zbývá dní = termín − dnes. Pod 0 po termínu; 0 až 7 brzy.

2026-06-01 + 3 měsíců = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 týden = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 měsíců = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Intervaly 1 až 3650 dní, týdnů nebo měsíců. Data mezi 1900-01-01 a 2999-12-31. Až 30 úkolů. Žádné připomínky, oznámení ani synchronizace s kalendářem; nic neopouští tuto stránku.

  • Interval: 1 ≤ x ≤ 3650
  • Naposledy: 1900-01-01 ≤ x ≤ 2999-12-31
  • Úkol: 1 ≤ n ≤ 30
