Vzorec a omezení

Zisk = příjmy celkem − výdaje celkem. Marže = zisk ÷ příjmy celkem. Čistý výdělek na hodinu = zisk ÷ odpracované hodiny. Částky se sčítají v celých haléřích, takže součty neujíždějí.

Příjmy celkem = 1500.00
Výdaje celkem = 400.39
Zisk = 1500.00 − 400.39 = 1099.61
Marže = 1099.61 ÷ 1500.00 = 73.3%
Čistý výdělek na hodinu = 1099.61 ÷ 12.5 = 87.97

Částky od 0 do 100 000 000 s nejvýše dvěma desetinnými místy, až 20 řádků příjmů a 20 výdajů, hodiny od 0,25 do 2000 po čtvrthodinách. Jedna měna, bez přepočtu, bez daňového či účetního poradenství.

  • Částka: 0 ≤ x ≤ 100,000,000
  • Odpracované hodiny: 0.25 ≤ h ≤ 2000
  • Příjem / Výdaj: 1 ≤ n ≤ 20
