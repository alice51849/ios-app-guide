Formel og begrænsninger

Tabellen beholder dine ord, som de er: overskrift, derefter punkterne i den rækkefølge, du skrev dem, derefter næste handling og til sidst nøgletallet. Den tæller punkterne og fjerner mellemrum i kanterne; intet omskrives, opsummeres eller bedømmes.

Overskrift ≤ 80 · Punkt × 3 ≤ 160 · Næste handling ≤ 160 · Nøgletal ≤ 60
Afsnit: Overskrift → Punkt 1…3 → Næste handling → Nøgletal

Overskrift på op til 80 tegn, 3 til 12 punkter på op til 160 tegn hver, næste handling på op til 160 tegn, nøgletal på op til 60 tegn. Hver linje skal være tekst på én linje. Tabellen læser ikke filer, optagelser eller kalendere.

  • Overskrift: ≤ 80
  • Punkt: 3 ≤ n ≤ 12, ≤ 160
  • Næste handling: ≤ 160
  • Nøgletal: ≤ 60
