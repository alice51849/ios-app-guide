Formel og begrænsninger

Fortjeneste = indtægter i alt − udgifter i alt. Margin = fortjeneste ÷ indtægter i alt. Netto pr. time = fortjeneste ÷ brugte timer. Beløb lægges sammen i hele ører, så totalerne skrider ikke.

Indtægter i alt = 1500.00
Udgifter i alt = 400.39
Fortjeneste = 1500.00 − 400.39 = 1099.61
Margin = 1099.61 ÷ 1500.00 = 73.3%
Netto pr. time = 1099.61 ÷ 12.5 = 87.97

Beløb fra 0 til 100.000.000 med højst to decimaler, op til 20 indtægts- og 20 udgiftsrækker, timer fra 0,25 til 2000 i kvarter. Samme valuta, ingen omregning, ingen skatte- eller regnskabsrådgivning.

  • Beløb: 0 ≤ x ≤ 100,000,000
  • Brugte timer: 0.25 ≤ h ≤ 2000
  • Indtægt / Udgift: 1 ≤ n ≤ 20
