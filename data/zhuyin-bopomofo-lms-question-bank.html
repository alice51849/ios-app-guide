QTI 2.1 packages

Each ZIP contains imsmanifest.xml and 37 self-contained QTI assessmentItem files using one accessible choiceInteraction each.

Moodle XML files

Each XML file contains one category and 37 multichoice questions with stable idnumbers, one-point grades and answer feedback.

Answer key and metadata

The CSV maps every stable item ID to category, Pinyin, Unicode and the correct symbol. JSON-LD records byte lengths and SHA-256 hashes.

Import into Canvas

  1. Download one QTI 2.1 ZIP without extracting it.
  2. In Course Settings, choose Import Course Content and QTI .zip file.
  3. Import into a staging course first and review all 37 questions.

Import into Moodle

  1. Download one Moodle XML file.
  2. Open the course Question bank, choose Import, then Moodle XML format.
  3. Review the imported category before using questions with learners.

Compatibility boundary

LMS import behavior varies by product and version. QTI 2.1 is provided because Canvas currently documents QTI 1.2 and 2.1 imports; QTI 3.0 is intentionally not mislabeled as compatible. Moodle receives its own native XML export.

What this bank measures - and what it does not

These editable practice items check symbol-to-Pinyin correspondence only. They do not assess pronunciation, tone production, reading fluency or school readiness, and include no norm, level or cut score.
