Three interoperable metadata views

OAI-DC XML

One standalone Simple Dublin Core record per language edition, validated offline against the official OAI-DC and DCMI schemas.

DCMI Terms JSON-LD

A bilingual RDF graph with audience, education level, instructional method, rights, format, provenance and relations.

LRMI JSON-LD

LearningResource and Book nodes using pinned LRMI terms plus official supportingDocument and instruction concept URIs.

Repository ingest workflow

  1. 1Download the ZIP or the individual metadata syntax.
  2. 2Verify SHA-256 and confirm the linked EPUB byte length.
  3. 3Map local subjects, audience fields and repository identifiers.
  4. 4Ingest into a staging collection and inspect language display.
  5. 5Publish only after the repository's own metadata review.

Audience and age boundary

No fixed age range. Beginner learners of any age can use the reference; children should use it with a caregiver or educator.

Validation and provenance

The two XML records are validated with locally pinned official schemas. Both JSON-LD files use inline contexts and must parse without network access. DCMI and LRMI terms and the two controlled values are checked against pinned official RDF vocabularies. Source EPUB URLs, sizes, timestamps and SHA-256 values come only from the published EPUB manifest.

Protocol and scope limits

These are downloadable metadata records, not an OAI-PMH endpoint: no Identify, ListRecords or harvesting service is claimed. The package does not claim IMS or IEEE LOM conformance, universal repository compatibility, DOI or institutional approval. Strict URL importers may need a local download because static hosting can return generic XML or JSON Content-Types.

Optional practice layer

The open EPUB and metadata package work without an app. If available in your region, Lumi Bopomofo adds short on-device activities after the free repository resource.
