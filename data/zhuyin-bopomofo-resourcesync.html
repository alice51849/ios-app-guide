What the feed covers

The synchronized set is intentionally narrow: reusable Bopomofo reference data, standards metadata, static API responses and free teaching tools. Marketing pages and unrelated app content are excluded.

How synchronization works

  1. Discover the feed at /.well-known/resourcesync.
  2. Read the Capability List to locate the current Resource List.
  3. Compare SHA-256 and byte length before downloading a resource.
  4. Use the Resource List snapshot time to detect a new inventory.

Scope and limitations

This is a synchronization inventory, not a pronunciation model, speech corpus, text converter, learner assessment or curriculum. ResourceSync does not guarantee that any third-party catalog will ingest it.
