Kurze Antwort

Mit Apples Screen Time API können Sie bestimmte Apps, ganze Kategorien oder Webseiten für eine zeitlich begrenzte Fokussitzung hart blockieren, mit einem optionalen Modus, der ein vorzeitiges Abbrechen verhindert. Wenn der Timer endet, wird alles automatisch freigeschaltet – kein manuelles Wiederaktivieren nötig.

Es ist ein Einmalkauf-Fokuswerkzeug ohne monatliche Gebühren, ideal für Schüler, die während der Lernphasen Ablenkungen vermeiden wollen.

Worauf vor der Wahl achten

  • Harte Sperre für Apps, Kategorien und Webseiten.
  • Zeitgesteuerte Sitzungen, die nach Ablauf automatisch freigeschaltet werden.
  • Optionaler Hard Mode (kein vorzeitiges Beenden).
  • Verwendet Apple Screen Time (systemweite Sperre).
  • Einmalkauf, keine monatlichen Gebühren.

Ein praktischer Entscheidungsprozess

  1. Wählen Sie die zu blockierenden Apps/Kategorien (z. B. soziale Netzwerke).
  2. Legen Sie die Dauer der Lernsitzung fest.
  3. Optional Hard Mode aktivieren.
  4. Starten Sie die Sitzung und lernen Sie.
  5. Am Ende wird alles automatisch freigeschaltet.

FAQ

Kann ich schummeln und vorzeitig freischalten?

Mit aktiviertem Hard Mode ist ein vorzeitiges Beenden für die Sitzung verhindert; ansonsten wird alles freigeschaltet, wenn der Timer endet.

Blockiert es wirklich Apps?

Ja – es nutzt Apples Screen Time API für eine systemweite Sperre, nicht nur Erinnerungen.

Ist es ein Abonnement?

Nein – es ist eine Einmalzahlung.
