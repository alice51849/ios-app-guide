Formel und Grenzen

Zwischensumme = alles Bestellte zusammengerechnet. Steuer = Zwischensumme × Steuersatz. Trinkgeld = Zwischensumme × Trinkgeldsatz. Der Anteil jeder Person ist ihr Bestellwert ÷ Zwischensumme; übrige Cents gehen an die größten Nachkommateile zuerst, damit die Summe der Anteile exakt den Rechnungsbetrag ergibt.

Zwischensumme = 32.40 + 18.90 + 25.00 = 76.30
Steuer = 76.30 × 8.25% = 6.29
Trinkgeld = 76.30 × 15.00% = 11.45
Person 1: 32.40 + 2.67 + 4.86 = 39.93
Person 2: 18.90 + 1.56 + 2.84 = 23.30
Person 3: 25.00 + 2.06 + 3.75 = 30.81
Rechnungsbetrag = 94.04

Eine einzige Währung, Steuer und Trinkgeld als Prozent der Zwischensumme. Keine Währungsumrechnung, keine Regeln für Servicezuschläge, keine Empfehlung zur Trinkgeldhöhe und keine Zahlung. Angezeigt wird auf zwei Nachkommastellen, gerechnet wird in ganzen Cent.

  • Bestellt für: 0 ≤ n ≤ 100,000,000
  • Steuer % / Trinkgeld %: 0 ≤ % ≤ 100
  • Person: 1 ≤ n ≤ 20
