Punktmatrix · Vollbild · kostenlos

LED-Laufschrift-Vorschau

Testen Sie eine Nachricht so, wie sie auf einem LED-Schild aussieht — fürs Konzert, die Abholung am Flughafen oder den Hinweis an der Theke — und zeigen Sie sie im Vollbild auf Laptop oder Tablet.

Ihre Nachricht

Eintippen, Farbe und Tempo wählen, dann Vollbild.

Nur eine Browser-Vorschau. Die Helligkeit hängt vom Bildschirm ab; Eingaben werden nicht gespeichert.

So funktioniert es

  1. Der Text wird einmal in ein 16 Pixel hohes Bild gezeichnet; jedes leuchtende Pixel wird zu einer runden LED.
  2. Die Laufschrift verschiebt dieses Bild LED-Spalte für LED-Spalte im Takt der Browser-Animation, damit das Tempo auf jedem Bildschirm gleich bleibt.
  3. Spiegeln dreht die Anzeige seitenverkehrt, damit die Nachricht durch ein Fenster oder im Rückspiegel richtig lesbar ist.
  4. Vollbild nutzt den Vollbildmodus des Browsers; Esc oder der Knopf beendet ihn.

Was dieses Tool nicht tut

  • Es ist eine Browser-Vorschau, keine Handy-App: keine gespeicherten Tafeln, Schriften oder Effektpakete.
  • Es hält nicht auf jedem Gerät den Bildschirm wach — prüfen Sie für längere Nutzung die Anzeigeeinstellungen.
  • Kein Konto, kein Tracking, kein Upload.

Fragen

Gehen Emojis oder chinesische Zeichen?

Ja. Jedes Zeichen, das der Browser darstellen kann, landet auf der Tafel; sehr detailreiche Zeichen werden durch die 16 LED Höhe vereinfacht.

Wie wird es größer?

Vollbild nutzen oder das Handy im Vollbild quer halten — dann bekommen die Buchstaben mehr Höhe.

Warum ist meine Nachricht spiegelverkehrt?

Die Option Spiegeln ist an. Schalten Sie sie aus, außer Sie zeigen die Tafel durch ein Fenster.

Eine Vollbild-LED-Tafel auch auf dem iPhone?

LED Moving Text ist optional — dieses Tool läuft komplett im Browser und funktioniert auch ohne die App. Funktionen, Preis und Verfügbarkeit stehen aktuell auf der App-Store-Seite.
