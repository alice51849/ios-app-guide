Formel und Grenzen

Gewinn = Summe Einnahmen − Summe Ausgaben. Marge = Gewinn ÷ Summe Einnahmen. Netto pro Stunde = Gewinn ÷ Stunden. Beträge werden in ganzen Cent addiert, Summen driften nicht.

Summe Einnahmen = 1500.00
Summe Ausgaben = 400.39
Gewinn = 1500.00 − 400.39 = 1099.61
Marge = 1099.61 ÷ 1500.00 = 73.3%
Netto pro Stunde = 1099.61 ÷ 12.5 = 87.97

Beträge von 0 bis 100.000.000 mit höchstens zwei Nachkommastellen, bis zu 20 Einnahme- und 20 Ausgabezeilen, Stunden von 0,25 bis 2000 in Viertelstundenschritten. Eine Währung, keine Umrechnung, keine Steuer- oder Buchhaltungsberatung.

  • Betrag: 0 ≤ x ≤ 100,000,000
  • Aufgewendete Stunden: 0.25 ≤ h ≤ 2000
  • Einnahme / Ausgabe: 1 ≤ n ≤ 20
