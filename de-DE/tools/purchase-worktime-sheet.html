Formel und Grenzen

Gesamt = Menge × Endpreis. Arbeitsstunden = Gesamt ÷ Nettostundenlohn. Arbeitstage = Arbeitsstunden ÷ Stunden pro Arbeitstag.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Gib Preise inklusive Steuern ein. Keine Währungsumrechnung, Lohnabrechnung, Sparprognose oder Kaufberatung. Die Anzeige rundet auf zwei Dezimalstellen; Summen verwenden ungerundete Werte.

  • Nettoeinkommen pro Stunde: 0 < x ≤ 100000000
  • Endpreis pro Stück: 0 ≤ x ≤ 100000000
  • Stunden pro Arbeitstag: 0 < x ≤ 24
  • Menge: 1 ≤ x ≤ 999
