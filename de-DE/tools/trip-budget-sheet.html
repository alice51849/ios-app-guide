Formel und Grenzen

Frei verfügbar = Gesamtbudget − Fixkosten. Pro Tag = frei verfügbar ÷ Tage. Pro Person und Tag = pro Tag ÷ Personen. Jede Kategorie = pro Tag × ihr Anteil. Beträge werden in ganzen Cent addiert; Tageswerte werden nur bei der Anzeige gerundet.

Fixkosten = 1750.50
Frei verfügbar = 3000.00 − 1750.50 = 1249.50
Pro Tag = 1249.50 ÷ 5 = 249.90
Pro Person und Tag = 249.90 ÷ 2 = 124.95
Essen = 249.90 × 40% = 99.96
Verkehr = 249.90 × 20% = 49.98
Tickets = 249.90 × 25% = 62.48
Einkaufen = 249.90 × 15% = 37.49

Beträge von 0 bis 100.000.000 mit höchstens zwei Nachkommastellen, 1 bis 120 Tage, 1 bis 20 Personen, bis zu 15 Fixkosten, vier Anteile mit genau 100 in Summe. Durchgehend dieselbe Währung, keine Wechselkurse, keine Preis- oder Buchungsempfehlung.

  • Gesamtbudget / Betrag: 0 ≤ x ≤ 100,000,000
  • Tage: 1 ≤ d ≤ 120
  • Personen: 1 ≤ p ≤ 20
  • Anteil: Σ = 100%
  • Fixkosten: 0 ≤ n ≤ 15
