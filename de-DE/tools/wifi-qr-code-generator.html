So funktioniert es

  1. Die Seite baut denselben Text WIFI:T:…;S:…;P:…;; den Handykameras erkennen, und maskiert dabei \ ; , : " in Name und Passwort.
  2. Der Text wird von einem kleinen Encoder direkt auf dieser Seite als QR-Code (Fehlerkorrektur M) gezeichnet — kein Bild kommt von einem Server.
  3. WPA umfasst WPA2- und WPA3-Personal; Firmen-Logins mit Benutzername unterstützt das Format nicht.
  4. Der Download behält einen weißen Rand von vier Modulen, damit der Code auch gedruckt sicher scannt.

Was dieses Tool nicht tut

  • Ihr Passwort wird nirgendwohin gesendet — der Code entsteht auf Ihrem Gerät.
  • Es ändert keine Router-Einstellungen und prüft das Passwort nicht; testen Sie den Code vor dem Druck mit dem eigenen Handy.
  • Kein Konto, kein Tracking, kein Wasserzeichen.

Fragen

Welche Handys können ihn scannen?

Aktuelle Kamera-Apps von iPhone und Android erkennen WLAN-QR-Codes und bieten das Verbinden an. Ältere Geräte brauchen eventuell eine QR-App.

Ist mein Passwort im QR-Code sicher?

Wer den Code sieht, kann das Passwort lesen — genau wie bei einer beschrifteten Karte. Nutzen Sie nach Möglichkeit ein Gastnetz.

Und wenn mein Netz versteckt ist?

Wählen Sie „Verstecktes Netz: Ja“. Dann sucht das Handy nach einem Netz, das seinen Namen nicht aussendet.

Codes auch auf dem iPhone scannen und erstellen?

QR Code Halo ist optional — dieses Tool läuft komplett im Browser und funktioniert auch ohne die App. Funktionen, Preis und Verfügbarkeit stehen aktuell auf der App-Store-Seite.
