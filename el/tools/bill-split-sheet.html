Τύπος και περιορισμοί

Μερικό σύνολο = όλα όσα παραγγέλθηκαν, αθροισμένα. Φόρος = μερικό σύνολο × ποσοστό φόρου. Φιλοδώρημα = μερικό σύνολο × ποσοστό φιλοδωρήματος. Το μερίδιο του καθενός είναι η δική του παραγγελία ÷ μερικό σύνολο· τα λεπτά που περισσεύουν πάνε πρώτα στα μεγαλύτερα δεκαδικά, ώστε τα μερίδια να δίνουν ακριβώς τον λογαριασμό.

Μερικό σύνολο = 32.40 + 18.90 + 25.00 = 76.30
Φόρος = 76.30 × 8.25% = 6.29
Φιλοδώρημα = 76.30 × 15.00% = 11.45
Άτομο 1: 32.40 + 2.67 + 4.86 = 39.93
Άτομο 2: 18.90 + 1.56 + 2.84 = 23.30
Άτομο 3: 25.00 + 2.06 + 3.75 = 30.81
Σύνολο λογαριασμού = 94.04

Χρησιμοποίησε ένα νόμισμα και δώσε φόρο και φιλοδώρημα ως ποσοστό του μερικού συνόλου. Καμία μετατροπή νομίσματος, κανένας κανόνας για κουβέρ ή σέρβις, καμία σύσταση για το ύψος του φιλοδωρήματος και καμία πληρωμή. Η οθόνη στρογγυλοποιεί σε δύο δεκαδικά· ο υπολογισμός γίνεται σε ακέραια λεπτά.

  • Παρήγγειλε για: 0 ≤ n ≤ 100,000,000
  • Φόρος % / Φιλοδώρημα %: 0 ≤ % ≤ 100
  • Άτομο: 1 ≤ n ≤ 20
