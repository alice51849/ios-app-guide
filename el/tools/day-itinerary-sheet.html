Τύπος και περιορισμοί

Άφιξη = προηγούμενη αναχώρηση + μετακίνηση. Αναχώρηση = άφιξη + παραμονή. Σύνολο = όλες οι παραμονές + όλες οι μετακινήσεις. Διαθέσιμα = λήξη − έναρξη· λήξη πριν από την έναρξη μετρά ως επόμενη ημέρα. Υπέρβαση = σύνολο − διαθέσιμα· πάνω από το μηδέν ξεπερνά. Απλή αριθμητική λεπτών, χωρίς ζώνες ώρας.

1. Μέρος 1: 09:00 + 120 = 11:00 + 25 →
2. Μέρος 2: 11:25 + 60 = 12:25 + 40 →
3. Μέρος 3: 13:05 + 180 = 16:05 + 30 →
Σύνολο (λεπτά) = 455; Διαθέσιμα (λεπτά) = 09:00–18:00 = 540
Υπέρβαση (λεπτά) = 455 − 540 = -85 → Χωράει

Ώρες σε 24ωρη μορφή HH:MM, παραμονές από 5 έως 720 λεπτά, μετακινήσεις από 0 έως 600 λεπτά, έως 25 μέρη. Ωράρια λειτουργίας, πραγματική κίνηση, χάρτες, διαδρομές και κρατήσεις είναι εκτός αυτού του φύλλου.

  • Ώρα έναρξης / Ώρα λήξης: HH:MM
  • Παραμονή (λεπτά): 5 ≤ m ≤ 720
  • Μετακίνηση στο επόμενο (λεπτά): 0 ≤ m ≤ 600
  • Μέρος: 1 ≤ n ≤ 25
