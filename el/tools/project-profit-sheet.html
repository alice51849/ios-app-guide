Τύπος και περιορισμοί

Κέρδος = σύνολο εσόδων − σύνολο εξόδων. Περιθώριο = κέρδος ÷ σύνολο εσόδων. Καθαρό ανά ώρα = κέρδος ÷ ώρες εργασίας. Τα ποσά προστίθενται σε ακέραια λεπτά, ώστε τα σύνολα να μην αποκλίνουν.

Σύνολο εσόδων = 1500.00
Σύνολο εξόδων = 400.39
Κέρδος = 1500.00 − 400.39 = 1099.61
Περιθώριο = 1099.61 ÷ 1500.00 = 73.3%
Καθαρό ανά ώρα = 1099.61 ÷ 12.5 = 87.97

Ποσά από 0 έως 100.000.000 με έως δύο δεκαδικά, έως 20 γραμμές εσόδων και 20 εξόδων, ώρες από 0,25 έως 2000 σε τέταρτα. Ίδιο νόμισμα, χωρίς μετατροπή, χωρίς φορολογικές ή λογιστικές συμβουλές.

  • Ποσό: 0 ≤ x ≤ 100,000,000
  • Ώρες εργασίας: 0.25 ≤ h ≤ 2000
  • Έσοδο / Έξοδο: 1 ≤ n ≤ 20
