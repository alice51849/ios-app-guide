Τύπος και περιορισμοί

Σύνολο = ποσότητα × τελική τιμή. Ώρες = σύνολο ÷ καθαρό ωρομίσθιο. Ημέρες = ώρες ÷ ώρες ανά εργάσιμη ημέρα.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Συμπεριλάβετε τους φόρους στις τιμές. Χωρίς μετατροπή νομίσματος, μισθοδοσία, πρόβλεψη αποταμίευσης ή αγοραστικές συμβουλές. Εμφάνιση με δύο δεκαδικά· τα σύνολα χρησιμοποιούν μη στρογγυλοποιημένες τιμές.

  • Καθαρό εισόδημα ανά ώρα: 0 < x ≤ 100000000
  • Τελική τιμή μονάδας: 0 ≤ x ≤ 100000000
  • Ώρες ανά εργάσιμη ημέρα: 0 < x ≤ 24
  • Ποσότητα: 1 ≤ x ≤ 999
