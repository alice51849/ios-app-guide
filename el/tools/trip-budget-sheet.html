Τύπος και περιορισμοί

Διαθέσιμο = συνολικός προϋπολογισμός − σταθερά έξοδα. Ανά ημέρα = διαθέσιμο ÷ ημέρες. Ανά άτομο την ημέρα = ανά ημέρα ÷ ταξιδιώτες. Κάθε κατηγορία = ανά ημέρα × το μερίδιό της. Τα ποσά προστίθενται σε ακέραια λεπτά· οι ημερήσιες τιμές στρογγυλοποιούνται μόνο στην εμφάνιση.

Σταθερά έξοδα = 1750.50
Διαθέσιμο για έξοδα = 3000.00 − 1750.50 = 1249.50
Ανά ημέρα = 1249.50 ÷ 5 = 249.90
Ανά άτομο την ημέρα = 249.90 ÷ 2 = 124.95
Φαγητό = 249.90 × 40% = 99.96
Μεταφορές = 249.90 × 20% = 49.98
Εισιτήρια = 249.90 × 25% = 62.48
Ψώνια = 249.90 × 15% = 37.49

Ποσά από 0 έως 100.000.000 με το πολύ δύο δεκαδικά, 1 έως 120 ημέρες, 1 έως 20 ταξιδιώτες, έως 15 σταθερά έξοδα, τέσσερα μερίδια με άθροισμα ακριβώς 100. Παντού το ίδιο νόμισμα, χωρίς ισοτιμίες, χωρίς συμβουλές τιμών ή κρατήσεων.

  • Συνολικός προϋπολογισμός / Ποσό: 0 ≤ x ≤ 100,000,000
  • Ημέρες: 1 ≤ d ≤ 120
  • Ταξιδιώτες: 1 ≤ p ≤ 20
  • Μερίδιο: Σ = 100%
  • Σταθερά έξοδα: 0 ≤ n ≤ 15
