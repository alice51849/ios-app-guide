Formula and limits

Arrive = previous leave + travel. Leave = arrive + stay. Total = all stays + all travel. Available = end − start; an end time earlier than the start counts as the next day. Over by = total − available; anything above zero is over time. Plain minute arithmetic, no time zones.

1. Place 1: 09:00 + 120 = 11:00 + 25 →
2. Place 2: 11:25 + 60 = 12:25 + 40 →
3. Place 3: 13:05 + 180 = 16:05 + 30 →
Total (min) = 455; Available (min) = 09:00–18:00 = 540
Over by (min) = 455 − 540 = -85 → Fits

Times as 24-hour HH:MM, stays from 5 to 720 minutes, travel from 0 to 600 minutes, up to 25 stops. Opening hours, real traffic, maps, routing and bookings are outside this sheet.

  • Start time / End time: HH:MM
  • Stay (min): 5 ≤ m ≤ 720
  • Travel to next (min): 0 ≤ m ≤ 600
  • Place: 1 ≤ n ≤ 25
