Days since equals today's date minus the start date; for 100-day anniversaries counted the Korean way the start day is day one so you add one, while a D-day such as an exam counts the day itself as D-day and the day before as D-1 with nothing added.

Before counting how many days since something happened, decide whether the first day is day one or day zero. Calendar arithmetic gives the difference between two dates, so the start day itself is zero. Many anniversary traditions, including the Korean 100-day and 1,000-day milestones, count the first day as day one, which means adding one to the calendar difference. That single day is why couples and parents sometimes celebrate a milestone a day late.

Counting toward a future date works the other way. The day itself is D-day and the day before is D-1, so for an exam you set the exam date as zero and use the plain calendar difference. If you use an app for both, check once whether it treats the start date as zero or one. Doing it by hand across month boundaries is where mistakes happen, because months have different lengths, so a date calculator is more reliable than counting squares on a calendar.

The steps that actually work

  1. Write down the start date and today, then take the calendar difference, checking month lengths at each boundary.
  2. For anniversaries that count the first day as day one, add one to the result.
  3. For a future date such as an exam, set that date as D-day and use the plain difference as the D-number.
  4. Put the numbers you check daily on a Home Screen widget or the Lock Screen and confirm they change without opening the app.
  5. Turn on the 7, 3 and 1 day reminders so day 100 or the eve of the exam is not missed.

FAQ

Is day 100 ninety-nine or a hundred days after the first day?

In the Korean convention the first day is day one, so day 100 falls 99 days later. Calendar arithmetic gives 99, so add one.

How is an exam D-day counted?

The exam day is D-day and the day before is D-1. The calendar difference from today to the exam date is the D-number as it stands.
