Real redaction removes the content from that area of the PDF, saves the result as a new file, and then reopens that file to test whether the text can still be selected or found by search. If search finds the number, you only drew over it.

A PDF has layers. What Markup on iPhone does is add an annotation, a rectangle, above the page; the original text stays underneath, untouched. The recipient can select the passage, copy it into a note, search for the number, or simply delete the annotation in any editor. This happens every day with bank statements, pay slips, ID scans and proof of address, and the sender never finds out.

The right way has three parts. First, the tool has to remove the content from the region rather than cover it: after processing, there should be no text and no image inside that rectangle. Second, the result goes out as a new file with a different name, and the original stays stored separately. Third, you reopen the new file and test it: long-press on the redaction to see whether anything gets selected, and search for a piece of the ID number or address. If nothing turns up, it is safe to send.

The testing step is the one most often skipped, because doing it page by page on a ten-page statement is tedious. Mask My File is built around it: you mark areas page by page with up to 5× zoom, it redacts them permanently, then reopens the exported file and verifies it before showing Private Ready. Everything runs on the device, the original is never overwritten, and it is free to start.

What to check before you choose

  • Whether the tool removes the content of the region or only adds an annotation on top
  • Whether the result is saved as a new file without touching the original
  • Whether you can work page by page and zoom in on small numbers
  • Whether there is a step that reopens the finished file and verifies it
  • Whether it strips PDF metadata such as author and edit history

The steps that actually work

  1. List what has to go before opening the file: national ID numbers, account and branch numbers, full address, the barcode on a bill, signature and face photo.
  2. Open the PDF in a tool that removes the content of the marked area, not in Markup. Go page by page and zoom in on the small numbers in headers and footers.
  3. Mark each passage and apply a solid redaction. For text files such as CSV or an exported statement, prefer a mask or pseudonym so the context stays readable.
  4. Export as a new file with a different name and remove metadata where the format allows. Never send the edited original.
  5. Reopen the exported file, long-press on each redaction, and search for three or four digits of the ID number. Send only if nothing comes up.

FAQ

Does screenshotting the page and sending the image solve it?

For one or two pages, yes: the screenshot is a new image and the annotation becomes pixels. But quality drops, it is tedious on long documents, and the image can still carry device metadata. For a statement or a contract, redact the PDF itself.

How do I know the text under the redaction is really gone?

Reopen the exported file, long-press on the redaction and see whether anything gets selected. Then search for part of the number. If nothing is found, the content was removed.
