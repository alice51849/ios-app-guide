What is QR Code Halo: Scan & Create?

QR Code Halo: Scan & Create is an iOS app. Opens Right Away, Check Later

QR Code Halo acts as soon as a code is read. Scan with the camera or choose a photo, and links open in your browser, passkey sign-in codes and app links go directly to iOS, Wi-Fi codes bring up the iOS Join prompt, and calls, messages, email and places open in their own apps. Contacts and events open the iOS add screen for you to confirm. Text is copied with a short note, and javascript:, data: or file: codes are never opened. To look at each code first, turn off “Run action after scanning” in Settings; batch scan only collects.

Security Check in History

Each scan outside batch mode is saved on this device unless “Skip saving to history” is on. Open any code in History and tap Security Check to review it with two local tools.

Local Payload Security Inspector

Breaks the full payload into scheme, host, path, query and fragment on the device. It provides deterministic Safe, Caution or Blocked findings, the reason for each finding and an action disposition. It does not consult network reputation services or hide uncertainty behind a fuzzy score.

QR Verification

Save a result as a local reference, then compare a later scan by its complete SHA-256 fingerprint, QR format, content type, URL components, security level and action disposition.

Batch Risk & Difference Audit

Groups exact duplicates and matching hosts across a batch, then checks lookalike hosts within a deliberately bounded comparison. You can read the batch summary, each item's risk and every complete payload without losing detail, and full audit reading stays available.

A local workflow built for quick, private scanning

What QR Code Halo does

Scan with the camera or recognize codes in photos, several codes in one frame

20 barcode formats: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar and MSI Plessey

Batch scanning with duplicate suppression, zoom and flashlight

Create text, link, Wi-Fi, contact, email, phone, SMS, location and calendar event QR codes

Unlimited history with no item cap: favorites, search, filters and sorting by type, date, format, tag or category

Automatic on-device categorization with manual override, and history export as CSV

Backup and restore preview the real counts, size and date range before you decide

Privacy mode with automatic clearing, save to Photos, print, Share Extension and Siri Shortcuts

The download includes three successful scans shared by camera and photo import on each device; a failed read, cancellation or permission refusal is not counted. All nine QR creation types, unlimited on-device history and full batch-audit reading remain available. The optional one-time Lifetime Pro purchase adds unlimited scanning, batch save and actions, batch creation and CSV, committed backup and restore, high-resolution PNG, PDF and SVG export, and custom Aurora styles. There is no subscription.

QR Code Halo is not a document digitizer. It does not scan pages, perform OCR or maintain a PDF filing library; PDF export is QR artwork only. The Share Extension accepts a URL or plain text for QR creation.
