With GitHub Copilot it pays to track three things separately: the premium request allowance, chat usage and code completions. The most important is how many premium requests are left and when they next reset, because a request counts differently depending on the model.

Premium requests are the part that runs short fastest, especially with stronger models or long agent runs. Finding out from an error that nothing is left costs time. It is better to check, before a bigger task, how much remains and when the allowance resets.

A fixed warning threshold helps. With an alert at 90 percent you can switch to a lighter model in time or move the task to after the reset. If you use several accounts, such as work and personal, see them side by side so you pick the right one for the next task.

For GitHub Copilot, UsageNow shows premium requests, chat and code completions, with a live countdown to the reset and the exact time in your region's format. You set your own alerts by percentage, flip through all accounts in the widget and see the state on the Lock Screen and Apple Watch. Claude, ChatGPT Codex and Gemini can be tracked alongside.

What to check before you choose

  • How many premium requests are left
  • Exactly when the allowance resets
  • Whether you get a warning before the limit
  • Whether several accounts are visible side by side
  • Whether you can see the state on the Home Screen without a browser

The steps that actually work

  1. Check premium requests before starting a bigger task.
  2. Look up when the allowance resets.
  3. Set an alert at a percentage such as 90.
  4. When it runs low, switch to a lighter model or another account.
  5. Turn on a reset alert so you know when it is available again.

FAQ

Does UsageNow only show Copilot?

No. Alongside GitHub Copilot it shows Claude, ChatGPT Codex and Gemini, each with their own limits and resets.

How often will I be warned?

Each alert fires only once per limit and cycle, so your Lock Screen stays quiet.

Where are my sign-in details kept?

You sign in on the service's own page and the sign-in stays in your device's keychain. UsageNow only talks to the services themselves.
