Extracting 7z on iPhone: why it will not open and what to do

You tap a .7z from an email or download and the iPhone shows nothing. The phone is fine and the file is usually fine too; the issue is the format.

The built-in Files app on iPhone handles ZIP, not 7z. Open the file in an app that supports 7z and you can see what is inside. For split files named .7z.001, .7z.002 and so on, save every part in the same folder and open .001. For password-protected files, get the password from the sender; 7z can also encrypt file names, so an empty list before you enter it is normal.

7z is known for strong compression and is often used to send large photo folders or document sets. The Files app on iPhone and iPad extracts ZIP but not 7z, so you get no preview and no app to open it in. The file is not broken; opening it in an app that supports 7z is the quickest fix.

Split archives are a common cause of failure. Large 7z files come as name.7z.001, name.7z.002 and onwards, and if one is missing extraction cannot finish. Saving attachments or cloud files one by one often scatters them across folders. Put them all in one folder, check the numbers run without gaps, then open the first part.

Password-protected 7z files usually use AES-256 encryption. If the password is lost, there is no practical way to crack it, so ask the sender. Also watch storage: extracted files take more space than the archive, so if you only need one file, check the contents and take out just that file instead of extracting everything.

What to check before you choose

  • Formats: opens 7z as well as RAR, ZIP, TAR, ISO and others
  • Split archives: supports parts such as .7z.001
  • Passwords: opens password-protected archives

The steps that actually work

  1. Save the .7z to On My iPhone or iCloud Drive in the Files app
  2. For split files, gather every part from .001 to the last number in one folder
  3. Open the first file in a 7z-capable app from Files or the share sheet
  4. Enter the password if asked and check the contents list before extracting
  5. Pick only the files you need and save them to Photos or Files

FAQ

Can the iPhone Files app extract 7z on its own?

No. The Files app handles ZIP; 7z needs a supporting app.

Can I open just one part of a split 7z?

Extraction needs every part. Save .001 through the last part in one folder, then open the first file.

What if I forgot the 7z password?

Ask the sender. There is no practical way to open an AES-256 encrypted 7z without the password.
