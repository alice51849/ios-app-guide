Because every AI tool counts usage differently, the practical approach is to put Claude's 5-hour and weekly limits, Codex's 5-hour and weekly windows, Copilot's premium requests and Gemini's per-model daily quotas on one widget, each with its reset time.

People looking for an AI usage tracker usually juggle several tools, not one. Each counts in its own way: Claude has a 5-hour session limit and weekly limits including per-model weekly caps, ChatGPT Codex has a 5-hour window and a weekly window, GitHub Copilot has premium requests, and Gemini has a daily request quota for each model. Opening each service page in turn to check is enough on its own to stop your work.

UsageNow brings all four onto one screen and shows them on Home Screen and Lock Screen widgets in every size and as Apple Watch complications. Each reset gets a live countdown and the exact reset time in your local format; you can flip through accounts on the widget and tap it to refresh. Sort by 5-hour reset, weekly reset, highest or lowest usage, name or service.

Which tool to switch to next can come from an alert. Pick the 5-hour limit, the weekly limit or all limits, type a percentage such as 90 or 98, and each alert arrives once per limit and cycle. Sign-in happens on each service's official login page and stays in the device's Keychain. There is no UsageNow server, no account to create and no tracking.

What to check before you choose

  • Whether every AI tool you use shows up on one screen
  • Whether each tool's own kind of limit is shown separately
  • Whether there is a countdown and an exact reset time
  • Whether the order can change, by service or by usage
  • Whether sign-in stays on the device with no separate server

The steps that actually work

  1. Sign in to each service you use on its official login page.
  2. Add a widget to the Home Screen or Lock Screen.
  3. Sort by service, or by the nearest 5-hour reset.
  4. Create alerts at 90 or 98 for the tools that tend to run close to their limits.
  5. Turn on the reset alert and switch back as soon as a tool returns.
