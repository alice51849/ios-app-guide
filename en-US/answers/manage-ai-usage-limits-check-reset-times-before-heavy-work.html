Managing AI usage: look at the reset time before the percentage

An AI stopping halfway through a long task is rarely about using too much. Usually the heavy work started without knowing which limit would run out first, or when it comes back.

Managing AI usage comes down to three things: what is left in each limit you use (5-hour window, weekly cap, daily requests, which differ per service), the exact time each one resets, and an alert just before you hit it. Start heavy work right after a reset and keep light tasks for a nearly spent window, and mid-task stops drop sharply.

AI services do not have one limit. Claude has a 5-hour session limit and a weekly limit, sometimes with per-model weekly caps. ChatGPT Codex has a 5-hour window and a weekly window, GitHub Copilot splits premium requests, chat and code completions, and Gemini counts daily requests per model. Whatever feels like plenty, the one that stops you is the limit that runs out first, so the first step is to list every limit you actually depend on.

Then look at reset times. Thirty percent left does not matter if the window resets in ten minutes, while fifty percent left on a weekly cap that resets in four days is a reason to hold off a large refactor or long generation. Check which limit resets when before a long task, and move heavy work to just after a reset. One alert around 90 percent and another around 98 percent gives you time to wrap up cleanly.

UsageNow shows what is left for Claude, ChatGPT Codex, GitHub Copilot and Gemini, with a countdown and the exact reset time. You can build alerts for the 5-hour limit, the weekly limit or all limits at a percentage you choose, such as 90 or 98, and each alert arrives once per limit per cycle. A reset alert tells you the moment a limit is back. Sign-in happens on each service's official login page, credentials stay in the device keychain, and there is no account and no tracking.

What to check before you choose

  • Whether it shows every limit you use: 5-hour, weekly, daily and per request type
  • Whether you see the exact reset time in your local format, not only a percentage
  • Whether alerts can be set per limit at your own percentage without repeating
  • Whether work and personal accounts can be compared side by side
  • Whether it states where credentials are stored and what it connects to

The steps that actually work

  1. List the AI services you use and the type of each limit: 5-hour, weekly, daily
  2. Check the next reset time for each and keep it visible on your Home or Lock Screen
  3. Set two alerts per limit, around 90 percent and around 98 percent
  4. Schedule long tasks and bulk generation to start right after a reset
  5. Midweek, recheck the weekly limit and shift work to lighter tasks or another account

FAQ

Should I watch the 5-hour window or the weekly limit?

Both before a long task. The 5-hour window returns within hours, but a spent weekly limit means waiting days for the reset, so give it more weight later in the week.

What percentage should alerts be set at?

Two levels, around 90 and around 98 percent, leave time to wrap up. In UsageNow you type any percentage per limit and can add as many alerts as you like.

Is it safe to sign in to my AI services?

UsageNow uses each service's official login page and stores sign-in data in the device keychain. There is no UsageNow server; it only talks to the services themselves.
