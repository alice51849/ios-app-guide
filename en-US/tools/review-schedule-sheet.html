Formula and limits

Review date = written on + 1, 3, 7, 16 and 35 days. Days left = review date − today, so a negative number is a date that has already gone by. Next review = the first date that is today or later.

Review date = Written on + [+1 · +3 · +7 · +16 · +35]
Note 1: 2026-09-01 → 2026-09-02 (-5), 2026-09-04 (-3), 2026-09-08 (+1), 2026-09-17 (+10), 2026-10-06 (+29)
Note 2: 2026-09-06 → 2026-09-07 (+0), 2026-09-09 (+2), 2026-09-13 (+6), 2026-09-22 (+15), 2026-10-11 (+34)
Note 3: 2026-08-20 → 2026-08-21 (-17), 2026-08-23 (-15), 2026-08-27 (-11), 2026-09-05 (-2), 2026-09-24 (+17)
Next review = 2026-09-07
Review dates = 3 × 5 = 15

A fixed interval ladder, not a memory model: nothing here predicts what you will remember, scores a note or marks an answer. Dates only, with no times, no time zones, no reminders and no notifications.

  • Today / Written on: YYYY-MM-DD
  • Review: +1 · +3 · +7 · +16 · +35
  • Note: 1 ≤ n ≤ 20
