Para quien reconoce ㄅㄆㄇ pero se detiene al unir los sonidos. Elige un conjunto corto, pronuncia cada parte y descubre después la sílaba.

Prepara un conjunto breve

Elige un paso

Señala el primer símbolo, haz una pausa, di el segundo y desliza el dedo hacia la sílaba unida.

El mismo modo, cantidad y número siempre devuelve las mismas tarjetas.

Toca una tarjeta para ver la sílaba unida y una palabra conocida.

Al imprimir se muestran todas las respuestas y se ocultan los controles. Recorta las tarjetas o conserva la hoja para deslizar el dedo.

Reconocer y combinar son pasos distintos

Una tarjeta de símbolos pregunta qué es cada signo; estas tarjetas practican cómo varias partes forman una sílaba. Incluyen solo ejemplos seleccionados, no todas las sílabas posibles.

Rutina tranquila en cuatro pasos

  1. Señala cada símbolo sin pedir rapidez.
  2. Pronuncia las partes con una pausa breve.
  3. Desliza un dedo mientras acortas la pausa.
  4. Muestra la sílaba y relaciónala con la palabra conocida.

Sin presión

Usa pocas tarjetas y para cuando el niño quiera. La herramienta no registra respuestas ni mide dominio, preparación o dificultad.

¿Puntúa a mi hijo?

No. No hay aciertos, errores, tiempo, nivel ni progreso guardado.

¿Es una tabla completa de sílabas?

No. Es un conjunto breve de ejemplos para combinar sonidos y comparar tonos.

¿Diagnostica una dificultad?

No. Es práctica acompañada, no evaluación, diagnóstico ni medida escolar.

¿Salen datos del navegador?

No se recogen respuestas; los ajustes se reinician al cerrar la página.
