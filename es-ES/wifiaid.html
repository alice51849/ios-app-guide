¿Qué es WiFi Aid: Diagnóstico de red?

WiFi Aid: Diagnóstico de red es una app de iOS. Diagnóstico router, mesh, DNS

Optimizada para el iPhone Duo. Creada con el SDK más reciente, la app ocupa toda la pantalla interior y ajusta su diseño automáticamente, con el dispositivo plegado o desplegado.

¿La wifi vuelve a ir lenta o se corta? WiFi Aid comprueba la wifi, el DNS e internet con un toque y te dice si el problema está probablemente en tu wifi, el DNS, tu proveedor de internet o una sola web, con las pruebas de cada diagnóstico.

El test profundo sigue tomando muestras para detectar conexiones intermitentes que parecen conectadas pero van a tirones, y en redes wifi mesh muestra a qué nodo estás conectado y si ha cambiado desde el último test.

Haz el test desde el Apple Watch o desde un widget de la pantalla de inicio; el historial se queda solo en este dispositivo.

• Hacer test — comprueba wifi, DNS e internet con un toque y obtén el diagnóstico en segundos

• Test profundo — más muestras de estabilidad para cazar fallos que van y vienen

• Probar una web — descubre si solo falla un sitio o toda la conexión

• Pruebas completas — DNS, TCP, TLS, TTFB, HTTP, IP directa, IPv4 e IPv6, punto por punto

• Nodo mesh — mira a qué nodo estás conectado y si has cambiado de nodo

• Historial — compara resultados anteriores, guardados solo en este dispositivo

• Apple Watch — haz un test desde la muñeca

• Widget y iPad — estado de la conexión en la pantalla de inicio y diseño completo para iPad
