Fórmula y límites

Próximo vencimiento = última vez + intervalo. En meses se conserva el mismo día; si no existe, se usa el último día del mes (incluidos años bisiestos). Días restantes = vencimiento − hoy. Atrasada si es menor que 0; próxima de 0 a 7.

2026-06-01 + 3 meses = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 semana = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 meses = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Intervalos de 1 a 3650 días, semanas o meses. Fechas entre 1900-01-01 y 2999-12-31. Hasta 30 tareas. Sin recordatorios, notificaciones ni sincronización con el calendario; nada sale de esta página.

  • Intervalo: 1 ≤ x ≤ 3650
  • Última vez: 1900-01-01 ≤ x ≤ 2999-12-31
  • Tarea: 1 ≤ n ≤ 30
