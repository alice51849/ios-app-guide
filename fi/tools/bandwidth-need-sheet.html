Kaava ja rajoitukset

Rivin summa = laitteet × laitekohtainen arvo. Tarve = rivien summa. Vara = liittymä − tarve; alle 20 % liittymästä on tiukka, alle nollan ei riitä. Luvut lasketaan kokonaisina Mbit/s-kymmenesosina, joten summat eivät koskaan ajaudu.

Ostos 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
Ostos 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
Ostos 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
Tarvittava lataus = 25.0; Tarvittava lähetys = 8.5
Vara ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
Tila = Riittää

Laitekohtaiset luvut ovat suuntaa antavia suunnitteluarvoja palveluiden omista suosituksista (Netflix, Zoom, konsolivalmistajat, FCC). Taulukko suunnittelee; se ei mittaa liittymääsi.

  • Suoratoisto (SD): 3.0 ↓ / 0.5 ↑ Mbps
  • Suoratoisto (HD): 5.0 ↓ / 0.5 ↑ Mbps
  • Suoratoisto (4K): 15.0 ↓ / 0.5 ↑ Mbps
  • Videopuhelut: 3.0 ↓ / 3.0 ↑ Mbps
  • Verkkopelaaminen: 3.0 ↓ / 1.0 ↑ Mbps
  • Pilvivarmuuskopiointi: 1.0 ↓ / 5.0 ↑ Mbps
  • Selailu ja viestit: 1.0 ↓ / 0.5 ↑ Mbps
  • Älykodin laitteet: 0.5 ↓ / 0.5 ↑ Mbps

Liittymän nopeudet 0,5–10000 Mbit/s enintään yhdellä desimaalilla, 1–50 laitetta riviä kohti, enintään 20 riviä. Wi‑Fi-kuuluvuus, viive ja todellisuudessa toimitettu nopeus eivät kuulu tähän taulukkoon.

  • Liittymän lataus (Mbit/s) / Liittymän lähetys (Mbit/s): 0.5 ≤ x ≤ 10000 Mbps
  • Laitteet: 1 ≤ n ≤ 50
  • Ostos: 1 ≤ n ≤ 20
