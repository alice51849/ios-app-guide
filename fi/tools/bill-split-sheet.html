Kaava ja rajoitukset

Välisumma = kaikki tilattu yhteenlaskettuna. Vero = välisumma × veroprosentti. Tippi = välisumma × tippiprosentti. Kunkin osuus on oma tilaus ÷ välisumma; yli jäävät sentit menevät ensin suurimmille desimaaleille, joten osuudet summautuvat tarkalleen laskun loppusummaksi.

Välisumma = 32.40 + 18.90 + 25.00 = 76.30
Vero = 76.30 × 8.25% = 6.29
Tippi = 76.30 × 15.00% = 11.45
Henkilö 1: 32.40 + 2.67 + 4.86 = 39.93
Henkilö 2: 18.90 + 1.56 + 2.84 = 23.30
Henkilö 3: 25.00 + 2.06 + 3.75 = 30.81
Lasku yhteensä = 94.04

Käytä yhtä valuuttaa ja anna vero ja tippi prosentteina välisummasta. Ei valuuttamuunnosta, ei palvelumaksusääntöjä, ei suositusta tipin määrästä eikä maksamista. Näytöllä pyöristetään kahteen desimaaliin; jako lasketaan kokonaisina sentteinä.

  • Tilasi: 0 ≤ n ≤ 100,000,000
  • Vero % / Tippi %: 0 ≤ % ≤ 100
  • Henkilö: 1 ≤ n ≤ 20
