Kaava ja rajoitukset

Saapuminen = edellinen lähtö + siirtymä. Lähtö = saapuminen + viipymä. Yhteensä = kaikki viipymät + kaikki siirtymät. Käytettävissä = päättyminen − alkaminen; alkamista aikaisempi päättymisaika lasketaan seuraavaksi päiväksi. Ylitys = yhteensä − käytettävissä; nollan ylittävä osa ylittyy. Pelkkää minuuttilaskentaa, ei aikavyöhykkeitä.

1. Kohde 1: 09:00 + 120 = 11:00 + 25 →
2. Kohde 2: 11:25 + 60 = 12:25 + 40 →
3. Kohde 3: 13:05 + 180 = 16:05 + 30 →
Yhteensä (min) = 455; Käytettävissä (min) = 09:00–18:00 = 540
Ylitys (min) = 455 − 540 = -85 → Mahtuu

Ajat 24 tunnin muodossa HH:MM, viipymät 5–720 minuuttia, siirtymät 0–600 minuuttia, enintään 25 kohdetta. Aukioloajat, todellinen liikenne, kartat, reititys ja varaukset eivät kuulu tähän taulukkoon.

  • Alkamisaika / Päättymisaika: HH:MM
  • Viipymä (min): 5 ≤ m ≤ 720
  • Siirtymä seuraavaan (min): 0 ≤ m ≤ 600
  • Kohde: 1 ≤ n ≤ 25
