Kaava ja rajoitukset

Seuraava eräpäivä = viimeksi tehty + väli. Kuukausissa päivä pysyy samana; jos sitä ei ole, käytetään kuun viimeistä päivää (myös karkausvuosina). Päiviä jäljellä = eräpäivä − tänään. Myöhässä alle 0; pian 0–7.

2026-06-01 + 3 kuukautta = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 viikko = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 kuukautta = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Välit 1–3650 päivää, viikkoa tai kuukautta. Päivämäärät 1900-01-01–2999-12-31. Enintään 30 tehtävää. Ei muistutuksia, ilmoituksia tai kalenterisynkronointia; mikään ei poistu tältä sivulta.

  • Väli: 1 ≤ x ≤ 3650
  • Viimeksi tehty: 1900-01-01 ≤ x ≤ 2999-12-31
  • Tehtävä: 1 ≤ n ≤ 30
