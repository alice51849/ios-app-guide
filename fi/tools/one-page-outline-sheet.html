Muuta sekavat kokousmuistiinpanot yhden sivun tiivistelmäksi: yksi otsikko, kolmesta kahteentoista avainkohtaa, yksi seuraava toimenpide ja valinnainen mittari, ja lataa se taulukkona, jonka voit liittää diaan tai yhteenvetoon.

Kaava ja rajoitukset

Taulukko säilyttää sanasi sellaisinaan: otsikko, sitten kohdat kirjoittamassasi järjestyksessä, sitten seuraava toimenpide ja lopuksi mittari. Se laskee kohdat ja poistaa reunojen välilyönnit; mitään ei kirjoiteta uudelleen, tiivistetä tai pisteytetä.

Otsikko ≤ 80 · Kohta × 3 ≤ 160 · Seuraava toimenpide ≤ 160 · Mittari ≤ 60
Osio: Otsikko → Kohta 1…3 → Seuraava toimenpide → Mittari

Otsikko enintään 80 merkkiä, 3–12 kohtaa enintään 160 merkkiä kukin, seuraava toimenpide enintään 160 merkkiä, mittari enintään 60 merkkiä. Jokaisen rivin on oltava yksirivistä tekstiä. Taulukko ei lue tiedostoja, tallenteita tai kalentereita.

  • Otsikko: ≤ 80
  • Kohta: 3 ≤ n ≤ 12, ≤ 160
  • Seuraava toimenpide: ≤ 160
  • Mittari: ≤ 60
