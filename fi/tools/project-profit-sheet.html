Kaava ja rajoitukset

Voitto = tulot yhteensä − menot yhteensä. Marginaali = voitto ÷ tulot yhteensä. Netto per tunti = voitto ÷ käytetyt tunnit. Summat lasketaan yhteen kokonaisina sentteinä, joten loppusummat eivät ajaudu.

Tulot yhteensä = 1500.00
Menot yhteensä = 400.39
Voitto = 1500.00 − 400.39 = 1099.61
Marginaali = 1099.61 ÷ 1500.00 = 73.3%
Netto per tunti = 1099.61 ÷ 12.5 = 87.97

Summat 0–100 000 000 enintään kahdella desimaalilla, enintään 20 tulo- ja 20 menoriviä, tunnit 0,25–2000 varttitunnin askelin. Sama valuutta, ei valuutanvaihtoa, ei vero- tai kirjanpitoneuvontaa.

  • Summa: 0 ≤ x ≤ 100,000,000
  • Käytetyt tunnit: 0.25 ≤ h ≤ 2000
  • Tulo / Meno: 1 ≤ n ≤ 20
