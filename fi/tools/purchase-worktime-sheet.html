Kaava ja rajoitukset

Yhteensä = määrä × yksikköhinta. Työtunnit = summa ÷ nettotuntitulo. Työpäivät = työtunnit ÷ työtunnit päivässä.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Sisällytä verot hintoihin. Ei valuutanvaihtoa, palkanlaskentaa, säästöennusteita tai ostosuosituksia. Näyttö pyöristää kahteen desimaaliin; summat lasketaan pyöristämättömistä arvoista.

  • Nettotulo tunnissa: 0 < x ≤ 100000000
  • Lopullinen yksikköhinta: 0 ≤ x ≤ 100000000
  • Työtunnit päivässä: 0 < x ≤ 24
  • Määrä: 1 ≤ x ≤ 999
