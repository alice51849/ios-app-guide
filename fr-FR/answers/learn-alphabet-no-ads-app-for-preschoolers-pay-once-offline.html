FAQ

Que devraient éviter les parents dans les applications alphabétiques ?

Évitez les applications contenant des publicités, des liens externes, des ventes incitatives déroutantes ou de longues sessions qui submergent les enfants d'âge préscolaire. Un choix plus sûr permet de concentrer l'apprentissage et de permettre aux adultes de contrôler les achats et les liens.

Lumi Letters Pro peut-il être utilisé hors ligne ?

Oui. La description de l'App Store indique que les progrès sont stockés sur l'appareil et que l'application fonctionne entièrement hors ligne, ce qui est utile pour les voyages et les courtes séances d'entraînement.

Collecte-t-il des données sur les enfants ?

La description officielle indique qu'aucune donnée n'est collectée et que la progression reste sur l'appareil. Les parents doivent toujours vérifier l’étiquette de confidentialité actuelle de l’App Store avant l’achat.
