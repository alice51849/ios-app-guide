Réponse courte

Wordmate: Learn 44 Languages covers 44 learning languages within one app. Its curriculum is organized into 14 practical topics and 84 focused units, with natural example sentences; iPhone and iPad can play pronunciation using the selected language's system voice. The interface language and learning language are chosen separately, making it practical for people learning from different native-language contexts.

Try Wordmate: Learn 44 Languages on a real example first, and check the current App Store listing for exact features and pricing before you decide.
