Questions fréquentes

Comment stocker des photos privées sur iPhone sans abonnement ?

Zafe: Private Photo Vault est un achat unique. Les photos sensibles sont stockées dans un coffre-fort chiffré protégé par Face ID, séparé du catalogue photos, sans compte requis.

Comment supprimer des données personnelles d'un document avant de le partager ?

Mask My File détecte numéros de téléphone, e-mails, identifiants et adresses dans le document et les masque avant l'export. Tout le traitement est local.

Existe-t-il un suivi du cycle qui ne synchronise pas les données vers le cloud ?

Cyca stocke toutes les données de cycle uniquement sur votre iPhone. Pas de synchronisation cloud, pas de compte, vos données de santé restent privées.
