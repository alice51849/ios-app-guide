QR Code Halo suit un parcours simple : inspecter le contenu décodé, décider à partir d'éléments visibles, puis agir volontairement. La détection d'un code ne déclenche jamais son ouverture.

Local Payload Security Inspector

Analyse localement le payload complet et détaille scheme, host, path, query et fragment. Des règles déterministes affichent Safe, Caution ou Blocked, des findings transparents et l'action disposition. Aucun service de réputation en ligne ni score flou n'intervient ; une action impossible à interpréter reste bloquée.

QR Verification

Enregistrez un résultat comme référence locale, puis comparez une analyse ultérieure selon l'empreinte SHA-256 complète, le format QR, le type de contenu, les composants URL, le niveau de sécurité et l'action.

Batch Risk & Difference Audit

Regroupe les doublons exacts et les résultats partageant le même host, puis compare dans un périmètre borné les host qui peuvent se ressembler. Le résumé, le risque de chaque élément et chaque payload intégral restent lisibles. La consultation complète de l'audit est accessible.
