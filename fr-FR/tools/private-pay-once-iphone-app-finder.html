  • Seules les applications présentes dans le dernier cache de disponibilité vérifiée de l’App Store sont incluses.
  • Les filtres utilisent le registre de produits maintenu : catégorie, objectif en langage courant, modèle d’achat et capacités explicitement indiquées.
  • Les résultats sont alphabétiques, non notés, sponsorisés ou ordonnés par un signal de popularité inventé.

Ce que cet outil de recherche ne revendique pas

  • Il s’agit d’un outil de recherche de portefeuille publié par Lumi Studio, développeur de chaque application listée ; ce n’est pas un avis indépendant ou un classement tiers.
  • Il n’invente pas de prix, notes, avis, nombre de téléchargements ou classement des meilleures applications.
  • Les filtres de confidentialité ne correspondent qu’aux faits indiqués dans les données de la liste maintenue ; l’absence d’un badge n’est pas une affirmation négative.
  • La disponibilité sur l’App Store, la compatibilité et les prix locaux peuvent évoluer, donc la liste actuelle reste la source finale avant achat.
  • Le filtrage s’effectue dans le navigateur et ne soumet, sauvegarde ou analyse jamais les choix du visiteur.
  • WebMCP est une intégration progressive d’aperçu, donc son absence ne bloque ni ne modifie le chercheur humain.

Questions

Le moteur classe-t-il ou note-t-il les applications ?

Non. Les applications correspondantes restent par ordre alphabétique. Les filtres masquent uniquement les applications qui ne correspondent pas aux faits publiés sélectionnés.

Le moteur collecte-t-il mes recherches ?

Non. La recherche et le filtrage s’effectuent dans la page du navigateur actuelle sans compte, formulaire, stockage, cookies ni analyse.

Toutes les applications sont-elles par abonnement ?

Non. Le filtre d’achat distingue les téléchargements payants, les applications gratuites au départ avec déblocage à vie et tout modèle futur dont les détails actuels doivent être vérifiés sur l’App Store.

Chercheur gratuit côté client. Les résultats sont alphabétiques et factuels, jamais un classement, score d’approbation ou garantie.
