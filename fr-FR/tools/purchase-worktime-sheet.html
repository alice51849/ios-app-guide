Formule et limites

Total = quantité × prix unitaire TTC. Heures = total ÷ revenu horaire net. Jours = heures ÷ durée d’une journée de travail.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Saisissez des prix taxes comprises. Sans conversion de devises, calcul de paie, prévision d’épargne ni conseil d’achat. Affichage à deux décimales ; totaux calculés sans arrondi intermédiaire.

  • Revenu net par heure: 0 < x ≤ 100000000
  • Prix unitaire TTC: 0 ≤ x ≤ 100000000
  • Heures par jour de travail: 0 < x ≤ 24
  • Quantité: 1 ≤ x ≤ 999
