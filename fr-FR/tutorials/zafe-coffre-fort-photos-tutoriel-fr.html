Comment utiliser Zafe Private Photo Vault sur iPhone — Guide complet

1
Télécharger et ouvrir Zafe

Téléchargez Zafe sur l'App Store. Au premier lancement, configurez Face ID ou un code PIN pour protéger le coffre-fort.

2
Importer des photos depuis votre pellicule

Appuyez sur + et sélectionnez des photos de votre pellicule. Elles sont copiées dans le coffre-fort chiffré.

3
Supprimer les originaux de la pellicule

Après avoir vérifié que les photos sont bien dans Zafe, supprimez-les de la pellicule pour garantir leur confidentialité.

4
Accéder à votre coffre-fort

Verrouillez l'iPhone et rouvrez Zafe. Face ID ou le code PIN est requis à chaque accès.

5
Exporter des photos si nécessaire

Pour partager ou restaurer une photo, appuyez dessus dans Zafe puis utilisez le bouton Partager pour l'exporter.

Questions fréquentes

Que se passe-t-il si j'oublie mon code PIN Zafe ?

Si vous oubliez votre code PIN et que Face ID n'est pas disponible, il est impossible d'accéder aux photos du coffre-fort. Définissez un code mémorable ou activez Face ID.

Les photos Zafe sont-elles synchronisées avec iCloud ?

Non. Zafe ne se connecte à aucun service cloud. Les photos restent uniquement sur votre appareil.

Puis-je déplacer toutes mes photos privées en même temps ?

Oui. Appuyez sur + dans Zafe et sélectionnez toutes les photos souhaitées. Après les avoir importées et vérifiées, supprimez-les de la pellicule.
