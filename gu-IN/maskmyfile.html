Mask My File શું છે?

Mask My File એક iOS ઍપ છે. શેર કરતાં પહેલાં માહિતી ઢાંકો

ઉપયોગી સંદર્ભ ગુમાવ્યા વિના સુરક્ષિત રીતે શેર કરો. Mask My File તમે ફાઇલ મોકલો તે પહેલાં ખાનગી વિગતો શોધે છે, તેને કાયમ માટે ઢાંકે છે, પછી તૈયાર થયેલી નવી ફાઇલ ફરી ખોલીને ચકાસે છે અને ત્યાર બાદ જ Private Ready બતાવે છે.

તમે શું કરી શકો

• છબીઓ અને PDF: પૂર્ણ-પહોળાઈ પૂર્વાવલોકન, 5× સુધી ઝૂમ, ખેંચીને ખસેડવું, અને ચોક્કસ મેન્યુઅલ પસંદગી.

• દૃશ્ય ફાઇલો: કાયમી નક્કર આવરણ અથવા ફક્ત દૂર કરો. ચહેરો અને બારકોડ શોધ માત્ર તમારી સમીક્ષા માટે વિસ્તાર દર્શાવે છે.

• ટેક્સ્ટ, JSON, XML, HTML, CSV, TSV અને RTF: દરેક મેળ શોધો; તારા વડે સંપૂર્ણ ઢાંકો, આંશિક ઢાંકો, સ્થાનધારક મૂકો, ઉપનામ આપો કે દૂર કરો.

• જ્યાં જરૂરી હોય ત્યાં મેટાડેટા દૂર કરો. PDF માં પાનાં-દર-પાનાં કામ કરો, અથવા 100 ફાઇલ સુધી—દરેક ફાઇલનું અલગ પૂર્વાવલોકન, ફાઇલો વચ્ચે શોધ, અને ફાઇલદીઠ મેન્યુઅલ પસંદગી સાથે.

• ખાનગી સત્ર, પ્રોજેક્ટ કાર્યસ્થળ અને સ્થાનધારક તિજોરી વડે તમારું કામ વ્યવસ્થિત રાખો.

જ્યારે મહત્ત્વનું હોય ત્યારે વાપરો

ભાડાની અરજી મોકલતાં પહેલાં, તબીબી દસ્તાવેજ શેર કરતાં પહેલાં, કે ગ્રાહકની ફાઇલ સાથીને સોંપતાં પહેલાં—ખાનગી વિગતોને કાયમ માટે ઢાંકીને ઉપયોગી સંદર્ભ જાળવી રાખો.

ડિઝાઇનથી જ ખાનગી

બધું જ તમારા ઉપકરણ પર પ્રક્રિયા થાય છે. કોઈ એકાઉન્ટ, જાહેરાત, ટ્રેકિંગ, વિશ્લેષણ કે સામગ્રી અપલોડ નથી. Apple Vision અને સમાવિષ્ટ Tesseract OCR સ્થાનિક રીતે ચાલે છે. ચહેરા શોધ માત્ર વિસ્તાર બનાવે છે: તે વ્યક્તિને ઓળખતું નથી, ટેમ્પલેટ બનાવતું નથી, અને ચહેરાનો ડેટા શેર કે સંગ્રહ કરતું નથી. ખરીદી Apple તેના StoreKit દ્વારા સંભાળે છે. Mask My File કોઈ VPN, NetworkExtension, પ્રોક્સી, ટનલ, DNS ફિલ્ટર કે નેટવર્ક રૂટિંગ વાપરતું નથી. મૂળ ફાઇલો ક્યારેય ઓવરરાઇટ થતી નથી; અસ્થાયી કાર્યસ્થળ ફાઇલો, ખાનગી સત્ર ડેટા અને પ્રોજેક્ટ તમે કાઢી ન નાખો ત્યાં સુધી ઉપકરણ પર રહે છે.

એક વાર ખરીદો, આજીવન વાપરો

માત્ર એક જ વાર ચૂકવણી કરો અને આજીવન અનલૉક મેળવો, જેનાથી તમે અમર્યાદિત ચકાસાયેલ આઉટપુટ અને બેચ પ્રક્રિયા કરી શકશો. કોઈ સબ્સ્ક્રિપ્શનની જરૂર નથી. App Store દ્વારા તમારી ખરીદી સરળતાથી પુનઃસ્થાપિત કરો.
