QR Code Halo વિચારપૂર્વકનો ક્રમ રાખે છે: decode થયેલું વિષય જુઓ, દેખાતા findings સમજો અને પછી જ ક્રિયા પસંદ કરો. માત્ર code ઓળખાવાથી કંઈ આપમેળે ખુલતું નથી.

Local Payload Security Inspector

આખું payload ઉપકરણ પર જ વિશ્લેષિત કરીને scheme, host, path, query અને fragment અલગ બતાવે છે. નક્કી નિયમો Safe, Caution અથવા Blocked, પારદર્શક findings અને action disposition આપે છે. Online reputation કે અસ્પષ્ટ score વપરાતો નથી; સુરક્ષિત રીતે સમજાય નહીં એવી ક્રિયા blocked રહે છે.

QR Verification

પરિણામને સ્થાનિક સંદર્ભ તરીકે સાચવો, પછી સંપૂર્ણ SHA-256 ફિંગરપ્રિન્ટ, QR ફોર્મેટ, સામગ્રી પ્રકાર, URL ઘટકો, સુરક્ષા સ્તર અને ક્રિયા પ્રમાણે પછીનું સ્કૅન સરખાવો.

Batch Risk & Difference Audit

ચોક્કસ સમાન પરિણામો અને સમાન host ધરાવતા પરિણામોના જૂથ બનાવે છે, પછી સ્પષ્ટ મર્યાદામાં ગૂંચવણ પેદા કરી શકે એવા host સરખાવે છે. સારાંશ, દરેક itemનું જોખમ અને બધા સંપૂર્ણ payload વાંચી શકાય છે. આખું audit જોઈ શકાય છે.

QR Code Halo શું કરે છે

કૅમેરાથી સ્કેન કરો કે ફોટામાંના કોડ ઓળખો, એક જ ફ્રેમમાં અનેક કોડ

દરેક પરિણામ માટે સુરક્ષિત પ્રિવ્યૂ: પૂરી સામગ્રી, લિંકની સ્કીમ અને હોસ્ટ, અને શંકાસ્પદ ફોર્મેટની ચેતવણી

20 બારકોડ ફોર્મેટ: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar અને MSI Plessey

ડુપ્લિકેટ અટકાવ, ઝૂમ અને ફ્લેશલાઇટ સાથે બેચ સ્કેનિંગ

ટેક્સ્ટ, લિંક, Wi-Fi, સંપર્ક, ઈમેલ, ફોન, SMS, સ્થાન અને કૅલેન્ડર ઇવેન્ટના QR કોડ બનાવો

અમર્યાદિત ઇતિહાસ, એન્ટ્રીની કોઈ મર્યાદા નથી: મનપસંદ, શોધ, પ્રકાર, તારીખ, ફોર્મેટ, ટૅગ કે શ્રેણી પ્રમાણે ફિલ્ટર અને સૉર્ટિંગ

ડિવાઇસ પર જ આપોઆપ વર્ગીકરણ, જે હાથે બદલી શકાય, અને ઇતિહાસનું CSV એક્સપોર્ટ

બેકઅપ અને રિસ્ટોર બંને નિર્ણય લેતાં પહેલાં ખરી સંખ્યા, કદ અને તારીખની અવધિ બતાવે છે

Lifetime Pro: અમર્યાદિત સ્કેન, સ્કેન કરેલા બેચને ઇતિહાસમાં સાચવવો અને તેનાં પરિણામ ખોલવાં, બેચ ક્રિએશન અને બેચ CSV, બેકઅપ કે રિસ્ટોર ચલાવવું, હાઈ રિઝોલ્યુશન PNG, PDF અને SVG એક્સપોર્ટ, અને કસ્ટમ Aurora સ્ટાઇલ

ઑટોમૅટિક ક્લિયરિંગ સાથેનો પ્રાઇવસી મોડ, Photos માં સેવ, પ્રિન્ટ, Share Extension અને Siri Shortcuts

QR Code Halo એ App Store પરથી મફત ડાઉનલોડ છે: ત્રણ મફત સ્કેન, બધા નવ QR પ્રકાર અને મનપસંદ, શોધ તથા ફિલ્ટર સાથે અમર્યાદિત ઇતિહાસ, એન્ટ્રીની કોઈ મર્યાદા વગર, જાહેરાત અને એકાઉન્ટ વગર. એક વૈકલ્પિક Lifetime Pro ખરીદી અમર્યાદિત સ્કેનિંગ, સ્કેન કરેલા બેચને સાચવવાનું અને ખોલવાનું, બેચ ક્રિએશન અને બેચ CSV, બેકઅપ અને રિસ્ટોર, હાઈ રિઝોલ્યુશન એક્સપોર્ટ અને કસ્ટમ Aurora સ્ટાઇલ ઉમેરે છે, અને તે કાયમ માટે તમારી રહે છે. કોઈ સબ્સ્ક્રિપ્શન નથી.
