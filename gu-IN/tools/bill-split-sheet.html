સૂત્ર અને મર્યાદાઓ

પેટા સરવાળો = બધા ઓર્ડરનો સરવાળો. ટૅક્સ = પેટા સરવાળો × ટૅક્સ દર. ટિપ = પેટા સરવાળો × ટિપ દર. દરેકનો હિસ્સો એટલે પોતાનો ઓર્ડર ÷ પેટા સરવાળો; વધેલા પૈસા પહેલા સૌથી મોટા દશાંશવાળાને જાય છે, એટલે બધા હિસ્સા મળીને હંમેશા આખું બિલ થાય છે.

પેટા સરવાળો = 32.40 + 18.90 + 25.00 = 76.30
ટૅક્સ = 76.30 × 8.25% = 6.29
ટિપ = 76.30 × 15.00% = 11.45
વ્યક્તિ 1: 32.40 + 2.67 + 4.86 = 39.93
વ્યક્તિ 2: 18.90 + 1.56 + 2.84 = 23.30
વ્યક્તિ 3: 25.00 + 2.06 + 3.75 = 30.81
બિલનો કુલ = 94.04

એક જ ચલણ વાપરો અને ટૅક્સ તથા ટિપ પેટા સરવાળાની ટકાવારીમાં ભરો. ચલણ રૂપાંતર નહીં, સર્વિસ ચાર્જના નિયમો નહીં, કેટલી ટિપ આપવી તેની સલાહ નહીં અને ચુકવણી પણ નહીં. સ્ક્રીન પર બે દશાંશ સુધી બતાવાય છે; ગણતરી આખા પૈસામાં થાય છે.

  • કેટલાનું મંગાવ્યું: 0 ≤ n ≤ 100,000,000
  • ટૅક્સ % / ટિપ %: 0 ≤ % ≤ 100
  • વ્યક્તિ: 1 ≤ n ≤ 20
