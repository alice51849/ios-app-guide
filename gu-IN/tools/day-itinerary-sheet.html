09:00 થી 18:00 નો દિવસ: સંગ્રહાલય (120 મિનિટ, 25 મિનિટ મુસાફરી), બપોરનું ભોજન (60 મિનિટ, 40 મિનિટ) અને જૂનું શહેર (180 મિનિટ, 30 મિનિટ): ઉપલબ્ધ 540 માંથી 455 મિનિટ વપરાય છે, એટલે 85 મિનિટ બચાવીને સમાય છે.

સૂત્ર અને મર્યાદાઓ

પહોંચવું = અગાઉનું નીકળવું + મુસાફરી. નીકળવું = પહોંચવું + રોકાણ. કુલ = બધાં રોકાણ + બધી મુસાફરી. ઉપલબ્ધ = અંત − શરૂઆત; શરૂઆત પહેલાંનો અંત બીજો દિવસ ગણાય. વધારે = કુલ − ઉપલબ્ધ; શૂન્યથી ઉપર હોય તો સમય વટાવે છે. ફક્ત મિનિટનો સરવાળો, ટાઇમ ઝોન નહીં.

1. સ્થળ 1: 09:00 + 120 = 11:00 + 25 →
2. સ્થળ 2: 11:25 + 60 = 12:25 + 40 →
3. સ્થળ 3: 13:05 + 180 = 16:05 + 30 →
કુલ (મિનિટ) = 455; ઉપલબ્ધ (મિનિટ) = 09:00–18:00 = 540
વધારે (મિનિટ) = 455 − 540 = -85 → સમાય છે

સમય 24-કલાક HH:MM સ્વરૂપમાં, રોકાણ 5 થી 720 મિનિટ, મુસાફરી 0 થી 600 મિનિટ, વધુમાં વધુ 25 સ્થળો. ખુલવાનો સમય, વાસ્તવિક ટ્રાફિક, નકશા, રૂટ અને બુકિંગ આ શીટની બહાર છે.

  • શરૂઆતનો સમય / અંતનો સમય: HH:MM
  • રોકાણ (મિનિટ): 5 ≤ m ≤ 720
  • આગલા સ્થળ સુધી (મિનિટ): 0 ≤ m ≤ 600
  • સ્થળ: 1 ≤ n ≤ 25
