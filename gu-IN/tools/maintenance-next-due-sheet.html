સૂત્ર અને મર્યાદાઓ

આગલી તારીખ = છેલ્લે કર્યું + અંતર. મહિનામાં એજ દિવસ રહે છે; ન હોય તો મહિનાનો છેલ્લો દિવસ લેવાય છે (લીપ વર્ષ સહિત). બાકી દિવસો = આગલી તારીખ − આજે. 0 થી ઓછું મોડું; 0 થી 7 ટૂંક સમયમાં.

2026-06-01 + 3 મહિનો = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 અઠવાડિયું = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 મહિનો = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

અંતર 1 થી 3650 દિવસ, અઠવાડિયા કે મહિના. તારીખો 1900-01-01 થી 2999-12-31. વધુમાં વધુ 30 કામ. કોઈ રિમાઇન્ડર, સૂચના કે કૅલેન્ડર સિંક નહીં; કંઈ પણ આ પેજ બહાર જતું નથી.

  • અંતર: 1 ≤ x ≤ 3650
  • છેલ્લે કર્યું: 1900-01-01 ≤ x ≤ 2999-12-31
  • કામ: 1 ≤ n ≤ 30
