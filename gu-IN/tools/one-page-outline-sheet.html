મીટિંગ નોંધોથી એક પાનાની રૂપરેખા

અવ્યવસ્થિત મીટિંગ નોંધોને એક પાનાની રૂપરેખામાં ફેરવો: એક શીર્ષક, ત્રણથી બાર મુખ્ય મુદ્દા, એક આગળનું પગલું અને વૈકલ્પિક માપદંડ, પછી સ્લાઇડ કે સારાંશમાં પેસ્ટ કરી શકાય તેવી શીટ ડાઉનલોડ કરો.

પાયલટમાં 48% છોડી દેવું

તમારી વિગતો આ ટૅબમાં જ રહે છે. અપલોડ, ખાતું, વિગતોનું ટ્રૅકિંગ કે સંગ્રહ નથી. ફરી લોડ કરવાથી ફેરફારો ભૂંસાઈ જાય છે.

પૂર્ણ ઉદાહરણ

ચેકઆઉટ રીડિઝાઇનની નોંધો આવી બને છે: શીર્ષક «30 સપ્ટેમ્બર સુધીમાં નવું ચેકઆઉટ લોન્ચ કરો», ત્રણ મુદ્દા (સરનામાના પગલે ડ્રોપ-ઓફ થાય છે, પાયલટે છોડી દેવાનો દર ઘટાડ્યો, એન્જિનિયરિંગને બે અઠવાડિયાં વધુ જોઈએ), આગળનું પગલું «સોમવારે વધારાનો સ્પ્રિન્ટ મંજૂર કરો» અને માપદંડ «પાયલટમાં 48% છોડી દેવું».

સૂત્ર અને મર્યાદાઓ

શીટ તમારા શબ્દો જેમના તેમ રાખે છે: શીર્ષક, પછી તમે લખેલા ક્રમમાં મુદ્દા, પછી આગળનું પગલું, પછી માપદંડ. તે મુદ્દા ગણે છે અને કિનારીની ખાલી જગ્યા કાઢે છે; કંઈ ફરી લખાતું, ટૂંકાવાતું કે સ્કોર થતું નથી.

શીર્ષક ≤ 80 · મુદ્દો × 3 ≤ 160 · આગળનું પગલું ≤ 160 · માપદંડ ≤ 60
વિભાગ: શીર્ષક → મુદ્દો 1…3 → આગળનું પગલું → માપદંડ

શીર્ષક વધુમાં વધુ 80 અક્ષર, 3 થી 12 મુદ્દા દરેક વધુમાં વધુ 160 અક્ષર, આગળનું પગલું વધુમાં વધુ 160 અક્ષર, માપદંડ વધુમાં વધુ 60 અક્ષર. દરેક લીટી એક લીટીનું લખાણ હોવી જોઈએ. શીટ ફાઇલો, રેકોર્ડિંગ કે કૅલેન્ડર વાંચતી નથી.

  • શીર્ષક: ≤ 80
  • મુદ્દો: 3 ≤ n ≤ 12, ≤ 160
  • આગળનું પગલું: ≤ 160
  • માપદંડ: ≤ 60
