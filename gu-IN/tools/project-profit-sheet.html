પ્રોજેક્ટ નફા શીટ

ફ્રીલાન્સ પ્રોજેક્ટ કે નાના કામમાં શું આવ્યું અને શું ખર્ચ થયો તે લખો, પછી કુલ નફો, માર્જિન અને કલાક દીઠ ચોખ્ખી આવક સાથેની શીટ ડાઉનલોડ કરો.

ઉકેલેલું ઉદાહરણ

સૂત્ર અને મર્યાદાઓ

નફો = કુલ આવક − કુલ ખર્ચ. માર્જિન = નફો ÷ કુલ આવક. કલાક દીઠ ચોખ્ખું = નફો ÷ લગાડેલા કલાક. રકમ પૂરા પૈસામાં ઉમેરાય છે, એટલે સરવાળા ખસતા નથી.

કુલ આવક = 1500.00
કુલ ખર્ચ = 400.39
નફો = 1500.00 − 400.39 = 1099.61
માર્જિન = 1099.61 ÷ 1500.00 = 73.3%
કલાક દીઠ ચોખ્ખું = 1099.61 ÷ 12.5 = 87.97

રકમ 0 થી 100,000,000 સુધી વધુમાં વધુ બે દશાંશ સાથે, વધુમાં વધુ 20 આવક અને 20 ખર્ચની હરોળ, કલાક 0.25 થી 2000 સુધી પા કલાકના પગલે. એક જ ચલણ, કોઈ વિનિમય નહીં, કોઈ કર કે હિસાબી સલાહ નહીં.

  • રકમ: 0 ≤ x ≤ 100,000,000
  • લગાડેલા કલાક: 0.25 ≤ h ≤ 2000
  • આવક / ખર્ચ: 1 ≤ n ≤ 20
