સૂત્ર અને મર્યાદાઓ

કુલ = જથ્થો × અંતિમ એકમ કિંમત. કામના કલાક = કુલ ÷ કલાકદીઠ ચોખ્ખી આવક. કાર્યદિવસ = કામના કલાક ÷ દરરોજના કામના કલાક.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

કિંમતમાં કર સામેલ કરો. ચલણ રૂપાંતર, પગાર ગણતરી, બચતની આગાહી કે ખરીદીની સલાહ નથી. દેખાવ બે દશાંશ સુધી છે; કુલ મૂળ મૂલ્યોથી ગણાય છે.

  • કલાકદીઠ ચોખ્ખી આવક: 0 < x ≤ 100000000
  • કર સહિત એકમ કિંમત: 0 ≤ x ≤ 100000000
  • દર કાર્યદિવસના કલાક: 0 < x ≤ 24
  • જથ્થો: 1 ≤ x ≤ 999
