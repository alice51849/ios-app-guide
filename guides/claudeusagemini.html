Tracking AI coding plan limits on iPhone: what to check

If you code with AI agents every day, the limit that cuts you off mid-task is the one to watch: how much of each plan is left and exactly when it resets. Each service counts in its own way: Claude has a 5-hour session limit and weekly limits, including per-model weekly caps; ChatGPT Codex has 5-hour and weekly windows; GitHub Copilot counts premium requests, chat and code completions; Gemini sets daily request quotas for each model. A tracker worth keeping puts all of them side by side with a live countdown to every reset, and lets work and personal accounts sit next to each other.

What to look for

  • Claude 5-hour and weekly limits, Codex windows, Copilot premium requests and Gemini daily quotas in one view.
  • A live countdown and the exact reset time, in your local format, for every limit.
  • Alerts at a percentage you choose, sent once per limit and cycle, with an optional reset alert.
  • Home Screen widgets you can refresh and flip through with a tap, plus Lock Screen widgets and Apple Watch complications.
  • Sign-in on each service's own login page, kept in the Keychain, with no extra account, server or tracking.
