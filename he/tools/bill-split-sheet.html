נוסחה ומגבלות

סכום ביניים = כל ההזמנות יחד. מס = סכום ביניים × אחוז המס. טיפ = סכום ביניים × אחוז הטיפ. החלק של כל אחד הוא ההזמנה שלו ÷ סכום הביניים; האגורות שנשארות הולכות קודם לשברים הגדולים ביותר, כך שסכום החלקים תמיד יוצא בדיוק החשבון.

סכום ביניים = 32.40 + 18.90 + 25.00 = 76.30
מס = 76.30 × 8.25% = 6.29
טיפ = 76.30 × 15.00% = 11.45
אדם 1: 32.40 + 2.67 + 4.86 = 39.93
אדם 2: 18.90 + 1.56 + 2.84 = 23.30
אדם 3: 25.00 + 2.06 + 3.75 = 30.81
סך החשבון = 94.04

השתמשו במטבע אחד, והזינו מס וטיפ כאחוז מסכום הביניים. בלי המרת מטבע, בלי כללי דמי שירות, בלי המלצה כמה טיפ להשאיר ובלי תשלומים. התצוגה מעגלת לשתי ספרות; החישוב עצמו נעשה באגורות שלמות.

  • הזמין ב: 0 ≤ n ≤ 100,000,000
  • מס % / טיפ %: 0 ≤ % ≤ 100
  • אדם: 1 ≤ n ≤ 20
