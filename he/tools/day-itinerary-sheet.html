נוסחה ומגבלות

הגעה = יציאה קודמת + נסיעה. יציאה = הגעה + שהייה. סה״כ = כל השהיות + כל הנסיעות. זמין = סיום − התחלה; סיום מוקדם מההתחלה נחשב ליום הבא. חריגה = סה״כ − זמין; מעל אפס חורג. חשבון דקות פשוט, בלי אזורי זמן.

1. מקום 1: 09:00 + 120 = 11:00 + 25 →
2. מקום 2: 11:25 + 60 = 12:25 + 40 →
3. מקום 3: 13:05 + 180 = 16:05 + 30 →
סה״כ (דק') = 455; זמין (דק') = 09:00–18:00 = 540
חריגה (דק') = 455 − 540 = -85 → נכנס

שעות בפורמט 24 שעות HH:MM, שהייה 5 עד 720 דקות, נסיעה 0 עד 600 דקות, עד 25 מקומות. שעות פתיחה, תנועה אמיתית, מפות, ניווט והזמנות אינם חלק מהגיליון.

  • שעת התחלה / שעת סיום: HH:MM
  • שהייה (דק'): 5 ≤ m ≤ 720
  • נסיעה לבא (דק'): 0 ≤ m ≤ 600
  • מקום: 1 ≤ n ≤ 25
