נוסחה ומגבלות

הגיליון שומר על המילים שלכם כפי שהן: כותרת, אחר כך הנקודות בסדר שהקלדתם, אחר כך הפעולה הבאה ולבסוף המדד. הוא סופר את הנקודות ומסיר רווחים בקצוות; שום דבר לא נכתב מחדש, לא מתומצת ולא מדורג.

כותרת ≤ 80 · נקודה × 3 ≤ 160 · הפעולה הבאה ≤ 160 · מדד ≤ 60
מקטע: כותרת → נקודה 1…3 → הפעולה הבאה → מדד

כותרת עד 80 תווים, 3 עד 12 נקודות של עד 160 תווים כל אחת, פעולה הבאה עד 160 תווים, מדד עד 60 תווים. כל שורה חייבת להיות טקסט בשורה אחת. הגיליון לא קורא קבצים, הקלטות או יומנים.

  • כותרת: ≤ 80
  • נקודה: 3 ≤ n ≤ 12, ≤ 160
  • הפעולה הבאה: ≤ 160
  • מדד: ≤ 60
