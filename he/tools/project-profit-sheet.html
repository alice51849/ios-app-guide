נוסחה ומגבלות

רווח = סך הכנסות − סך הוצאות. שולי רווח = רווח ÷ סך הכנסות. נטו לשעה = רווח ÷ שעות שהושקעו. הסכומים נסכמים באגורות שלמות, ולכן הסיכומים לא נסחפים.

סך הכנסות = 1500.00
סך הוצאות = 400.39
רווח = 1500.00 − 400.39 = 1099.61
שולי רווח = 1099.61 ÷ 1500.00 = 73.3%
נטו לשעה = 1099.61 ÷ 12.5 = 87.97

סכומים בין 0 ל‑100,000,000 עם שתי ספרות עשרוניות לכל היותר, עד 20 שורות הכנסה ו‑20 שורות הוצאה, שעות בין 0.25 ל‑2000 בקפיצות של רבע שעה. מטבע אחד, ללא המרה, ללא ייעוץ מס או חשבונאות.

  • סכום: 0 ≤ x ≤ 100,000,000
  • שעות שהושקעו: 0.25 ≤ h ≤ 2000
  • הכנסה / הוצאה: 1 ≤ n ≤ 20
