सूत्र और सीमाएँ

पहुँचना = पिछला निकलना + आगे का समय। निकलना = पहुँचना + ठहराव। कुल = सभी ठहराव + सभी आने-जाने का समय। उपलब्ध = अंत − शुरू; शुरू से पहले का अंत अगला दिन माना जाता है। अधिक = कुल − उपलब्ध; शून्य से ऊपर हो तो समय से अधिक। सिर्फ़ मिनटों का जोड़, समय-क्षेत्र नहीं।

1. जगह 1: 09:00 + 120 = 11:00 + 25 →
2. जगह 2: 11:25 + 60 = 12:25 + 40 →
3. जगह 3: 13:05 + 180 = 16:05 + 30 →
कुल (मिनट) = 455; उपलब्ध (मिनट) = 09:00–18:00 = 540
अधिक (मिनट) = 455 − 540 = -85 → समा जाता है

समय 24-घंटे HH:MM में, ठहराव 5 से 720 मिनट, आने-जाने का समय 0 से 600 मिनट, अधिकतम 25 जगहें। खुलने के समय, असली ट्रैफ़िक, नक्शे, रास्ते और बुकिंग इस शीट में शामिल नहीं हैं।

  • शुरू का समय / अंत का समय: HH:MM
  • ठहराव (मिनट): 5 ≤ m ≤ 720
  • अगली जगह तक (मिनट): 0 ≤ m ≤ 600
  • जगह: 1 ≤ n ≤ 25
