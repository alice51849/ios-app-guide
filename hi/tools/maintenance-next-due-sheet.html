सूत्र और सीमाएँ

अगली तारीख = आखिरी बार + अंतराल। महीनों में वही दिन रहता है; न होने पर महीने का आखिरी दिन लिया जाता है (लीप वर्ष सहित)। बचे दिन = अगली तारीख − आज। 0 से कम देर हो चुकी; 0 से 7 जल्द देय।

2026-06-01 + 3 महीने = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 सप्ताह = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 महीने = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

अंतराल 1 से 3650 दिन, सप्ताह या महीने। तारीखें 1900-01-01 से 2999-12-31 तक। अधिकतम 30 काम। कोई रिमाइंडर, सूचना या कैलेंडर सिंक नहीं; कुछ भी इस पेज से बाहर नहीं जाता।

  • अंतराल: 1 ≤ x ≤ 3650
  • आखिरी बार: 1900-01-01 ≤ x ≤ 2999-12-31
  • काम: 1 ≤ n ≤ 30
