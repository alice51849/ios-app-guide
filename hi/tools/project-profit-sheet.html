सूत्र और सीमाएँ

लाभ = कुल आय − कुल व्यय। मार्जिन = लाभ ÷ कुल आय। प्रति घंटा शुद्ध = लाभ ÷ लगे घंटे। राशियाँ पूरे पैसों में जोड़ी जाती हैं, इसलिए योग नहीं बिगड़ते।

कुल आय = 1500.00
कुल व्यय = 400.39
लाभ = 1500.00 − 400.39 = 1099.61
मार्जिन = 1099.61 ÷ 1500.00 = 73.3%
प्रति घंटा शुद्ध = 1099.61 ÷ 12.5 = 87.97

राशि 0 से 100,000,000 तक अधिकतम दो दशमलव के साथ, अधिकतम 20 आय और 20 व्यय पंक्तियाँ, घंटे 0.25 से 2000 तक चौथाई घंटे के चरणों में। एक ही मुद्रा, कोई विनिमय नहीं, कोई कर या लेखा सलाह नहीं।

  • राशि: 0 ≤ x ≤ 100,000,000
  • लगे घंटे: 0.25 ≤ h ≤ 2000
  • आय / व्यय: 1 ≤ n ≤ 20
