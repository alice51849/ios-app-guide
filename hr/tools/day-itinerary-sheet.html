Formula i ograničenja

Dolazak = prethodni odlazak + put. Odlazak = dolazak + boravak. Ukupno = svi boravci + svi putovi. Raspoloživo = kraj − početak; kraj raniji od početka broji se kao sljedeći dan. Prekoračenje = ukupno − raspoloživo; sve iznad nule prekoračuje. Čista računica u minutama, bez vremenskih zona.

1. Mjesto 1: 09:00 + 120 = 11:00 + 25 →
2. Mjesto 2: 11:25 + 60 = 12:25 + 40 →
3. Mjesto 3: 13:05 + 180 = 16:05 + 30 →
Ukupno (min) = 455; Raspoloživo (min) = 09:00–18:00 = 540
Prekoračenje (min) = 455 − 540 = -85 → Stane

Vremena u 24-satnom formatu HH:MM, boravci od 5 do 720 minuta, putovi od 0 do 600 minuta, najviše 25 mjesta. Radno vrijeme, stvarni promet, karte, rute i rezervacije nisu dio tablice.

  • Početak / Kraj: HH:MM
  • Boravak (min): 5 ≤ m ≤ 720
  • Put do sljedećeg (min): 0 ≤ m ≤ 600
  • Mjesto: 1 ≤ n ≤ 25
