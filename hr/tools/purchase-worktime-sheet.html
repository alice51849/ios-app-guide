Formula i ograničenja

Ukupno = količina × konačna cijena. Sati = ukupni iznos ÷ neto prihod po satu. Dani = sati ÷ sati po radnom danu.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Unesite cijene s porezom. Bez konverzije valuta, obračuna plaće, predviđanja uštede ili savjeta za kupnju. Prikaz se zaokružuje na dvije decimale; zbrojevi koriste nezaokružene vrijednosti.

  • Neto prihod po satu: 0 < x ≤ 100000000
  • Konačna jedinična cijena: 0 ≤ x ≤ 100000000
  • Sati po radnom danu: 0 < x ≤ 24
  • Količina: 1 ≤ x ≤ 999
