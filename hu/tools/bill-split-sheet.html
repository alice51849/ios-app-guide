Képlet és korlátok

Részösszeg = az összes rendelés összeadva. Adó = részösszeg × adókulcs. Borravaló = részösszeg × borravalókulcs. Mindenki adó- és borravalórésze a saját rendelése ÷ részösszeg; a maradék fillérek előbb a legnagyobb tizedesekhez kerülnek, így a részek összege mindig pontosan kiadja a számlát.

Részösszeg = 32.40 + 18.90 + 25.00 = 76.30
Adó = 76.30 × 8.25% = 6.29
Borravaló = 76.30 × 15.00% = 11.45
Személy 1: 32.40 + 2.67 + 4.86 = 39.93
Személy 2: 18.90 + 1.56 + 2.84 = 23.30
Személy 3: 25.00 + 2.06 + 3.75 = 30.81
Számla összesen = 94.04

Egyetlen pénznemet használj, az adót és a borravalót a részösszeg százalékaként add meg. Nincs átváltás, nincs szervizdíjszabály, nincs javaslat a borravaló mértékére és nincs fizetés. A képernyőn két tizedesre kerekítünk; az osztás egész fillérekkel számol.

  • Ennyiért rendelt: 0 ≤ n ≤ 100,000,000
  • Adó % / Borravaló %: 0 ≤ % ≤ 100
  • Személy: 1 ≤ n ≤ 20
