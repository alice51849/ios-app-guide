Képlet és korlátok

Érkezés = előző indulás + út. Indulás = érkezés + tartózkodás. Összesen = minden tartózkodás + minden út. Rendelkezésre áll = befejezés − kezdés; a kezdésnél korábbi befejezés a következő napnak számít. Túllépés = összesen − rendelkezésre áll; nulla felett túlfut. Egyszerű percszámítás, időzónák nélkül.

1. Helyszín 1: 09:00 + 120 = 11:00 + 25 →
2. Helyszín 2: 11:25 + 60 = 12:25 + 40 →
3. Helyszín 3: 13:05 + 180 = 16:05 + 30 →
Összesen (perc) = 455; Rendelkezésre áll (perc) = 09:00–18:00 = 540
Túllépés (perc) = 455 − 540 = -85 → Belefér

Idők 24 órás HH:MM formátumban, tartózkodás 5–720 perc, út 0–600 perc, legfeljebb 25 helyszín. Nyitvatartás, valós forgalom, térkép, útvonaltervezés és foglalás nem része a táblázatnak.

  • Kezdés / Befejezés: HH:MM
  • Tartózkodás (perc): 5 ≤ m ≤ 720
  • Út a következőhöz (perc): 0 ≤ m ≤ 600
  • Helyszín: 1 ≤ n ≤ 25
