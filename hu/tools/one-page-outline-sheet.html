Képlet és korlátok

A táblázat változatlanul megőrzi a szavaidat: címsor, majd a pontok a beírt sorrendben, aztán a következő lépés, végül a mérőszám. Megszámolja a pontokat és levágja a szélső szóközöket; semmit nem ír át, foglal össze vagy pontoz.

Címsor ≤ 80 · Pont × 3 ≤ 160 · Következő lépés ≤ 160 · Mérőszám ≤ 60
Szakasz: Címsor → Pont 1…3 → Következő lépés → Mérőszám

Címsor legfeljebb 80 karakter, 3–12 pont egyenként legfeljebb 160 karakter, következő lépés legfeljebb 160 karakter, mérőszám legfeljebb 60 karakter. Minden sor egysoros szöveg legyen. A táblázat nem olvas fájlokat, felvételeket vagy naptárakat.

  • Címsor: ≤ 80
  • Pont: 3 ≤ n ≤ 12, ≤ 160
  • Következő lépés: ≤ 160
  • Mérőszám: ≤ 60
