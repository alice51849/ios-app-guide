Képlet és korlátok

Összesen = mennyiség × végső egységár. Munkaóra = összeg ÷ nettó órabér. Munkanap = munkaóra ÷ napi munkaóra.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Adóval növelt árakat adj meg. Nincs pénzváltás, bérszámfejtés, megtakarítási előrejelzés vagy vásárlási tanács. A kijelzés két tizedesre kerekít; az összesítés kerekítetlen értékeket használ.

  • Nettó jövedelem óránként: 0 < x ≤ 100000000
  • Végső egységár: 0 ≤ x ≤ 100000000
  • Óra munkanaponként: 0 < x ≤ 24
  • Mennyiség: 1 ≤ x ≤ 999
