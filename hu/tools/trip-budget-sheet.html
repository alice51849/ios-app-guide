Képlet és korlátok

Szabadon költhető = teljes keret − fix költségek. Naponta = szabadon költhető ÷ napok. Főre és napra = naponta ÷ utazók. Minden kategória = naponta × az aránya. Az összegeket egész fillérekben adjuk össze; a napi számokat csak megjelenítéskor kerekítjük.

Fix költségek = 1750.50
Szabadon költhető = 3000.00 − 1750.50 = 1249.50
Naponta = 1249.50 ÷ 5 = 249.90
Főre és napra = 249.90 ÷ 2 = 124.95
Étkezés = 249.90 × 40% = 99.96
Közlekedés = 249.90 × 20% = 49.98
Belépők = 249.90 × 25% = 62.48
Vásárlás = 249.90 × 15% = 37.49

Összegek 0 és 100 000 000 között legfeljebb két tizedessel, 1–120 nap, 1–20 utazó, legfeljebb 15 fix költség, négy arány, amely pontosan 100-at ad. Végig ugyanaz a pénznem, nincs árfolyam, nincs ár- vagy foglalási tanács.

  • Teljes keret / Összeg: 0 ≤ x ≤ 100,000,000
  • Napok: 1 ≤ d ≤ 120
  • Utazók: 1 ≤ p ≤ 20
  • Arány: Σ = 100%
  • Fix költségek: 0 ≤ n ≤ 15
