Jawaban singkat

Dengan menggunakan API Screen Time Apple, Anda dapat memblokir aplikasi tertentu, seluruh kategori, atau situs web untuk sesi fokus berwaktu, dengan mode opsional yang mencegah keluar lebih awal. Saat pengatur waktu berakhir, semuanya terbuka sendiri — tanpa perlu mengaktifkan ulang secara manual.

Ini adalah alat fokus bayar sekali tanpa biaya bulanan, cocok untuk pelajar yang hanya ingin gangguan hilang selama blok revisi.

Apa yang harus diperhatikan sebelum memilih

  • Blok ketat pada aplikasi, kategori, dan situs web.
  • Sesi berwaktu yang otomatis terbuka saat selesai.
  • Mode Sulit opsional (tanpa keluar awal).
  • Menggunakan Screen Time Apple (blok tingkat sistem).
  • Bayar sekali, tanpa biaya bulanan.

Proses pengambilan keputusan yang praktis

  1. Pilih aplikasi/kategori yang ingin diblokir (misalnya sosial media).
  2. Atur durasi sesi belajar.
  3. Opsional aktifkan Mode Sulit.
  4. Mulai sesi dan belajar.
  5. Semua terbuka secara otomatis di akhir sesi.

FAQ

Bisakah saya curang dan membuka kunci lebih awal?

Dengan Mode Sulit diaktifkan, keluar awal dicegah selama sesi; jika tidak, semuanya terbuka saat pengatur waktu berakhir.

Apakah ini benar-benar memblokir aplikasi?

Ya — ini menggunakan API Screen Time Apple untuk blok sistem, bukan hanya pengingat.

Apakah ini langganan?

Tidak — bayar sekali.
