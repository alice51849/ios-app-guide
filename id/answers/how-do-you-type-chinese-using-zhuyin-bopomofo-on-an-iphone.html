Can my child type Chinese after learning Zhuyin?

Yes — Zhuyin is a built-in iPhone keyboard, so learning the 37 symbols lets a child type traditional Chinese, not just read it.

How do I add the Zhuyin keyboard?

Settings > General > Keyboard > Keyboards > Add New Keyboard, then choose the Chinese (Traditional) Zhuyin option.

Does Lumi Bopomofo teach typing?

Lumi Bopomofo teaches the 37 symbols, tones and penggabungan — the foundation you use to type with the system Zhuyin keyboard.
