Rumus dan batasan

Total per baris = perangkat × nilai per perangkat. Kebutuhan = jumlah semua baris. Sisa ruang = paket − kebutuhan; di bawah 20% paket berarti mepet, di bawah nol berarti kurang. Dijumlahkan dalam sepersepuluh Mbps bulat, jadi totalnya tidak pernah meleset.

Belanja 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
Belanja 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
Belanja 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
Unduh yang dibutuhkan = 25.0; Unggah yang dibutuhkan = 8.5
Sisa ruang ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑

Angka per perangkat adalah nilai perkiraan untuk perencanaan dari panduan layanan itu sendiri (Netflix, Zoom, produsen konsol, FCC). Lembar ini merencanakan; tidak mengukur jalur Anda.

  • Streaming (SD): 3.0 ↓ / 0.5 ↑ Mbps
  • Streaming (HD): 5.0 ↓ / 0.5 ↑ Mbps
  • Streaming (4K): 15.0 ↓ / 0.5 ↑ Mbps
  • Panggilan video: 3.0 ↓ / 3.0 ↑ Mbps
  • Game online: 3.0 ↓ / 1.0 ↑ Mbps
  • Cadangan cloud: 1.0 ↓ / 5.0 ↑ Mbps
  • Browsing dan pesan: 1.0 ↓ / 0.5 ↑ Mbps
  • Perangkat rumah pintar: 0.5 ↓ / 0.5 ↑ Mbps

Kecepatan paket 0,5 sampai 10000 Mbps dengan maksimal satu desimal, 1 sampai 50 perangkat per baris, maksimal 20 baris. Jangkauan Wi‑Fi, latensi, dan kecepatan sebenarnya dari penyedia berada di luar lembar ini.

  • Unduh paket (Mbps) / Unggah paket (Mbps): 0.5 ≤ x ≤ 10000 Mbps
  • Perangkat: 1 ≤ n ≤ 50
  • Belanja: 1 ≤ n ≤ 20
