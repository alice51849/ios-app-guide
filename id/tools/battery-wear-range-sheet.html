Rumus dan batasan

Keausan per bulan = (100 − kapasitas) ÷ umur dalam bulan, ditampilkan dengan pita ±25%. Bulan hingga 80% = (kapasitas − 80) ÷ keausan; batas bawah dari laju tinggi, batas atas dari laju rendah. Siklus per bulan = siklus ÷ umur.

Perangkat 1: (100 − 88) ÷ 24 = 0.50 %/Umur (bulan) → ±25% → 0.38–0.63; (88 − 80) ÷ Keausan % per bulan → 12–22
Perangkat 2: (100 − 100) ÷ 1 = 0.00 %/Umur (bulan) → ±25% → 0.00–0.00; (100 − 80) ÷ Keausan % per bulan → Belum ada keausan terukur
Perangkat 3: (100 − 79) ÷ 66 = 0.32 %/Umur (bulan) → ±25% → 0.24–0.40; (79 − 80) ÷ Keausan % per bulan → Sudah di 80% atau lebih rendah

Kapasitas 60 sampai 100 dalam persen bulat, siklus 0 sampai 3000, bulan pembelian antara 2007 dan 2099 dengan umur 1 sampai 240 bulan, hingga 10 perangkat. Bulan dalam format YYYY-MM. Isian tetap di tab ini; tidak ada yang diukur atau dibaca dari ponsel Anda.

  • Kapasitas maksimum %: 60 ≤ x ≤ 100
  • Jumlah siklus: 0 ≤ x ≤ 3000
  • Umur (bulan): 1 ≤ m ≤ 240
  • Perangkat: 1 ≤ n ≤ 10
