Rumus dan batasan

Subtotal = semua pesanan dijumlahkan. Pajak = subtotal × persen pajak. Tip = subtotal × persen tip. Bagian tiap orang adalah pesanannya ÷ subtotal; sisa sen diberikan lebih dulu ke pecahan desimal terbesar, jadi jumlah semua bagian selalu pas dengan tagihan.

Subtotal = 32.40 + 18.90 + 25.00 = 76.30
Pajak = 76.30 × 8.25% = 6.29
Tip = 76.30 × 15.00% = 11.45
Orang 1: 32.40 + 2.67 + 4.86 = 39.93
Orang 2: 18.90 + 1.56 + 2.84 = 23.30
Orang 3: 25.00 + 2.06 + 3.75 = 30.81
Total tagihan = 94.04

Pakai satu mata uang, dan isi pajak serta tip sebagai persen dari subtotal. Tidak ada konversi mata uang, tidak ada aturan biaya layanan, tidak ada saran berapa tip yang pantas, dan tidak ada pembayaran. Tampilan dibulatkan dua angka desimal; pembagiannya dihitung dalam sen bulat.

  • Nilai pesanan: 0 ≤ n ≤ 100,000,000
  • Pajak % / Tip %: 0 ≤ % ≤ 100
  • Orang: 1 ≤ n ≤ 20
