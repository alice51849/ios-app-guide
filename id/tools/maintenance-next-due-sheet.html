Rumus dan batasan

Jatuh tempo berikutnya = terakhir dilakukan + interval. Untuk bulan, tanggal yang sama dipertahankan; jika tidak ada, dipakai hari terakhir bulan itu (termasuk tahun kabisat). Sisa hari = jatuh tempo − hari ini. Di bawah 0 terlambat; 0 sampai 7 segera.

2026-06-01 + 3 bulan = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 minggu = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 bulan = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Interval 1 sampai 3650 hari, minggu, atau bulan. Tanggal antara 1900-01-01 dan 2999-12-31. Maksimal 30 tugas. Tanpa pengingat, notifikasi, atau sinkronisasi kalender; tidak ada data yang keluar dari halaman ini.

  • Interval: 1 ≤ x ≤ 3650
  • Terakhir dilakukan: 1900-01-01 ≤ x ≤ 2999-12-31
  • Tugas: 1 ≤ n ≤ 30
