Rumus dan batasan

Lembar ini menjaga kata-kata Anda apa adanya: judul, lalu poin sesuai urutan yang Anda ketik, lalu tindakan berikutnya, lalu metrik. Ia menghitung poin dan memangkas spasi di tepi; tidak ada yang ditulis ulang, diringkas, atau dinilai.

Judul ≤ 80 · Poin × 3 ≤ 160 · Tindakan berikutnya ≤ 160 · Metrik ≤ 60
Bagian: Judul → Poin 1…3 → Tindakan berikutnya → Metrik

Judul maksimal 80 karakter, 3 sampai 12 poin masing-masing maksimal 160 karakter, tindakan berikutnya maksimal 160 karakter, metrik maksimal 60 karakter. Setiap baris harus berupa teks satu baris. Lembar ini tidak membaca berkas, rekaman, atau kalender.

  • Judul: ≤ 80
  • Poin: 3 ≤ n ≤ 12, ≤ 160
  • Tindakan berikutnya: ≤ 160
  • Metrik: ≤ 60
