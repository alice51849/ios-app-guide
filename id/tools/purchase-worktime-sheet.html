Rumus dan batasan

Total = jumlah × harga akhir. Jam kerja = total ÷ penghasilan bersih per jam. Hari kerja = jam kerja ÷ jam per hari kerja.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Masukkan harga termasuk pajak. Tanpa konversi mata uang, penggajian, prediksi tabungan, atau saran membeli. Tampilan dibulatkan dua desimal; total memakai nilai tanpa pembulatan.

  • Penghasilan bersih per jam: 0 < x ≤ 100000000
  • Harga akhir per unit: 0 ≤ x ≤ 100000000
  • Jam per hari kerja: 0 < x ≤ 24
  • Jumlah: 1 ≤ x ≤ 999
