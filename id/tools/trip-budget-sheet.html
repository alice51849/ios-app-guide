Rumus dan batasan

Sisa = total anggaran − biaya tetap. Per hari = sisa ÷ hari. Per orang per hari = per hari ÷ jumlah orang. Setiap kategori = per hari × porsinya. Jumlah dijumlahkan dalam sen bulat; angka harian hanya dibulatkan saat ditampilkan.

Biaya tetap = 1750.50
Sisa untuk dibelanjakan = 3000.00 − 1750.50 = 1249.50
Per hari = 1249.50 ÷ 5 = 249.90
Per orang per hari = 249.90 ÷ 2 = 124.95
Makan = 249.90 × 40% = 99.96
Transportasi = 249.90 × 20% = 49.98
Tiket = 249.90 × 25% = 62.48
Belanja = 249.90 × 15% = 37.49

Jumlah 0 sampai 100.000.000 dengan maksimal dua desimal, 1 sampai 120 hari, 1 sampai 20 orang, maksimal 15 biaya tetap, empat porsi yang berjumlah tepat 100. Satu mata uang sepanjang lembar, tanpa kurs, tanpa saran harga atau pemesanan.

  • Total anggaran / Jumlah: 0 ≤ x ≤ 100,000,000
  • Hari: 1 ≤ d ≤ 120
  • Jumlah orang: 1 ≤ p ≤ 20
  • Porsi: Σ = 100%
  • Biaya tetap: 0 ≤ n ≤ 15
