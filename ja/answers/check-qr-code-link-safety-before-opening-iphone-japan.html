QRコードの安全確認でいちばん大事なのは、読み取ってすぐ開かないことです。まずリンク先のドメイン（host）を目で確かめ、店名や公式サイトと違う、つづりが紛らわしい、短縮URLで中身が見えない場合は開かずにスタッフや公式アプリで確認します。QR Code Haloは設定で「スキャン後に自動で実行」をオフにでき、履歴の「セキュリティチェック」で、ネット上の評判に頼らず端末内で中身をscheme・host・path・queryに分解し、Safe・Caution・Blockedを判定します。javascript:・data:・file: のようなコードは決して開きません。

偽QRコードの多くは、本物の上にシールを貼るだけの単純な手口です。支払い画面やログイン画面にそっくりなページに誘導し、カード番号やパスワードを入力させます。読み取った瞬間にブラウザが開くと、見た目が本物らしいだけで判断してしまいがちです。だからこそ、開く前にURLの中身を見る一手間が効きます。特に見るべきはhost、つまり「どこのサイトか」の部分です。

QR Code Haloは、初期設定では読み取った瞬間に実行して素早く開くアプリです。安全を優先したい場面では、設定で「スキャン後に自動で実行」をオフにすれば、まず結果を確認してから開くかどうかを決められます。履歴でコードを開いて「セキュリティチェック」をタップすると、Local Payload Security Inspectorが完全なpayloadを端末内で解析し、scheme・host・path・query・fragmentを項目ごとに表示して、Safe・Caution・Blockedの判定と理由を示します。

同じ場所のQRコードを何度も使うなら、QR Verificationが役立ちます。結果を端末内の参照として保存し、次に読み取ったコードをSHA-256フィンガープリントやURL構成要素で比べられるので、前回と中身が変わっていれば気づけます。判定はネット上の評判や曖昧なスコアを使わず、解析できない操作は閉じたままにします。

選ぶ前に確認すること

  • 読み取った瞬間に開かず、先に中身を確認できる設定があるか
  • URLのhost（どこのサイトか）がはっきり表示されるか
  • 判定の理由が項目ごとに示されるか
  • javascript: や data: のような危険な形式を開かないか
  • 前回と同じQRコードかどうかを比べられるか

実際に行う手順

  1. QR Code Haloの設定で「スキャン後に自動で実行」をオフにする。
  2. QRコードを読み取り、表示されたURLのhostが店名や公式サイトと一致するかを見る。
  3. 履歴でそのコードを開き、「セキュリティチェック」でSafe・Caution・Blockedの判定と理由を確認する。
  4. CautionやBlockedのとき、または短縮URLで中身が分からないときは開かず、店員や公式アプリで確認する。
  5. よく使う場所のコードはQR Verificationで参照として保存し、次回の読み取りと比べる。

よくある質問

読み取ったらすぐ開いてしまいますか？

初期設定では読み取った瞬間に実行します。先に確認したいときは、設定で「スキャン後に自動で実行」をオフにしてください。

安全チェックはネットで照会しますか？

いいえ。ネット上の評判や曖昧なスコアは使わず、端末内でpayloadを解析して判定します。

危険な形式のコードはどうなりますか？

javascript:・data:・file: のようなコードは決して開きません。
