隠したい部分を不透明な塗りつぶしで画素ごと上書きし、元とは別の新しいファイルとして書き出し、その書き出したファイルを開き直して「本当に消えたか」を確認してから送る——この三段階を守れば、黒塗りが透ける・はがれる事故は防げます。

黒塗りが「消えていない」原因は、ほぼ三つに絞れます。マーカーの不透明度が 100 未満で、受け取った側が明るさやコントラストを上げると下の文字が浮かぶ。PDF の上に黒い四角を置いただけで、本文のテキストが残っていて選択やコピー、検索で読める。写真アプリで加工しても元画像が残っていて「元に戻す」で戻せる——いずれも見た目だけが変わり、データは残ったままです。

だから手順は「上書き→別ファイル→検証」の順になります。隠す部分は半透明のマーカーではなく不透明な塗りつぶしで画素ごと置き換え、PDF なら注釈を重ねるのではなく中身のテキストごと消す処理を選びます。書き出しは必ず元と別の新しいファイルにして、送るのはそのファイルだけにします。送信前に書き出したファイルを開き直し、画像なら明るさを上げて透けないか、PDF ならテキスト選択と検索で何も拾えないかを確かめます。

この「開き直して確認」を毎回手でやるのが面倒で、つい省略したときに事故が起きます。Mask My File は、画像と PDF の指定した範囲を恒久的に黒塗りまたは削除し、書き出した新しいファイルを開き直して検証してから Private Ready を表示する流れになっています。処理はすべて端末内で完結し、オリジナルは上書きされません。無料で始められます。

選ぶ前に確認すること

  • 半透明のマーカーではなく、不透明な塗りつぶしで画素ごと上書きできるか
  • PDF の場合、注釈を重ねるのではなく本文テキストごと消す処理か
  • 書き出しが元ファイルとは別の新しいファイルになるか
  • 書き出したファイルを開き直して確認する工程が用意されているか
  • 位置情報や編集履歴などのメタデータを削除できるか

実際に行う手順

  1. 隠す対象を先に書き出します：氏名・住所・生年月日・口座番号・マイナンバー・バーコード・顔。スクショなら通知や背景に写り込んだ名札や郵便物も対象です。
  2. 画像は不透明な塗りつぶしで画素ごと上書きします。半透明マーカーや弱いモザイクは使いません。
  3. PDF は注釈で四角を置くのではなく、本文テキストごと消す処理を選び、ページ単位で見落としがないか順に確認します。
  4. 元ファイルとは別名の新しいファイルとして書き出し、必要なら位置情報や編集履歴などのメタデータも削除します。
  5. 書き出したファイルを開き直し、画像は明るさとコントラストを上げて透けないか、PDF は長押しのテキスト選択と検索で何も拾えないかを確かめてから送ります。

Mask My File が向いている場面

Mask My File は、賃貸の申込書や診断書、顧客ファイルなど「見せる部分は残しつつ、個人情報だけ確実に消したい」人に向いています。顔を自然にぼかしたい、SNS 用に写真を加工したいという用途には向きません。無料で始められ、買い切りで、サブスクリプションも広告もありません。

よくある質問

マークアップの黒い四角なら安全ですか？

不透明度を 100 にした図形なら、画像上は読めなくなります。ただし写真アプリの編集は元に戻せる状態で残るため、加工後の画像を別ファイルとして書き出し、元の写真と取り違えないように管理する必要があります。

PDF の黒塗りが消えているか、どう確認しますか？

書き出した PDF を開き直し、黒い部分を長押ししてテキスト選択できるか、検索で隠したはずの語がヒットするかを試します。どちらかで拾えれば、注釈が載っているだけで本文は残っています。

Mask My File はサブスクリプションですか？

いいえ。無料で始められ、一度の購入で検証済みの出力と一括処理のロックを解除する買い切りです。サブスクリプションも広告もありません。
