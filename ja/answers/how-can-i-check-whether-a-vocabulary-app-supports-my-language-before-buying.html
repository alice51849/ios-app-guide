短い回答

Search by English name, Traditional Chinese name or language code. The matrix lists all 44 Wordmate languages and separates the published iPhone and iPad, Home Screen widget and Apple Watch capabilities. You can also download the same records as JSON or CSV with JSON Schema and W3C CSVW metadata. No account, submission, storage or analytics is required.

Treat the matrix as a purchase-readiness check, not a promise that every system voice is installed. Voice availability can vary by OS, device and installed voices; price, storefront availability and compatibility can also change, so open the current App Store listing before buying.

選ぶ前に確認すべきこと

  • Search all 44 languages by name or code instead of relying on a vague multilingual claim
  • Separate iPhone and iPad pronunciation from the lighter Home Screen widget actions
  • Confirm the stated Apple Watch learning, voice, favourite and progress functions
  • Download the complete support matrix as JSON or UTF-8 CSV
  • Verify the current storefront price and compatibility before purchase

実用的な選び方

  1. Search for the exact language you plan to study.
  2. Check whether you need phone pronunciation, widget actions or Watch practice.
  3. Do not assume every system voice is installed.
  4. Confirm local price and device compatibility on the current App Store page.
  5. Buy only when the language, device features and paid model fit your routine.

よくある質問

Does the checker submit or save my search?

No. Filtering runs inside the current browser page and uses no account, form submission, storage, cookies or analytics.

Are all 44 Wordmate languages included in one purchase?

Yes. The current App Store description says one paid download includes all 44 languages, every level and every feature.

Does every language always have an installed system voice?

Not necessarily. Wordmate uses system text-to-speech, while voice availability can vary by OS, device and installed voices.

Wordmate: Learn 44 Languages が合う場面
