UsageNow：AI使用量トラッカー とは?

UsageNow：AI使用量トラッカー は iOS アプリです。 Claude・Codex・Copilot・Gemini残量

作業の途中でAIの上限に達して手が止まる。そんな悩みはUsageNowで終わりにしましょう。各AIプランの残りとリセットされる正確な時刻を、ホーム画面でいつでも確認でき、使い切る前にお知らせもします。

すべての上限をひと目で

Claude：5時間のセッション上限と週間上限（モデル別の週間上限も含む）

ChatGPT Codex：5時間枠と週間枠

GitHub Copilot：プレミアムリクエスト、チャット、コード補完

Gemini：モデルごとの1日あたりのリクエスト上限

リセットまでのカウントダウンに加えて、正確なリセット時刻をお住まいの地域の表記で表示

上限に届く前に、先にお知らせ

自分だけのアラートを作れます。5時間の上限、週間上限、またはすべての上限を選び、気になるパーセンテージ（90や98など）を入力するだけ。いくつでも追加できます。

アラートは上限ごと・サイクルごとに1回だけ届くので、ロック画面が通知だらけになることはありません。リセットアラートをオンにすれば、上限が戻った瞬間にわかります。

もっと使えるウィジェット

ウィジェット上ですべてのアカウントをめくって確認

最新の数値が見たいときはウィジェットをタップして更新

ホーム画面とロック画面のウィジェットを全サイズで用意、Apple Watchのコンプリケーションにも対応

すべてのアカウントを、好きな順番で

仕事用と個人用、ProとMaxを並べて表示。5時間リセットが近い順、週間リセットが近い順、使用量の多い順・少ない順、名前順、サービス順で並べ替えたり、ドラッグして自由な順番にしたりできます。

どこで作業していても

iPhone、iPad、Apple Watchで使えます。

プライバシーを最優先した設計

サインインは各サービス公式のログインページで行います。サインイン情報はデバイスのキーチェーンに保存され、UsageNowが通信するのは各サービスだけです。UsageNowのサーバはなく、アカウント登録もトラッキングも一切ありません。

あなたの言語で

50の言語に完全対応し、日付と時刻もお住まいの地域の書式で表示します。言語は設定からいつでも変更できます。

まずはすべて試せます

アプリ内で24時間の無料トライアルを開始すれば、ウィジェットを含むすべての機能を使えます。トライアル終了後もUsageNowとウィジェットを使い続けるには、1回限りの購入でUsageNow Proのロックを解除してください。サブスクリプションはありません。

UsageNowは独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Googleとは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Geminiは各所有者の商標です。
