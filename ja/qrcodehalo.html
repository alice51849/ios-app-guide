QR Code Halo：QRコードをすぐ開く とは?

QR Code Halo：QRコードをすぐ開く は iOS アプリです。 あとからURLを端末内で安全チェック

QR Code Halo は、コードを読み取った瞬間に実行します。カメラでスキャンしても写真を選んでも、リンクはブラウザで開き、パスキーでサインインするコードや App リンクはそのまま iOS へ、Wi-Fi のコードでは iOS の接続確認が表示され、電話・メッセージ・メール・場所はそれぞれの App で開きます。連絡先と予定は iOS の追加画面が開き、確認してから登録されます。テキストはコピーして一行でお知らせし、javascript:・data:・file: のようなコードは決して開きません。先に確認したいときは、設定で「スキャン後に自動で実行」をオフにしてください。一括スキャンは収集のみです。

履歴からセキュリティチェック

「履歴に保存しない」をオンにしない限り、一括スキャン以外のスキャンはすべてこの端末に保存されます。履歴でコードを開いて「セキュリティチェック」をタップすると、次の2つのローカルツールで見直せます。

Local Payload Security Inspector

完全な payload を端末内で解析し、scheme、host、path、query、fragment を項目ごとに表示。Safe、Caution、Blocked の確定的な判定、透明な findings、action disposition まで示します。ネット上の評判や曖昧なスコアは使わず、解析できない操作は閉じたままにします。

QR Verification

結果を端末内の参照として保存し、後のスキャンを完全なSHA-256フィンガープリント、QR形式、コンテンツタイプ、URL構成要素、セキュリティレベル、アクションで比較できます。

Batch Risk & Difference Audit

複数の結果から完全一致のグループと host ごとのグループを作り、範囲を限定して見間違えやすい類似 host を比較。全体の要点と各コードのリスク、完全な payload をそのまま読めます。監査結果の閲覧はすべて利用できます。

QR Code Halo にできること

カメラでスキャン、写真の中のコードも認識。1画面に複数あってもまとめて読み取り

20種類のバーコード形式：QR、Micro QR、Aztec、Data Matrix、PDF417、Micro PDF417、EAN-8、EAN-13、UPC-A、UPC-E、Code 39、Code 93、Code 128、Interleaved 2 of 5、ITF-14、Codabar、GS1 DataBar、MSI Plessey

重複を自動で除外する一括スキャン、ズームとライト

テキスト、URL、Wi-Fi、連絡先、メール、電話、SMS、位置情報、カレンダーの予定のQRコードを作成

履歴は件数無制限。お気に入り、検索、種類・日付・形式・タグ・カテゴリでの絞り込みと並べ替え

端末内での自動仕分けとあとからの手動変更、履歴のCSV書き出し

バックアップも復元も、実際の件数・サイズ・期間をプレビューで確かめてから決められます

履歴を自動で消去するプライバシーモード、写真への保存、プリント、共有機能拡張、Siriショートカット

QR Code Halo は App Store から無料でダウンロードできます。スキャンは無料で3回、9種類のQRコード作成はすべて使えて、履歴は件数無制限。お気に入り、検索、絞り込みも最初から使えて、広告もアカウントもありません。買い切りの Lifetime Pro を一度購入すれば、無制限スキャン、一括保存と結果を開く操作、CSVでの一括作成と一括書き出し、バックアップと復元、高解像度書き出し、カスタム Aurora スタイルがずっと使えます。サブスクリプションはありません。

読み取れないコードや、ほしい機能があれば：hourstag.app@gmail.com
