Mask My File レビュー — 書類の個人情報を隠すiPhoneアプリ

★★★★☆ 4.5/5
Mask My File はPDFや画像書類内の個人情報（電話番号、メールアドレス、マイナンバーなど）を自動検出して黒塗りするアプリです。共有前に素早く個人情報を保護できます。

良い点

  • 個人情報の自動検出と黒塗り
  • オフラインで処理 — データはサーバーに送られない
  • PDF・画像フォーマット対応
  • 黒塗り後は情報の復元が不可能で安全

気になる点

  • 手書き文字の検出精度は低め
  • 日本語のOCR精度は文書の状態に依存

こんな方におすすめ

書類を共有する前にマイナンバーや電話番号などの個人情報を隠したい方

こんな方には向かない

高精度な日本語OCRや手書き認識が必要な方

よくある質問

Mask My File はマイナンバーも自動検出できますか?

12桁の数字パターンを検出しますが、すべてのケースで正確とは限りません。重要な書類は検出結果を必ず目視で確認してください。

墨消しした後に元の情報を見ることはできますか?

いいえ。エクスポートした黒塗りファイルから元の情報を復元することはできません。これが意図的なセキュリティ設計です。

Mask My File はインターネットなしで使えますか?

はい。すべての処理が端末上で行われます。スキャンデータや書類がサーバーに送られることはありません。
