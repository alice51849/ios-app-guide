計算式と制限

行の小計＝台数 × 1台あたりの値。必要量＝各行の合計。余裕＝プラン − 必要量。プランの 20% 未満はぎりぎり、マイナスは不足。0.1 Mbps 単位の整数で足すため合計がずれません。

購入品 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
購入品 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
購入品 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
必要な下り = 25.0; 必要な上り = 8.5
余裕 ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
判定 = 足りる

1台あたりの値は各サービス公式の目安（Netflix、Zoom、ゲーム機メーカー、FCC）に基づく概算です。このシートは計画用で、回線を測定しません。

  • 動画視聴（SD）: 3.0 ↓ / 0.5 ↑ Mbps
  • 動画視聴（HD）: 5.0 ↓ / 0.5 ↑ Mbps
  • 動画視聴（4K）: 15.0 ↓ / 0.5 ↑ Mbps
  • ビデオ通話: 3.0 ↓ / 3.0 ↑ Mbps
  • オンラインゲーム: 3.0 ↓ / 1.0 ↑ Mbps
  • クラウドバックアップ: 1.0 ↓ / 5.0 ↑ Mbps
  • 閲覧・メッセージ: 1.0 ↓ / 0.5 ↑ Mbps
  • スマートホーム機器: 0.5 ↓ / 0.5 ↑ Mbps

プラン速度は 0.5〜10000 Mbps、小数は 1 桁まで。1 行あたり 1〜50 台、最大 20 行。Wi‑Fi の届く範囲、遅延、実際に出る速度は対象外です。

  • プランの下り（Mbps） / プランの上り（Mbps）: 0.5 ≤ x ≤ 10000 Mbps
  • 台数: 1 ≤ n ≤ 50
  • 購入品: 1 ≤ n ≤ 20
