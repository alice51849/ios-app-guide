計算式と制限

月あたり劣化＝(100−容量)÷使用か月数を±25%の幅で表示。80%までの月数＝(容量−80)÷劣化率で、下限は高い劣化率、上限は低い劣化率から算出。月あたり回数＝充放電回数÷使用か月数。

デバイス 1: (100 − 88) ÷ 24 = 0.50 %/使用期間（か月） → ±25% → 0.38–0.63; (88 − 80) ÷ 月あたり劣化 % → 12–22
デバイス 2: (100 − 100) ÷ 1 = 0.00 %/使用期間（か月） → ±25% → 0.00–0.00; (100 − 80) ÷ 月あたり劣化 % → 測定できる劣化はまだなし
デバイス 3: (100 − 79) ÷ 66 = 0.32 %/使用期間（か月） → ±25% → 0.24–0.40; (79 − 80) ÷ 月あたり劣化 % → すでに80%以下

容量は60〜100の整数％、充放電回数は0〜3000、購入月は2007〜2099で使用期間1〜240か月、最大10台。月は YYYY-MM 形式。入力はこのタブ内だけに留まり、端末の測定や読み取りは行いません。

  • 最大容量 %: 60 ≤ x ≤ 100
  • 充放電回数: 0 ≤ x ≤ 3000
  • 使用期間（か月）: 1 ≤ m ≤ 240
  • デバイス: 1 ≤ n ≤ 10
