計算式と制限

小計＝全員が頼んだ金額の合計。税＝小計 × 税率。チップ＝小計 × チップの割合。一人あたりの税・チップは「自分の注文額 ÷ 小計」で按分し、割り切れない端数は小数部分が大きい人から順に足すので、全員の合計は必ず請求額と一致します。

小計 = 32.40 + 18.90 + 25.00 = 76.30
税 = 76.30 × 8.25% = 6.29
チップ = 76.30 × 15.00% = 11.45
人 1: 32.40 + 2.67 + 4.86 = 39.93
人 2: 18.90 + 1.56 + 2.84 = 23.30
人 3: 25.00 + 2.06 + 3.75 = 30.81
合計金額 = 94.04

通貨は1種類で、税とチップは小計に対する割合として入力してください。為替換算、サービス料の規則、チップの目安の提案、支払い処理はいずれも行いません。表示は小数第2位まで、計算自体は最小通貨単位で行います。

  • 頼んだ金額: 0 ≤ n ≤ 100,000,000
  • 税率 % / チップ %: 0 ≤ % ≤ 100
  • 人: 1 ≤ n ≤ 20
