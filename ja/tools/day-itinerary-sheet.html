計算例

09:00〜18:00 の 1 日で、博物館（120 分・移動 25 分）、昼食（60 分・移動 40 分）、旧市街（180 分・移動 30 分）：使える 540 分のうち 455 分を使い、85 分の余裕をもって収まります。

計算式と制限

到着＝前の出発＋移動。出発＝到着＋滞在。合計＝すべての滞在＋すべての移動。使える時間＝終了 − 開始。終了が開始より早い場合は翌日扱い。超過＝合計 − 使える時間。0 より大きければ時間超過。分の足し算だけで、時差は扱いません。

1. 場所 1: 09:00 + 120 = 11:00 + 25 →
2. 場所 2: 11:25 + 60 = 12:25 + 40 →
3. 場所 3: 13:05 + 180 = 16:05 + 30 →
合計（分） = 455; 使える時間（分） = 09:00–18:00 = 540
超過（分） = 455 − 540 = -85 → 収まる

時刻は 24 時間制の HH:MM、滞在は 5〜720 分、移動は 0〜600 分、最大 25 か所。営業時間、実際の交通状況、地図、経路探索、予約は対象外です。

  • 開始時刻 / 終了時刻: HH:MM
  • 滞在（分）: 5 ≤ m ≤ 720
  • 次への移動（分）: 0 ≤ m ≤ 600
  • 場所: 1 ≤ n ≤ 25
