計算式と制限

次回期限＝前回実施＋間隔。月単位では同じ日を保ち、その日が存在しない月は月末にします（うるう年を含む）。残り日数＝次回期限−今日。0未満は期限切れ、0〜7は期限間近です。

2026-06-01 + 3 か月 = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 週 = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 か月 = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

間隔は1〜3650の日・週・か月。日付は 1900-01-01 から 2999-12-31 まで。項目は30件まで。リマインダー、通知、カレンダー同期はなく、データはこのページの外に出ません。

  • 間隔: 1 ≤ x ≤ 3650
  • 前回実施: 1900-01-01 ≤ x ≤ 2999-12-31
  • 項目: 1 ≤ n ≤ 30
