計算式と制限

粗利＝収入合計−支出合計。利益率＝粗利÷収入合計。1時間あたりの純収入＝粗利÷作業時間。金額は最小単位の整数で加算するため合計がずれません。

収入合計 = 1500.00
支出合計 = 400.39
粗利 = 1500.00 − 400.39 = 1099.61
利益率 = 1099.61 ÷ 1500.00 = 73.3%
1時間あたりの純収入 = 1099.61 ÷ 12.5 = 87.97

金額は0〜100,000,000で小数第2位まで、収入・支出それぞれ最大20行、作業時間は0.25〜2000（0.25時間単位）。同一通貨、為替換算なし、税務・会計の助言はありません。

  • 金額: 0 ≤ x ≤ 100,000,000
  • 作業時間: 0.25 ≤ h ≤ 2000
  • 収入 / 支出: 1 ≤ n ≤ 20
