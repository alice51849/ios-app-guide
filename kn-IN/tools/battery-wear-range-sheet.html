ಸೂತ್ರ ಮತ್ತು ಮಿತಿಗಳು

ತಿಂಗಳ ಸವೆತ = (100 − ಸಾಮರ್ಥ್ಯ) ÷ ತಿಂಗಳುಗಳಲ್ಲಿ ವಯಸ್ಸು, ±25% ಪಟ್ಟಿಯೊಂದಿಗೆ. 80% ಕ್ಕೆ ತಿಂಗಳುಗಳು = (ಸಾಮರ್ಥ್ಯ − 80) ÷ ಸವೆತ; ಕಡಿಮೆ ಮಿತಿ ಹೆಚ್ಚಿನ ದರದಿಂದ, ಹೆಚ್ಚಿನ ಮಿತಿ ಕಡಿಮೆ ದರದಿಂದ. ತಿಂಗಳ ಸೈಕಲ್ = ಸೈಕಲ್ ÷ ವಯಸ್ಸು.

  • ಗರಿಷ್ಠ ಸಾಮರ್ಥ್ಯ %: 60 ≤ x ≤ 100
  • ಸೈಕಲ್ ಸಂಖ್ಯೆ: 0 ≤ x ≤ 3000
