ಸೂತ್ರ ಮತ್ತು ಮಿತಿಗಳು

ಆಗಮನ = ಹಿಂದಿನ ನಿರ್ಗಮನ + ಪ್ರಯಾಣ. ನಿರ್ಗಮನ = ಆಗಮನ + ತಂಗುವಿಕೆ. ಒಟ್ಟು = ಎಲ್ಲಾ ತಂಗುವಿಕೆಗಳು + ಎಲ್ಲಾ ಪ್ರಯಾಣಗಳು. ಲಭ್ಯ = ಅಂತ್ಯ − ಆರಂಭ; ಆರಂಭಕ್ಕಿಂತ ಮುಂಚಿನ ಅಂತ್ಯದ ಸಮಯ ಮರುದಿನವೆಂದು ಲೆಕ್ಕ. ಮೀರಿದ್ದು = ಒಟ್ಟು − ಲಭ್ಯ; ಸೊನ್ನೆಗಿಂತ ಹೆಚ್ಚಿದ್ದರೆ ಸಮಯ ಮೀರಿದೆ. ಕೇವಲ ನಿಮಿಷಗಳ ಕೂಡುವಿಕೆ, ಸಮಯ ವಲಯಗಳಿಲ್ಲ.

1. ಸ್ಥಳ 1: 09:00 + 120 = 11:00 + 25 →
2. ಸ್ಥಳ 2: 11:25 + 60 = 12:25 + 40 →
3. ಸ್ಥಳ 3: 13:05 + 180 = 16:05 + 30 →
ಒಟ್ಟು (ನಿಮಿ) = 455; ಲಭ್ಯ (ನಿಮಿ) = 09:00–18:00 = 540
ಮೀರಿದ್ದು (ನಿಮಿ) = 455 − 540 = -85 → ಹೊಂದುತ್ತದೆ

ಸಮಯಗಳು 24 ಗಂಟೆ HH:MM ರೂಪದಲ್ಲಿ; ತಂಗುವಿಕೆ 5 ರಿಂದ 720 ನಿಮಿಷ; ಪ್ರಯಾಣ 0 ರಿಂದ 600 ನಿಮಿಷ; ಗರಿಷ್ಠ 25 ಸ್ಥಳಗಳು. ತೆರೆಯುವ ಸಮಯ, ನಿಜವಾದ ಸಂಚಾರ, ನಕ್ಷೆ, ಮಾರ್ಗ ಮತ್ತು ಬುಕಿಂಗ್ ಈ ಶೀಟ್‌ನ ವ್ಯಾಪ್ತಿಯಲ್ಲಿಲ್ಲ.

  • ಆರಂಭದ ಸಮಯ / ಅಂತ್ಯದ ಸಮಯ: HH:MM
  • ತಂಗುವಿಕೆ (ನಿಮಿ): 5 ≤ m ≤ 720
  • ಮುಂದಿನದಕ್ಕೆ ಪ್ರಯಾಣ (ನಿಮಿ): 0 ≤ m ≤ 600
  • ಸ್ಥಳ: 1 ≤ n ≤ 25
