ಸೂತ್ರ ಮತ್ತು ಮಿತಿಗಳು

ಮುಂದಿನ ದಿನಾಂಕ = ಕೊನೆಯ ಬಾರಿ + ಅಂತರ. ತಿಂಗಳುಗಳಲ್ಲಿ ಅದೇ ದಿನ ಉಳಿಯುತ್ತದೆ; ಇಲ್ಲದಿದ್ದರೆ ತಿಂಗಳ ಕೊನೆಯ ದಿನ ತೆಗೆದುಕೊಳ್ಳಲಾಗುತ್ತದೆ (ಅಧಿಕ ವರ್ಷ ಸೇರಿ). ಉಳಿದ ದಿನಗಳು = ಮುಂದಿನ ದಿನಾಂಕ − ಇಂದು. 0 ಕ್ಕಿಂತ ಕಡಿಮೆ ತಡ; 0 ರಿಂದ 7 ಶೀಘ್ರದಲ್ಲೇ.

2026-06-01 + 3 ತಿಂಗಳು = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 ವಾರ = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 ತಿಂಗಳು = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

ಅಂತರ 1 ರಿಂದ 3650 ದಿನ, ವಾರ ಅಥವಾ ತಿಂಗಳು. ದಿನಾಂಕಗಳು 1900-01-01 ರಿಂದ 2999-12-31. ಗರಿಷ್ಠ 30 ಕೆಲಸಗಳು. ಜ್ಞಾಪನೆ, ಅಧಿಸೂಚನೆ ಅಥವಾ ಕ್ಯಾಲೆಂಡರ್ ಸಿಂಕ್ ಇಲ್ಲ; ಯಾವುದೂ ಈ ಪುಟದಿಂದ ಹೊರಹೋಗುವುದಿಲ್ಲ.

  • ಅಂತರ: 1 ≤ x ≤ 3650
  • ಕೊನೆಯ ಬಾರಿ: 1900-01-01 ≤ x ≤ 2999-12-31
  • ಕೆಲಸ: 1 ≤ n ≤ 30
