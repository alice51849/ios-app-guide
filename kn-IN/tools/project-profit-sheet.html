ಪ್ರಾಜೆಕ್ಟ್ ಲಾಭ ಶೀಟ್

ನಿಮ್ಮ ವಿವರಗಳು ಈ ಟ್ಯಾಬ್‌ನಲ್ಲೇ ಉಳಿಯುತ್ತವೆ. ಅಪ್‌ಲೋಡ್, ಖಾತೆ, ನಮೂದುಗಳ ಟ್ರ್ಯಾಕಿಂಗ್ ಅಥವಾ ಸಂಗ್ರಹಣೆ ಇಲ್ಲ. ಮರುಲೋಡ್ ಮಾಡಿದರೆ ಬದಲಾವಣೆಗಳು ಅಳಿಯುತ್ತವೆ.

ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಸೂತ್ರ ಮತ್ತು ಮಿತಿಗಳು

ಲಾಭ = ಒಟ್ಟು ಆದಾಯ − ಒಟ್ಟು ವೆಚ್ಚ. ಮಾರ್ಜಿನ್ = ಲಾಭ ÷ ಒಟ್ಟು ಆದಾಯ. ಗಂಟೆಗೆ ನಿವ್ವಳ = ಲಾಭ ÷ ವ್ಯಯಿಸಿದ ಗಂಟೆಗಳು. ಮೊತ್ತಗಳನ್ನು ಪೂರ್ಣ ಪೈಸೆಗಳಲ್ಲಿ ಕೂಡಿಸುವುದರಿಂದ ಮೊತ್ತಗಳು ಜಾರುವುದಿಲ್ಲ.

ಒಟ್ಟು ಆದಾಯ = 1500.00
ಒಟ್ಟು ವೆಚ್ಚ = 400.39
ಲಾಭ = 1500.00 − 400.39 = 1099.61
ಮಾರ್ಜಿನ್ = 1099.61 ÷ 1500.00 = 73.3%
ಗಂಟೆಗೆ ನಿವ್ವಳ = 1099.61 ÷ 12.5 = 87.97

ಮೊತ್ತ 0 ರಿಂದ 100,000,000, ಗರಿಷ್ಠ ಎರಡು ದಶಮಾಂಶ; ಗರಿಷ್ಠ 20 ಆದಾಯ ಮತ್ತು 20 ವೆಚ್ಚ ಸಾಲುಗಳು; ಗಂಟೆ 0.25 ರಿಂದ 2000, ಕಾಲು ಗಂಟೆಯ ಹೆಜ್ಜೆಗಳಲ್ಲಿ. ಒಂದೇ ಕರೆನ್ಸಿ, ವಿನಿಮಯ ಇಲ್ಲ, ತೆರಿಗೆ ಅಥವಾ ಲೆಕ್ಕಪತ್ರ ಸಲಹೆ ಇಲ್ಲ.

  • ಮೊತ್ತ: 0 ≤ x ≤ 100,000,000
  • ವ್ಯಯಿಸಿದ ಗಂಟೆಗಳು: 0.25 ≤ h ≤ 2000
  • ಆದಾಯ / ವೆಚ್ಚ: 1 ≤ n ≤ 20
