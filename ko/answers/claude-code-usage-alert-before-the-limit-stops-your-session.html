이미 이 앱을 사용 중이신가요? App Store에서 평가하거나 리뷰를 작성할 수 있습니다

클로드 사용량은 5시간 한도와 주간 한도에 90이나 98처럼 원하는 퍼센트로 알림을 걸어 두고 초기화 알림까지 켜 두면, 수시로 확인하지 않아도 멈추기 전과 다시 열리는 순간을 모두 알 수 있습니다.

클로드 사용량을 검색하는 분 중에는 Claude Code 같은 도구로 긴 작업을 돌리다 갑자기 멈춘 경험이 있는 개발자가 많습니다. Claude는 5시간 세션 한도와 주간 한도가 따로 돌아가고 모델별 주간 한도까지 있어서, 어느 쪽에 먼저 닿을지 예측하기 어렵습니다. 그렇다고 몇 분마다 사용량을 열어 보는 것은 지키려던 집중을 스스로 깨는 일입니다.

그래서 확인하는 대신 알림을 받는 쪽이 낫습니다. UsageNow에서는 5시간 한도, 주간 한도 또는 모든 한도를 고른 뒤 신경 쓰이는 퍼센트를 직접 입력해 알림을 만들 수 있고, 원하는 만큼 추가할 수 있습니다. 알림은 한도별로 주기마다 한 번만 울리므로 잠금 화면이 알림으로 가득 차지 않습니다. 예를 들어 90에서는 지금 단계를 정리할 시점을, 98에서는 지금까지의 작업을 커밋할 시점을 알리게 둘 수 있습니다.

멈춘 뒤에는 초기화 알림이 다시 시작할 때를 알려 줍니다. 초기화까지 남은 시간은 홈 화면·잠금 화면 위젯과 Apple Watch 컴플리케이션에서 실시간으로 카운트다운되고, 정확한 초기화 시각도 사용자 지역 형식으로 표시됩니다. 로그인은 각 서비스의 공식 로그인 페이지에서 하며, 로그인 정보는 기기의 키체인에만 보관됩니다.

고르기 전에 확인할 것

  • 알림 기준 퍼센트를 직접 입력할 수 있는지
  • 5시간 한도와 주간 한도에 따로 알림을 걸 수 있는지
  • 같은 한도에 대해 알림이 반복해서 울리지 않는지
  • 한도가 다시 열릴 때 초기화 알림을 받을 수 있는지
  • 알림 외에 위젯과 Apple Watch에서도 남은 양을 볼 수 있는지

실제로 해볼 순서

  1. 각 서비스의 공식 로그인 페이지에서 로그인합니다.
  2. 5시간 한도에 90 같은 첫 번째 알림을 만듭니다.
  3. 98처럼 작업을 마무리할 시점의 두 번째 알림을 추가합니다.
  4. 주간 한도에도 같은 방식으로 알림을 겁니다.
  5. 초기화 알림을 켜서 다시 시작할 시점을 받습니다.

UsageNow: 어떤 경우에 맞나

UsageNow는 Claude·Codex·Copilot·Gemini로 매일 코딩하는 개발자에게 맞습니다. 각 요금제의 남은 사용량과 초기화 시각을 홈 화면·잠금 화면 위젯과 Apple Watch 컴플리케이션에서 보여 주고, 원하는 퍼센트에서 미리 알려 줍니다. 24시간 무료 체험으로 모든 기능을 써 본 뒤 한 번의 구매로 UsageNow Pro를 잠금 해제하며, 구독은 없습니다.
