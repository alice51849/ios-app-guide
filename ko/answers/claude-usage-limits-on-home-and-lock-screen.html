Claude 사용량은 5시간 세션 한도와 주간 한도를 함께 봐야 하고, 남은 양과 다음 초기화 시각을 홈 화면이나 잠금 화면 위젯에 두면 작업 도중 서비스 페이지를 열 필요가 없습니다.

claude 사용량을 검색하는 분은 대개 작업 중간에 한도에 걸려 멈춘 경험이 있습니다. Claude는 5시간 세션 한도와 주간 한도가 따로 돌아가고 모델별 주간 한도까지 있어서, 하나만 보고 있으면 다른 쪽에서 막히기 쉽습니다. 그래서 숫자 하나가 아니라 한도마다 남은 양과 정확한 초기화 시각을 같이 확인하는 것이 기본입니다.

매번 서비스 페이지를 열어 확인하는 대신 위젯에 두고 보는 쪽이 현실적입니다. UsageNow는 Claude의 5시간 세션 한도와 주간 한도, ChatGPT Codex의 5시간 및 주간 구간, GitHub Copilot의 프리미엄 요청, Gemini의 모델별 일일 요청 한도를 홈 화면과 잠금 화면 위젯, Apple Watch 컴플리케이션에서 보여 주고, 초기화까지 남은 시간을 실시간으로 카운트다운합니다.

업무용과 개인용, Pro와 Max처럼 계정이 여러 개라면 위젯에서 계정을 넘겨 보거나 5시간 초기화 순으로 정렬해 두면 어느 계정으로 이어서 작업할지 바로 정해집니다. 한도에 닿기 전 알림은 90이나 98처럼 신경 쓰이는 퍼센트를 직접 입력해 만들 수 있고, 한도별로 주기마다 한 번만 울려 잠금 화면이 조용합니다. 로그인은 각 서비스의 공식 페이지에서 하고 정보는 기기의 키체인에만 남습니다.

고르기 전에 확인할 것

  • 5시간 한도와 주간 한도가 따로 표시되는지
  • 남은 퍼센트만 보이는지, 정확한 초기화 시각까지 보이는지
  • 홈 화면과 잠금 화면 위젯, Apple Watch에서 볼 수 있는지
  • 업무용과 개인용처럼 계정 여러 개를 같이 둘 수 있는지
  • 로그인 정보가 기기에만 남고 별도 서버가 없는지

실제로 해볼 순서

  1. 각 서비스의 공식 로그인 페이지에서 로그인합니다.
  2. 홈 화면이나 잠금 화면에 위젯을 추가하고 원하는 크기를 고릅니다.
  3. 계정이 여러 개라면 5시간 초기화 순으로 정렬하거나 드래그해 순서를 정합니다.
  4. 90이나 98처럼 신경 쓰이는 퍼센트로 알림을 만듭니다.
  5. 초기화 알림을 켜서 한도가 다시 열리는 순간을 받습니다.

UsageNow: 어떤 경우에 맞나

UsageNow는 Claude·Codex·Copilot·Gemini를 매일 쓰는 개발자에게 맞습니다. 각 요금제의 남은 사용량과 초기화 시각을 홈 화면·잠금 화면 위젯과 Apple Watch 컴플리케이션에서 보여 주고, 24시간 무료 체험 뒤 한 번의 구매로 UsageNow Pro를 잠금 해제하며 구독은 없습니다.

자주 묻는 질문

Claude 사용량은 어디서 확인하나요?

작업 중에 Claude 안에서 꺼내 보기는 번거롭습니다. 5시간·주간 한도와 초기화 시각을 위젯에 두면 홈 화면에서 바로 보입니다.

5시간 한도와 주간 한도 중 무엇을 먼저 봐야 하나요?

초기화가 가까운 쪽입니다. 5시간 한도는 금방 돌아오지만 주간 한도는 한 번 닿으면 오래 기다려야 합니다.

UsageNow는 구독인가요?

아닙니다. 24시간 무료 체험으로 모든 기능을 써 본 뒤, 한 번의 구매로 UsageNow Pro를 잠금 해제합니다. 구독은 없습니다.
