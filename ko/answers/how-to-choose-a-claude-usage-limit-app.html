짧은 답변

서비스마다 사용량을 세는 방식이 다릅니다. Claude는 5시간 세션 한도와 모델별 주간 한도를 포함한 주간 한도가 있고, ChatGPT Codex는 5시간 및 주간 사용 구간이 있으며, GitHub Copilot은 프리미엄 요청, 채팅, 코드 완성을 따로 셉니다. Gemini는 모델별로 일일 요청 한도를 둡니다. 계속 쓸 만한 트래커라면 이 모든 한도를 나란히 보여 주고 초기화까지 실시간으로 카운트다운하며, 업무용과 개인용 계정을 함께 확인할 수 있어야 합니다.

나머지 절반은 한도에 닿기 전에 받는 경고입니다. 신경 쓰이는 퍼센트를 직접 정해 만드는 알림이 있는지, 새로 고칠 때마다가 아니라 한도별로 주기마다 한 번만 울리는지, 한도가 다시 열리는 순간을 알려 주는 초기화 알림이 있는지 확인하세요. 사용량 트래커는 로그인 정보도 필요하므로 그 정보가 어디로 가는지도 살펴봐야 합니다. 로그인은 각 서비스의 공식 로그인 페이지에서 해야 하고, 세션은 기기의 키체인에 보관되어야 하며, 트래커는 해당 서비스와만 통신해야 합니다.

이 가이드에서 다루는 앱은 UsageNow입니다. UsageNow는 각 AI 요금제에 남은 사용량과 정확한 초기화 시각을 홈 화면에서 바로 보여 주고, 한도가 바닥나기 전에 미리 알려 줍니다. 24시간 무료 체험 · 한 번 구매로 잠금 해제 · 구독 없음. 정확한 기능과 가격은 현재 App Store 페이지에서 확인하세요.

선택 전에 확인할 점

  • Claude 5시간·주간 한도, Codex 사용 구간, Copilot 프리미엄 요청, Gemini 일일 한도를 한 화면에서 확인합니다.
  • 모든 한도에 대해 실시간 카운트다운과 정확한 초기화 시각을 사용자 지역 형식으로 표시합니다.
  • 직접 고른 퍼센트에서 울리는 알림은 한도별로 주기마다 한 번만 오며, 초기화 알림도 선택해서 켤 수 있습니다.
  • 탭 한 번으로 새로 고치고 넘겨 볼 수 있는 홈 화면 위젯, 잠금 화면 위젯과 Apple Watch 컴플리케이션까지 지원합니다.
  • 각 서비스의 공식 로그인 페이지에서 로그인하고 정보는 키체인에 보관되며, 따로 만들 계정도, 서버도, 추적도 없습니다.

실용적인 선택 절차

  1. 실제로 쓰는 서비스에 로그인한 뒤 각 서비스의 사용량 페이지와 수치를 비교해 보세요.
  2. 가장 자주 닿는 5시간 한도나 주간 한도에 90퍼센트 알림을 설정하고, 해당 주기에 한 번만 오는지 확인하세요.
  3. 홈 화면 위젯을 추가하고 새로 고침 버튼을 탭한 뒤, 위젯에서 계정을 넘겨 보세요.
  4. 계정을 5시간 초기화 순이나 주간 초기화 순으로 정렬해 어느 요금제가 먼저 풀리는지 확인하세요.
  5. 결제하기 전에 24시간 무료 체험으로 위젯을 포함한 모든 기능을 써 보세요.

UsageNow가 맞는 사람

UsageNow는 Claude, Codex, Copilot, Gemini 요금제를 함께 쓰면서 남은 사용량과 초기화 시각을 별도 계정 없이 홈 화면, 잠금 화면, Apple Watch에서 확인하고 싶은 개발자에게 맞습니다. 앱에서 모든 기능의 24시간 무료 체험을 시작할 수 있고, 그 후에는 한 번의 구매로 UsageNow Pro를 잠금 해제합니다. 구독은 없습니다.

자주 묻는 질문

UsageNow는 Anthropic, OpenAI, GitHub, Microsoft 또는 Google이 만든 앱인가요?

아니요. UsageNow는 독립 앱이며 Anthropic, OpenAI, GitHub, Microsoft 또는 Google과 제휴 관계가 없습니다. Claude, ChatGPT, Codex, GitHub Copilot 및 Gemini는 각 소유자의 상표입니다.

로그인 정보는 어디로 가나요?

로그인은 각 서비스의 공식 로그인 페이지에서 진행합니다. 로그인 정보는 기기의 키체인에 보관되며, UsageNow는 각 서비스와만 통신합니다. UsageNow 서버도, 따로 만들 계정도, 추적도 없습니다.

구독이 있나요?

아니요. 앱에서 24시간 무료 체험을 시작하면 위젯을 포함한 모든 기능을 무료로 사용할 수 있습니다. 체험 기간이 끝난 후에도 UsageNow와 위젯을 계속 사용하려면 한 번의 구매로 UsageNow Pro를 잠금 해제하세요.
