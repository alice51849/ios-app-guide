짧은 답변

Pinyin is convenient for typing and is the global standard, but its Latin letters (x, q, zh, c, r) tempt English speakers into English sounds, which can fossilise into an accent. Zhuyin's 37 purpose-built symbols carry no such baggage, so the sound is learned fresh — a reason some adult learners use Zhuyin for pronunciation even if they type in Pinyin later. Lumi Bopomofo teaches all 37 symbols with native Taiwanese audio, a tone game and blending, so pronunciation and tones are built together. It's ad-free and a one-time unlock. Many learners use both systems; Zhuyin for sound, Pinyin for input.

자주 묻는 질문

Is Zhuyin worth it for an adult?

If cleaner pronunciation matters to you, Zhuyin avoids English-sound interference; many learners use it for sound and Pinyin for typing.

Will I still be able to type Chinese?

Yes — Zhuyin is a built-in iPhone/Mac input method, and you can also use Pinyin input; learning Zhuyin doesn't stop you typing.

Is this app for adults or kids?

Lumi Bopomofo is designed for first-time learners of the symbols; adults can use it to build the same phonetic foundation, at their own pace.
