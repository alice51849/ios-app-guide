중고폰 팔기 전 배터리 리포트 내보내기

설정에서는 지금의 배터리 성능 최대치만 보이고, 어떻게 변해 왔는지는 알 수 없어요. BattAI는 평소처럼 쓰는 동안 배터리 잔량과 충전을 기록해 점수, 추세, 80% 예상, 리포트로 정리해 주는 배터리 체크 앱이에요. 폰을 바꾸거나 중고폰을 팔고 살 때 배터리 상태를 분명하게 보여 줄 수 있어요. 성능 최대치나 사이클 수를 언제든 추가하면 결과가 더 자세해져요.

■ 배터리 상태 점수

• 0~100점을 매우 좋음·좋음·보통·관리가 필요함·서비스 확인 5단계로 표시

• 점수를 만드는 요소: 용량 40%, 사이클 25%, 기기 사용 기간 10%, 열 노출 10%, 충전 습관 15%. 가장 큰 요인을 바로 보여 줘요

■ 성능 최대치 추세와 80% 예상

• 성능 최대치(배터리 용량) 기록을 95% 신뢰 구간과 함께 그래프에 표시

• 월별 용량 변화로 배터리 노화·열화 속도 확인

• 80%까지 남은 기간을 '약 ○–○개월' 범위로 예상해요. 배터리 수명이 걱정될 때 배터리 교체나 기기 변경 시기를 정하는 참고가 돼요

■ 충전 관리

• 충전할 때마다 0~100점 충전 관리 점수(시작·종료 잔량, 충전 속도, 100% 유지 시간 등 반영)

• 충전 구간(예: 30% → 88%), 충전 시간, 충전 속도(느림·보통·빠름·매우 빠름) 기록

• 충전 습관을 항목별로 평가(방전 깊이, 충전 상한, 밤샘 충전, 충전 중 발열, 충전 빈도)하고, 내 기록에 맞춰 '괜찮을 때는 80–90%' 같은 팁을 알려 줘요

■ 배터리 알림

• 80%·90%·100% 완충 알림으로 충전기 뺄 때를 알려 줘요

• 잔량 10%·20%·30%에서 배터리 부족 알림

• 휴대폰이 뜨거워지면 과열 알림

• 소모가 평소보다 많으면 앱 안에서 평소와 다른 소모를 안내

■ 소모와 발열

• 시간당 소모량과 밤사이 대기 소모로 배터리 광탈 원인 확인

• 7일간 기기 발열로 뜨거워지는 시간대 확인

■ 리포트와 내보내기

• 중고 판매 리포트: 값마다 출처를 표시하고, 구매자가 설정에서 성능 최대치를 확인하는 방법을 담은 1페이지. 중고폰을 팔거나 살 때 활용

• 전체 리포트(3페이지)와 간단 리포트(1페이지, 80% 계획 범위 포함)

• PDF 또는 PNG 이미지로 저장해 구매자나 수리점에 전달, 기록 데이터는 CSV·JSON으로 내보내기

• 폰을 바꿀 때 다른 기기로 데이터 이동

■ 위젯, Apple Watch, 단축어

• 홈 화면·잠금 화면 위젯으로 점수, 성능 최대치, 오늘 소모를 바로 확인

• 워치 앱과 컴플리케이션으로 점수와 80% 예상을 손목에서 확인

• 단축어: 현재 점수를 확인하거나, 충전기를 연결하거나 뺄 때 기록을 자동으로 추가

■ 가져오기와 개인정보

• 시스템 분석 데이터(log-aggregated 파일)에서 성능 최대치와 사이클 수를 가져오거나 직접 입력. 사이클 수, 공칭 충전 용량, 설계 용량만 읽고 나머지는 바로 버려요

• 계정, 분석, 추적, 타사 SDK, 네트워크 요청이 없어요. 데이터는 이 휴대폰에만 저장되고, 페어링된 워치로는 최소한의 스냅샷만 보내요. 모든 데이터는 언제든 삭제할 수 있어요

일부 기능은 구매 후 이용할 수 있어요: 무제한 기록, 80% 계획 범위, PDF 배터리 리포트, CSV·JSON 데이터 내보내기, 평소와 다른 소모 알림, 충전 속도 노출, 모든 위젯, 주간 배터리 관리 요약, 다른 기기로 데이터 이동.

데이터 출처와 한계

시스템 공개 API로 얻을 수 있는 것은 배터리 잔량, 충전 상태, 저전력 모드, 기기 전체의 열 상태, 시간뿐이에요. 성능 최대치와 사이클 수는 직접 입력하거나 가져온 파일에서 와요. 배터리 온도, 전압, 전류는 앱이 읽을 수 없고, 발열은 기기 전체 상태예요. 점수와 예상은 기록으로 계산한 참고 범위이며, 공식·제조사 수치가 아니고 배터리를 얼마나 더 쓸 수 있는지 약속하지도 않아요. 구매 전 첫 리포트에는 14일 기록이, 80% 예상에는 30일 이상에 걸친 성능 최대치 기록 3개 이상이 필요해요. 백그라운드 확인 시점은 시스템이 정하기 때문에 알림 시간이 달라질 수 있어요.
