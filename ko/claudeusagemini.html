작업 도중 AI 사용 한도에 걸려 멈춘 적 있나요? UsageNow는 각 AI 요금제에 남은 사용량과 정확한 초기화 시각을 홈 화면에서 바로 보여 주고, 한도가 바닥나기 전에 미리 알려 줍니다.

모든 한도를 한눈에

Claude: 5시간 세션 한도와 주간 한도, 모델별 주간 한도까지

ChatGPT Codex: 5시간 및 주간 사용 구간

GitHub Copilot: 프리미엄 요청, 채팅, 코드 완성

Gemini: 모델별 일일 요청 한도

초기화까지 남은 시간을 실시간으로 카운트다운하고, 정확한 초기화 시각을 사용자 지역 형식으로 표시

한도에 닿기 전에 미리 알림

나만의 알림을 만드세요. 5시간 한도, 주간 한도 또는 모든 한도를 고른 뒤 신경 쓰이는 퍼센트(예: 90, 98)를 직접 입력하면 됩니다. 원하는 만큼 추가할 수 있습니다.

알림은 한도별로 주기마다 한 번만 울리므로 잠금 화면이 조용하게 유지됩니다. 초기화 알림을 켜면 한도가 다시 열리는 순간 바로 알 수 있습니다.

처음부터 개인정보 보호를 고려한 설계

로그인은 각 서비스의 공식 로그인 페이지에서 진행합니다. 로그인 정보는 기기의 키체인에 보관되며, UsageNow는 각 서비스와만 통신합니다. UsageNow 서버도, 따로 만들 계정도, 추적도 없습니다.

내 언어로

50개 언어로 완전히 번역되어 있으며, 날짜와 시간도 사용자 지역의 표기 방식으로 보여 줍니다. 언어는 설정에서 언제든지 바꿀 수 있습니다.
