QR Code Halo: 열기 전 확인이란?

QR Code Halo: 열기 전 확인은(는) iOS 앱입니다. 실행 전 위험부터 확인

QR Code Halo는 인식하자마자 링크를 여는 스캐너가 아닙니다. 확인하고, 판단하고, 실행하는 순서로 내용과 근거를 먼저 살핀 뒤 다음 동작을 선택합니다.

Local Payload Security Inspector

전체 payload를 기기에서 분석해 scheme, host, path, query, fragment를 각각 보여 줍니다. Safe, Caution, Blocked의 재현 가능한 판정과 투명한 findings, action disposition도 함께 표시합니다. 인터넷 평판이나 모호한 점수는 쓰지 않으며, 해석에 실패한 동작은 차단 상태로 둡니다.

QR Verification

결과를 기기 내 참조로 저장한 다음 전체 SHA-256 지문, QR 형식, 콘텐츠 유형, URL 구성 요소, 보안 수준 및 동작을 기준으로 이후 스캔과 비교합니다.

Batch Risk & Difference Audit

여러 결과를 완전히 같은 내용과 host별로 묶고, 정해진 범위 안에서 혼동하기 쉬운 유사 host를 비교합니다. 전체 위험 요약과 각 항목의 위험, 원문 payload를 모두 읽을 수 있으며 감사 결과 열람은 제한하지 않습니다.

QR Code Halo가 하는 일

카메라로 스캔하거나 사진 속 코드를 인식, 한 화면의 여러 코드도 한 번에

모든 결과에 미리보기: 전체 내용, 링크의 스킴과 호스트, 수상한 형식 힌트

20가지 바코드 형식: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar, MSI Plessey

중복을 자동으로 거르는 일괄 스캔, 줌과 손전등

텍스트, 링크, Wi-Fi, 연락처, 이메일, 전화, SMS, 위치, 캘린더 일정 QR 코드 생성

개수 제한 없는 무제한 기록: 즐겨찾기, 검색, 유형·날짜·형식·태그·분류별 필터와 정렬

기기 안에서 자동으로 분류하고 직접 바꿀 수도 있으며, 기록을 CSV로 내보내기

백업도 복원도 실제 개수와 용량, 기간을 먼저 미리 보고 결정

Lifetime Pro: 무제한 스캔, 일괄 스캔 결과를 기록에 저장하고 결과 열기, CSV 일괄 생성과 일괄 내보내기, 백업과 복원 실행, 고해상도 PNG·PDF·SVG 내보내기, 커스텀 Aurora 스타일

기록을 자동으로 지우는 프라이버시 모드, 사진 앱 저장, 프린트, 공유 확장, Siri 단축어

QR Code Halo는 App Store에서 무료로 내려받을 수 있습니다. 스캔은 무료로 3회, 9가지 QR 코드 생성은 전부 사용할 수 있고 기록은 개수 제한 없이 즐겨찾기와 검색, 필터까지 그대로 쓸 수 있으며, 광고도 계정도 없습니다. 선택 사항인 Lifetime Pro는 한 번 결제하면 무제한 스캔, 일괄 저장과 결과 열기, CSV 일괄 생성과 일괄 내보내기, 백업과 복원, 고해상도 내보내기, 커스텀 Aurora 스타일이 영원히 내 것이 됩니다. 구독은 없습니다.
