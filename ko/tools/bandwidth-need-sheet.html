계산식과 한계

행 소계 = 기기 수 × 기기당 값. 필요량 = 각 행의 합. 여유 = 요금제 − 필요량. 요금제의 20% 미만이면 빠듯함, 0 미만이면 부족. 0.1 Mbps 단위 정수로 더해 합계가 흔들리지 않습니다.

구매 항목 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
구매 항목 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
구매 항목 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
필요 다운로드 = 25.0; 필요 업로드 = 8.5
여유 ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
상태 = 충분

기기당 수치는 각 서비스의 공식 권장값(Netflix, Zoom, 콘솔 제조사, FCC)을 바탕으로 한 대략적인 계획값입니다. 이 시트는 계획용이며 회선을 측정하지 않습니다.

  • 스트리밍(SD): 3.0 ↓ / 0.5 ↑ Mbps
  • 스트리밍(HD): 5.0 ↓ / 0.5 ↑ Mbps
  • 스트리밍(4K): 15.0 ↓ / 0.5 ↑ Mbps
  • 영상 통화: 3.0 ↓ / 3.0 ↑ Mbps
  • 온라인 게임: 3.0 ↓ / 1.0 ↑ Mbps
  • 클라우드 백업: 1.0 ↓ / 5.0 ↑ Mbps
  • 웹 서핑·메시지: 1.0 ↓ / 0.5 ↑ Mbps
  • 스마트홈 기기: 0.5 ↓ / 0.5 ↑ Mbps

요금제 속도는 0.5~10000 Mbps, 소수 한 자리까지. 행당 기기 1~50대, 최대 20행. Wi‑Fi 도달 범위, 지연 시간, 실제 제공 속도는 다루지 않습니다.

  • 요금제 다운로드(Mbps) / 요금제 업로드(Mbps): 0.5 ≤ x ≤ 10000 Mbps
  • 기기 수: 1 ≤ n ≤ 50
  • 구매 항목: 1 ≤ n ≤ 20
