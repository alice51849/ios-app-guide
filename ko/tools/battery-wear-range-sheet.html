계산식과 한계

월 마모 = (100 − 용량) ÷ 사용 개월, ±25% 폭으로 표시. 80%까지 개월 = (용량 − 80) ÷ 마모율로, 하한은 높은 마모율에서, 상한은 낮은 마모율에서 계산. 월 사이클 = 사이클 수 ÷ 사용 개월.

기기 1: (100 − 88) ÷ 24 = 0.50 %/사용 기간(개월) → ±25% → 0.38–0.63; (88 − 80) ÷ 월 마모 % → 12–22
기기 2: (100 − 100) ÷ 1 = 0.00 %/사용 기간(개월) → ±25% → 0.00–0.00; (100 − 80) ÷ 월 마모 % → 측정 가능한 마모 없음
기기 3: (100 − 79) ÷ 66 = 0.32 %/사용 기간(개월) → ±25% → 0.24–0.40; (79 − 80) ÷ 월 마모 % → 이미 80% 이하

용량은 60~100 정수 %, 사이클 수는 0~3000, 구매 월은 2007~2099이며 사용 기간 1~240개월, 최대 10대. 월은 YYYY-MM. 입력은 이 탭에만 남고 기기를 측정하거나 읽지 않습니다.

  • 최대 용량 %: 60 ≤ x ≤ 100
  • 사이클 수: 0 ≤ x ≤ 3000
  • 사용 기간(개월): 1 ≤ m ≤ 240
  • 기기: 1 ≤ n ≤ 10
