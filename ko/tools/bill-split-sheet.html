계산식과 한계

소계＝모두가 주문한 금액의 합. 세금＝소계 × 세금 비율. 팁＝소계 × 팁 비율. 각자 부담하는 세금과 팁은 자기 주문 금액 ÷ 소계로 나누고, 나누어떨어지지 않는 잔돈은 소수 부분이 큰 사람부터 붙이므로 각자 금액의 합은 항상 총 결제액과 같습니다.

소계 = 32.40 + 18.90 + 25.00 = 76.30
세금 = 76.30 × 8.25% = 6.29
팁 = 76.30 × 15.00% = 11.45
사람 1: 32.40 + 2.67 + 4.86 = 39.93
사람 2: 18.90 + 1.56 + 2.84 = 23.30
사람 3: 25.00 + 2.06 + 3.75 = 30.81
총 결제액 = 94.04

통화는 하나만 쓰고, 세금과 팁은 소계에 대한 비율로 입력하세요. 환율 변환, 봉사료 규칙, 팁 액수 조언, 결제 처리는 하지 않습니다. 화면 표시는 소수점 둘째 자리까지이며 계산은 최소 화폐 단위로 합니다.

  • 주문 금액: 0 ≤ n ≤ 100,000,000
  • 세금 % / 팁 %: 0 ≤ % ≤ 100
  • 사람: 1 ≤ n ≤ 20
