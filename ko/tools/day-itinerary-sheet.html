계산식과 한계

도착 = 이전 출발 + 이동. 출발 = 도착 + 체류. 합계 = 모든 체류 + 모든 이동. 가용 = 종료 − 시작; 종료가 시작보다 이르면 다음 날로 봅니다. 초과 = 합계 − 가용; 0보다 크면 시간 초과. 분 단위 덧셈만 하며 시간대는 다루지 않습니다.

1. 장소 1: 09:00 + 120 = 11:00 + 25 →
2. 장소 2: 11:25 + 60 = 12:25 + 40 →
3. 장소 3: 13:05 + 180 = 16:05 + 30 →
합계(분) = 455; 가용(분) = 09:00–18:00 = 540
초과(분) = 455 − 540 = -85 → 들어감

시각은 24시간 HH:MM, 체류 5~720분, 이동 0~600분, 최대 25곳. 영업시간, 실제 교통, 지도, 경로 탐색, 예약은 이 시트의 범위 밖입니다.

  • 시작 시각 / 종료 시각: HH:MM
  • 체류(분): 5 ≤ m ≤ 720
  • 다음까지 이동(분): 0 ≤ m ≤ 600
  • 장소: 1 ≤ n ≤ 25
