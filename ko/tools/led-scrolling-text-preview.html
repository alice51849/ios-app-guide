LED 전광판 문구 미리보기

콘서트 응원, 공항 마중, 가게 안내. 전광판에서 어떻게 보일지 미리 보고 노트북이나 태블릿에서 바로 전체 화면으로 띄우세요.

도트 느낌8가지 색왼쪽·오른쪽·정지전체 화면

표시할 문구

문구를 입력하고 색과 속도를 고른 뒤 전체 화면으로 띄우세요.

브라우저 미리보기입니다. 밝기는 화면에 따라 다릅니다. 입력한 내용은 저장되지 않습니다.

작동 방식

  1. 문구를 높이 16픽셀 이미지로 한 번 그리고, 켜진 픽셀 하나하나를 둥근 LED로 표시합니다.
  2. 스크롤은 LED 한 칸씩 움직이며 브라우저 애니메이션 시계에 맞추므로 화면 성능과 상관없이 속도가 일정합니다.
  3. 좌우 반전은 창밖이나 백미러로 볼 때 바르게 읽히도록 화면을 뒤집습니다.
  4. 전체 화면은 브라우저 전체 화면 모드를 씁니다. Esc 키나 버튼을 다시 누르면 나옵니다.

이 도구가 하지 않는 일

  • 브라우저 미리보기일 뿐 휴대폰 앱이 아닙니다. 보드 저장, 글꼴, 효과 팩은 없습니다.
  • 기기에 따라 화면 자동 잠금을 막지 못합니다. 오래 쓸 때는 화면 설정을 확인하세요.
  • 계정 없음, 추적 없음, 업로드 없음.

자주 묻는 질문

이모지나 한자도 되나요?

네. 브라우저가 그릴 수 있는 글자는 전광판에 표시됩니다. 획이 많은 글자는 16칸 높이에 맞게 단순해집니다.

더 크게 보려면?

전체 화면을 쓰거나, 전체 화면에서 휴대폰을 가로로 돌리면 글자가 커집니다.

글자가 거꾸로 보여요.

‘좌우 반전’이 켜져 있습니다. 창 너머로 보여 줄 때가 아니면 끄세요.
