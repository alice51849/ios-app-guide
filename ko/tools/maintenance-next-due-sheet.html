계산식과 한계

다음 예정일 = 마지막 완료 + 간격. 월 단위는 같은 날을 유지하고 그 날이 없는 달은 말일로 조정합니다(윤년 포함). 남은 일수 = 다음 예정일 − 오늘. 0 미만은 기한 지남, 0~7은 임박입니다.

2026-06-01 + 3 개월 = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 주 = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 개월 = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

간격은 1~3650일·주·개월. 날짜는 1900-01-01부터 2999-12-31까지. 항목은 최대 30개. 알림, 푸시, 캘린더 동기화는 없으며 데이터는 이 페이지를 벗어나지 않습니다.

  • 간격: 1 ≤ x ≤ 3650
  • 마지막 완료: 1900-01-01 ≤ x ≤ 2999-12-31
  • 항목: 1 ≤ n ≤ 30
