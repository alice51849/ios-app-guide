회의 메모를 한 장 개요로

어지러운 회의 메모를 한 장 개요로 정리합니다. 헤드라인 하나, 핵심 포인트 3~12개, 다음 행동 하나, 선택 지표를 넣고 슬라이드나 요약에 붙여 넣을 수 있는 시트로 내려받으세요.

핵심 포인트

포인트 3~12개.

선택: 포인트를 뒷받침하는 숫자 하나, 예를 들어 비율이나 건수.

포인트 수

3

구역

6

9월 30일까지 결제 개편 출시

  1. 이탈은 주소 단계에서 발생
  2. 파일럿에서 이탈률 감소
  3. 개발에 2주 더 필요

월요일에 추가 스프린트 승인

파일럿 이탈률 48%

입력은 이 탭에만 머뭅니다. 업로드, 계정, 입력 추적이나 데이터 저장이 없습니다. 새로고침하면 수정 내용이 지워집니다.

작성 예시

결제 화면 개편 회의 메모가 헤드라인 ‘9월 30일까지 결제 개편 출시’, 포인트 3개(이탈은 주소 단계에서 발생, 파일럿에서 이탈률 감소, 개발에 2주 더 필요), 다음 행동 ‘월요일에 추가 스프린트 승인’, 지표 ‘파일럿 이탈률 48%’가 됩니다.

계산식과 한계

시트는 입력한 문구를 그대로 유지합니다. 헤드라인, 입력한 순서의 포인트, 다음 행동, 지표 순입니다. 포인트 수를 세고 앞뒤 공백만 정리하며 고쳐 쓰기·요약·채점은 하지 않습니다.

헤드라인 ≤ 80 · 포인트 × 3 ≤ 160 · 다음 행동 ≤ 160 · 지표 ≤ 60
구역: 헤드라인 → 포인트 1…3 → 다음 행동 → 지표

헤드라인 80자 이내, 포인트 3~12개 각 160자 이내, 다음 행동 160자 이내, 지표 60자 이내. 모든 줄은 한 줄 텍스트여야 합니다. 파일, 녹음, 캘린더는 읽지 않습니다.

  • 헤드라인: ≤ 80
  • 포인트: 3 ≤ n ≤ 12, ≤ 160
  • 다음 행동: ≤ 160
  • 지표: ≤ 60
