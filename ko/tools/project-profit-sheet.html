계산식과 한계

이익 = 수입 합계 − 지출 합계. 이익률 = 이익 ÷ 수입 합계. 시간당 순수입 = 이익 ÷ 투입 시간. 금액은 최소 단위 정수로 더하므로 합계가 어긋나지 않습니다.

수입 합계 = 1500.00
지출 합계 = 400.39
이익 = 1500.00 − 400.39 = 1099.61
이익률 = 1099.61 ÷ 1500.00 = 73.3%
시간당 순수입 = 1099.61 ÷ 12.5 = 87.97

금액은 0~100,000,000, 소수점 둘째 자리까지. 수입·지출 각각 최대 20행, 시간은 0.25~2000(0.25시간 단위). 같은 통화, 환율 변환 없음, 세무·회계 조언 없음.

  • 금액: 0 ≤ x ≤ 100,000,000
  • 투입 시간: 0.25 ≤ h ≤ 2000
  • 수입 / 지출: 1 ≤ n ≤ 20
