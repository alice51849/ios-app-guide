계산식과 한계

합계 = 수량 × 세금 포함 단가. 근무 시간 = 합계 ÷ 실수령 시급. 근무 일수 = 근무 시간 ÷ 하루 근무 시간.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

세금이 포함된 가격을 입력하세요. 환전, 급여 계산, 저축 예측이나 구매 조언은 제공하지 않습니다. 표시는 소수 둘째 자리까지이며 합계는 반올림 전 값으로 계산합니다.

  • 실수령 시급: 0 < x ≤ 100000000
  • 세금 포함 단가: 0 ≤ x ≤ 100000000
  • 하루 근무 시간: 0 < x ≤ 24
  • 수량: 1 ≤ x ≤ 999
