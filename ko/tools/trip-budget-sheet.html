계산식과 한계

자유롭게 쓸 금액 = 총예산 − 고정 비용. 하루 = 자유롭게 쓸 금액 ÷ 일수. 1인 하루 = 하루 ÷ 인원. 각 항목 = 하루 × 비율. 금액은 최소 단위 정수로 더하고, 하루 수치는 표시할 때만 반올림합니다.

고정 비용 = 1750.50
자유롭게 쓸 금액 = 3000.00 − 1750.50 = 1249.50
하루 = 1249.50 ÷ 5 = 249.90
1인 하루 = 249.90 ÷ 2 = 124.95
식비 = 249.90 × 40% = 99.96
교통 = 249.90 × 20% = 49.98
입장권 = 249.90 × 25% = 62.48
쇼핑 = 249.90 × 15% = 37.49

금액 0~100,000,000, 소수 두 자리까지; 일수 1~120; 인원 1~20; 고정 비용 최대 15행; 네 비율의 합은 정확히 100. 같은 통화만 사용하며 환율, 가격·예약 조언은 다루지 않습니다.

  • 총예산 / 금액: 0 ≤ x ≤ 100,000,000
  • 일수: 1 ≤ d ≤ 120
  • 인원: 1 ≤ p ≤ 20
  • 비율: Σ = 100%
  • 고정 비용: 0 ≤ n ≤ 15
