വീട്ടിലെ ഇന്റർനെറ്റ് വേഗ ഷീറ്റ്

വീട്ടിൽ ഒരേ സമയം ഓൺലൈനിൽ എന്തൊക്കെ നടക്കുന്നു, എത്ര ഉപകരണങ്ങളിൽ എന്ന് എഴുതുക; ആവശ്യമായ Mbps-ഉം നിങ്ങളുടെ പ്ലാനിൽ ബാക്കിയുള്ള മാർജിനും ഉള്ള ഷീറ്റ് ഡൗൺലോഡ് ചെയ്യുക.

ഓരോ ഉപകരണത്തിനുമുള്ള കണക്കുകൾ സേവനങ്ങളുടെ സ്വന്തം മാർഗനിർദേശങ്ങളിൽ നിന്ന് (Netflix, Zoom, കൺസോൾ നിർമാതാക്കൾ, FCC) എടുത്ത ഏകദേശ ആസൂത്രണ മൂല്യങ്ങളാണ്. ഈ ഷീറ്റ് ആസൂത്രണം ചെയ്യുന്നു; നിങ്ങളുടെ ലൈൻ അളക്കുന്നില്ല.

സൂത്രവും പരിധികളും

വരിയുടെ ആകെ = ഉപകരണങ്ങൾ × ഓരോ ഉപകരണ മൂല്യം. ആവശ്യം = വരികളുടെ തുക. മാർജിൻ = പ്ലാൻ − ആവശ്യം; പ്ലാനിന്റെ 20%-ൽ താഴെയെങ്കിൽ ഇറുകിയത്, പൂജ്യത്തിനു താഴെയെങ്കിൽ പോരാ. പൂർണ പത്തിലൊന്ന് Mbps യൂണിറ്റിൽ കൂട്ടുന്നതിനാൽ തുകകൾ ഒരിക്കലും തെറ്റുന്നില്ല.

വാങ്ങൽ 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
വാങ്ങൽ 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
വാങ്ങൽ 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
ആവശ്യമായ ഡൗൺലോഡ് = 25.0; ആവശ്യമായ അപ്‌ലോഡ് = 8.5
മാർജിൻ ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
നില = മതി

ഓരോ ഉപകരണത്തിനുമുള്ള കണക്കുകൾ സേവനങ്ങളുടെ സ്വന്തം മാർഗനിർദേശങ്ങളിൽ നിന്ന് (Netflix, Zoom, കൺസോൾ നിർമാതാക്കൾ, FCC) എടുത്ത ഏകദേശ ആസൂത്രണ മൂല്യങ്ങളാണ്. ഈ ഷീറ്റ് ആസൂത്രണം ചെയ്യുന്നു; നിങ്ങളുടെ ലൈൻ അളക്കുന്നില്ല.

  • സ്ട്രീമിംഗ് (SD): 3.0 ↓ / 0.5 ↑ Mbps
  • സ്ട്രീമിംഗ് (HD): 5.0 ↓ / 0.5 ↑ Mbps
  • സ്ട്രീമിംഗ് (4K): 15.0 ↓ / 0.5 ↑ Mbps
  • വീഡിയോ കോളുകൾ: 3.0 ↓ / 3.0 ↑ Mbps
  • ഓൺലൈൻ ഗെയിമിംഗ്: 3.0 ↓ / 1.0 ↑ Mbps
  • ക്ലൗഡ് ബാക്കപ്പ്: 1.0 ↓ / 5.0 ↑ Mbps
  • ബ്രൗസിംഗും സന്ദേശങ്ങളും: 1.0 ↓ / 0.5 ↑ Mbps
  • സ്മാർട്ട് ഹോം ഉപകരണങ്ങൾ: 0.5 ↓ / 0.5 ↑ Mbps

പ്ലാൻ വേഗം 0.5 മുതൽ 10000 Mbps വരെ, പരമാവധി ഒരു ദശാംശം; ഓരോ വരിയിലും 1 മുതൽ 50 ഉപകരണങ്ങൾ; പരമാവധി 20 വരികൾ. Wi‑Fi കവറേജ്, ലേറ്റൻസി, ദാതാവ് യഥാർഥത്തിൽ നൽകുന്ന വേഗം എന്നിവ ഈ ഷീറ്റിന്റെ പരിധിക്കു പുറത്താണ്.

  • പ്ലാൻ ഡൗൺലോഡ് (Mbps) / പ്ലാൻ അപ്‌ലോഡ് (Mbps): 0.5 ≤ x ≤ 10000 Mbps
  • ഉപകരണങ്ങൾ: 1 ≤ n ≤ 50
  • വാങ്ങൽ: 1 ≤ n ≤ 20
