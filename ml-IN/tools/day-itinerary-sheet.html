സൂത്രവും പരിധികളും

എത്തൽ = മുൻ പുറപ്പെടൽ + യാത്ര. പുറപ്പെടൽ = എത്തൽ + താമസം. ആകെ = എല്ലാ താമസങ്ങളും + എല്ലാ യാത്രകളും. ലഭ്യം = അവസാനം − തുടക്കം; തുടക്കത്തിനു മുമ്പുള്ള അവസാന സമയം അടുത്ത ദിവസമായി കണക്കാക്കും. കവിഞ്ഞത് = ആകെ − ലഭ്യം; പൂജ്യത്തിനു മുകളിലെങ്കിൽ സമയം കവിയും. വെറും മിനിറ്റ് കൂട്ടൽ, സമയ മേഖലകളില്ല.

1. സ്ഥലം 1: 09:00 + 120 = 11:00 + 25 →
2. സ്ഥലം 2: 11:25 + 60 = 12:25 + 40 →
3. സ്ഥലം 3: 13:05 + 180 = 16:05 + 30 →
ആകെ (മിനിറ്റ്) = 455; ലഭ്യം (മിനിറ്റ്) = 09:00–18:00 = 540
കവിഞ്ഞത് (മിനിറ്റ്) = 455 − 540 = -85 → ഒതുങ്ങും

സമയങ്ങൾ 24 മണിക്കൂർ HH:MM രൂപത്തിൽ; താമസം 5 മുതൽ 720 മിനിറ്റ്; യാത്ര 0 മുതൽ 600 മിനിറ്റ്; പരമാവധി 25 സ്ഥലങ്ങൾ. തുറക്കുന്ന സമയം, യഥാർഥ ഗതാഗതം, ഭൂപടങ്ങൾ, റൂട്ടുകൾ, ബുക്കിംഗ് എന്നിവ ഈ ഷീറ്റിന്റെ പരിധിക്കു പുറത്താണ്.

  • തുടക്ക സമയം / അവസാന സമയം: HH:MM
  • താമസം (മിനിറ്റ്): 5 ≤ m ≤ 720
  • അടുത്തതിലേക്കുള്ള യാത്ര (മിനിറ്റ്): 0 ≤ m ≤ 600
  • സ്ഥലം: 1 ≤ n ≤ 25
