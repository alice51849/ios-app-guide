സൂത്രവും പരിധികളും

അടുത്ത തീയതി = അവസാനം ചെയ്തത് + ഇടവേള. മാസങ്ങളിൽ അതേ ദിവസം നിലനിർത്തും; ഇല്ലെങ്കിൽ മാസത്തിന്റെ അവസാന ദിവസം (അധിവർഷം ഉൾപ്പെടെ). ശേഷിക്കുന്ന ദിവസങ്ങൾ = അടുത്ത തീയതി − ഇന്ന്. 0-ൽ താഴെ വൈകി; 0 മുതൽ 7 വരെ ഉടൻ.

2026-06-01 + 3 മാസം = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 ആഴ്ച = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 മാസം = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

ഇടവേള 1 മുതൽ 3650 ദിവസം, ആഴ്ച അല്ലെങ്കിൽ മാസം. തീയതികൾ 1900-01-01 മുതൽ 2999-12-31 വരെ. പരമാവധി 30 ജോലികൾ. ഓർമ്മപ്പെടുത്തലോ അറിയിപ്പോ കലണ്ടർ സിങ്കോ ഇല്ല; ഒന്നും ഈ പേജ് വിട്ടുപോകുന്നില്ല.

  • ഇടവേള: 1 ≤ x ≤ 3650
  • അവസാനം ചെയ്തത്: 1900-01-01 ≤ x ≤ 2999-12-31
  • ജോലി: 1 ≤ n ≤ 30
