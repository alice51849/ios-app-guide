വിവരങ്ങൾ ഈ ടാബിൽ മാത്രം തുടരും. അപ്‌ലോഡ്, അക്കൗണ്ട്, നൽകിയ വിവരങ്ങളുടെ ട്രാക്കിങ്, സംഭരണം എന്നിവയില്ല. വീണ്ടും ലോഡ് ചെയ്താൽ മാറ്റങ്ങൾ മായും.

ചെക്ക്ഔട്ട് പുനർരൂപകൽപ്പനയുടെ കുറിപ്പുകൾ ഇങ്ങനെ മാറുന്നു: തലക്കെട്ട് «സെപ്റ്റംബർ 30-നകം പുതിയ ചെക്ക്ഔട്ട് പുറത്തിറക്കുക», മൂന്ന് പോയിന്റുകൾ (വിലാസ ഘട്ടത്തിലാണ് ഡ്രോപ്പ്-ഓഫ്, പൈലറ്റ് ഉപേക്ഷിക്കൽ നിരക്ക് കുറച്ചു, എൻജിനീയറിംഗിന് രണ്ടാഴ്ച കൂടി വേണം), അടുത്ത നടപടി «തിങ്കളാഴ്ച അധിക സ്പ്രിന്റ് അംഗീകരിക്കുക», അളവ് «പൈലറ്റിൽ 48% ഉപേക്ഷിക്കൽ».

സൂത്രവും പരിധികളും

ഷീറ്റ് നിങ്ങളുടെ വാക്കുകൾ അതേപടി നിലനിർത്തുന്നു: തലക്കെട്ട്, പിന്നെ നിങ്ങൾ ടൈപ്പ് ചെയ്ത ക്രമത്തിൽ പോയിന്റുകൾ, പിന്നെ അടുത്ത നടപടി, പിന്നെ അളവ്. പോയിന്റുകൾ എണ്ണി അരികിലെ സ്പേസുകൾ നീക്കുന്നു; ഒന്നും മാറ്റിയെഴുതുകയോ സംഗ്രഹിക്കുകയോ സ്കോർ ചെയ്യുകയോ ഇല്ല.

തലക്കെട്ട് ≤ 80 · പോയിന്റ് × 3 ≤ 160 · അടുത്ത നടപടി ≤ 160 · അളവ് ≤ 60
വിഭാഗം: തലക്കെട്ട് → പോയിന്റ് 1…3 → അടുത്ത നടപടി → അളവ്

തലക്കെട്ട് പരമാവധി 80 അക്ഷരങ്ങൾ; 3 മുതൽ 12 വരെ പോയിന്റുകൾ, ഓരോന്നും പരമാവധി 160 അക്ഷരങ്ങൾ; അടുത്ത നടപടി പരമാവധി 160 അക്ഷരങ്ങൾ; അളവ് പരമാവധി 60 അക്ഷരങ്ങൾ. ഓരോ വരിയും ഒറ്റവരി വാചകമായിരിക്കണം. ഷീറ്റ് ഫയലുകളോ റെക്കോർഡിംഗുകളോ കലണ്ടറുകളോ വായിക്കില്ല.

  • തലക്കെട്ട്: ≤ 80
  • പോയിന്റ്: 3 ≤ n ≤ 12, ≤ 160
  • അടുത്ത നടപടി: ≤ 160
  • അളവ്: ≤ 60
