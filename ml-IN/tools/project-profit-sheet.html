സൂത്രവും പരിധികളും

ലാഭം = മൊത്തം വരവ് − മൊത്തം ചെലവ്. മാർജിൻ = ലാഭം ÷ മൊത്തം വരവ്. മണിക്കൂറിന് അറ്റം = ലാഭം ÷ ചെലവഴിച്ച മണിക്കൂർ. തുകകൾ പൂർണ്ണ പൈസയിൽ കൂട്ടുന്നതിനാൽ ആകെത്തുകകൾ തെന്നിപ്പോകില്ല.

മൊത്തം വരവ് = 1500.00
മൊത്തം ചെലവ് = 400.39
ലാഭം = 1500.00 − 400.39 = 1099.61
മാർജിൻ = 1099.61 ÷ 1500.00 = 73.3%
മണിക്കൂറിന് അറ്റം = 1099.61 ÷ 12.5 = 87.97

തുക 0 മുതൽ 100,000,000 വരെ, പരമാവധി രണ്ട് ദശാംശം; പരമാവധി 20 വരവ്, 20 ചെലവ് വരികൾ; മണിക്കൂർ 0.25 മുതൽ 2000 വരെ, കാൽ മണിക്കൂർ പടികളിൽ. ഒരേ കറൻസി, വിനിമയമില്ല, നികുതി അല്ലെങ്കിൽ അക്കൗണ്ടിംഗ് ഉപദേശമില്ല.

  • തുക: 0 ≤ x ≤ 100,000,000
  • ചെലവഴിച്ച മണിക്കൂർ: 0.25 ≤ h ≤ 2000
  • വരവ് / ചെലവ്: 1 ≤ n ≤ 20
