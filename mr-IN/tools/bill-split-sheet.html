सूत्र आणि मर्यादा

उप-बेरीज = सर्वांच्या मागणीची बेरीज. कर = उप-बेरीज × कर दर. टिप = उप-बेरीज × टिप दर. प्रत्येकाचा वाटा म्हणजे स्वतःची मागणी ÷ उप-बेरीज; उरलेले पैसे आधी सर्वात मोठ्या दशांशाला मिळतात, त्यामुळे सर्वांचे वाटे मिळून नेहमी पूर्ण बिल होते.

उप-बेरीज = 32.40 + 18.90 + 25.00 = 76.30
कर = 76.30 × 8.25% = 6.29
टिप = 76.30 × 15.00% = 11.45
व्यक्ती 1: 32.40 + 2.67 + 4.86 = 39.93
व्यक्ती 2: 18.90 + 1.56 + 2.84 = 23.30
व्यक्ती 3: 25.00 + 2.06 + 3.75 = 30.81
बिलाची एकूण रक्कम = 94.04

एकच चलन वापरा आणि कर व टिप उप-बेरजेच्या टक्केवारीत भरा. चलन रूपांतर नाही, सर्व्हिस चार्जचे नियम नाहीत, किती टिप द्यावी याचा सल्ला नाही आणि कोणतेही पेमेंट नाही. पडद्यावर दोन दशांशांपर्यंत दिसते; वाटणी पूर्ण पैशांत मोजली जाते.

  • किती रकमेचं मागवलं: 0 ≤ n ≤ 100,000,000
  • कर % / टिप %: 0 ≤ % ≤ 100
  • व्यक्ती: 1 ≤ n ≤ 20
