सूत्र आणि मर्यादा

पोहोचणे = मागील निघणे + प्रवास. निघणे = पोहोचणे + थांबा. एकूण = सर्व थांबे + सर्व प्रवास. उपलब्ध = शेवट − सुरुवात; सुरुवातीपूर्वीचा शेवट पुढचा दिवस मानला जातो. जास्त = एकूण − उपलब्ध; शून्यापेक्षा जास्त असल्यास वेळ ओलांडली. फक्त मिनिटांची बेरीज, टाइम झोन नाही.

1. जागा 1: 09:00 + 120 = 11:00 + 25 →
2. जागा 2: 11:25 + 60 = 12:25 + 40 →
3. जागा 3: 13:05 + 180 = 16:05 + 30 →
एकूण (मिनिटे) = 455; उपलब्ध (मिनिटे) = 09:00–18:00 = 540
जास्त (मिनिटे) = 455 − 540 = -85 → बसते

वेळा 24-तास HH:MM स्वरूपात, थांबा 5 ते 720 मिनिटे, प्रवास 0 ते 600 मिनिटे, जास्तीत जास्त 25 जागा. उघडण्याच्या वेळा, प्रत्यक्ष वाहतूक, नकाशे, मार्ग आणि बुकिंग या शीटमध्ये नाहीत.

  • सुरुवातीची वेळ / शेवटची वेळ: HH:MM
  • थांबा (मिनिटे): 5 ≤ m ≤ 720
  • पुढच्या जागेपर्यंत (मिनिटे): 0 ≤ m ≤ 600
  • जागा: 1 ≤ n ≤ 25
