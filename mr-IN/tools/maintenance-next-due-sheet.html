सूत्र आणि मर्यादा

पुढील तारीख = शेवटी केले + अंतर. महिन्यांत तोच दिवस राहतो; तो नसल्यास महिन्याचा शेवटचा दिवस घेतला जातो (लीप वर्षासह). उरलेले दिवस = पुढील तारीख − आज. 0 पेक्षा कमी उशीर; 0 ते 7 लवकरच.

2026-06-01 + 3 महिना = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 आठवडा = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 महिना = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

अंतर 1 ते 3650 दिवस, आठवडे किंवा महिने. तारखा 1900-01-01 ते 2999-12-31. जास्तीत जास्त 30 कामे. स्मरणपत्र, सूचना किंवा कॅलेंडर सिंक नाही; काहीही या पानाबाहेर जात नाही.

  • अंतर: 1 ≤ x ≤ 3650
  • शेवटी केले: 1900-01-01 ≤ x ≤ 2999-12-31
  • काम: 1 ≤ n ≤ 30
