सूत्र आणि मर्यादा

नफा = एकूण जमा − एकूण खर्च. मार्जिन = नफा ÷ एकूण जमा. तासाला निव्वळ = नफा ÷ लागलेले तास. रकमा पूर्ण पैशांत मिळवल्या जातात, त्यामुळे बेरजा सरकत नाहीत.

एकूण जमा = 1500.00
एकूण खर्च = 400.39
नफा = 1500.00 − 400.39 = 1099.61
मार्जिन = 1099.61 ÷ 1500.00 = 73.3%
तासाला निव्वळ = 1099.61 ÷ 12.5 = 87.97

रक्कम 0 ते 100,000,000, जास्तीत जास्त दोन दशांश; जास्तीत जास्त 20 जमा आणि 20 खर्चाच्या ओळी; तास 0.25 ते 2000, पाव तासाच्या टप्प्यांत. एकच चलन, विनिमय नाही, कर किंवा लेखा सल्ला नाही.

  • रक्कम: 0 ≤ x ≤ 100,000,000
  • लागलेले तास: 0.25 ≤ h ≤ 2000
  • जमा / खर्च: 1 ≤ n ≤ 20
