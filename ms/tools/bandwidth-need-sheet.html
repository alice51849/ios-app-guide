Formula dan batasan

Jumlah setiap baris = peranti × nilai setiap peranti. Keperluan = jumlah semua baris. Baki ruang = pelan − keperluan; di bawah 20% pelan bermakna ketat, di bawah sifar bermakna tidak cukup. Dijumlahkan dalam persepuluh Mbps bulat, jadi jumlahnya tidak pernah tersasar.

Belian 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
Belian 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
Belian 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
Muat turun diperlukan = 25.0; Muat naik diperlukan = 8.5
Baki ruang ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
Status = Mencukupi

Angka setiap peranti ialah nilai anggaran untuk perancangan daripada panduan perkhidmatan itu sendiri (Netflix, Zoom, pengeluar konsol, FCC). Helaian ini merancang; ia tidak mengukur talian anda.

  • Penstriman (SD): 3.0 ↓ / 0.5 ↑ Mbps
  • Penstriman (HD): 5.0 ↓ / 0.5 ↑ Mbps
  • Penstriman (4K): 15.0 ↓ / 0.5 ↑ Mbps
  • Panggilan video: 3.0 ↓ / 3.0 ↑ Mbps
  • Permainan dalam talian: 3.0 ↓ / 1.0 ↑ Mbps
  • Sandaran awan: 1.0 ↓ / 5.0 ↑ Mbps
  • Melayari web dan mesej: 1.0 ↓ / 0.5 ↑ Mbps
  • Peranti rumah pintar: 0.5 ↓ / 0.5 ↑ Mbps

Kelajuan pelan 0.5 hingga 10000 Mbps dengan paling banyak satu tempat perpuluhan, 1 hingga 50 peranti setiap baris, sehingga 20 baris. Liputan Wi‑Fi, kependaman dan kelajuan sebenar daripada penyedia berada di luar helaian ini.

  • Muat turun pelan (Mbps) / Muat naik pelan (Mbps): 0.5 ≤ x ≤ 10000 Mbps
  • Peranti: 1 ≤ n ≤ 50
  • Belian: 1 ≤ n ≤ 20
