Formula dan batasan

Jumlah kecil = semua pesanan dicampur. Cukai = jumlah kecil × kadar cukai. Tip = jumlah kecil × kadar tip. Bahagian setiap orang ialah pesanannya ÷ jumlah kecil; sen yang berbaki diberikan dahulu kepada pecahan perpuluhan terbesar, jadi semua bahagian sentiasa mencukupkan jumlah bil.

Jumlah kecil = 32.40 + 18.90 + 25.00 = 76.30
Cukai = 76.30 × 8.25% = 6.29
Tip = 76.30 × 15.00% = 11.45
Orang 1: 32.40 + 2.67 + 4.86 = 39.93
Orang 2: 18.90 + 1.56 + 2.84 = 23.30
Orang 3: 25.00 + 2.06 + 3.75 = 30.81
Jumlah bil = 94.04

Guna satu mata wang sahaja, dan masukkan cukai serta tip sebagai peratus daripada jumlah kecil. Tiada penukaran mata wang, tiada peraturan caj perkhidmatan, tiada nasihat berapa tip patut diberi, dan tiada pembayaran. Paparan dibundarkan kepada dua tempat perpuluhan; pembahagian dikira dalam sen penuh.

  • Nilai pesanan: 0 ≤ n ≤ 100,000,000
  • Cukai % / Tip %: 0 ≤ % ≤ 100
  • Orang: 1 ≤ n ≤ 20
