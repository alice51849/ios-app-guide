Formula dan batasan

Untung = jumlah pendapatan − jumlah perbelanjaan. Margin = untung ÷ jumlah pendapatan. Bersih sejam = untung ÷ jam digunakan. Amaun dijumlahkan dalam sen penuh supaya jumlah tidak terpesong.

Jumlah pendapatan = 1500.00
Jumlah perbelanjaan = 400.39
Untung = 1500.00 − 400.39 = 1099.61
Margin = 1099.61 ÷ 1500.00 = 73.3%
Bersih sejam = 1099.61 ÷ 12.5 = 87.97

Amaun dari 0 hingga 100,000,000 dengan paling banyak dua tempat perpuluhan, hingga 20 baris pendapatan dan 20 perbelanjaan, jam dari 0.25 hingga 2000 dalam langkah suku jam. Satu mata wang, tiada penukaran, tiada nasihat cukai atau perakaunan.

  • Amaun: 0 ≤ x ≤ 100,000,000
  • Jam digunakan: 0.25 ≤ h ≤ 2000
  • Pendapatan / Perbelanjaan: 1 ≤ n ≤ 20
