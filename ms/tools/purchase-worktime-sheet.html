Formula dan batasan

Jumlah = kuantiti × harga akhir. Jam = jumlah ÷ pendapatan bersih sejam. Hari = jam ÷ jam sehari bekerja.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Masukkan harga termasuk cukai. Tiada pertukaran mata wang, pengiraan gaji, ramalan simpanan atau nasihat membeli. Paparan dibundarkan kepada dua perpuluhan; jumlah menggunakan nilai tanpa pembundaran.

  • Pendapatan bersih sejam: 0 < x ≤ 100000000
  • Harga akhir seunit: 0 ≤ x ≤ 100000000
  • Jam sehari bekerja: 0 < x ≤ 24
  • Kuantiti: 1 ≤ x ≤ 999
