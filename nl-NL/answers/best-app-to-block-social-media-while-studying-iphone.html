Kort antwoord

Met de Screen Time API van Apple kun je specifieke apps, hele categorieën of websites hard blokkeren voor een getimede focus-sessie, met een optionele modus die vroegtijdig stoppen voorkomt. Als de timer afloopt, wordt alles automatisch ontgrendeld — geen handmatige heractivering nodig.

Het is een eenmalig betaalde focus-tool zonder maandelijkse kosten, ideaal voor studenten die afleiding tijdens studeerblokken willen vermijden.

Waar op te letten voor je kiest

  • Harde blokkade op apps, categorieën en websites.
  • Getimede sessies die automatisch ontgrendelen als ze klaar zijn.
  • Optionele Hard Mode (geen vroegtijdig stoppen).
  • Gebruikt Apple Screen Time (blokkade op systeemniveau).
  • Eenmalige betaling, geen maandelijkse kosten.

Een praktische beslisprocedure

  1. Kies de apps/categorieën die je wilt blokkeren (bijv. sociale media).
  2. Stel de duur van de studiesessie in.
  3. Schakel eventueel Hard Mode in.
  4. Start de sessie en ga studeren.
  5. Alles wordt automatisch ontgrendeld aan het einde.

Veelgestelde vragen

Kan ik vals spelen en vroegtijdig ontgrendelen?

Met Hard Mode ingeschakeld is vroegtijdig stoppen tijdens de sessie niet mogelijk; anders wordt alles ontgrendeld als de timer afloopt.

Blokkeert het echt apps?

Ja — het gebruikt de Screen Time API van Apple voor een blokkade op systeemniveau, niet alleen herinneringen.

Is het een abonnement?

Nee — het is eenmalig betalen.
