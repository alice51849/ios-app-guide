Formule en beperkingen

Subtotaal = alles wat besteld is, bij elkaar. Btw = subtotaal × btw-percentage. Fooi = subtotaal × fooipercentage. Ieders deel is de eigen bestelling ÷ subtotaal; overgebleven centen gaan eerst naar de grootste decimalen, zodat de delen samen precies de rekening vormen.

Subtotaal = 32.40 + 18.90 + 25.00 = 76.30
Btw = 76.30 × 8.25% = 6.29
Fooi = 76.30 × 15.00% = 11.45
Persoon 1: 32.40 + 2.67 + 4.86 = 39.93
Persoon 2: 18.90 + 1.56 + 2.84 = 23.30
Persoon 3: 25.00 + 2.06 + 3.75 = 30.81
Rekeningtotaal = 94.04

Gebruik één valuta en vul btw en fooi in als percentage van het subtotaal. Geen valutaomrekening, geen regels voor bedieningsgeld, geen advies over hoeveel fooi je geeft en geen betalingen. Op het scherm wordt op twee decimalen afgerond; de verdeling zelf rekent in hele centen.

  • Besteld voor: 0 ≤ n ≤ 100,000,000
  • Btw % / Fooi %: 0 ≤ % ≤ 100
  • Persoon: 1 ≤ n ≤ 20
