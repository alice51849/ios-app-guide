Formule en beperkingen

Winst = totaal inkomsten − totaal uitgaven. Marge = winst ÷ totaal inkomsten. Netto per uur = winst ÷ bestede uren. Bedragen worden in hele centen opgeteld, dus totalen verschuiven niet.

Totaal inkomsten = 1500.00
Totaal uitgaven = 400.39
Winst = 1500.00 − 400.39 = 1099.61
Marge = 1099.61 ÷ 1500.00 = 73.3%
Netto per uur = 1099.61 ÷ 12.5 = 87.97

Bedragen van 0 tot 100.000.000 met hoogstens twee decimalen, tot 20 inkomsten- en 20 uitgavenregels, uren van 0,25 tot 2000 in kwartieren. Eén valuta, geen omrekening, geen belasting- of boekhoudadvies.

  • Bedrag: 0 ≤ x ≤ 100,000,000
  • Bestede uren: 0.25 ≤ h ≤ 2000
  • Inkomst / Uitgave: 1 ≤ n ≤ 20
