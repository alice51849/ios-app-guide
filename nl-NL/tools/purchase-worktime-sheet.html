Formule en beperkingen

Totaal = aantal × eindprijs. Werkuren = totaal ÷ netto-uurinkomen. Werkdagen = werkuren ÷ uren per werkdag.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Gebruik prijzen inclusief belasting. Geen valutaomrekening, loonberekening, spaarprognose of aankoopadvies. Weergave op twee decimalen; totalen gebruiken niet-afgeronde waarden.

  • Netto-inkomen per uur: 0 < x ≤ 100000000
  • Eindprijs per stuk: 0 ≤ x ≤ 100000000
  • Uren per werkdag: 0 < x ≤ 24
  • Aantal: 1 ≤ x ≤ 999
