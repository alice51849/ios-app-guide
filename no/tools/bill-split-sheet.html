Formel og begrensninger

Delsum = alt det bestilte lagt sammen. Avgift = delsum × avgiftssats. Tips = delsum × tipssats. Andelen til hver person er egen bestilling ÷ delsum; ørene som blir til overs går først til de største desimalene, slik at andelene til sammen treffer regningen nøyaktig.

Delsum = 32.40 + 18.90 + 25.00 = 76.30
Avgift = 76.30 × 8.25% = 6.29
Tips = 76.30 × 15.00% = 11.45
Person 1: 32.40 + 2.67 + 4.86 = 39.93
Person 2: 18.90 + 1.56 + 2.84 = 23.30
Person 3: 25.00 + 2.06 + 3.75 = 30.81
Regningen totalt = 94.04

Bruk én valuta, og oppgi avgift og tips som prosent av delsummen. Ingen valutaomregning, ingen regler for serviceavgift, ingen råd om hvor mye du bør gi i tips og ingen betaling. Visningen avrundes til to desimaler; selve fordelingen regnes i hele øre.

  • Bestilte for: 0 ≤ n ≤ 100,000,000
  • Avgift % / Tips %: 0 ≤ % ≤ 100
  • Person: 1 ≤ n ≤ 20
