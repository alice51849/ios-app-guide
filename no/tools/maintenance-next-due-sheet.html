Formel og begrensninger

Neste frist = sist utført + intervall. Ved måneder beholdes samme dag; finnes den ikke, brukes månedens siste dag (også i skuddår). Dager igjen = frist − i dag. Forfalt under 0; snart fra 0 til 7.

2026-06-01 + 3 måneder = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 uke = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 måneder = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Intervaller fra 1 til 3650 dager, uker eller måneder. Datoer mellom 1900-01-01 og 2999-12-31. Opptil 30 oppgaver. Ingen påminnelser, varsler eller kalendersynkronisering; ingenting forlater denne siden.

  • Intervall: 1 ≤ x ≤ 3650
  • Sist utført: 1900-01-01 ≤ x ≤ 2999-12-31
  • Oppgave: 1 ≤ n ≤ 30
