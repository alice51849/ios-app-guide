Formel og begrensninger

Fortjeneste = sum inntekter − sum utgifter. Margin = fortjeneste ÷ sum inntekter. Netto per time = fortjeneste ÷ timer brukt. Beløp summeres i hele øre, så totalene driver ikke.

Sum inntekter = 1500.00
Sum utgifter = 400.39
Fortjeneste = 1500.00 − 400.39 = 1099.61
Margin = 1099.61 ÷ 1500.00 = 73.3%
Netto per time = 1099.61 ÷ 12.5 = 87.97

Beløp fra 0 til 100 000 000 med høyst to desimaler, opptil 20 inntekts- og 20 utgiftsrader, timer fra 0,25 til 2000 i kvarter. Samme valuta, ingen veksling, ingen skatte- eller regnskapsråd.

  • Beløp: 0 ≤ x ≤ 100,000,000
  • Timer brukt: 0.25 ≤ h ≤ 2000
  • Inntekt / Utgift: 1 ≤ n ≤ 20
