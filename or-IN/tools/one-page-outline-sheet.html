ପାଇଲଟ୍‌ରେ 48% ଛାଡ଼ିବା

ଆପଣଙ୍କ ତଥ୍ୟ ଏହି ଟ୍ୟାବ୍‌ରେ ରହେ। ଅପଲୋଡ୍, ଖାତା, ଦିଆଯାଇଥିବା ତଥ୍ୟର ଟ୍ରାକିଂ କିମ୍ବା ସଂରକ୍ଷଣ ନାହିଁ। ପୁଣି ଲୋଡ୍ କଲେ ପରିବର୍ତ୍ତନ ହଟିଯାଏ।

ପୂର୍ଣ୍ଣ ଉଦାହରଣ

ଚେକ୍‌ଆଉଟ୍ ପୁନଃଡିଜାଇନ୍‌ର ନୋଟ୍ ଏହିପରି ହୁଏ: ଶିରୋନାମା «30 ସେପ୍ଟେମ୍ବର ସୁଦ୍ଧା ନୂଆ ଚେକ୍‌ଆଉଟ୍ ଲଞ୍ଚ», ତିନୋଟି ବିନ୍ଦୁ (ଠିକଣା ପଦକ୍ଷେପରେ ଡ୍ରପ୍-ଅଫ୍ ହୁଏ, ପାଇଲଟ୍ ଛାଡ଼ିବା ହାର କମାଇଲା, ଇଞ୍ଜିନିୟରିଂକୁ ଆଉ ଦୁଇ ସପ୍ତାହ ଦରକାର), ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ «ସୋମବାର ଅତିରିକ୍ତ ସ୍ପ୍ରିଣ୍ଟ ଅନୁମୋଦନ» ଓ ମାପ «ପାଇଲଟ୍‌ରେ 48% ଛାଡ଼ିବା»।

ସୂତ୍ର ଓ ସୀମା

ଶିଟ୍ ଆପଣଙ୍କ ଶବ୍ଦକୁ ଯେମିତି ଅଛି ସେମିତି ରଖେ: ଶିରୋନାମା, ତାପରେ ଆପଣ ଲେଖିଥିବା କ୍ରମରେ ବିନ୍ଦୁ, ତାପରେ ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ, ତାପରେ ମାପ। ଏହା ବିନ୍ଦୁ ଗଣେ ଓ ଧାରର ଖାଲି ସ୍ଥାନ ହଟାଏ; କିଛି ପୁନଃଲିଖନ, ସଂକ୍ଷିପ୍ତ କିମ୍ବା ସ୍କୋର କରାଯାଏ ନାହିଁ।

ଶିରୋନାମା ≤ 80 · ବିନ୍ଦୁ × 3 ≤ 160 · ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ ≤ 160 · ମାପ ≤ 60
ବିଭାଗ: ଶିରୋନାମା → ବିନ୍ଦୁ 1…3 → ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ → ମାପ

ଶିରୋନାମା ସର୍ବାଧିକ 80 ଅକ୍ଷର, 3 ରୁ 12 ବିନ୍ଦୁ ପ୍ରତ୍ୟେକ ସର୍ବାଧିକ 160 ଅକ୍ଷର, ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ ସର୍ବାଧିକ 160 ଅକ୍ଷର, ମାପ ସର୍ବାଧିକ 60 ଅକ୍ଷର। ପ୍ରତ୍ୟେକ ଧାଡ଼ି ଗୋଟିଏ ଧାଡ଼ିର ଲେଖା ହେବା ଆବଶ୍ୟକ। ଶିଟ୍ ଫାଇଲ୍, ରେକର୍ଡିଂ କିମ୍ବା କ୍ୟାଲେଣ୍ଡର ପଢ଼େ ନାହିଁ।

  • ଶିରୋନାମା: ≤ 80
  • ବିନ୍ଦୁ: 3 ≤ n ≤ 12, ≤ 160
  • ପରବର୍ତ୍ତୀ ପଦକ୍ଷେପ: ≤ 160
  • ମାପ: ≤ 60
