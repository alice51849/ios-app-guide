ਫ਼ਾਰਮੂਲਾ ਅਤੇ ਹੱਦਾਂ

ਲਾਭ = ਕੁੱਲ ਆਮਦਨ − ਕੁੱਲ ਖਰਚ। ਮਾਰਜਿਨ = ਲਾਭ ÷ ਕੁੱਲ ਆਮਦਨ। ਪ੍ਰਤੀ ਘੰਟਾ ਸ਼ੁੱਧ = ਲਾਭ ÷ ਲੱਗੇ ਘੰਟੇ। ਰਕਮਾਂ ਪੂਰੇ ਪੈਸਿਆਂ ਵਿੱਚ ਜੋੜੀਆਂ ਜਾਂਦੀਆਂ ਹਨ, ਇਸ ਲਈ ਜੋੜ ਨਹੀਂ ਖਿਸਕਦੇ।

ਕੁੱਲ ਆਮਦਨ = 1500.00
ਕੁੱਲ ਖਰਚ = 400.39
ਲਾਭ = 1500.00 − 400.39 = 1099.61
ਮਾਰਜਿਨ = 1099.61 ÷ 1500.00 = 73.3%
ਪ੍ਰਤੀ ਘੰਟਾ ਸ਼ੁੱਧ = 1099.61 ÷ 12.5 = 87.97

ਰਕਮ 0 ਤੋਂ 100,000,000 ਤੱਕ ਵੱਧ ਤੋਂ ਵੱਧ ਦੋ ਦਸ਼ਮਲਵ ਨਾਲ, ਵੱਧ ਤੋਂ ਵੱਧ 20 ਆਮਦਨ ਅਤੇ 20 ਖਰਚ ਕਤਾਰਾਂ, ਘੰਟੇ 0.25 ਤੋਂ 2000 ਤੱਕ ਚੌਥਾਈ ਘੰਟੇ ਦੇ ਕਦਮਾਂ ਵਿੱਚ। ਇੱਕੋ ਮੁਦਰਾ, ਕੋਈ ਵਟਾਂਦਰਾ ਨਹੀਂ, ਕੋਈ ਟੈਕਸ ਜਾਂ ਲੇਖਾ ਸਲਾਹ ਨਹੀਂ।

  • ਰਕਮ: 0 ≤ x ≤ 100,000,000
  • ਲੱਗੇ ਘੰਟੇ: 0.25 ≤ h ≤ 2000
  • ਆਮਦਨ / ਖਰਚ: 1 ≤ n ≤ 20
