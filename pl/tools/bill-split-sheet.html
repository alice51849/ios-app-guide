Wzór i ograniczenia

Suma częściowa = wszystkie zamówienia razem. Podatek = suma częściowa × stawka podatku. Napiwek = suma częściowa × stawka napiwku. Część każdej osoby to jej zamówienie ÷ suma częściowa; pozostałe grosze trafiają najpierw do największych części dziesiętnych, więc udziały zawsze sumują się dokładnie do rachunku.

Suma częściowa = 32.40 + 18.90 + 25.00 = 76.30
Podatek = 76.30 × 8.25% = 6.29
Napiwek = 76.30 × 15.00% = 11.45
Osoba 1: 32.40 + 2.67 + 4.86 = 39.93
Osoba 2: 18.90 + 1.56 + 2.84 = 23.30
Osoba 3: 25.00 + 2.06 + 3.75 = 30.81
Rachunek razem = 94.04

Używaj jednej waluty, a podatek i napiwek podawaj jako procent sumy częściowej. Bez przeliczania walut, bez zasad opłaty serwisowej, bez podpowiedzi ile dać napiwku i bez płatności. Na ekranie zaokrąglamy do dwóch miejsc; sam podział liczony jest w pełnych groszach.

  • Zamówiła za: 0 ≤ n ≤ 100,000,000
  • Podatek % / Napiwek %: 0 ≤ % ≤ 100
  • Osoba: 1 ≤ n ≤ 20
