Wzór i ograniczenia

Następny termin = ostatnio wykonane + odstęp. Dla miesięcy zachowany jest ten sam dzień; jeśli go nie ma, brany jest ostatni dzień miesiąca (także w latach przestępnych). Pozostało dni = termin − dziś. Poniżej 0 zaległe; od 0 do 7 wkrótce.

2026-06-01 + 3 miesięcy = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 tydzień = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 miesięcy = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Odstępy od 1 do 3650 dni, tygodni lub miesięcy. Daty od 1900-01-01 do 2999-12-31. Do 30 zadań. Bez przypomnień, powiadomień i synchronizacji z kalendarzem; nic nie opuszcza tej strony.

  • Odstęp: 1 ≤ x ≤ 3650
  • Ostatnio wykonane: 1900-01-01 ≤ x ≤ 2999-12-31
  • Zadanie: 1 ≤ n ≤ 30
