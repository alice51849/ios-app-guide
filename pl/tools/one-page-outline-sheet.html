Wzór i ograniczenia

Arkusz zachowuje Twoje słowa bez zmian: nagłówek, potem punkty w kolejności wpisania, potem kolejne działanie, na końcu miara. Liczy punkty i usuwa spacje na brzegach; niczego nie przepisuje, nie streszcza ani nie ocenia.

Nagłówek ≤ 80 · Punkt × 3 ≤ 160 · Kolejne działanie ≤ 160 · Miara ≤ 60
Sekcja: Nagłówek → Punkt 1…3 → Kolejne działanie → Miara

Nagłówek do 80 znaków, od 3 do 12 punktów po maksymalnie 160 znaków, kolejne działanie do 160 znaków, miara do 60 znaków. Każda linia musi być tekstem jednowierszowym. Arkusz nie czyta plików, nagrań ani kalendarzy.

  • Nagłówek: ≤ 80
  • Punkt: 3 ≤ n ≤ 12, ≤ 160
  • Kolejne działanie: ≤ 160
  • Miara: ≤ 60
