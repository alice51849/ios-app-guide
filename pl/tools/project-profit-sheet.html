Wzór i ograniczenia

Zysk = suma przychodów − suma kosztów. Marża = zysk ÷ suma przychodów. Netto za godzinę = zysk ÷ przepracowane godziny. Kwoty sumowane są w pełnych groszach, więc sumy się nie rozjeżdżają.

Suma przychodów = 1500.00
Suma kosztów = 400.39
Zysk = 1500.00 − 400.39 = 1099.61
Marża = 1099.61 ÷ 1500.00 = 73.3%
Netto za godzinę = 1099.61 ÷ 12.5 = 87.97

Kwoty od 0 do 100 000 000 z najwyżej dwoma miejscami po przecinku, do 20 wierszy przychodów i 20 kosztów, godziny od 0,25 do 2000 co kwadrans. Jedna waluta, bez przeliczania, bez porad podatkowych i księgowych.

  • Kwota: 0 ≤ x ≤ 100,000,000
  • Przepracowane godziny: 0.25 ≤ h ≤ 2000
  • Przychód / Koszt: 1 ≤ n ≤ 20
