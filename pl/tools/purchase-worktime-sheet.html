Wzór i ograniczenia

Razem = ilość × cena końcowa. Godziny = suma ÷ dochód netto za godzinę. Dni = godziny ÷ godziny w dniu pracy.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Podaj ceny z podatkiem. Bez przeliczania walut, naliczania wynagrodzeń, prognoz oszczędności i porad zakupowych. Wyświetlane są dwa miejsca po przecinku; sumy wykorzystują wartości niezaokrąglone.

  • Dochód netto za godzinę: 0 < x ≤ 100000000
  • Końcowa cena jednostkowa: 0 ≤ x ≤ 100000000
  • Godziny w dniu pracy: 0 < x ≤ 24
  • Ilość: 1 ≤ x ≤ 999
