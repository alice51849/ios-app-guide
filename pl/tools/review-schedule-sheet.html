Wzór i ograniczenia

Data powtórki = data napisania + 1, 3, 7, 16 i 35 dni. Dni do terminu = data powtórki − dzisiaj; liczba ujemna oznacza termin, który już minął. Najbliższa powtórka = pierwszy termin przypadający dzisiaj lub później.

Data powtórki = Napisana + [+1 · +3 · +7 · +16 · +35]
Notatka 1: 2026-09-01 → 2026-09-02 (-5), 2026-09-04 (-3), 2026-09-08 (+1), 2026-09-17 (+10), 2026-10-06 (+29)
Notatka 2: 2026-09-06 → 2026-09-07 (+0), 2026-09-09 (+2), 2026-09-13 (+6), 2026-09-22 (+15), 2026-10-11 (+34)
Notatka 3: 2026-08-20 → 2026-08-21 (-17), 2026-08-23 (-15), 2026-08-27 (-11), 2026-09-05 (-2), 2026-09-24 (+17)
Najbliższa powtórka = 2026-09-07
Terminy powtórek = 3 × 5 = 15

To stała drabinka odstępów, a nie model pamięci: nic tu nie przewiduje, co zapamiętasz, nie ocenia notatki ani nie sprawdza odpowiedzi. Wyłącznie daty, bez godzin, stref czasowych, przypomnień i powiadomień.

  • Dzisiaj / Napisana: YYYY-MM-DD
  • Powtórka: +1 · +3 · +7 · +16 · +35
  • Notatka: 1 ≤ n ≤ 20
