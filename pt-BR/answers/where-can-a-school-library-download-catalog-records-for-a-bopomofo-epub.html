Resposta curta

The records describe the exact open EPUB files rather than an app. Each edition includes a stable local identifier, language, title, corporate creator, publication data, format, rights, subjects, direct download URL, byte size and SHA-256. MARCXML and MODS are validated against pinned official schemas; the two BIBFRAME serializations must parse to the same RDF graph and use terms declared by the official vocabulary. Download from the bilingual guide at https://alice51849.github.io/ios-app-guide/data/zhuyin-bopomofo-library-catalog-records.html. These are candidate records, so a cataloger should still review local 040, subject, classification, access and holdings policy before import; they do not assign an ISBN, LCCN or OCLC number.

Import into a test collection first. Confirm title display, script handling, subjects, links and local control fields before exposing the record in a public catalog. A static host may return generic XML or JSON Content-Types, so download-first import is the documented fallback for strict systems.

O que observar antes de escolher

  • One deterministic ZIP contains the MARCXML, MODS 3.8, BIBFRAME JSON-LD, BIBFRAME Turtle, README and SHA-256 checksum list.
  • The MARCXML collection carries two bibliographic records with 001, 005, 007, 008, 041, 245, 264, 3XX, 5XX, 6XX and 856 data.
  • Each record links to one exact EPUB edition and carries its byte length and SHA-256 provenance.
  • The package is CC BY 4.0, requires no account and remains usable without any app.

Um processo prático de decisão

  1. Open the bilingual library catalog guide.
  2. Download the complete ZIP or the syntax your library system accepts.
  3. Verify checksums, then review local descriptive cataloging and access fields.
  4. Import into a test collection before publishing the record to the public catalog.

Perguntas frequentes

Can I import these records without reviewing them?

No. They are schema-valid candidate records, not institution-approved cataloging. Review local control fields, subjects, classification, access and holdings policy in a staging collection.

Do the records assign an ISBN, LCCN or OCLC number?

No. They use clearly labeled local identifiers and do not claim an external control number.

What if my library system rejects the file URL?

Download the MARCXML, MODS, JSON-LD or Turtle file first and import it locally. Static hosting can return generic XML or JSON Content-Types that strict URL importers reject.
