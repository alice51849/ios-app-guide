Fórmula e limites

A planilha mantém suas palavras como estão: título, depois os pontos na ordem digitada, depois a próxima ação e por fim a métrica. Ela conta os pontos e remove espaços nas pontas; nada é reescrito, resumido ou avaliado.

Título ≤ 80 · Ponto × 3 ≤ 160 · Próxima ação ≤ 160 · Métrica ≤ 60
Seção: Título → Ponto 1…3 → Próxima ação → Métrica

Título com até 80 caracteres, de 3 a 12 pontos com até 160 caracteres cada, próxima ação com até 160 caracteres, métrica com até 60 caracteres. Cada linha deve ser texto de uma linha só. A planilha não lê arquivos, gravações nem calendários.

  • Título: ≤ 80
  • Ponto: 3 ≤ n ≤ 12, ≤ 160
  • Próxima ação: ≤ 160
  • Métrica: ≤ 60
