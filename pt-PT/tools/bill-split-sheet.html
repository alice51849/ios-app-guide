Fórmula e limites

Subtotal = tudo o que foi pedido, somado. Imposto = subtotal × percentagem de imposto. Gorjeta = subtotal × percentagem de gorjeta. A parte de cada pessoa é o pedido dela ÷ subtotal; os cêntimos que sobram vão primeiro para as maiores casas decimais, por isso a soma das partes dá exactamente a conta.

Subtotal = 32.40 + 18.90 + 25.00 = 76.30
Imposto = 76.30 × 8.25% = 6.29
Gorjeta = 76.30 × 15.00% = 11.45
Pessoa 1: 32.40 + 2.67 + 4.86 = 39.93
Pessoa 2: 18.90 + 1.56 + 2.84 = 23.30
Pessoa 3: 25.00 + 2.06 + 3.75 = 30.81
Total da conta = 94.04

Use uma só moeda e indique imposto e gorjeta como percentagem do subtotal. Sem conversão cambial, sem regras de taxa de serviço, sem sugestão de quanto deixar de gorjeta e sem pagamentos. O ecrã arredonda a duas casas; o cálculo é feito em cêntimos inteiros.

  • Quanto pediu: 0 ≤ n ≤ 100,000,000
  • Imposto % / Gorjeta %: 0 ≤ % ≤ 100
  • Pessoa: 1 ≤ n ≤ 20
