Reunião numa página

Transforme notas de reunião desorganizadas num resumo de uma página: um título, três a doze pontos-chave, uma próxima ação e uma métrica opcional, e descarregue como tabela para colar num diapositivo ou num resumo.

Pontos-chave

Entre 3 e 12 pontos.

Opcional: um número que comprove o ponto, por exemplo uma taxa ou uma contagem.

Fórmula e limites

A tabela mantém as suas palavras tal como estão: título, depois os pontos pela ordem em que os escreveu, depois a próxima ação e por fim a métrica. Conta os pontos e remove espaços nas extremidades; nada é reescrito, resumido ou classificado.

Título ≤ 80 · Ponto × 3 ≤ 160 · Próxima ação ≤ 160 · Métrica ≤ 60
Secção: Título → Ponto 1…3 → Próxima ação → Métrica

Título até 80 caracteres, 3 a 12 pontos até 160 caracteres cada, próxima ação até 160 caracteres, métrica até 60 caracteres. Cada linha tem de ser texto de uma só linha. A tabela não lê ficheiros, gravações nem calendários.

  • Título: ≤ 80
  • Ponto: 3 ≤ n ≤ 12, ≤ 160
  • Próxima ação: ≤ 160
  • Métrica: ≤ 60
