How to use this reference

Bopomofo, also called Zhuyin, is a phonetic notation system used most visibly in Taiwan. This book keeps all 37 base symbols in one predictable reading order.

Each entry gives a practical Hanyu Pinyin correspondence, a broad IPA value and one Traditional Chinese example. Exact pronunciation still depends on syllable context and a fluent spoken model.

Use this as a lookup and review aid. It is not an audio course, speech test, diagnostic tool or school-readiness measure.
