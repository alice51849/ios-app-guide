Ce este QR Code Halo: Scaner coduri?

QR Code Halo: Scaner coduri este o aplicație pentru iOS. Verifică înainte de acțiune

QR Code Halo păstrează ordinea sub controlul tău: inspectezi conținutul decodat, evaluezi constatările afișate și abia apoi alegi o acțiune. Recunoașterea unui cod nu deschide nimic automat.

Local Payload Security Inspector

Analizează pe dispozitiv întregul payload și afișează separat scheme, host, path, query și fragment. Reguli deterministe oferă Safe, Caution sau Blocked, findings transparente și action disposition. Nu folosește reputație online sau scoruri neclare; o acțiune care nu poate fi interpretată rămâne blocată.

QR Verification

Salvați un rezultat ca referință locală, apoi comparați o scanare ulterioară după amprenta SHA-256 completă, formatul QR, tipul de conținut, componentele URL, nivelul de securitate și acțiunea.

Batch Risk & Difference Audit

Grupează rezultatele identice și rezultatele cu același host, apoi compară într-un interval clar limitat host care pot fi confundate. Rezumatul, riscul fiecărui element și toate payloadurile complete rămân lizibile. Întregul audit poate fi consultat.

Ce face QR Code Halo

Scanare cu camera sau recunoașterea codurilor din fotografii, mai multe coduri într-un cadru

Previzualizare sigură pentru fiecare rezultat: conținut complet, schema și gazda linkului, plus avertismente pentru formate suspecte

20 de formate de coduri de bare: QR, Micro QR, Aztec, Data Matrix, PDF417, Micro PDF417, EAN-8, EAN-13, UPC-A, UPC-E, Code 39, Code 93, Code 128, Interleaved 2 of 5, ITF-14, Codabar, GS1 DataBar și MSI Plessey

Scanare în loturi cu eliminarea duplicatelor, zoom și lanternă

Creare de coduri QR: text, link, Wi-Fi, contact, e-mail, telefon, SMS, locație și eveniment de calendar

Istoric nelimitat, fără limită de intrări: favorite, căutare, filtre și sortare după tip, dată, format, etichetă sau categorie

Clasificare automată pe dispozitiv, cu modificare manuală, și export al istoricului în CSV

Copia de rezervă și restaurarea arată numărul real de intrări, dimensiunea și perioada înainte să decizi

Lifetime Pro: Scanări nelimitate, salvarea unui lot scanat în istoric și deschiderea rezultatelor lui, creare în loturi și CSV de lot, rularea unei copii de rezervă sau a unei restaurări, export PNG, PDF și SVG la rezoluție înaltă și stiluri Aurora personalizate

Mod de confidențialitate cu ștergere automată, salvare în Poze, tipărire, extensie de partajare și scurtături Siri
