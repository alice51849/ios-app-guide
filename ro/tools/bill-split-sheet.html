Formulă și limite

Subtotal = tot ce s-a comandat, adunat. Taxă = subtotal × procentul de taxă. Bacșiș = subtotal × procentul de bacșiș. Partea fiecăruia este comanda proprie ÷ subtotal; bănuții rămași merg întâi la cele mai mari zecimale, astfel încât suma părților să dea exact nota.

Subtotal = 32.40 + 18.90 + 25.00 = 76.30
Taxă = 76.30 × 8.25% = 6.29
Bacșiș = 76.30 × 15.00% = 11.45
Persoană 1: 32.40 + 2.67 + 4.86 = 39.93
Persoană 2: 18.90 + 1.56 + 2.84 = 23.30
Persoană 3: 25.00 + 2.06 + 3.75 = 30.81
Nota totală = 94.04

Folosește o singură monedă și introdu taxa și bacșișul ca procent din subtotal. Fără conversie valutară, fără reguli de taxă de serviciu, fără recomandări despre cât bacșiș să lași și fără plăți. Pe ecran se rotunjește la două zecimale; împărțirea se calculează în bănuți întregi.

  • A comandat de: 0 ≤ n ≤ 100,000,000
  • Taxă % / Bacșiș %: 0 ≤ % ≤ 100
  • Persoană: 1 ≤ n ≤ 20
