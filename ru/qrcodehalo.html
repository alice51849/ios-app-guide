Что такое QR Code Halo: сканер кодов?

QR Code Halo: сканер кодов — приложение для iOS. Проверь перед действием

QR Code Halo сохраняет осознанный порядок: сначала изучите расшифрованное содержимое, затем оцените показанные факты и только после этого выберите действие. Само распознавание кода ничего не открывает.

Local Payload Security Inspector

Разбирает весь payload на устройстве и отдельно показывает scheme, host, path, query и fragment. Детерминированные правила выдают Safe, Caution или Blocked, прозрачные findings и action disposition. Сетевая репутация и расплывчатая оценка не используются; действие, которое нельзя надёжно разобрать, остаётся заблокированным.

QR Verification

Сохраните результат как локальный образец, а затем сравните последующее сканирование по полному отпечатку SHA-256, формату QR, типу содержимого, компонентам URL, уровню безопасности и действию.

Batch Risk & Difference Audit

Объединяет полностью совпадающие результаты и результаты с одним host, затем в строго ограниченных пределах сравнивает host, которые легко перепутать. Сводка, риск каждой записи и все полные payload остаются читаемыми. Весь аудит доступен для просмотра.
