Формула и ограничения

Прибытие = предыдущий отъезд + дорога. Отъезд = прибытие + пребывание. Итого = все пребывания + вся дорога. Доступно = конец − начало; конец раньше начала считается следующим днём. Перебор = итого − доступно; больше нуля — не укладывается. Простая арифметика минут, без часовых поясов.

1. Место 1: 09:00 + 120 = 11:00 + 25 →
2. Место 2: 11:25 + 60 = 12:25 + 40 →
3. Место 3: 13:05 + 180 = 16:05 + 30 →
Итого (мин) = 455; Доступно (мин) = 09:00–18:00 = 540
Перебор (мин) = 455 − 540 = -85 → Укладывается

Время в 24-часовом формате ЧЧ:ММ, пребывание от 5 до 720 минут, дорога от 0 до 600 минут, до 25 мест. Часы работы, реальные пробки, карты, маршруты и бронирование в таблицу не входят.

  • Начало / Конец: HH:MM
  • Пребывание (мин): 5 ≤ m ≤ 720
  • Дорога до следующего (мин): 0 ≤ m ≤ 600
  • Место: 1 ≤ n ≤ 25
