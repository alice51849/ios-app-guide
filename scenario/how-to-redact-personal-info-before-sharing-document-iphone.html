How to Redact Personal Information Before Sharing a Document on iPhone

Sending a contract, application or invoice that contains personal data? Redacting it before sharing prevents identity theft and is required under GDPR and similar regulations in many countries.

Step by step

  1. Open the document in Mask My File

    Import a PDF, Word file or image containing personal information. Mask My File scans the content automatically.

  2. Review the detected items

    The app highlights phone numbers, email addresses, national ID numbers and postal addresses. Review the list before masking.

  3. Apply redaction

    Tap to confirm the items to redact. Mask My File replaces them with black bars or removes them from the exported file.

  4. Share the redacted version

    Export the cleaned file and share it. The original is unchanged on your device.

Frequently asked questions

Does Mask My File upload my documents to a server?

No. All processing is on-device. Your documents are never sent to any external server.

Can it handle handwritten text?

Mask My File focuses on printed and typed text recognised via OCR. Handwriting recognition depends on legibility and is less reliable than printed text.

What file formats does it support?

PDF and common image formats. Check the current App Store listing for the exact supported file types.
