Vzorec a obmedzenia

Medzisúčet = všetky objednávky spolu. Daň = medzisúčet × sadzba dane. Prepitné = medzisúčet × sadzba prepitného. Podiel každého je jeho objednávka ÷ medzisúčet; zvyšné centy pripadnú najskôr najväčším desatinným zvyškom, takže podiely vždy dajú presne sumu účtu.

Medzisúčet = 32.40 + 18.90 + 25.00 = 76.30
Daň = 76.30 × 8.25% = 6.29
Prepitné = 76.30 × 15.00% = 11.45
Osoba 1: 32.40 + 2.67 + 4.86 = 39.93
Osoba 2: 18.90 + 1.56 + 2.84 = 23.30
Osoba 3: 25.00 + 2.06 + 3.75 = 30.81
Účet spolu = 94.04

Používaj jednu menu a daň aj prepitné zadávaj ako percento z medzisúčtu. Žiadny prepočet mien, žiadne pravidlá pre servisný poplatok, žiadne odporúčanie, koľko dať, a žiadne platenie. Na obrazovke sa zaokrúhľuje na dve desatinné miesta; samotné delenie počíta v celých centoch.

  • Objednal(a) si za: 0 ≤ n ≤ 100,000,000
  • Daň % / Prepitné %: 0 ≤ % ≤ 100
  • Osoba: 1 ≤ n ≤ 20
