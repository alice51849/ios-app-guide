Vzorec a obmedzenia

Ďalší termín = naposledy + interval. Pri mesiacoch zostáva rovnaký deň; ak neexistuje, použije sa posledný deň mesiaca (vrátane priestupných rokov). Zostáva dní = termín − dnes. Pod 0 po termíne; 0 až 7 čoskoro.

2026-06-01 + 3 mesiacov = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 týždeň = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 mesiacov = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Intervaly 1 až 3650 dní, týždňov alebo mesiacov. Dátumy medzi 1900-01-01 a 2999-12-31. Najviac 30 úloh. Žiadne pripomienky, upozornenia ani synchronizácia s kalendárom; nič neopúšťa túto stránku.

  • Interval: 1 ≤ x ≤ 3650
  • Naposledy: 1900-01-01 ≤ x ≤ 2999-12-31
  • Úloha: 1 ≤ n ≤ 30
