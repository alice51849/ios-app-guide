Vzorec a obmedzenia

Zisk = príjmy spolu − výdavky spolu. Marža = zisk ÷ príjmy spolu. Čistý zárobok na hodinu = zisk ÷ odpracované hodiny. Sumy sa sčítavajú v celých centoch, takže súčty neujdú.

Príjmy spolu = 1500.00
Výdavky spolu = 400.39
Zisk = 1500.00 − 400.39 = 1099.61
Marža = 1099.61 ÷ 1500.00 = 73.3%
Čistý zárobok na hodinu = 1099.61 ÷ 12.5 = 87.97

Sumy od 0 do 100 000 000 s najviac dvoma desatinnými miestami, až 20 riadkov príjmov a 20 výdavkov, hodiny od 0,25 do 2000 po štvrťhodinách. Jedna mena, bez prepočtu, bez daňového či účtovného poradenstva.

  • Suma: 0 ≤ x ≤ 100,000,000
  • Odpracované hodiny: 0.25 ≤ h ≤ 2000
  • Príjem / Výdavok: 1 ≤ n ≤ 20
