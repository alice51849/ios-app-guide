Formula in omejitve

Vmesni seštevek = vsa naročila skupaj. Davek = vmesni seštevek × stopnja davka. Napitnina = vmesni seštevek × stopnja napitnine. Delež posameznika je njegovo naročilo ÷ vmesni seštevek; preostali centi gredo najprej k največjim decimalnim ostankom, zato se deleži vedno seštejejo natanko v znesek računa.

Vmesni seštevek = 32.40 + 18.90 + 25.00 = 76.30
Davek = 76.30 × 8.25% = 6.29
Napitnina = 76.30 × 15.00% = 11.45
Oseba 1: 32.40 + 2.67 + 4.86 = 39.93
Oseba 2: 18.90 + 1.56 + 2.84 = 23.30
Oseba 3: 25.00 + 2.06 + 3.75 = 30.81
Račun skupaj = 94.04

Uporabljaj eno valuto, davek in napitnino pa vnesi kot odstotek vmesnega seštevka. Brez menjave valut, brez pravil o strežbi, brez nasvetov, koliko napitnine dati, in brez plačevanja. Na zaslonu zaokrožujemo na dve decimalki; sama delitev računa v celih centih.

  • Naročila za: 0 ≤ n ≤ 100,000,000
  • Davek % / Napitnina %: 0 ≤ % ≤ 100
  • Oseba: 1 ≤ n ≤ 20
