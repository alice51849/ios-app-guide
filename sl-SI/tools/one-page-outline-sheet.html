Formula in omejitve

Tabela ohrani tvoje besede takšne, kot so: naslov, nato točke v vrstnem redu, kot si jih vnesel, nato naslednji korak in nazadnje kazalnik. Prešteje točke in odstrani presledke na robovih; nič se ne prepisuje, povzema ali ocenjuje.

Naslov ≤ 80 · Točka × 3 ≤ 160 · Naslednji korak ≤ 160 · Kazalnik ≤ 60
Razdelek: Naslov → Točka 1…3 → Naslednji korak → Kazalnik

Naslov do 80 znakov, 3 do 12 točk po največ 160 znakov, naslednji korak do 160 znakov, kazalnik do 60 znakov. Vsaka vrstica mora biti enovrstično besedilo. Tabela ne bere datotek, posnetkov ali koledarjev.

  • Naslov: ≤ 80
  • Točka: 3 ≤ n ≤ 12, ≤ 160
  • Naslednji korak: ≤ 160
  • Kazalnik: ≤ 60
