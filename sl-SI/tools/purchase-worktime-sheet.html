Formula in omejitve

Skupaj = količina × končna cena. Ure = skupni znesek ÷ neto urni dohodek. Dnevi = ure ÷ ure na delovni dan.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Vnesite cene z davkom. Brez pretvorbe valut, obračuna plač, napovedi prihrankov ali nakupnih nasvetov. Prikaz je zaokrožen na dve decimalki; vsote uporabljajo nezaokrožene vrednosti.

  • Neto dohodek na uro: 0 < x ≤ 100000000
  • Končna cena na enoto: 0 ≤ x ≤ 100000000
  • Ure na delovni dan: 0 < x ≤ 24
  • Količina: 1 ≤ x ≤ 999
