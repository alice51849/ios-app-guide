Formel och begränsningar

Slitage per månad = (100 − kapacitet) ÷ ålder i månader, visat med ±25 %. Månader till 80 % = (kapacitet − 80) ÷ slitage; undre gräns med den höga takten, övre gräns med den låga. Cykler per månad = cykler ÷ ålder.

Enhet 1: (100 − 88) ÷ 24 = 0.50 %/Ålder (månader) → ±25% → 0.38–0.63; (88 − 80) ÷ Slitage % per månad → 12–22
Enhet 2: (100 − 100) ÷ 1 = 0.00 %/Ålder (månader) → ±25% → 0.00–0.00; (100 − 80) ÷ Slitage % per månad → Inget mätbart slitage ännu
Enhet 3: (100 − 79) ÷ 66 = 0.32 %/Ålder (månader) → ±25% → 0.24–0.40; (79 − 80) ÷ Slitage % per månad → Redan på eller under 80 %

Kapacitet 60–100 som helt procenttal, cykler 0–3000, köpmånad mellan 2007 och 2099 med 1–240 månaders ålder, upp till 10 enheter. Månader som ÅÅÅÅ-MM. Uppgifterna stannar i den här fliken; ingenting mäts eller läses från din telefon.

  • Maximal kapacitet %: 60 ≤ x ≤ 100
  • Laddcykler: 0 ≤ x ≤ 3000
  • Ålder (månader): 1 ≤ m ≤ 240
  • Enhet: 1 ≤ n ≤ 10
