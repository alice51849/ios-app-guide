Formel och begränsningar

Delsumma = allt beställt hopräknat. Moms = delsumma × momssats. Dricks = delsumma × dricksprocent. Varje persons andel är den egna beställningen ÷ delsumman; ören som blir över går först till de största decimalerna, så att andelarna tillsammans blir exakt notan.

Delsumma = 32.40 + 18.90 + 25.00 = 76.30
Moms = 76.30 × 8.25% = 6.29
Dricks = 76.30 × 15.00% = 11.45
Person 1: 32.40 + 2.67 + 4.86 = 39.93
Person 2: 18.90 + 1.56 + 2.84 = 23.30
Person 3: 25.00 + 2.06 + 3.75 = 30.81
Hela notan = 94.04

Använd en enda valuta och ange moms och dricks som procent av delsumman. Ingen valutaväxling, inga regler för serveringsavgift, inga råd om hur mycket dricks du bör lämna och inga betalningar. På skärmen avrundas till två decimaler; själva fördelningen räknas i hela ören.

  • Beställde för: 0 ≤ n ≤ 100,000,000
  • Moms % / Dricks %: 0 ≤ % ≤ 100
  • Person: 1 ≤ n ≤ 20
