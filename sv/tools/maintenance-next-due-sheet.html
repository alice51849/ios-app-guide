Formel och begränsningar

Nästa förfallodatum = senast gjord + intervall. Vid månader behålls samma dag; finns den inte används månadens sista dag (även skottår). Dagar kvar = förfallodatum − i dag. Försenad under 0; snart från 0 till 7.

2026-06-01 + 3 månader = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 vecka = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 månader = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Intervall från 1 till 3650 dagar, veckor eller månader. Datum mellan 1900-01-01 och 2999-12-31. Upp till 30 uppgifter. Inga påminnelser, notiser eller kalendersynkning; ingenting lämnar den här sidan.

  • Intervall: 1 ≤ x ≤ 3650
  • Senast gjord: 1900-01-01 ≤ x ≤ 2999-12-31
  • Uppgift: 1 ≤ n ≤ 30
