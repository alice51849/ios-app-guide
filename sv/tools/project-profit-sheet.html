Formel och begränsningar

Vinst = summa intäkter − summa kostnader. Marginal = vinst ÷ summa intäkter. Netto per timme = vinst ÷ arbetade timmar. Beloppen summeras i hela ören, så totalerna driver inte.

Summa intäkter = 1500.00
Summa kostnader = 400.39
Vinst = 1500.00 − 400.39 = 1099.61
Marginal = 1099.61 ÷ 1500.00 = 73.3%
Netto per timme = 1099.61 ÷ 12.5 = 87.97

Belopp från 0 till 100 000 000 med högst två decimaler, upp till 20 intäkts- och 20 kostnadsrader, timmar från 0,25 till 2000 i kvartssteg. Samma valuta, ingen växling, ingen skatte- eller bokföringsrådgivning.

  • Belopp: 0 ≤ x ≤ 100,000,000
  • Arbetade timmar: 0.25 ≤ h ≤ 2000
  • Intäkt / Kostnad: 1 ≤ n ≤ 20
