Formel och begränsningar

Totalt = antal × styckpris. Arbetstimmar = totalbelopp ÷ nettoinkomst per timme. Arbetsdagar = arbetstimmar ÷ timmar per arbetsdag.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Ange priser inklusive skatt. Ingen valutaväxling, löneberäkning, sparprognos eller köprådgivning. Visningen avrundas till två decimaler; totaler använder oavrundade värden.

  • Nettoinkomst per timme: 0 < x ≤ 100000000
  • Slutligt styckpris: 0 ≤ x ≤ 100000000
  • Timmar per arbetsdag: 0 < x ≤ 24
  • Antal: 1 ≤ x ≤ 999
