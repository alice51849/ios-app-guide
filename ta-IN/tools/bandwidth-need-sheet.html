திட்ட வேகம் 0.5 முதல் 10000 Mbps வரை, அதிகபட்சம் ஒரு தசமம்; ஒரு வரிசைக்கு 1 முதல் 50 சாதனங்கள்; அதிகபட்சம் 20 வரிசைகள். Wi‑Fi கவரேஜ், தாமதம், வழங்குநரின் உண்மையான வேகம் இந்தத் தாளின் எல்லைக்கு வெளியே.

  • திட்ட பதிவிறக்கம் (Mbps) / திட்ட பதிவேற்றம் (Mbps): 0.5 ≤ x ≤ 10000 Mbps
  • சாதனங்கள்: 1 ≤ n ≤ 50
  • வாங்குதல்: 1 ≤ n ≤ 20
