உள்ளீடுகள் இந்தத் தாவலில் மட்டுமே இருக்கும். பதிவேற்றம், கணக்கு, உள்ளீட்டுக் கண்காணிப்பு அல்லது சேமிப்பு இல்லை. மீண்டும் ஏற்றினால் மாற்றங்கள் அழியும்.

முழு எடுத்துக்காட்டு

செக்அவுட் மறுவடிவமைப்புக் குறிப்புகள் இவ்வாறு மாறும்: தலைப்பு «செப்டம்பர் 30க்குள் புதிய செக்அவுட்டை வெளியிடு», மூன்று புள்ளிகள் (முகவரிப் படியில் வெளியேறல் நிகழ்கிறது, பைலட் கைவிடல் விகிதத்தைக் குறைத்தது, பொறியியலுக்கு இன்னும் இரண்டு வாரங்கள் தேவை), அடுத்த நடவடிக்கை «திங்களன்று கூடுதல் ஸ்பிரிண்டை ஒப்புதல் செய்», அளவீடு «பைலட்டில் 48% கைவிடல்».

சூத்திரமும் வரம்புகளும்

தாள் உங்கள் சொற்களை அப்படியே வைத்திருக்கும்: தலைப்பு, பின்னர் நீங்கள் தட்டச்சு செய்த வரிசையில் புள்ளிகள், பின்னர் அடுத்த நடவடிக்கை, பின்னர் அளவீடு. புள்ளிகளை எண்ணி ஓரங்களின் வெற்றிடங்களை நீக்குகிறது; எதுவும் மீண்டும் எழுதப்படவோ சுருக்கப்படவோ மதிப்பிடப்படவோ இல்லை.

தலைப்பு ≤ 80 · புள்ளி × 3 ≤ 160 · அடுத்த நடவடிக்கை ≤ 160 · அளவீடு ≤ 60
பிரிவு: தலைப்பு → புள்ளி 1…3 → அடுத்த நடவடிக்கை → அளவீடு

தலைப்பு அதிகபட்சம் 80 எழுத்துகள்; 3 முதல் 12 புள்ளிகள், ஒவ்வொன்றும் அதிகபட்சம் 160 எழுத்துகள்; அடுத்த நடவடிக்கை அதிகபட்சம் 160 எழுத்துகள்; அளவீடு அதிகபட்சம் 60 எழுத்துகள். ஒவ்வொரு வரியும் ஒற்றை வரி உரையாக இருக்க வேண்டும். தாள் கோப்புகள், பதிவுகள் அல்லது நாட்காட்டிகளைப் படிக்காது.

  • தலைப்பு: ≤ 80
  • புள்ளி: 3 ≤ n ≤ 12, ≤ 160
  • அடுத்த நடவடிக்கை: ≤ 160
  • அளவீடு: ≤ 60
