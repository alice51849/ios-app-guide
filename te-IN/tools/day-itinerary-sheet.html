సూత్రం మరియు పరిమితులు

చేరిక = మునుపటి బయలుదేరడం + ప్రయాణం. బయలుదేరడం = చేరిక + ఉండే సమయం. మొత్తం = అన్ని ఉండే సమయాలు + అన్ని ప్రయాణాలు. అందుబాటు = ముగింపు − ప్రారంభం; ప్రారంభం కంటే ముందు ముగింపు మరుసటి రోజుగా లెక్క. మించినది = మొత్తం − అందుబాటు; సున్నా కంటే ఎక్కువైతే సమయం మించింది. కేవలం నిమిషాల కూడిక, టైమ్ జోన్లు లేవు.

1. ప్రదేశం 1: 09:00 + 120 = 11:00 + 25 →
2. ప్రదేశం 2: 11:25 + 60 = 12:25 + 40 →
3. ప్రదేశం 3: 13:05 + 180 = 16:05 + 30 →
మొత్తం (నిమి) = 455; అందుబాటు (నిమి) = 09:00–18:00 = 540
మించినది (నిమి) = 455 − 540 = -85 → సరిపోతుంది

సమయాలు 24 గంటల HH:MM రూపంలో; ఉండే సమయం 5 నుండి 720 నిమిషాలు; ప్రయాణం 0 నుండి 600 నిమిషాలు; గరిష్ఠంగా 25 ప్రదేశాలు. తెరిచే వేళలు, నిజమైన ట్రాఫిక్, మ్యాప్‌లు, రూట్లు, బుకింగ్‌లు ఈ షీట్ పరిధిలో లేవు.

  • ప్రారంభ సమయం / ముగింపు సమయం: HH:MM
  • ఉండే సమయం (నిమి): 5 ≤ m ≤ 720
  • తర్వాతి చోటుకు ప్రయాణం (నిమి): 0 ≤ m ≤ 600
  • ప్రదేశం: 1 ≤ n ≤ 25
