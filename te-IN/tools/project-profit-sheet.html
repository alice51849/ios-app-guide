సూత్రం మరియు పరిమితులు

లాభం = మొత్తం ఆదాయం − మొత్తం వ్యయం. మార్జిన్ = లాభం ÷ మొత్తం ఆదాయం. గంటకు నికరం = లాభం ÷ వెచ్చించిన గంటలు. మొత్తాలను పూర్తి పైసలలో కూడతాం, అందుకే మొత్తాలు జారవు.

మొత్తం ఆదాయం = 1500.00
మొత్తం వ్యయం = 400.39
లాభం = 1500.00 − 400.39 = 1099.61
మార్జిన్ = 1099.61 ÷ 1500.00 = 73.3%
గంటకు నికరం = 1099.61 ÷ 12.5 = 87.97

మొత్తం 0 నుంచి 100,000,000 వరకు, గరిష్ఠంగా రెండు దశాంశాలు; గరిష్ఠంగా 20 ఆదాయ, 20 వ్యయ వరుసలు; గంటలు 0.25 నుంచి 2000 వరకు, పావు గంట మెట్లలో. ఒకే కరెన్సీ, మార్పిడి లేదు, పన్ను లేదా అకౌంటింగ్ సలహా లేదు.

  • మొత్తం: 0 ≤ x ≤ 100,000,000
  • వెచ్చించిన గంటలు: 0.25 ≤ h ≤ 2000
  • ఆదాయం / వ్యయం: 1 ≤ n ≤ 20
