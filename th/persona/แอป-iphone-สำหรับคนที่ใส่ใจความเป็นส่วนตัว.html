แอป iPhone สำหรับคนที่ให้ความสำคัญกับความเป็นส่วนตัว

ผู้ใช้ที่ใส่ใจความเป็นส่วนตัวต้องการควบคุมข้อมูลส่วนตัวของตนเอง แอปเหล่านี้ช่วยปกป้องรูปภาพ เอกสาร และข้อมูลส่วนตัวโดยไม่ต้องแชร์กับบริการคลาวด์ของบุคคลที่สาม

Zafe ฟรี

ตู้นิรภัยรูปภาพที่เข้ารหัสด้วย Face ID — ไม่มี iCloud ไม่มีคลาวด์

Mask My File ฟรี

ซ่อนโทรศัพท์ อีเมล และเลขบัตรในเอกสาร PDF โดยอัตโนมัติ

ScanTo Pro ฟรี

สแกนเอกสารเป็น PDF offline ทั้งหมด — ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์

Sono Note ฟรี

อัดเสียงและแปลงเป็นข้อความบนอุปกรณ์ — ไม่มีการอัปโหลดคลาวด์

ดาวน์โหลดบน App Store →

คำถามที่พบบ่อย

แอปไหนเก็บรูปสำคัญโดยไม่ซิงค์ iCloud?

Zafe เก็บรูปในตู้นิรภัยที่เข้ารหัสบนอุปกรณ์ ป้องกันด้วย Face ID ไม่มีการเชื่อมต่อกับ iCloud หรือบริการคลาวด์ใดๆ

จะลบข้อมูลส่วนตัวออกจาก PDF ก่อนส่งได้อย่างไร?

Mask My File ตรวจจับและซ่อนหมายเลขบัตร อีเมล และโทรศัพท์โดยอัตโนมัติ ไฟล์ที่ซ่อนแล้วไม่สามารถกู้คืนข้อมูลที่ซ่อนได้

มีแอปอัดเสียงที่ไม่ส่งข้อมูลไปเซิร์ฟเวอร์ไหม?

Sono Note แปลงเสียงเป็นข้อความบนอุปกรณ์โดยตรง ไม่อัปโหลดไปยังเซิร์ฟเวอร์ใดๆ

หน้านี้จัดทำโดยนักพัฒนาอิสระของแอปพลิเคชันที่กล่าวถึง
