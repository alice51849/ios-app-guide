สูตรและข้อจำกัด

รวมต่อแถว = จำนวนเครื่อง × ค่าต่อเครื่อง ที่ต้องใช้ = ผลรวมทุกแถว ส่วนเผื่อ = แพ็กเกจ − ที่ต้องใช้ ต่ำกว่า 20% ของแพ็กเกจถือว่าตึงมือ ต่ำกว่าศูนย์ถือว่าไม่พอ บวกกันเป็นหน่วย 0.1 Mbps แบบจำนวนเต็ม ผลรวมจึงไม่คลาดเคลื่อน

รายการซื้อ 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
รายการซื้อ 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
รายการซื้อ 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
ดาวน์โหลดที่ต้องใช้ = 25.0; อัปโหลดที่ต้องใช้ = 8.5
ส่วนเผื่อ ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
สถานะ = เพียงพอ

ตัวเลขต่อเครื่องเป็นค่าโดยประมาณสำหรับวางแผน อ้างอิงคำแนะนำของผู้ให้บริการเอง (Netflix, Zoom, ผู้ผลิตเครื่องเกม, FCC) ตารางนี้ใช้วางแผน ไม่ได้วัดสายของคุณ

  • สตรีมมิง (SD): 3.0 ↓ / 0.5 ↑ Mbps
  • สตรีมมิง (HD): 5.0 ↓ / 0.5 ↑ Mbps
  • สตรีมมิง (4K): 15.0 ↓ / 0.5 ↑ Mbps
  • วิดีโอคอล: 3.0 ↓ / 3.0 ↑ Mbps
  • เกมออนไลน์: 3.0 ↓ / 1.0 ↑ Mbps
  • สำรองข้อมูลบนคลาวด์: 1.0 ↓ / 5.0 ↑ Mbps
  • ท่องเว็บและส่งข้อความ: 1.0 ↓ / 0.5 ↑ Mbps
  • อุปกรณ์สมาร์ตโฮม: 0.5 ↓ / 0.5 ↑ Mbps

ความเร็วแพ็กเกจ 0.5 ถึง 10000 Mbps ทศนิยมไม่เกินหนึ่งตำแหน่ง แถวละ 1 ถึง 50 เครื่อง สูงสุด 20 แถว ระยะสัญญาณ Wi‑Fi ความหน่วง และความเร็วจริงจากผู้ให้บริการอยู่นอกขอบเขตของตารางนี้

  • ดาวน์โหลดตามแพ็กเกจ (Mbps) / อัปโหลดตามแพ็กเกจ (Mbps): 0.5 ≤ x ≤ 10000 Mbps
  • จำนวนเครื่อง: 1 ≤ n ≤ 50
  • รายการซื้อ: 1 ≤ n ≤ 20
