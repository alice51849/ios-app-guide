สูตรและข้อจำกัด

การเสื่อมต่อเดือน = (100 − ความจุ) ÷ อายุเป็นเดือน แสดงพร้อมแถบ ±25% เดือนถึง 80% = (ความจุ − 80) ÷ การเสื่อม ขอบล่างจากอัตราสูง ขอบบนจากอัตราต่ำ รอบชาร์จต่อเดือน = รอบชาร์จ ÷ อายุ

อุปกรณ์ 1: (100 − 88) ÷ 24 = 0.50 %/อายุ (เดือน) → ±25% → 0.38–0.63; (88 − 80) ÷ การเสื่อม % ต่อเดือน → 12–22
อุปกรณ์ 2: (100 − 100) ÷ 1 = 0.00 %/อายุ (เดือน) → ±25% → 0.00–0.00; (100 − 80) ÷ การเสื่อม % ต่อเดือน → ยังไม่มีการเสื่อมที่วัดได้
อุปกรณ์ 3: (100 − 79) ÷ 66 = 0.32 %/อายุ (เดือน) → ±25% → 0.24–0.40; (79 − 80) ÷ การเสื่อม % ต่อเดือน → ถึง 80% หรือต่ำกว่าแล้ว

ความจุ 60 ถึง 100 เป็นเปอร์เซ็นต์จำนวนเต็ม รอบชาร์จ 0 ถึง 3000 เดือนที่ซื้อระหว่างปี 2007 ถึง 2099 และอายุ 1 ถึง 240 เดือน สูงสุด 10 อุปกรณ์ เดือนใช้รูปแบบ YYYY-MM ข้อมูลอยู่ในแท็บนี้เท่านั้น ไม่มีการวัดหรืออ่านค่าจากโทรศัพท์ของคุณ

  • ความจุสูงสุด %: 60 ≤ x ≤ 100
  • จำนวนรอบชาร์จ: 0 ≤ x ≤ 3000
  • อายุ (เดือน): 1 ≤ m ≤ 240
  • อุปกรณ์: 1 ≤ n ≤ 10
