สูตรและข้อจำกัด

ยอดรวมย่อย = ยอดที่ทุกคนสั่งรวมกัน ภาษี = ยอดรวมย่อย × อัตราภาษี ทิป = ยอดรวมย่อย × อัตราทิป ส่วนแบ่งของแต่ละคนคือยอดที่ตัวเองสั่ง ÷ ยอดรวมย่อย เศษสตางค์ที่เหลือจะให้คนที่มีทศนิยมมากที่สุดก่อน ผลรวมของทุกคนจึงตรงกับยอดบิลเสมอ

ยอดรวมย่อย = 32.40 + 18.90 + 25.00 = 76.30
ภาษี = 76.30 × 8.25% = 6.29
ทิป = 76.30 × 15.00% = 11.45
คน 1: 32.40 + 2.67 + 4.86 = 39.93
คน 2: 18.90 + 1.56 + 2.84 = 23.30
คน 3: 25.00 + 2.06 + 3.75 = 30.81
ยอดบิลทั้งหมด = 94.04

ใช้สกุลเงินเดียว และกรอกภาษีกับทิปเป็นเปอร์เซ็นต์ของยอดรวมย่อย ไม่มีการแปลงสกุลเงิน ไม่มีกฎค่าบริการ ไม่แนะนำว่าควรให้ทิปเท่าไร และไม่มีการชำระเงิน หน้าจอปัดเศษสองตำแหน่ง ส่วนการหารคำนวณเป็นหน่วยสตางค์เต็ม

  • ยอดที่สั่ง: 0 ≤ n ≤ 100,000,000
  • ภาษี % / ทิป %: 0 ≤ % ≤ 100
  • คน: 1 ≤ n ≤ 20
