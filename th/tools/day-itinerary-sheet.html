ตัวอย่างการคำนวณ

วันหนึ่งตั้งแต่ 09:00 ถึง 18:00 มีพิพิธภัณฑ์ (120 นาที เดินทาง 25 นาที) มื้อเที่ยง (60 นาที 40 นาที) และเมืองเก่า (180 นาที 30 นาที): ใช้ไป 455 จาก 540 นาทีที่มี จึงพอดีและเหลืออีก 85 นาที

สูตรและข้อจำกัด

ถึง = ออกจากที่ก่อนหน้า + เดินทาง ออก = ถึง + อยู่ รวม = เวลาอยู่ทั้งหมด + เวลาเดินทางทั้งหมด มีให้ใช้ = เลิก − เริ่ม หากเวลาเลิกมาก่อนเวลาเริ่ม ถือเป็นวันถัดไป เกิน = รวม − มีให้ใช้ มากกว่าศูนย์คือเกินเวลา บวกลบนาทีล้วน ๆ ไม่มีเขตเวลา

1. สถานที่ 1: 09:00 + 120 = 11:00 + 25 →
2. สถานที่ 2: 11:25 + 60 = 12:25 + 40 →
3. สถานที่ 3: 13:05 + 180 = 16:05 + 30 →
รวม (นาที) = 455; มีให้ใช้ (นาที) = 09:00–18:00 = 540
เกิน (นาที) = 455 − 540 = -85 → พอดี

เวลาแบบ 24 ชั่วโมง HH:MM อยู่ 5 ถึง 720 นาที เดินทาง 0 ถึง 600 นาที สูงสุด 25 สถานที่ เวลาเปิดทำการ การจราจรจริง แผนที่ เส้นทาง และการจอง อยู่นอกขอบเขตของตารางนี้

  • เวลาเริ่ม / เวลาเลิก: HH:MM
  • อยู่ (นาที): 5 ≤ m ≤ 720
  • เดินทางไปที่ถัดไป (นาที): 0 ≤ m ≤ 600
  • สถานที่: 1 ≤ n ≤ 25
