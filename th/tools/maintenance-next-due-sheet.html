สูตรและข้อจำกัด

ครบกำหนดถัดไป = ทำล่าสุด + ช่วงห่าง หน่วยเดือนจะคงวันที่เดิม หากเดือนนั้นไม่มีวันดังกล่าวจะใช้วันสุดท้ายของเดือน (รวมปีอธิกสุรทิน) วันที่เหลือ = ครบกำหนด − วันนี้ น้อยกว่า 0 คือเกินกำหนด 0 ถึง 7 คือใกล้ครบกำหนด

2026-06-01 + 3 เดือน = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 สัปดาห์ = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 เดือน = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

ช่วงห่าง 1 ถึง 3650 วัน สัปดาห์ หรือเดือน วันที่ระหว่าง 1900-01-01 ถึง 2999-12-31 สูงสุด 30 งาน ไม่มีการเตือน การแจ้งเตือน หรือซิงก์ปฏิทิน ข้อมูลไม่ออกจากหน้านี้

  • ช่วงห่าง: 1 ≤ x ≤ 3650
  • ทำล่าสุด: 1900-01-01 ≤ x ≤ 2999-12-31
  • งาน: 1 ≤ n ≤ 30
