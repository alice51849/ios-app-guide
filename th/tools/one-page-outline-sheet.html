โน้ตประชุมเป็นสรุปหนึ่งหน้า

เปลี่ยนโน้ตประชุมที่กระจัดกระจายให้เป็นโครงร่างหนึ่งหน้า: หัวข้อหลักหนึ่งข้อ ประเด็นสำคัญสามถึงสิบสองข้อ การดำเนินการถัดไปหนึ่งข้อ และตัวชี้วัด (ไม่บังคับ) แล้วดาวน์โหลดเป็นตารางเพื่อวางลงในสไลด์หรือสรุป

ประเด็นสำคัญ

3 ถึง 12 ประเด็น

ไม่บังคับ: ตัวเลขหนึ่งค่าที่ยืนยันประเด็น เช่น อัตราหรือจำนวน

จำนวนประเด็น

3

ส่วน

6

เปิดตัวหน้าชำระเงินใหม่ภายใน 30 กันยายน

  1. ลูกค้าหลุดที่ขั้นตอนที่อยู่
  2. การทดลองลดอัตราการทิ้งตะกร้าได้
  3. ทีมวิศวกรต้องการอีกสองสัปดาห์

อนุมัติสปรินต์เพิ่มในวันจันทร์

อัตราการทิ้งตะกร้า 48% ในการทดลอง

ข้อมูลอยู่ในแท็บนี้เท่านั้น ไม่มีการอัปโหลด บัญชี การติดตามข้อมูลที่กรอก หรือการบันทึก โหลดใหม่จะล้างการแก้ไข

ตัวอย่างแบบเต็ม

โน้ตเรื่องปรับปรุงหน้าชำระเงินกลายเป็นหัวข้อหลัก «เปิดตัวหน้าชำระเงินใหม่ภายใน 30 กันยายน» ประเด็นสามข้อ (ลูกค้าหลุดที่ขั้นตอนที่อยู่, การทดลองลดอัตราการทิ้งตะกร้าได้, ทีมวิศวกรต้องการอีกสองสัปดาห์) การดำเนินการถัดไป «อนุมัติสปรินต์เพิ่มในวันจันทร์» และตัวชี้วัด «อัตราการทิ้งตะกร้า 48% ในการทดลอง»

ประเด็น1ลูกค้าหลุดที่ขั้นตอนที่อยู่

สูตรและข้อจำกัด

ตารางเก็บถ้อยคำของคุณไว้ตามเดิม: หัวข้อหลัก ตามด้วยประเด็นตามลำดับที่พิมพ์ จากนั้นการดำเนินการถัดไป แล้วตัวชี้วัด ตารางนับจำนวนประเด็นและตัดช่องว่างหัวท้ายเท่านั้น ไม่มีการเขียนใหม่ สรุป หรือให้คะแนน

หัวข้อหลัก ≤ 80 · ประเด็น × 3 ≤ 160 · การดำเนินการถัดไป ≤ 160 · ตัวชี้วัด ≤ 60
ส่วน: หัวข้อหลัก → ประเด็น 1…3 → การดำเนินการถัดไป → ตัวชี้วัด

หัวข้อหลักไม่เกิน 80 ตัวอักษร ประเด็น 3 ถึง 12 ข้อ ข้อละไม่เกิน 160 ตัวอักษร การดำเนินการถัดไปไม่เกิน 160 ตัวอักษร ตัวชี้วัดไม่เกิน 60 ตัวอักษร ทุกบรรทัดต้องเป็นข้อความบรรทัดเดียว ตารางไม่อ่านไฟล์ บันทึกเสียง หรือปฏิทิน

  • หัวข้อหลัก: ≤ 80
  • ประเด็น: 3 ≤ n ≤ 12, ≤ 160
  • การดำเนินการถัดไป: ≤ 160
  • ตัวชี้วัด: ≤ 60
