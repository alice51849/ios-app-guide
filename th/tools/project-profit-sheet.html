สูตรและข้อจำกัด

กำไร = รวมรายรับ − รวมรายจ่าย อัตรากำไร = กำไร ÷ รวมรายรับ สุทธิต่อชั่วโมง = กำไร ÷ ชั่วโมงที่ใช้ จำนวนเงินบวกกันเป็นสตางค์เต็มหน่วย ยอดรวมจึงไม่คลาดเคลื่อน

รวมรายรับ = 1500.00
รวมรายจ่าย = 400.39
กำไร = 1500.00 − 400.39 = 1099.61
อัตรากำไร = 1099.61 ÷ 1500.00 = 73.3%
สุทธิต่อชั่วโมง = 1099.61 ÷ 12.5 = 87.97

จำนวนเงิน 0 ถึง 100,000,000 ทศนิยมไม่เกินสองตำแหน่ง รายรับและรายจ่ายอย่างละไม่เกิน 20 แถว ชั่วโมง 0.25 ถึง 2000 เป็นขั้นละสิบห้านาที สกุลเงินเดียว ไม่แปลงค่าเงิน ไม่มีคำแนะนำด้านภาษีหรือบัญชี

  • จำนวนเงิน: 0 ≤ x ≤ 100,000,000
  • ชั่วโมงที่ใช้: 0.25 ≤ h ≤ 2000
  • รายรับ / รายจ่าย: 1 ≤ n ≤ 20
