สูตรและข้อจำกัด

ยอดรวม = จำนวน × ราคาสุดท้ายต่อชิ้น ชั่วโมง = ยอดรวม ÷ รายได้สุทธิต่อชั่วโมง วัน = ชั่วโมง ÷ ชั่วโมงทำงานต่อวัน

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

ใส่ราคารวมภาษี ไม่แปลงสกุลเงิน คำนวณเงินเดือน คาดการณ์เงินออม หรือแนะนำให้ซื้อ แสดงทศนิยมสองตำแหน่ง โดยคำนวณยอดรวมจากค่าที่ไม่ปัดเศษ

  • รายได้สุทธิต่อชั่วโมง: 0 < x ≤ 100000000
  • ราคาต่อชิ้นรวมภาษี: 0 ≤ x ≤ 100000000
  • ชั่วโมงทำงานต่อวัน: 0 < x ≤ 24
  • จำนวน: 1 ≤ x ≤ 999
