Import in three steps

  1. Download the English or Traditional Chinese TSV file.
  2. In Anki, choose File > Import and select the downloaded file.
  3. Keep Front mapped to Front and Back mapped to Back, then import.

The symbol is the first field, so importing an updated edition can match the same notes without relying on custom GUIDs.

What every card includes

  • One of the complete 37 Zhuyin symbols
  • Hanyu Pinyin correspondence
  • Broad IPA transcription
  • Initial, medial or final classification
  • A Traditional Chinese example with marked Pinyin and English meaning

Questions

Does this work with Anki?

Yes. It follows Anki's official UTF-8 text import headers and uses a tab separator with two named fields.

Does the deck include all Bopomofo symbols?

Yes. It contains 21 initials, 3 medials and 13 finals: 37 notes total.

Does it include audio?

No. This edition is deliberately text-only so it remains small, inspectable, remixable and free of third-party media rights.

Is this an official Anki deck?

No. It is an independent open educational resource and is not affiliated with or endorsed by Anki.
