How many Bopomofo (Zhuyin) symbols are there?

There are 37 symbols: 21 initials (consonants), 3 medials (glides), and 13 finals (vowels and endings).

Is Zhuyin the same as Pinyin?

No — Zhuyin uses 37 purpose-built symbols and is standard in Taiwan; Pinyin uses the Latin alphabet and is the mainland/international standard. Many learners use Zhuyin for pronunciation and can still type with the system Zhuyin keyboard.

How do I type these on iPhone?

Add the Zhuyin keyboard under Settings > General > Keyboard > Keyboards > Add New Keyboard > Chinese (Traditional) — Zhuyin.
