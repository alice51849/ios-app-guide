Formül ve sınırlar

Ara toplam = tüm siparişlerin toplamı. Vergi = ara toplam × vergi oranı. Bahşiş = ara toplam × bahşiş oranı. Herkesin payı kendi siparişi ÷ ara toplamdır; artan kuruşlar önce en büyük ondalık kalanlara gider, böylece paylar her zaman hesabın tam toplamını verir.

Ara toplam = 32.40 + 18.90 + 25.00 = 76.30
Vergi = 76.30 × 8.25% = 6.29
Bahşiş = 76.30 × 15.00% = 11.45
Kişi 1: 32.40 + 2.67 + 4.86 = 39.93
Kişi 2: 18.90 + 1.56 + 2.84 = 23.30
Kişi 3: 25.00 + 2.06 + 3.75 = 30.81
Hesap toplamı = 94.04

Tek para birimi kullan; vergi ve bahşişi ara toplamın yüzdesi olarak gir. Döviz çevirisi, servis ücreti kuralı, ne kadar bahşiş bırakılacağına dair tavsiye ve ödeme yoktur. Ekranda iki basamağa yuvarlanır; paylaştırma tam kuruş üzerinden hesaplanır.

  • Sipariş tutarı: 0 ≤ n ≤ 100,000,000
  • Vergi % / Bahşiş %: 0 ≤ % ≤ 100
  • Kişi: 1 ≤ n ≤ 20
