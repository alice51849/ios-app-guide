Formül ve sınırlar

Varış = önceki ayrılış + yol. Ayrılış = varış + kalış. Toplam = tüm kalışlar + tüm yollar. Kullanılabilir = bitiş − başlangıç; başlangıçtan önceki bitiş saati ertesi gün sayılır. Aşım = toplam − kullanılabilir; sıfırın üstü aşıyor demektir. Yalnızca dakika toplama, saat dilimi yok.

1. Yer 1: 09:00 + 120 = 11:00 + 25 →
2. Yer 2: 11:25 + 60 = 12:25 + 40 →
3. Yer 3: 13:05 + 180 = 16:05 + 30 →
Toplam (dk) = 455; Kullanılabilir (dk) = 09:00–18:00 = 540
Aşım (dk) = 455 − 540 = -85 → Sığıyor

Saatler 24 saatlik SS:DD biçiminde, kalış 5–720 dakika, yol 0–600 dakika, en fazla 25 yer. Açılış saatleri, gerçek trafik, harita, rota ve rezervasyon bu tablonun dışındadır.

  • Başlangıç saati / Bitiş saati: HH:MM
  • Kalış (dk): 5 ≤ m ≤ 720
  • Sonrakine yol (dk): 0 ≤ m ≤ 600
  • Yer: 1 ≤ n ≤ 25
