Formül ve sınırlar

Kâr = toplam gelir − toplam gider. Kâr marjı = kâr ÷ toplam gelir. Saatlik net = kâr ÷ harcanan saat. Tutarlar tam kuruş olarak toplanır, böylece toplamlar kaymaz.

Toplam gelir = 1500.00
Toplam gider = 400.39
Kâr = 1500.00 − 400.39 = 1099.61
Kâr marjı = 1099.61 ÷ 1500.00 = 73.3%
Saatlik net = 1099.61 ÷ 12.5 = 87.97

Tutarlar 0 ile 100.000.000 arasında en fazla iki ondalıklı, en fazla 20 gelir ve 20 gider satırı, saat 0,25 ile 2000 arasında çeyrek saat adımlarıyla. Aynı para birimi, kur çevrimi yok, vergi veya muhasebe tavsiyesi yok.

  • Tutar: 0 ≤ x ≤ 100,000,000
  • Harcanan saat: 0.25 ≤ h ≤ 2000
  • Gelir / Gider: 1 ≤ n ≤ 20
