Formül ve sınırlar

Toplam = adet × son fiyat. Saat = toplam ÷ net saatlik gelir. İş günü = saat ÷ günlük çalışma saati.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Vergileri fiyata dâhil edin. Döviz dönüşümü, bordro hesabı, tasarruf tahmini veya satın alma tavsiyesi sunulmaz. Görünüm iki ondalığa yuvarlanır; toplamlar yuvarlanmamış değerleri kullanır.

  • Saatlik net gelir: 0 < x ≤ 100000000
  • Vergi dâhil birim fiyat: 0 ≤ x ≤ 100000000
  • İş günü başına saat: 0 < x ≤ 24
  • Adet: 1 ≤ x ≤ 999
