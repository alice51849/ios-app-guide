How to Use CV Desk to Build and Score Your Resume on iPhone

1
Create or import your resume

Open CV Desk. Either start from a template or import an existing resume file.

2
Fill in all sections

Complete each section: work experience, education, skills and contact details. More complete resumes score higher.

3
Run the ATS scan

Tap Scan to run the ATS analysis. CV Desk checks formatting, keyword density and common ATS filter patterns.

4
Fix highlighted issues

Review the flagged problems. Common issues include tables, graphics, unusual fonts or missing keywords. Fix each one.

5
Export the PDF

When satisfied with the score, tap Export to generate a clean PDF for submission.

Frequently asked questions

What ATS score should I aim for in CV Desk?

A score above 80 typically means your resume is unlikely to be filtered out by common ATS systems. Below 60 suggests significant formatting or content issues.

Should I tailor my CV Desk resume for each job application?

Yes. Adding keywords from the specific job description improves your ATS score for that role. CV Desk makes it easy to scan and re-export quickly.

Can I use CV Desk to create a resume from scratch if I have no previous experience?

Yes. CV Desk templates are suitable for entry-level applicants. Focus on education, skills and any volunteer or project experience.
