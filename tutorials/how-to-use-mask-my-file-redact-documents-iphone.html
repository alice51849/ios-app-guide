How to Use Mask My File to Redact Personal Information on iPhone

1
Import your document

Open Mask My File and tap Import. Select a PDF or image file from Files, Photos or any app.

2
Run automatic detection

The app scans the document for phone numbers, email addresses, ID numbers and home addresses.

3
Review detected items

Check the list of detected personal data. Deselect any item you want to keep visible in the shared version.

4
Apply the mask

Tap Mask to apply black bars over the selected personal data fields.

5
Export and share the redacted file

Tap Export to save or share the masked document via email, AirDrop or Files.

Frequently asked questions

What formats does Mask My File support?

Mask My File supports PDF and common image formats. For scanned documents, text-based PDFs give the most reliable detection results.

Can Mask My File detect handwritten personal data?

Detection is based on text recognition. Handwritten text in scanned documents may not be detected reliably.

Is the redaction permanent?

Yes. Once you export the masked file, the personal data is replaced with black bars and cannot be recovered from that exported file.
