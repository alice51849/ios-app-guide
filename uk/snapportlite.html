Snapport Lite

- Створюйте фотографії для паспорта, візи та документів з керівництвом по розмірам, інструментами для фону та експортом, готовим до друку.

- Одноразова покупка · назавжди ваша · без підписки

- Без реклами, без відстеження

Шаблони

- Фотографії для паспорта, візи та ID — готові до друку.

- Snapport Lite працює повністю офлайн. Перевірка лише завантажує публічний список загальних розмірів — жодні особисті дані не надсилаються.

Обрізати та вирівняти

- Вирівняйте обличчя в межах направляючої. Вимоги можуть відрізнятися, тому ознайомтеся з офіційними правилами перед подачею.

Фон

- Видалення фону може потребувати перевірки.

Налаштування

- Зберігайте природний вигляд для офіційних документів.

Експорт

- Експортуйте одне зображення або аркуш для друку.

Конфіденційність

- Ваші фотографії залишаються на вашому iPhone.

- Без облікового запису

- Без завантаження в хмару

- Визначення обличчя працює на пристрої, щоб допомогти вирівняти вашу фотографію. Біометрична інформація не зберігається.

- Ви контролюєте експорт та обмін

Вимоги до фотографій різняться в залежності від країни, агентства та типу заявки. Будь ласка, ознайомтеся з офіційними вимогами перед поданням.
