Формула й обмеження

Проміжний підсумок = сума всіх замовлень. Податок = проміжний підсумок × ставка податку. Чайові = проміжний підсумок × відсоток чайових. Частка кожного — його замовлення ÷ проміжний підсумок; копійки, що лишилися, дістаються спершу найбільшим дробовим частинам, тож частки завжди дають рівно суму рахунку.

Проміжний підсумок = 32.40 + 18.90 + 25.00 = 76.30
Податок = 76.30 × 8.25% = 6.29
Чайові = 76.30 × 15.00% = 11.45
Людина 1: 32.40 + 2.67 + 4.86 = 39.93
Людина 2: 18.90 + 1.56 + 2.84 = 23.30
Людина 3: 25.00 + 2.06 + 3.75 = 30.81
Разом за рахунком = 94.04

Використовуйте одну валюту, а податок і чайові вказуйте у відсотках від проміжного підсумку. Без конвертації валют, без правил щодо сервісного збору, без порад про розмір чайових і без платежів. На екрані округлення до двох знаків; сам розрахунок ведеться в цілих копійках.

  • Замовив(ла) на: 0 ≤ n ≤ 100,000,000
  • Податок % / Чайові %: 0 ≤ % ≤ 100
  • Людина: 1 ≤ n ≤ 20
