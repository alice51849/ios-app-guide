Формула й обмеження

Прибуття = попередній від'їзд + дорога. Від'їзд = прибуття + перебування. Разом = усі перебування + уся дорога. Доступно = кінець − початок; кінець раніший за початок вважається наступним днем. Перевищення = разом − доступно; більше нуля — не вкладається. Проста арифметика хвилин, без часових поясів.

1. Місце 1: 09:00 + 120 = 11:00 + 25 →
2. Місце 2: 11:25 + 60 = 12:25 + 40 →
3. Місце 3: 13:05 + 180 = 16:05 + 30 →
Разом (хв) = 455; Доступно (хв) = 09:00–18:00 = 540
Перевищення (хв) = 455 − 540 = -85 → Вкладається

Час у 24-годинному форматі ГГ:ХХ, перебування від 5 до 720 хвилин, дорога від 0 до 600 хвилин, до 25 місць. Години роботи, реальний рух, карти, маршрути та бронювання до таблиці не входять.

  • Початок / Кінець: HH:MM
  • Перебування (хв): 5 ≤ m ≤ 720
  • Дорога до наступного (хв): 0 ≤ m ≤ 600
  • Місце: 1 ≤ n ≤ 25
