Формула й обмеження

Наступний термін = останній раз + інтервал. Для місяців зберігається те саме число; якщо його немає, береться останній день місяця (з урахуванням високосних років). Залишилось днів = термін − сьогодні. Менше 0 — прострочено; від 0 до 7 — незабаром.

2026-06-01 + 3 місяців = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 тиждень = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 місяців = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

Інтервали від 1 до 3650 днів, тижнів або місяців. Дати з 1900-01-01 до 2999-12-31. До 30 справ. Без нагадувань, сповіщень і синхронізації з календарем; дані не залишають цю сторінку.

  • Інтервал: 1 ≤ x ≤ 3650
  • Останній раз: 1900-01-01 ≤ x ≤ 2999-12-31
  • Справа: 1 ≤ n ≤ 30
