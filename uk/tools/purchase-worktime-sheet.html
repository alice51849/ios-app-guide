Формула й обмеження

Разом = кількість × кінцева ціна. Години = сума ÷ чистий дохід за годину. Дні = години ÷ годин у робочому дні.

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

Вказуйте ціни з податками. Без обміну валют, розрахунку зарплати, прогнозу заощаджень чи порад щодо покупки. Показано два десяткові знаки; підсумки використовують неокруглені значення.

  • Чистий дохід за годину: 0 < x ≤ 100000000
  • Кінцева ціна за одиницю: 0 ≤ x ≤ 100000000
  • Годин у робочому дні: 0 < x ≤ 24
  • Кількість: 1 ≤ x ≤ 999
