فارمولا اور حدود

ذیلی میزان = سب کے آرڈر کا مجموعہ۔ ٹیکس = ذیلی میزان × ٹیکس کی شرح۔ ٹپ = ذیلی میزان × ٹپ کی شرح۔ ہر فرد کا حصہ = اُس کا اپنا آرڈر ÷ ذیلی میزان؛ بچے ہوئے پیسے پہلے سب سے بڑے اعشاریے والے کو جاتے ہیں، اس لیے سب کے حصے جمع کر کے ہمیشہ پورا بل بنتا ہے۔

ذیلی میزان = 32.40 + 18.90 + 25.00 = 76.30
ٹیکس = 76.30 × 8.25% = 6.29
ٹپ = 76.30 × 15.00% = 11.45
فرد 1: 32.40 + 2.67 + 4.86 = 39.93
فرد 2: 18.90 + 1.56 + 2.84 = 23.30
فرد 3: 25.00 + 2.06 + 3.75 = 30.81
بل کا کل = 94.04

ایک ہی کرنسی استعمال کریں اور ٹیکس و ٹپ کو ذیلی میزان کے فیصد میں لکھیں۔ کرنسی کی تبدیلی نہیں، سروس چارج کے قواعد نہیں، کتنی ٹپ دی جائے اس کا مشورہ نہیں، اور کوئی ادائیگی بھی نہیں۔ اسکرین پر دو اعشاریے؛ حساب پورے پیسوں میں ہوتا ہے۔

  • آرڈر کی رقم: 0 ≤ n ≤ 100,000,000
  • ٹیکس % / ٹپ %: 0 ≤ % ≤ 100
  • فرد: 1 ≤ n ≤ 20
