ایک دن کے سفر کی وقت شیٹ

ایک دن میں جن جگہوں پر جانا ہے، ہر جگہ کتنی دیر رکیں گے اور اگلی جگہ پہنچنے میں کتنا وقت لگے گا لکھیں، پھر پہنچنے اور نکلنے کے اوقات والی شیٹ ڈاؤن لوڈ کریں جو بتاتی ہے کہ سب کچھ آپ کے آغاز اور اختتام کے درمیان سما جاتا ہے یا نہیں۔

فارمولا اور حدود

پہنچنا = پچھلا نکلنا + سفر۔ نکلنا = پہنچنا + قیام۔ کل = تمام قیام + تمام سفر۔ دستیاب = اختتام − آغاز؛ آغاز سے پہلے کا اختتام اگلا دن شمار ہوتا ہے۔ زائد = کل − دستیاب؛ صفر سے اوپر ہو تو وقت سے زیادہ۔ صرف منٹوں کی جمع، ٹائم زون نہیں۔

1. جگہ 1: 09:00 + 120 = 11:00 + 25 →
2. جگہ 2: 11:25 + 60 = 12:25 + 40 →
3. جگہ 3: 13:05 + 180 = 16:05 + 30 →
کل (منٹ) = 455; دستیاب (منٹ) = 09:00–18:00 = 540
زائد (منٹ) = 455 − 540 = -85 → سما جاتا ہے

اوقات 24 گھنٹے HH:MM میں، قیام 5 سے 720 منٹ، سفر 0 سے 600 منٹ، زیادہ سے زیادہ 25 جگہیں۔ کھلنے کے اوقات، اصل ٹریفک، نقشے، راستے اور بکنگ اس شیٹ سے باہر ہیں۔

  • آغاز کا وقت / اختتام کا وقت: HH:MM
  • قیام (منٹ): 5 ≤ m ≤ 720
  • اگلی جگہ تک (منٹ): 0 ≤ m ≤ 600
  • جگہ: 1 ≤ n ≤ 25
