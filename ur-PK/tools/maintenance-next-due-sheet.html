فارمولا اور حدود

اگلی تاریخ = آخری بار + وقفہ۔ مہینوں میں وہی دن رہتا ہے؛ نہ ہو تو مہینے کا آخری دن لیا جاتا ہے (لیپ سال سمیت)۔ باقی دن = اگلی تاریخ − آج۔ 0 سے کم تاخیر؛ 0 سے 7 جلد۔

2026-06-01 + 3 مہینے = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 ہفتہ = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 مہینے = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

وقفہ 1 سے 3650 دن، ہفتے یا مہینے۔ تاریخیں 1900-01-01 سے 2999-12-31 تک۔ زیادہ سے زیادہ 30 کام۔ کوئی یاد دہانی، اطلاع یا کیلنڈر سنک نہیں؛ کچھ بھی اس صفحے سے باہر نہیں جاتا۔

  • وقفہ: 1 ≤ x ≤ 3650
  • آخری بار: 1900-01-01 ≤ x ≤ 2999-12-31
  • کام: 1 ≤ n ≤ 30
