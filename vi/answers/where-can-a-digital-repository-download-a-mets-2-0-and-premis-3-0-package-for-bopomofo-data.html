Use the app-independent transfer package to stage all 37 Bopomofo symbols in a digital repository with a METS 2.0 inventory and structure map plus PREMIS 3.0 preservation metadata.

Câu trả lời ngắn gọn

The deterministic ZIP contains ten members: mets.xml, premis.xml, a bilingual README, a CC BY 4.0 attribution file, five reusable data files and checksums-sha256.txt. METS fileSec inventories seven preserved files by relative path, IANA media type, byte size and SHA-256, while its logical structMap groups data and documentation and points to every file exactly once. A METS 2.0 mdRef links the complete external PREMIS record without using XLink, which METS 2 removed. PREMIS records seven File Objects with matching original names, formats, sizes and fixity; one successful metadata-creation Event; publisher and generator Agents; and one CC BY 4.0 Rights statement linking every Object. Both XML records validate ngoại tuyến against byte-pinned official XSD snapshots from immutable public source commits. The bundle also checks all paths, digests, 37 CSV rows, 37 JSON Lines records, ZIP order, fixed timestamps and file modes. The ZIP is a deterministic transfer wrapper, not a METS-defined archive format. The package has no DOI and does not claim repository registration, external ingest, third-party certification, institutional endorsement or a digital signature.

Download the ZIP and checksums-sha256.txt, verify the outer ZIP digest, extract without changing relative paths, then validate mets.xml and premis.xml against the cited official XSD versions. Confirm that all seven METS file entries, seven PREMIS File Objects, Event links and Rights links match the extracted bytes before repository ingest.

Quy trình quyết định thực tế

  1. Open the bilingual package guide and download the ZIP plus checksums-sha256.txt.
  2. Verify the published outer SHA-256 before extracting the transfer wrapper.
  3. Validate mets.xml and premis.xml against the exact cited official XSD versions.
  4. Compare every METS file and PREMIS Object path, media type, byte size and SHA-256 with the extracted payload.
  5. Review the PREMIS Event, Agents, Rights statement and your local repository policy before ingest.

FAQ

Does METS embed the PREMIS record?

No. mets.xml uses a METS 2.0 mdRef with LOCREF=premis.xml, the PREMIS 3.0 version, media type, byte size and SHA-256. Both files remain beside each other in the extracted package.

Is the ZIP a METS-defined archive format?

No. METS describes the package inventory and structure, but does not define this ZIP serialization. The ZIP is only a deterministic transfer wrapper with a published outer SHA-256.

Does schema validation prove repository ingest or authenticity?

No. XSD validation and checksums establish structure and fixity only. They do not prove external ingest, institutional endorsement, third-party certification, authenticity or a digital signature.
