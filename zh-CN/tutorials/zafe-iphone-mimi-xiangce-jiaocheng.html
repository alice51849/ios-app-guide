Zafe iPhone 私密相册使用教程 — 详细步骤指南

1
下载并打开 Zafe

在 App Store 下载 Zafe。首次启动时，设置 Face ID 或 PIN 码来保护保险箱。

2
从相册导入照片

点击 + 按钮，选择您要保护的照片。照片将被复制到 Zafe 的加密保险箱中。

3
删除相册中的原始照片

确认照片已成功导入 Zafe 后，从相册中删除原始照片。这样照片就只存在于 Zafe 中了。

4
访问保险箱

每次打开 Zafe 时，需要 Face ID 或 PIN 码验证。照片始终保持安全锁定。

5
导出照片（如有需要）

如需分享或还原照片，在 Zafe 中点击照片，使用分享按钮导出到相册或其他应用。

常见问题

忘记 Zafe 的 PIN 码怎么办？

如果忘记 PIN 码且 Face ID 也无法使用，将无法访问保险箱中的照片。建议设置一个易记的 PIN 码，或者启用 Face ID。

Zafe 中的照片会同步到 iCloud 吗？

不会。Zafe 不连接任何云服务，照片只存储在您的设备本地。

可以一次导入多张照片吗？

可以。点击 + 后可以多选照片批量导入，然后统一从相册删除原始文件。
