公式与限制

小计＝所有人点的金额之和。税＝小计 × 税率。小费＝小计 × 小费比例。每人分摊的税和小费＝自己点的金额 ÷ 小计，除不尽的零头先给小数部分最大的人，所以各人金额相加一定等于账单合计。

小计 = 32.40 + 18.90 + 25.00 = 76.30
税 = 76.30 × 8.25% = 6.29
小费 = 76.30 × 15.00% = 11.45
分账人 1: 32.40 + 2.67 + 4.86 = 39.93
分账人 2: 18.90 + 1.56 + 2.84 = 23.30
分账人 3: 25.00 + 2.06 + 3.75 = 30.81
账单合计 = 94.04

请使用同一币种，税和小费都按小计的百分比填写。不做汇率换算、不套用服务费规则、不建议给多少小费，也不经手任何支付。显示保留两位小数，分账计算本身以「分」为单位。

  • 他点的金额: 0 ≤ n ≤ 100,000,000
  • 税率 % / 小费 %: 0 ≤ % ≤ 100
  • 分账人: 1 ≤ n ≤ 20
