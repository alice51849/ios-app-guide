公式与限制

到达＝上一站离开＋移动。离开＝到达＋停留。合计＝所有停留＋所有移动。可用＝结束－开始；结束时间早于开始时视为次日。超出＝合计－可用；大于零即超时。纯分钟加法，不处理时区。

1. 地点 1: 09:00 + 120 = 11:00 + 25 →
2. 地点 2: 11:25 + 60 = 12:25 + 40 →
3. 地点 3: 13:05 + 180 = 16:05 + 30 →
合计（分） = 455; 可用（分） = 09:00–18:00 = 540
超出（分） = 455 − 540 = -85 → 排得下

时间为 24 小时制 HH:MM；停留 5 至 720 分钟；移动 0 至 600 分钟；最多 25 站。营业时间、实际路况、地图、路线规划与预订不在本表范围。

  • 开始时间 / 结束时间: HH:MM
  • 停留（分）: 5 ≤ m ≤ 720
  • 移动到下一站（分）: 0 ≤ m ≤ 600
  • 地点: 1 ≤ n ≤ 25
