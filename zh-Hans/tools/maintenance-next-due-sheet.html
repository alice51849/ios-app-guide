公式与限制

下次到期＝上次完成＋间隔。以月为单位时保留同一日，该月没有这天则取月底（含闰年）。剩余天数＝下次到期－今天；小于 0 为已逾期，0 至 7 为即将到期。

2026-06-01 + 3 个月 = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 周 = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 个月 = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

间隔为 1 至 3650 天、周或个月；日期介于 1900-01-01 与 2999-12-31；最多 30 个项目。不提醒、不推送、不同步日历，数据不会离开本页。

  • 间隔: 1 ≤ x ≤ 3650
  • 上次完成: 1900-01-01 ≤ x ≤ 2999-12-31
  • 项目: 1 ≤ n ≤ 30
