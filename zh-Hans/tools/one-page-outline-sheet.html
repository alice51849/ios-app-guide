公式与限制

本表原样保留你的文字：先标题，再按你输入的顺序列要点，接着下一步行动，最后指标。它只统计要点数并去掉前后空白；不改写、不摘要、不打分。

标题 ≤ 80 · 要点 × 3 ≤ 160 · 下一步行动 ≤ 160 · 指标 ≤ 60
区块: 标题 → 要点 1…3 → 下一步行动 → 指标

标题最多 80 个字符；要点 3 到 12 个、每个最多 160 个字符；下一步行动最多 160 个字符；指标最多 60 个字符。每一行都必须是单行文字。本表不会读取文件、录音或日历。

  • 标题: ≤ 80
  • 要点: 3 ≤ n ≤ 12, ≤ 160
  • 下一步行动: ≤ 160
  • 指标: ≤ 60
