公式与限制

毛利＝收入合计－支出合计。毛利率＝毛利÷收入合计。每小时净收入＝毛利÷投入时长。金额按最小单位整数相加，合计不会漂移。

收入合计 = 1500.00
支出合计 = 400.39
毛利 = 1500.00 − 400.39 = 1099.61
毛利率 = 1099.61 ÷ 1500.00 = 73.3%
每小时净收入 = 1099.61 ÷ 12.5 = 87.97

金额 0 至 100,000,000、最多两位小数；收入与支出各最多 20 行；时长 0.25 至 2000，以 0.25 小时为单位。同币种、不换汇，不提供税务或会计建议。

  • 金额: 0 ≤ x ≤ 100,000,000
  • 投入时长: 0.25 ≤ h ≤ 2000
  • 收入 / 支出: 1 ≤ n ≤ 20
