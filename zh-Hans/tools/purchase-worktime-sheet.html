公式与限制

合计＝数量 × 含税单价。所需工时＝合计 ÷ 到手时薪。工作天数＝所需工时 ÷ 每天工作时长。

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

请输入含税价格。不换汇、不核算工资、不预测存款，也不建议是否购买。显示保留两位小数，合计使用未四舍五入的数值。

  • 每小时到手收入: 0 < x ≤ 100000000
  • 含税单价: 0 ≤ x ≤ 100000000
  • 每天工作时长: 0 < x ≤ 24
  • 数量: 1 ≤ x ≤ 999
