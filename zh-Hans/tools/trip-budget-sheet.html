公式与限制

可自由花费＝总预算－固定支出。每天＝可自由花费÷天数。每人每天＝每天÷人数。各类别＝每天×比例。金额以最小单位整数相加；每日数字只在显示时四舍五入。

固定支出 = 1750.50
可自由花费 = 3000.00 − 1750.50 = 1249.50
每天 = 1249.50 ÷ 5 = 249.90
每人每天 = 249.90 ÷ 2 = 124.95
餐饮 = 249.90 × 40% = 99.96
交通 = 249.90 × 20% = 49.98
门票 = 249.90 × 25% = 62.48
购物 = 249.90 × 15% = 37.49

金额 0 至 100,000,000、最多两位小数；1 至 120 天；1 至 20 人；固定支出最多 15 行；四个比例合计必须正好 100。全程同币种、不换汇，不提供价格或订房建议。

  • 总预算 / 金额: 0 ≤ x ≤ 100,000,000
  • 天数: 1 ≤ d ≤ 120
  • 人数: 1 ≤ p ≤ 20
  • 比例: Σ = 100%
  • 固定支出: 0 ≤ n ≤ 15
