簡短解答

利用 Apple 的螢幕使用時間 API，你可以在定時專注時段內嚴格封鎖特定應用程式、整個類別或網站，並可選擇防止提前結束的模式。計時結束後，所有封鎖自動解除，無需手動重新啟用。

這是一款一次付費的專注工具，無需每月付費，適合只想在複習時段消除干擾的學生。

選擇前要注意什麼

  • 嚴格封鎖應用程式、類別和網站。
  • 定時時段結束自動解除封鎖。
  • 可選擇困難模式（無法提前結束）。
  • 使用 Apple 螢幕使用時間（系統層級封鎖）。
  • 一次付費，無月費。

實用的決策流程

  1. 選擇要封鎖的應用程式或類別（例如社交軟體）。
  2. 設定學習時段長度。
  3. 可選擇啟用困難模式。
  4. 開始學習時段並專心學習。
  5. 結束時所有封鎖自動解除。

常見問題

我可以作弊提前解鎖嗎？

啟用困難模式後，本次使用期間無法提前結束；否則計時結束時所有功能會解鎖。

它真的會封鎖應用程式嗎？

會的——它使用 Apple 的螢幕使用時間 API 進行系統層級封鎖，而不僅是提醒。

是訂閱制嗎？

不是 — 一次付費。
