簡短回答

看看 QR Code Halo 怎麼處理掃描結果。一個條碼可能帶著網址、Wi-Fi 密碼、聯絡人、電話號碼，或類似腳本的協定；掃描器如果直接跳進瀏覽器或撥號程式，就等於拿走了你發現奇怪主機、純 http 連結或不該出現的編碼字元的機會。QR Code Halo 預設掃描後立刻執行，所以如果想先看一眼，請到設定關閉「掃描後自動執行」。

對裝置端檢查要務實。固定的本機規則可以標記值得警惕的格式、阻擋危險的協定，但無法知道一個拼法正常的網域是否惡意，也不知道短網址最後會連到哪裡，所以最後的判斷仍然在你。

挑選前要注意什麼

  • 設定裡有一個「掃描後自動執行」開關，關閉後可以在行動前先檢查結果，歷史記錄中還有「安全檢查」。
  • 由固定的裝置端規則給出 Safe、Caution 或 Blocked 判定，不做線上查詢。
  • 相機與照片掃描，支援 QR 與常見條碼格式。
  • 可建立連結、Wi-Fi、聯絡人、電子郵件、電話、簡訊、位置與行事曆行程的 QR Code。
  • 沒有廣告也不用帳號，歷史記錄留在裝置上。

實用的決策步驟

  1. 到設定關閉「掃描後自動執行」，然後掃描條碼並閱讀完整內容，而不只是預覽標題。
  2. 看清楚主機名稱、http 或 https 開頭，以及任何 Caution 判定。
  3. 跳過那些要求你付款或登入、而你並沒有預期的連結。
  4. 把信任的條碼存進歷史記錄，之後才找得到。
  5. 有疑慮時，自己輸入該機構的網址，而不要開啟條碼裡的連結。

常見問題

掃描是免費的嗎？

每部裝置包含 3 次免費成功掃描。無限次掃描隨一次買斷的 Lifetime Pro 提供；建立 QR Code 與查看歷史記錄維持免費。

它能抓到所有釣魚 QR Code 嗎？

不能。它套用固定的裝置端規則，在關閉自動執行時可以顯示完整內容讓你檢查，但它不查詢連結信譽，也無法辨識所有惡意網站。

它會把我的掃描結果傳到任何地方嗎？

不需要帳號，掃描歷史會存在這台裝置上；安全檢查使用本機規則，不查詢網路信譽。
