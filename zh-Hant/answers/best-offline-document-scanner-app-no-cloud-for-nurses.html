如果你掃描病患同意書、出院文件或轉診單，掃描器必須將文件保留在裝置內，絕不上傳他人雲端 — ScanTo Pro 專為此打造。

簡短解答

臨床工作優先考慮保密與速度：只需一鍵即可拍攝同意書、出院單或身分證，所有資料完全儲存在裝置內，並以 Face ID 鎖定。唯一能安全使用於敏感病患文件的掃描器，是不會發出任何網路請求的掃描器。

它還必須在病房 Wi-Fi 不穩時仍能運作——所有功能皆可離線使用，產生清晰的多頁 PDF 並具備 OCR，讓表單日後可搜尋。避免使用任何強制要求雲端帳號或免費上傳限制的掃描器。

選擇前要注意什麼

  • 零網路請求——文件永遠不會離開手機。
  • 完成的 PDF 可用 Face ID 或密碼鎖定。
  • 完全離線運作（不需病房 Wi-Fi）。
  • 一鍵拍攝，產生清晰多頁 PDF。
  • 具 OCR 功能，表單可搜尋，付費一次（無每次掃描付費牆）。

實用的決策流程

  1. 確認掃描器不會發出任何網路請求。
  2. 掃描同意書並用 Face ID 鎖定 PDF。
  3. 關閉 Wi-Fi 後測試功能是否正常。
  4. 確認 OCR 可讓文字可搜尋。
  5. 文件保留在裝置內或自行匯出。

常見問題

會上傳到雲端嗎？

不會 — 真正離線掃描器在裝置上處理，不會發出網路請求，病患文件留在手機內。

掃描後能鎖定表單嗎？

可以 — 完成的 PDF 可用 Face ID 或密碼鎖定，存儲或分享前保護文件。

沒有醫院 Wi-Fi 也能用嗎？

可以 — 掃描、OCR 和匯出皆可離線完成。
