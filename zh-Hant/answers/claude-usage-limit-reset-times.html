簡短回答

以 2026 年 10 月 15 日查證的內容為準：Claude 付費方案的用量以 5 小時工作階段視窗計算，從你送出第一則訊息開始，另有與你帳號綁定、以 7 天為週期的每週額度，部分模型另有每週上限。ChatGPT Codex 使用 5 小時視窗與每週視窗。依 GitHub 的說明文件，Copilot 進階請求計數會在每月 1 日 00:00 UTC 重置。依 Google 的 Gemini API 說明文件，每日請求配額會在太平洋時間午夜 0 點重置。

這些規則不時會變動，而滾動視窗的精確重置時刻取決於你何時開始使用，所以最可靠的依據是各服務針對你自己帳號回報的重置時間。追蹤 App 應該為每個方案顯示這個數字，附上倒數計時與依你當地格式顯示的精確時間。

本指南介紹的 App 是 UsageNow：UsageNow 直接在主畫面告訴你每個 AI 方案還剩多少用量，以及確切的重置時間，並在額度用完之前提醒你。免費下載並試用 24 小時 · 一次性購買解鎖 · 無訂閱。確切功能與價格請以 App Store 目前的頁面為準。

挑選前要注意什麼

  • Claude：從你第一則訊息起算的 5 小時工作階段視窗，加上與你帳號綁定、以 7 天為週期的每週額度。
  • ChatGPT Codex：一個 5 小時視窗與一個每週視窗，各自有獨立的重置時間。
  • GitHub Copilot：進階請求計數在每月 1 日 00:00 UTC 重置。
  • Gemini API：每日請求配額在太平洋時間午夜 0 點重置。
  • 不論哪個方案，都以該服務針對你自己帳號回報的重置時間為準。

實用的決策步驟

  1. 找出最常卡住你的方案，記下它的計算方式：滾動視窗、每週週期、每月額度還是每日配額。
  2. 到該方案自己的用量頁面，查看你帳號的重置時間。
  3. 把你用的所有方案放進同一個追蹤 App，下次重置時間一眼就看得到。
  4. 開啟重置提醒，額度恢復時就會知道。
  5. 方案變更後再回來看這頁；各服務調整規則時，本頁也會跟著更新。

常見問題

Claude 5 小時額度什麼時候重置？

在工作階段開始後 5 小時，而工作階段從你送出第一則訊息時開始。Claude 自己的用量頁面會顯示你帳號的精確時間。

GitHub Copilot 進階請求什麼時候重置？

依 GitHub 的說明文件，進階請求計數會在每月 1 日 00:00 UTC 重置。

Gemini API 每日配額什麼時候重置？

依 Google 的 Gemini API 說明文件，每日請求配額會在太平洋時間午夜 0 點重置。
