簡短回答

可依英文名稱、繁體中文名稱或語言代碼搜尋。矩陣列出 Wordmate 全部 44 種語言，並分開呈現公開說明中的 iPhone 與 iPad、主畫面小工具及 Apple Watch 功能。相同資料也能下載成 JSON 或 CSV，並附 JSON Schema 與 W3C CSVW metadata。全程免帳號、不送出、不儲存，也沒有分析。

請把矩陣視為購買前檢查，而不是每種系統語音都已安裝的承諾。語音是否可用可能因 OS、裝置與已安裝語音而異；價格、商店地區供應與相容性也可能變動，因此購買前請開啟目前 App Store 頁面確認。

挑選前要注意什麼

  • 依名稱或代碼搜尋全部 44 種語言，不依賴模糊的多語支援宣稱
  • 分清 iPhone 與 iPad 發音功能，以及較輕量的主畫面小工具操作
  • 確認公開說明中的 Apple Watch 學習、語音、收藏與進度功能
  • 將完整支援矩陣下載成 JSON 或 UTF-8 CSV
  • 購買前確認目前商店地區的價格與相容性

實用的決策步驟

  1. 搜尋你實際打算學習的語言。
  2. 確認你需要手機發音、小工具操作，還是 Apple Watch 練習。
  3. 不要假設每一種系統語音都已安裝。
  4. 在目前 App Store 頁面確認當地價格與裝置相容性。
  5. 只有語言、裝置功能與付費模式符合你的日常節奏時才購買。
