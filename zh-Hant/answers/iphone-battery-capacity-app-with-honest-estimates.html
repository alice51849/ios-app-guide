為什麼 BattAI 顯示區間而不是一個數字？

因為容量是由有限的公開資料推估；單一數字會是假的精確。

它使用私有 API 嗎？

不。BattAI 只用 iOS 公開 API 和你可選擇提供的診斷檔。
