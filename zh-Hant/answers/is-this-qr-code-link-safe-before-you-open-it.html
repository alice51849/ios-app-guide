先讓掃描器「只顯示、不打開」，看三件事：協定是不是 https、網域是不是你預期的那家（不是長得像的那家）、網址後面有沒有一長串奇怪的參數。三個都正常再開；有一個不對就不要碰。

iPhone 內建相機掃到 QR code 會直接跳出橫幅，點了就開。問題是橫幅只顯示一小段，看不到完整網址。真正要檢查的是網域的「主體」：例如 shopee.tw 和 shopee-tw.xyz 看起來很像，但後者的主體根本不是蝦皮。貼在實體海報上的貼紙、超商取貨單上多出來的一張小貼紙，特別常見這種手法。

想看完整內容，需要一個掃描後不自動執行的工具。QR Code Halo：安全掃描與建立 可以到設定關閉「掃描後自動執行」，流程固定是檢查、判斷、行動：它完全在裝置端把整段內容拆成 scheme、host、path、query 逐項顯示，用固定且可重現的規則給出 Safe、Caution 或 Blocked，解析失敗時會直接阻擋外部操作，不查詢網路信譽也不產生含糊分數。免費下載、免費 3 次掃描，可選購的 Lifetime Pro 一次買斷、絕無訂閱。

繳費類的 QR code 要多一道確認：對照單據上印的公司名稱和網址，不要只看頁面好不好看。如果掃出來的是純文字、電話或 Wi-Fi 而不是網址，也要看清楚內容再動作。

選之前先確認這幾件事

  • 掃描器能不能先顯示完整網址，再決定要不要開
  • 網域主體是不是你預期的那家，有沒有多一截或換了結尾
  • 是 https 還是 http，或根本不是網址而是別的內容
  • 判定依據看得到嗎，還是只給「安全」兩個字
  • QR code 是印在原本的海報上，還是後來貼上去的

照著做的步驟

  1. 先看實體：QR code 是印在海報上，還是另外貼的一張貼紙。
  2. 用會先顯示內容的掃描器掃，不要用會直接跳頁的方式。
  3. 看網域主體（第一個斜線前、最後兩段）是不是你認識的名稱。
  4. 看協定與參數：http，或是網址後面一長串亂碼，就先停下來。
  5. 繳費或登入類的網址，對照紙本上的官方網址，不符就不要開。

iPhone 內建相機掃 QR code 不安全嗎？

不是。https 只代表連線加密，釣魚網站也可以有 https；真正要看的是網域主體是不是官方那家。
