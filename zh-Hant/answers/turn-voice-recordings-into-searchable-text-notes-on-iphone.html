錄音只有轉成文字才找得回來：在 iPhone 上直接錄、直接轉成摘要與重點，再匯出成文字或 Markdown 放進你平常的筆記工具，之後用關鍵字就搜得到。Sono Note 整個流程都在裝置上完成，不需要帳號。

先想清楚這段錄音要拿來做什麼。一堂三小時的課、一場客戶會議、走路時冒出來的一個想法，三種錄音需要的「文字」完全不同：課堂要的是重點和可以搜尋的內容，會議要的是行動項目和誰負責，走路時的想法只需要一段乾淨的句子。先決定你要的是哪一種，否則最後只會得到一堆沒人想讀的原始文字。

第二步是把轉錄和整理放在同一個動作裡。Sono Note 的做法是錄完直接交給你一份完成的筆記：摘要、重點、行動項目，還有一封可以直接寄出的後續郵件；原始錄音留在筆記裡隨時可以重播，不用再從頭聽一次。它有課堂、客戶電話、面試、就醫、創意等現成範本，全部在 iPhone 上處理，沒有帳號、飛航模式也能用，捷運進隧道收訊斷掉也不會中斷。

第三步是讓文字真的找得到。轉好的筆記用文字或 Markdown 匯出，放進你平常搜尋的地方——備忘錄、公司的雲端硬碟都可以——下週要找「那次說到的截止日」時，搜關鍵字就跳出來。免費可以每天錄 3 則、每則最多 3 分鐘，先用這個額度試試自己的講話習慣轉出來準不準；要更長的錄音與 PDF 匯出，專業版可以一次性永久解鎖，沒有訂閱。

選之前先確認這幾件事

  • 轉出來的是原始逐字稿，還是已經整理好的摘要與重點
  • 錄音和轉錄是不是都在手機上完成、不用上傳
  • 沒有網路（捷運、地下室）時還能不能錄
  • 能不能匯出成文字或 Markdown，放進你習慣搜尋的工具
  • 免費額度夠不夠你試出準確度，付費是訂閱還是一次解鎖

照著做的步驟

  1. 錄之前先選用途：上課、會議，還是走路時的靈感，決定你要的是摘要還是完整內容。
  2. 手機放在離講者近的地方；單一說話者、環境安靜，轉出來最乾淨。
  3. 錄完先看摘要和重點，核對專有名詞有沒有聽錯；不確定的地方直接在筆記裡重播那段原音。
  4. 把行動項目勾進待辦，再把筆記匯出成文字或 Markdown，存到你每天會搜尋的地方。
  5. 每週挑一次，從同一個地方把用不到的錄音刪掉，留下的就是真的要找的。

常見問題

上課錄三小時，轉出來準嗎？

準確度取決於收音：靠近講者、單一說話者、環境安靜，結果最清楚。轉出來的文字仍建議先核對專有名詞再使用。免費版每則最多 3 分鐘，長課堂需要專業版的最長 3 小時錄音。

Sono Note 轉出的文字可以在別的 App 搜尋嗎？

可以匯出成文字或 Markdown（專業版可匯出 PDF），放進你習慣的筆記或雲端硬碟後，就能用那邊的搜尋找關鍵字。

沒有網路也能錄嗎？

可以，所有處理都在 iPhone 上進行，飛航模式一樣能用，錄音和筆記不會離開裝置。
