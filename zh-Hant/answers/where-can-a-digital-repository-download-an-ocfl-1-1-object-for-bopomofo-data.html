簡短回答

Deterministic ZIP 解壓後只產生一個 OCFL Object root。精確的 0=ocfl_object_1.1 Namaste 檔宣告 OCFL 1.1；object root 的 inventory.json、inventory.json.sha512 與 head-version 目錄內的對應檔案 byte-identical。Inventory 以穩定 URI 識別物件、使用 SHA-512 進行 content addressing、在 manifest 對應實體 version content paths，並於 head state 將 content digests 對應至十個可攜 logical paths。完整 SHA-256 fixity block 另行涵蓋每個已儲存 content file。Logical state 保存 37 列 UTF-8 標準 CSV、等價 JSON Lines、W3C CSVW metadata、MLCommons Croissant 1.1 metadata、JSON-LD／Turtle／N-Triples SKOS 詞彙、SHACL shapes、驗證指南與 CC BY 4.0 聲明。解壓物件已用 ocfl-py 2.1.0 驗證。OCFL 定義 object-at-rest filesystem layout，不定義 ZIP transfer serialization 或 OCFL 專屬 media type，因此下載檔使用通用 application/zip，並另行發布外層 SHA-256。這是一個 OCFL Object，不是 OCFL Storage Root、repository service、機構背書或已匯入證明。

將 ZIP 與 checksum 下載到同一目錄，先核對外層 SHA-256，再解壓單一 object root，並以 ocfl-py 2.1.0 對該目錄執行 ocfl-validate.py。典藏庫匯入前，請檢查 inventory id、head、manifest、version state 與本地權利政策。

挑選前要注意什麼

  • 完整涵蓋 U+3105 至 U+3129 注音符號，不含音訊或學習者紀錄
  • 精確 OCFL 1.1 Namaste declaration，以及 root、head-version inventory sidecars
  • SHA-512 content-addressed manifest 與完整 SHA-256 fixity block
  • 十個 logical files，實體 content paths 與 logical paths 分離
  • 單一 root 的 deterministic ZIP，另發布外層 SHA-256

實用的決策步驟

  1. 從物件指南下載 ZIP、checksums-sha256.txt 與 metadata.jsonld。
  2. 解壓 transfer wrapper 前，執行 shasum -a 256 -c checksums-sha256.txt。
  3. 解壓 ZIP，確認只建立 bopomofo-37-symbols-ocfl object root。
  4. 使用 ocfl-py 2.1.0 執行 ocfl-validate.py bopomofo-37-symbols-ocfl。
  5. 典藏庫 staging 匯入前，確認 inventory id 與本地保存政策。

常見問題

ZIP 本身是 OCFL 定義的 serialization 嗎？

不是。OCFL 1.1 定義 object-at-rest 與 storage-root filesystem layouts，不定義 transfer archive 或 OCFL 專屬 media type。下載檔使用通用 application/zip wrapper，並另行發布該 ZIP bytes 的 checksum。

這份下載檔是完整 OCFL Storage Root 嗎？

不是。它是具 object declaration、可獨立驗證的一個 OCFL Object。典藏庫可依自己的 deterministic storage layout，將它放入另行宣告的 OCFL Storage Root。

這個物件如何保存未來變更？

Generator 會比較目前 logical state 與已發布 head；若來源 bytes 或 logical paths 改變，便附加新的 forward-delta version、保留先前 version directories，並重用既有 content digests，而不覆寫歷史。
