圖書館可以在哪裡載入涵蓋全部 37 個注音符號的 IIIF Presentation 3 Manifest？

使用開放的 IIIF Presentation API 3.0.0 資源，在相容的圖書館與數位人文 viewer 中，將每個注音符號顯示為有序的雙語複合物件。

簡短回答

靜態 Manifest 包含恰好 37 個有序的 1200×1200 Canvas。每個 Canvas 都有一個 AnnotationPage 與一個以該 Canvas 為 target 的 painting Annotation，其 body 是穩定的 image/svg+xml 資源。SVG 圖卡內含 deterministic glyph outline，來源是依 hash 固定、採 SIL Open Font License 的 Noto Sans TC；不含 script、foreignObject、event handler、外部字型或 App 宣傳。雙語 language map 提供符號、Unicode notation、漢語拼音、概略 IPA、分類與例字 metadata。獨立 IIIF Collection 引用此 Manifest；seeAlso 連結公開標準 CSV、Croissant 與 SKOS machine data，rendering 則指向 deterministic ZIP。資源發布 CC BY 4.0 rights、必要標示、精確 SHA-256 checksum 與不依賴 App 的套件 metadata，並以固定至公開 source commit 的 IIIF Presentation Validator 驗證。內容沒有 service block：此靜態資源不宣稱提供 IIIF Image API、deep zoom、Content Search API、外部 Collection 成員資格、IIIF 認證或機構已匯入。

在相容 Presentation API 3 的 viewer 開啟 collection.json 或 manifest.json，確認 37 個 Canvas 依序載入，並於本地重用前驗證已發布的 SHA-256。Viewer 必須支援一般 SVG image body；需要分塊 deep zoom 的部署環境應另行營運 IIIF Image service，不可從本 Manifest 推定其存在。

挑選前要注意什麼

  • 恰好 37 個有序 Canvas，完整涵蓋注音符號清單
  • 每個 Canvas 各有一個 painting Annotation 與一個安全靜態 SVG Image
  • 雙語 label，以及 Unicode、拼音、概略 IPA、分類與例字 metadata
  • IIIF Collection、Manifest、deterministic ZIP 與精確 SHA-256 checksum
  • 不宣稱具備 Image API、deep zoom、認證或已被外部匯入

實用的決策步驟

  1. 開啟雙語指南，下載 collection.json、manifest.json 或 deterministic ZIP。
  2. 典藏庫匯入前，使用固定版本的 IIIF Presentation Validator 驗證 manifest.json。
  3. 確認 Manifest 包含 37 個有序 Canvas，且沒有 service property。
  4. 鏡像 SVG 圖片或 ZIP 前，先驗證 checksums-sha256.txt。
  5. 先在目標 viewer 測試一個 SVG body；只有需要 deep zoom 時才另加 Image API。

常見問題

這份 Manifest 有提供 IIIF Image API 或 deep zoom 嗎？

沒有。Presentation API 的 image body 可以引用一般網路影像；這些 body 是不含 service block 的靜態 SVG 檔。需要分塊縮放或 deep zoom 的典藏庫，必須自行營運並宣告獨立的 Image API service。

IIIF Presentation 本身是採集或搜尋協定嗎？

不是。Presentation API 為 viewer 組織複合物件，不能取代目錄採集或內容搜尋。本資源另行提供 DCAT 與 ResourceSync 發現連結，且不宣稱具備 Content Search API。

通過 validator 是否代表取得 IIIF 認證或典藏庫接受？

不是。通過 validator 只表示已發布 JSON 結構符合所選 Presentation API 規則，不代表 IIIF Consortium 背書、認證、保證 viewer 相容，或已由任何機構匯入。
