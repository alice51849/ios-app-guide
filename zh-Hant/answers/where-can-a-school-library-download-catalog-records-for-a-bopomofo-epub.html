學校圖書館可以在哪裡下載注音 EPUB 的書目紀錄？

使用開放的注音圖書館書目資料包。它提供英文與繁體中文兩筆可供審核的版本紀錄，格式包含 MARCXML、MODS 3.8、BIBFRAME 2.0 JSON-LD 與 Turtle，另附一份完整 ZIP。

簡短回答

這些紀錄描述確切的開放 EPUB 檔案，而不是 App。每個版本都包含穩定的本機識別碼、語言、題名、團體創作者、出版資訊、格式、權利、主題、直接下載網址、位元組大小與 SHA-256。MARCXML 與 MODS 會以固定版本的官方 schema 驗證；兩種 BIBFRAME 序列化必須解析成相同 RDF 圖，並只使用官方詞彙宣告的術語。請至雙語指南下載：https://alice51849.github.io/ios-app-guide/data/zhuyin-bopomofo-library-catalog-records.html。這些是候選紀錄，編目員匯入前仍應審查館內的 040、主題、分類、取用與館藏政策；資料包不會指派 ISBN、LCCN 或 OCLC 號碼。

請先匯入測試館藏。將紀錄公開前，確認題名顯示、文字系統處理、主題、連結與本機控制欄位。靜態主機可能回傳通用 XML 或 JSON Content-Type，因此嚴格系統應依文件先下載再匯入。

挑選前要注意什麼

  • 一份可重現的 ZIP 內含 MARCXML、MODS 3.8、BIBFRAME JSON-LD、BIBFRAME Turtle、README 與 SHA-256 檢查碼清單。
  • MARCXML 集合包含兩筆書目紀錄，具備 001、005、007、008、041、245、264、3XX、5XX、6XX 與 856 資料。
  • 每筆紀錄都連到一個確切的 EPUB 版本，並帶有其位元組長度與 SHA-256 來源資訊。
  • 資料包採 CC BY 4.0 授權，不需帳號，也不需任何 App 即可使用。

實用的決策步驟

  1. 開啟雙語圖書館書目指南。
  2. 下載完整 ZIP，或下載圖書館系統可接受的格式。
  3. 驗證檢查碼，再審查館內的描述編目與取用欄位。
  4. 先匯入測試館藏，再將紀錄發布至公開目錄。

常見問題

可以不經審查就匯入這些紀錄嗎？

不可以。它們是通過 schema 驗證的候選紀錄，不代表機構已核定編目。請在測試館藏中審查本機控制欄、主題、分類、取用與館藏政策。

這些紀錄會指派 ISBN、LCCN 或 OCLC 號碼嗎？

不會。紀錄使用明確標示的本機識別碼，不宣稱任何外部控制號碼。

如果圖書館系統拒絕檔案網址怎麼辦？

請先下載 MARCXML、MODS、JSON-LD 或 Turtle 檔案，再從本機匯入。靜態主機可能回傳通用 XML 或 JSON Content-Type，嚴格的網址匯入器可能因此拒絕。
