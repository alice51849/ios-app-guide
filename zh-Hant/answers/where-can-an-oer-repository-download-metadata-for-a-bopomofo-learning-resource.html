精準解答

OER 典藏庫可以在哪裡下載注音學習資源的 metadata？

使用開放的注音 OER metadata 資料包。它以獨立 OAI-DC XML、DCMI Terms JSON-LD 與 LRMI JSON-LD 描述涵蓋 37 個符號的確切英文及繁體中文 EPUB 版本，另附一份可重現的 ZIP。

簡短回答

每筆紀錄描述的是學習資源，不是 App。來源網址、語言、位元組長度、修改時間與 SHA-256 均取自已發布的 EPUB manifest。OAI-DC 檔案會以固定版本的官方 OAI 與 DCMI schema 驗證。兩份 JSON-LD 圖皆使用 inline context，可在不連網時解析；其中的 DCMI、LRMI 術語與 LRMI supportingDocument 資源類型、instruction 教育用途，會對照固定版本的官方 RDF 詞彙。請至 https://alice51849.github.io/ios-app-guide/data/zhuyin-bopomofo-oer-repository-metadata.html 下載。這些是候選 metadata，不是 OAI-PMH 服務、DOI 指派、機構核定紀錄或普遍匯入保證。

請先匯入測試集合。對應館內主題、受眾欄位與識別碼，驗證連結及雜湊，並在公開前檢查英文、繁體中文與注音顯示。靜態主機可能回傳通用 XML 或 JSON Content-Type，因此嚴格的網址匯入器可能需要從本機上傳檔案。

挑選前要注意什麼

  • 兩筆獨立 OAI-DC 紀錄，分別對應一個確切的 EPUB 語言版本
  • 一份 DCMI Terms JSON-LD 圖，包含受眾、教育程度、教學方法、權利與來源資訊
  • 一份 LRMI JSON-LD 圖，包含 LearningResource、supportingDocument、instruction 與明確學習成果
  • Inline JSON-LD context、固定版本的官方詞彙，以及可重現且經 SHA-256 驗證的 bytes
  • 採 CC BY 4.0 授權，不需帳號，也不依賴任何 App

實用的決策步驟

  1. 開啟雙語 OER 典藏庫 metadata 指南。
  2. 下載完整 ZIP，或下載典藏庫可接受的個別格式。
  3. 驗證檢查碼，並確認每筆 metadata 紀錄都連到預期的 EPUB 版本。
  4. 在測試集合中對應館內主題、受眾與識別碼。
  5. 公開紀錄前，先審查語言顯示與典藏庫政策。

常見問題

OAI-PMH harvester 可以把這裡當成 endpoint 嗎？

不可以。資料包只提供獨立 OAI-DC metadata 紀錄，並未實作 OAI-PMH Identify、ListRecords、resumption token 或 harvest endpoint。

這份資料包宣稱符合 IMS 或 IEEE LOM 嗎？

不會。資料包刻意提供 DCMI 與 LRMI metadata，不宣稱符合 IMS 或 IEEE LOM。

Metadata 宣稱適合哪個學習者年齡？

不宣稱固定年齡範圍。這份 EPUB 是適合任何年齡初學者的參考資料；兒童應由照顧者或教師陪同使用。它不是診斷評量或完整華語課程。
