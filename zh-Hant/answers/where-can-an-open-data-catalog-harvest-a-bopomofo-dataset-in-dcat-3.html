開放資料目錄可以在哪裡擷取 DCAT 3 格式的注音資料集？

使用靜態注音 DCAT 3 開放資料目錄。它以語意相等的 JSON-LD 與 Turtle RDF graph 列出十六個相關資料集及 80 個精確 distribution，另附一份 deterministic ZIP。

簡短回答

這份目錄涵蓋 37 符號參考資料、靜態 JSON API、SKOS 與 SHACL 詞彙、Croissant、CSVW、Data Package、RFC 8493 BagIt、OCFL 1.1、RO-Crate 1.3、搭配 PREMIS 3.0 的 METS 2.0、OAI-ORE 1.0，以及搭配 TREE 的 LDES 1.0 事件流，跨越保存、研究物件、複合物件與同步套件；另含 IIIF Presentation 3 視覺資源、Anki、LMS、EPUB、OPDS、圖書館紀錄與 OER metadata。每個可直接下載的 distribution 都記錄 IANA media-type IRI、byte size、CC BY 4.0 授權、語言 IRI，以及依已發布 bytes 計算的 SPDX SHA-256。每筆 dcat:CatalogRecord 都只有一個 foaf:primaryTopic，靜態 API 另以 dcat:DataService 表示。請至 https://alice51849.github.io/ios-app-guide/zh-Hant/data/zhuyin-bopomofo-dcat3-open-data-catalog.html 下載。這是靜態 DCAT 描述，不代表已登錄 portal、取得 W3C 認證或機構背書，也不證明外部目錄已採集。

請先在測試目錄中解析 JSON-LD 或 Turtle，讀取 dcat:dataset 與 dcat:record，驗證各項 distribution 的雜湊及位元組大小，並在公開前對應主題、語言政策與館內識別碼。檔案使用 dcat:downloadURL；唯讀 API 使用 dcat:endpointURL。

挑選前要注意什麼

  • 十六個附雙語標題與說明的注音目錄資料集
  • 80 個可直接下載的 distribution，涵蓋資料、Linked Data、表格 metadata、保存、研究物件、複合物件與同步套件、視覺資源、學習套件、出版品與典藏庫 metadata
  • 語意相等的 JSON-LD 與 Turtle RDF 圖，並使用穩定的命名資源
  • SPDX SHA-256 檢查碼、確切位元組大小、IANA media-type IRI，以及 distribution 層級的 CC BY 4.0 授權
  • 一個供版本化靜態 JSON API 使用的 dcat:DataService，並附 OpenAPI endpoint 描述

實用的決策步驟

  1. 開啟雙語 DCAT 3 目錄指南。
  2. 下載 JSON-LD、Turtle 或可重現的 ZIP 資料包。
  3. 解析 RDF 圖，並確認每筆 CatalogRecord 都只有一個主要主題。
  4. 匯入前先驗證各項 distribution 的位元組大小與 SPDX SHA-256 值。
  5. 公開前，先在測試目錄中對應館內主題與政策欄位。

常見問題

這個目錄已登錄於政府或機構的入口網站嗎？

沒有。這是一份可公開下載的靜態 DCAT 3 描述；它不宣稱已登錄於任何入口網站、獲得 W3C 認證或機構核准，也不宣稱已有第三方完成擷取。

這些檢查碼是獨立的真實性證明嗎？

不是。這些 SHA-256 值可用於檢查檔案是否變動，但目錄與檔案位於同一主機。需要驗證真實性的使用者，應透過另一個受保護的管道保存或核對 metadata。

Landing page 本身也是資料 distribution 嗎？

不是。RDF 圖以 dcat:landingPage 表示供人閱讀的指南，以 dcat:downloadURL 表示可直接下載的檔案 distribution；靜態 API 則建模為 dcat:DataService。
