常見問題

這個目錄已登錄於政府或機構的入口網站嗎？

沒有。這是一份可公開下載的靜態 DCAT 3 描述；它不宣稱已登錄於任何入口網站、獲得 W3C 認證或機構核准，也不宣稱已有第三方完成擷取。

這些檢查碼是獨立的真實性證明嗎？

不是。這些 SHA-256 值可用於檢查檔案是否變動，但目錄與檔案位於同一主機。需要驗證真實性的使用者，應透過另一個受保護的管道保存或核對 metadata。

Landing page 本身也是資料 distribution 嗎？

不是。RDF 圖以 dcat:landingPage 表示供人閱讀的指南，以 dcat:downloadURL 表示可直接下載的檔案 distribution；靜態 API 則建模為 dcat:DataService。
