哪裡可以下載供電子閱讀器使用的免費注音 EPUB？

使用本頁提供的免費雙語 EPUB 資源：它分別提供涵蓋全部 37 個注音符號的英文版與繁體中文版，另有網頁閱讀與 OPDS 目錄選項。

簡短回答

每一份採 CC BY 4.0 授權的 EPUB 3.3 都包含目錄、以文字為主的 21 個聲母、3 個介音與 13 個韻母章節、漢語拼音與概略 IPA 對照、例字，以及簡短且不具診斷用途的練習指南。檔案不含 script、圖片、追蹤、帳號、學習者個人檔案或兒童資料收集。可下載的 Readium manifest JSON 與 OPDS 2.0／1.2 目錄檔案描述相同的英文及繁體中文版本。由於靜態主機可能回傳一般 JSON 或 XML HTTP Content-Type，本頁不宣稱嚴格的目錄工具一定能透過 URL 匯入。各閱讀系統的 EPUB 支援程度也不同，因此本頁提供 SHA-256 metadata，並建議實際檢查目標閱讀器，而不宣稱所有系統都能完整顯示。

下載符合閱讀者語言的版本，以目前仍維護的 EPUB 3 閱讀 App 開啟，並確認導覽及注音字型支援。若裝置無法正確顯示 EPUB，請使用線上文字版。這是一份符號參考資料，不是音訊教學、發音評量或完整華語課程。

挑選前要注意什麼

  • 以同一份權威 37 符號資料集完整涵蓋 21 個聲母、3 個介音與 13 個韻母
  • 分開提供英文與繁體中文 EPUB 3.3，且每次建置的 bytes 完全一致
  • 以文字為主的閱讀順序、結構化導覽與明確的無障礙 metadata
  • 可下載的 Readium manifest JSON，加上 OPDS 2.0 與 OPDS 1.2 目錄檔案
  • CC BY 4.0，無帳號、script、追蹤、外部媒體或學習者資料收集

實用的決策步驟

  1. 依閱讀者需求選擇英文版或繁體中文版。
  2. 直接下載 EPUB 而不要解壓縮，或下載 OPDS 檔案並在相容的目錄閱讀器中測試匯入。
  3. 在目標裝置上檢查目錄、閱讀順序與注音字形顯示。
  4. 若閱讀器無法可靠支援 EPUB 3 或字型，請使用對應的線上文字版。
  5. 請搭配流暢且正確的口語示範，因為純文字電子書無法評量發音。

常見問題

這份 EPUB 能在每一款電子閱讀器中使用嗎？

無法保證適用於所有裝置，因為各閱讀系統對 EPUB 3 與注音字型的支援不同。請先在目標閱讀器中測試；若導覽或字形顯示不完整，可改用對應的線上文字版。靜態主機可能回傳一般 JSON 或 XML HTTP Content-Type，因此嚴格要求 OPDS 或 WebPub 專用 media type 的目錄工具可能需要直接匯入檔案。

這份 EPUB 包含音訊或發音測驗嗎？

沒有。這是一份以文字為主的參考資料，供查閱符號、拼音、IPA 與例字。請搭配流暢且正確的口語示範使用；本資料不會評量語音、聲調、流暢度或入學準備程度。

這份開放電子書會收集學習者資料嗎？

不會。EPUB 與網路出版品不使用帳號、script、分析、追蹤或兒童個人檔案；兩者皆為可下載的 CC BY 4.0 檔案。
