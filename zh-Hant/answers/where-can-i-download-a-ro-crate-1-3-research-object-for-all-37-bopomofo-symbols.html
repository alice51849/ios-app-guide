哪裡可以下載涵蓋全部 37 個注音符號的 RO-Crate 1.3 研究物件？

使用這份內附式且不依賴 App 的 RO-Crate，將完整 37 符號注音參考表與標準 metadata 作為單一可重現研究物件移轉。

簡短回答

Deterministic ZIP 的 crate 根目錄包含十個成員：ro-crate-metadata.json、不含 script 的 ro-crate-preview.html、雙語 README、CC BY 4.0 標示檔、五個 data entity，以及 checksums-sha256.txt。Payload 包含標準 37 列 UTF-8 CSV、語意相同的 JSON Lines、MLCommons Croissant 1.1 metadata、W3C CSVW metadata 與 SKOS JSON-LD 詞彙。Metadata descriptor 使用必要的 ro-crate-metadata.json identifier，指向一個絕對 IRI root Dataset，並宣告符合 RO-Crate 1.3。每個 root hasPart File 都有相對 URI、名稱、說明、media type、精確 byte size 與 SHA-256。驗證採用固定至不可變公開 source commit 的官方 1.3 context，離線展開 graph，並檢查每個路徑、byte、digest、checksum 與 deterministic ZIP 屬性。目前可用的第三方 validator profile 僅支援至 RO-Crate 1.2，因此本資源不宣稱取得第三方 1.3 認證；也未指派 DOI、未登錄典藏庫存放紀錄，且不宣稱已被外部匯入或獲得 RO-Crate 社群背書。

下載 ZIP 與 checksums-sha256.txt，驗證 ZIP bytes，在不變更路徑的情況下解壓縮，再以支援 RO-Crate 1.3 的工具解析 ro-crate-metadata.json。進入典藏庫 staging 前，請確認 root Dataset、七個 hasPart entity、相對檔案路徑、byte 長度與 SHA-256 值。

挑選前要注意什麼

  • 標準 37 列 CSV 與語意相同的 JSON Lines，完整涵蓋 U+3105 至 U+3129
  • RO-Crate 1.3 descriptor、root Dataset 與七個精確的本地 File data entity
  • 單一內附式 crate 中收錄 Croissant 1.1、W3C CSVW 與 SKOS JSON-LD metadata
  • 不含 script 的靜態預覽、雙語重用指南與 CC BY 4.0 標示
  • 包含十個成員的 deterministic ZIP，附 byte-exact SHA-256 checksum

實用的決策步驟

  1. 開啟雙語指南，下載內附式 ZIP 與 checksums-sha256.txt。
  2. 解壓縮前，先驗證已發布的 ZIP SHA-256。
  3. 確認 ro-crate-metadata.json 引用官方 RO-Crate 1.3 context 與 profile。
  4. 確認七個 root hasPart 路徑都存在，且符合各自的 contentSize 與 sha256 值。
  5. 典藏庫匯入前，先以支援 1.3 的 consumer 測試解壓縮後的 crate。

常見問題

這是內附式還是分離式 RO-Crate？

這是內附式 RO-Crate 套件。ZIP 根目錄中的 ro-crate-metadata.json 與本地 payload 檔案及靜態預覽並列；相同檔案也各自公開，方便直接檢查。

此套件有 DOI，或能證明已存入典藏庫嗎？

沒有。它使用穩定的 canonical web identifier，但未指派 DOI、未登錄典藏庫紀錄，也不證明任何機構已完成匯入。

是否已有第三方 validator 認證其符合 RO-Crate 1.3？

沒有。目前可用的第三方 base profile 僅支援至 1.2。本 generator 改以固定版本的規範性 1.3 context 與必要結構進行檢查，離線展開 JSON-LD，並驗證套件中的每個 byte，但不宣稱取得認證。

下載、解析、驗證或重用任何 RO-Crate data entity 都不需要 Lumi Bopomofo。若目前可供下載，它只會在完整研究物件之後，作為選用的裝置端練習層出現。
