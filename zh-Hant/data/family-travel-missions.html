出發前7 個觀察目標

安全界線: 請在家使用這組卡片。旅行文件、藥物、鑰匙與最後打包決定，全都由大人保管與確認。

  1. 一件讓大家旅途中更舒適的物品
  2. 一件大人會檢查的旅行文件用品
  3. 一件可重複使用而非用完即丟的物品
  4. 一種等待時可安靜進行的活動
  5. 兩件擁有相同顏色的行李物品
  6. 一件大人可能需要快速拿到的物品
  7. 一種同行成員可互相幫忙的方法
機場7 個觀察目標

安全界線: 留在陪同大人身旁，不阻擋走道或安檢區，並遵守機場與安檢人員指示。這組卡片完全沒有拍照任務。

  1. 從目前等待位置看得到的兩種標誌
  2. 一台從窗戶看得到的車輛
  3. 建築裡一種重複出現的形狀
  4. 工作人員身上的一種顏色
  5. 一件有輪子的物品
  6. 一個安靜聲音與一個較大的聲音
  7. 一個協助旅客找到地點的符號
飛行途中7 個觀察目標

安全界線: 只有在坐好且機組人員允許時才使用。安全說明、任何指示、亂流，或大人要求暫停時，立即停止活動。

  1. 座位看得到窗外時，窗外的一種形狀
  2. 座位附近兩種不同材質
  3. 一個安靜的聲音
  4. 一件可以折疊的物品
  5. 一件機組人員用來傳達資訊的物品
  6. 看得到天空時，一朵雲的形狀
  7. 一種可協助同排乘客的禮貌做法
公路旅行7 個觀察目標

安全界線: 只能從正確使用安全座椅或安全帶的乘客座位觀察。行車期間，駕駛絕不閱讀、回答或操作卡片。

  1. 兩個道路標誌上重複出現的一種顏色
  2. 一座橋、隧道或高架道路
  3. 一項逐漸改變的地景
  4. 一台載著特別物品的車輛
  5. 一個安全休息站裡的細節
  6. 一個雲朵或天氣線索
  7. 一個由大人指出的地標
火車或渡輪7 個觀察目標

安全界線: 遵守運輸業者與陪同大人的指示，留在標線內，依指示使用座位或扶手；絕不為了卡片靠近月台或船邊。

  1. 一個抵達或出發標誌
  2. 一種重複出現的座椅或欄杆圖案
  3. 一個表示移動開始的聲音
  4. 一件工作人員使用的物品
  5. 一個旅途中逐漸改變的景色
  6. 一個由大人指出的安全扶手
  7. 一種乘客彼此留出空間的方法
城市散步7 個觀察目標

安全界線: 只有在大人選定安全停留處後才使用卡片。導航、過馬路、車流與行走路線，全部由大人判斷。

  1. 一個老建築的細節
  2. 一個新建築的細節
  3. 一個用於過馬路或指路的符號
  4. 同一街區裡的三種顏色
  5. 一棵樹、一個花台或一座公共花園
  6. 一個高於視線的細節
  7. 一個人們會停下來的地方
博物館7 個觀察目標

安全界線: 遵守場館當下規則。除非明確允許，否則不觸摸、不拍照；任何時候都可選擇只看或停止。

  1. 一件材質觸感看起來很特別的物品
  2. 一件來自不同年代或地方的物品
  3. 一個大型展示裡的微小細節
  4. 兩件作品裡重複出現的一種形狀
  5. 一個展示說明可能回答的問題
  6. 一件你會小心保護的物品
  7. 一個不用觸摸就能描述的展示
主題樂園7 個觀察目標

安全界線: 只有在安全停留且大人允許時才使用。排隊、設施、身高、安全裝置與工作人員指示永遠優先。

  1. 等候區裡的一個設計細節
  2. 地圖上的一個符號
  3. 一件協助工作人員溝通的物品
  4. 一種用來引導遊客的顏色
  5. 一個有遮蔭或較安靜的休息區
  6. 一個符合主題的聲音
  7. 一種讓同行成員保持在一起的方法
自然景點或海邊7 個觀察目標

安全界線: 只停留在大人與當地規則允許的地方，和野生動物保持安全距離；不為了卡片觸摸、撿走或餵食任何東西。

  1. 一種由風或水形成的圖案
  2. 一件只觀察、不帶走的自然物
  3. 一個從安全距離看得到的動物線索
  4. 同一種顏色的兩種深淺
  5. 一項天氣變化
  6. 一個不用靠近也聽得到的聲音
  7. 一種讓環境保持原樣的方法
飯店7 個觀察目標

安全界線: 卡片上不寫房號、姓名或行程資料，並尊重其他旅客。房卡、出口與緊急資訊都由大人管理。

  1. 一個協助找到房間或出口的標誌
  2. 公共空間裡一種重複出現的圖案
  3. 一件節省水或能源的物品
  4. 一種安靜通過走廊的方法
  5. 一件離開房間前同行成員需要的物品
  6. 一個從允許使用的公共空間看得到的景色
  7. 一種讓房間保持整齊的方法
餐廳7 個觀察目標

安全界線: 過敏、食品安全與走動方式由大人和餐廳人員處理；不為了卡片拍攝或靠近其他客人。

  1. 菜單上寫到的一種食材
  2. 餐具擺設裡重複出現的一種形狀
  3. 一句同行成員可以使用的禮貌用語
  4. 兩種食物共有的一種顏色
  5. 一件工作人員用來安排服務的物品
  6. 一個和準備餐點有關的聲音
  7. 一種協助整理自己座位空間的方法
安靜等待7 個觀察目標

安全界線: 只從大人選定的座位或區域觀察，不為了卡片靠近陌生人；任何可能打擾現場的內容都直接跳過。

  1. 一件有直線的物品
  2. 一件有曲線的物品
  3. 三件屬於相近色系的東西
  4. 一個近處聲音與一個遠處聲音
  5. 一件名稱以指定聲音開頭的物品
  6. 一個剛才沒有注意到的細節
  7. 一個以普通物品為主角的迷你故事
