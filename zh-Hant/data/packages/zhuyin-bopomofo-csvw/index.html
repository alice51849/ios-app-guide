Python

from csvw.metadata import Table

table = Table.from_file("https://alice51849.github.io/ios-app-guide/data/zhuyin-bopomofo-ml-dataset.csv-metadata.json")
rows = list(table)
assert len(rows) == 37

適合用途

  • CSV 匯入與 schema-aware ETL
  • 資料目錄中繼資料探索
  • 確定性表格品質檢查
  • 使用宣告 mapping 的 CSV-to-RDF 工作流程

範圍與限制

  • 這是精簡符號參考資料，不是發音語料庫
  • 不含音訊、學習者紀錄或行為資料
  • 不宣稱獲 W3C 認證或已被外部目錄收錄
  • 例字不能取代完整華語音韻指南
