範圍與限制

  • 套件包含完整 37 符號參考資料與標準 metadata，不含音訊或學習者紀錄。
  • Canonical URL 是網頁識別碼，沒有取得 DOI。
  • 發布不代表已登錄典藏庫，也不證明已被外部系統匯入。
  • Checksum 可偵測 bytes 變更，但不是數位簽章或獨立真偽證明。
  • 符合 RO-Crate 規格不代表獲得 RO-Crate 社群背書或認證。
