注音符號 Frictionless Data Package 2.0

一個自含目錄即可用於 ETL、notebook、資料目錄與可重現流程；不需帳號或 API 金鑰。

37 筆已驗證資料12 個型別欄位可攜相對路徑SHA-256 驗證

套件檔案

descriptor 以相對路徑解析 CSV 與 Table Schema，因此線上或下載整個目錄後都能使用。

Data Package descriptordatapackage.jsonTable Schematable-schema.jsonUTF-8 CSVsymbols.csv

驗證與載入

Frictionless 會驗證 descriptor、schema、主鍵、型別、約束與每一筆 CSV 資料。

pip install frictionless==5.19.0
frictionless validate https://alice51849.github.io/ios-app-guide/data/packages/zhuyin-bopomofo/datapackage.json

Python

from frictionless import Package

package = Package("https://alice51849.github.io/ios-app-guide/data/packages/zhuyin-bopomofo/datapackage.json")
with package.get_resource("symbols") as resource:
    rows = resource.read_rows()

可攜欄位契約

欄位型別意義
order整數1 至 37 的穩定教學順序。
symbol_id字串由 Unicode 碼位產生的穩定 ASCII 識別碼。
concept_uri字串對應 SKOS 概念的穩定 URI。
symbol字串單一注音符號字元。
unicode字串U+XXXX 格式的 Unicode 碼位。
pinyin字串對應漢語拼音。
ipa字串符號的精簡 IPA 對照。
category字串聲母、介音或韻母分類。
category_uri字串SKOS 分類概念的穩定 URI。
example_character字串繁體中文例字。
example_pinyin字串例字的聲調拼音。
example_meaning_en字串例字的精簡英文釋義。

適合用途

  • ETL 與資料品質檢查
  • Notebook 與 dataframe 匯入
  • 資料目錄匯入與可重現建置
  • 語言工具的參考表

限制

  • 不是發音或語音資料集
  • 不是文字轉換 API
  • 不是學習者評量或課程
  • 例字是精簡參考，不代表完整語音規則
