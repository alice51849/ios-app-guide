靜態資料服務

將版本化唯讀 JSON API 描述為 DCAT DataService。

採集流程

  1. 1下載 JSON-LD 或 Turtle 目錄並解析為 RDF。
  2. 2讀取 dcat:dataset 與 dcat:record；每筆 record 僅有一個 foaf:primaryTopic。
  3. 3直接檔案使用 dcat:downloadURL，API 使用 dcat:endpointURL。
  4. 4以 SPDX SHA-256 與 byte size 驗證每個 distribution。
  5. 5匯入其他目錄前，先對應當地 theme 與政策欄位。

驗證與 provenance

兩種 serialization 描述相同 RDF graph；DCAT terms 對照固定的未修改 W3C vocabulary，且每個 distribution 都從已發布本機 bytes 計算 hash。

範圍與限制

這是靜態 DCAT 3 描述，不代表已登錄外部 portal、取得 W3C 認證、機構背書或保證被任何外部目錄採集。Checksum 與檔案位於同一網站，可驗證 fixity，但不是獨立 authenticity 證明。
