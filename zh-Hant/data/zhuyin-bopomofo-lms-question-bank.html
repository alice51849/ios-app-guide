免費注音 LMS 題庫：QTI 2.1 與 Moodle XML

教師可直接匯入的免帳號題庫，以漢語拼音對照完整涵蓋所有注音聲母、介音與韻母。

37 題單選題英文＋繁體中文無圖片與外部媒體固定可重現套件

選擇匯入格式

LMS 支援 QTI 時使用 QTI 2.1；Moodle 則使用另外提供的原生 Moodle XML 檔案。

QTI 2.1 套件

每個 ZIP 內含 imsmanifest.xml 與 37 個自含 QTI assessmentItem，每題只使用一個易讀的 choiceInteraction。

Moodle XML 檔案

每個 XML 內含一個分類與 37 題單選題，具穩定 idnumber、每題一分與答案回饋。

答案鍵與 metadata

CSV 將每個穩定題目 ID 對應至分類、拼音、Unicode 與正確符號；JSON-LD 記錄 byte 長度與 SHA-256。

匯入 Canvas

  1. 下載一個 QTI 2.1 ZIP，不要解壓縮。
  2. 在 Course Settings 選擇 Import Course Content 與 QTI .zip file。
  3. 先匯入測試課程，逐一確認 37 題後再使用。

匯入 Moodle

  1. 下載一個 Moodle XML 檔案。
  2. 進入課程 Question bank，選擇 Import，再選 Moodle XML format。
  3. 先檢查匯入的題目分類，再提供給學習者使用。

相容性界線

LMS 匯入行為會因產品與版本而異。Canvas 目前文件列出 QTI 1.2 與 2.1，因此提供 QTI 2.1，而不把 QTI 3.0 誤標為相容；Moodle 另提供原生 XML。

本題庫可觀察與不可判斷的範圍

這些可編輯練習題只檢查符號與拼音對照，不評量發音、聲調表達、閱讀流暢度或入學準備，也沒有常模、分級或門檻分數。
