使用 mlcroissant 載入

官方 Python reader 可驗證中繼資料、下載 CSV，並逐筆讀取 symbols RecordSet。

import mlcroissant as mlc

dataset = mlc.Dataset(jsonld="https://alice51849.github.io/ios-app-guide/data/zhuyin-bopomofo-ml-dataset.croissant.jsonld")
records = dataset.records(record_set="symbols")
first = next(iter(records))

限制與不適用情境

  • 不是音訊、語音或聲學訓練語料

  • 不是學習者能力評量或診斷資料
  • 精簡對照僅供參考，不代表完整語音規則

常見問題

什麼是 Croissant？

Croissant 是 MLCommons 的 JSON-LD 格式，用來描述資料檔、紀錄結構、欄位、來源與使用條件。

CSV 與 JSONL 的紀錄相同嗎？

相同。自動檢查會逐欄比較全部 37 筆紀錄。

資料集包含全部注音符號嗎？

包含，共 21 個聲母、3 個介音及 13 個韻母，合計 37 個符號。

可以拿來訓練語音模型嗎？

不適合。這是沒有音訊或錄音的精簡符號參考，資料量也不足以訓練語音模型。
