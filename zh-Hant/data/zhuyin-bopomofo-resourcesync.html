機器入口

先讀取標準 well-known Source Description，再依序找到 Capability List 與以 Sitemap 為基礎的完整 Resource List。

Source Description →Capability List →Resource List →資源集合 metadata →

同步範圍

本集合刻意維持聚焦：只同步可重用的注音參考資料、標準 metadata、靜態 API 回應與免費教學工具，不納入行銷頁或無關 App 內容。

資料與 Linked Data

JSON、CSV、JSON-LD、Turtle 與 N-Triples

可攜套件

Croissant、Data Package、LMS 匯入檔與無障礙 EPUB 版本

靜態 API

OpenAPI 與完整 37 個版本化符號回應

開放教學工具

雙語指南、牌組與可列印活動

同步方式

  1. 從 /.well-known/resourcesync 發現同步入口。
  2. 讀取 Capability List，取得目前 Resource List。
  3. 下載前先比對 SHA-256 與檔案位元組長度。
  4. 以 Resource List 快照時間判斷是否出現新清單。

範圍與限制

這是同步清單，不是發音模型、語音語料、文字轉換器、學習評量或完整課程；ResourceSync 也不保證任何第三方目錄一定會收錄。
