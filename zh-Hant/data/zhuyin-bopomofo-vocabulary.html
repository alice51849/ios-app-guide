Graph 模型

Concept scheme 以聲母、介音與韻母為三個頂層概念。每個符號都是 SKOS Concept，具有英語及繁中 prefLabel、具型別的 Unicode notation，並且只連到一個 broader 分類。

  • 21 個聲母、3 個介音與 13 個韻母
  • 以 Unicode code point 建立穩定 hash IRI
  • 漢語拼音、寬式 IPA 與例字欄位
  • 雙向 broader / narrower 關係
  • 免帳號、無追蹤、無分析、無執行期 API

SPARQL 查詢範例

列出每個符號及其漢語拼音與寬式 IPA：

PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
PREFIX zhuyin: <https://alice51849.github.io/ios-app-guide/data/zhuyin-bopomofo-vocabulary.html#>

SELECT ?symbol ?pinyin ?ipa WHERE {
  ?concept a skos:Concept ;
           skos:prefLabel ?symbol ;
           zhuyin:pinyin ?pinyin ;
           zhuyin:ipa ?ipa .
  FILTER(LANG(?symbol) = "zh-Hant")
}
ORDER BY ?concept

常見問題

什麼是 SKOS？

SKOS 是 W3C 用來把分類法、受控詞彙及其他知識組織系統發布成 RDF 的標準模型。

JSON-LD、Turtle 與 N-Triples 的資料相同嗎？

相同。自動 graph-isomorphism 檢查會確認三種 serialization 包含完全相同的 RDF triples。

Concept IRI 如何保持穩定？

每個符號使用大寫 Unicode code point 建立 ASCII hash IRI；例如 ㄅ 使用 #u3105。

這是政府官方詞彙嗎？

不是。這是獨立開放資料詞彙，並連結官方資料供查核。
