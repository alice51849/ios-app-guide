公式與限制

每列小計＝裝置數 × 每台數值。所需＝各列相加。餘裕＝方案－所需；低於方案 20% 為偏緊，小於零為不足。以 0.1 Mbps 為單位整數相加，合計不會漂移。

購買項目 1: 1 × 15.0 ↓ / 0.5 ↑ = 15.0 ↓ / 0.5 ↑
購買項目 2: 2 × 3.0 ↓ / 3.0 ↑ = 6.0 ↓ / 6.0 ↑
購買項目 3: 4 × 1.0 ↓ / 0.5 ↑ = 4.0 ↓ / 2.0 ↑
所需下載 = 25.0; 所需上傳 = 8.5
餘裕 ↓ / ↑ = 100.0 − 25.0 = 75.0 ↓; 20.0 − 8.5 = 11.5 ↑
狀態 = 足夠

每台數值是各服務官方建議的約略規劃值（Netflix、Zoom、主機廠商、FCC）。本表只做規劃，不量測你的線路。

  • 串流（SD）: 3.0 ↓ / 0.5 ↑ Mbps
  • 串流（HD）: 5.0 ↓ / 0.5 ↑ Mbps
  • 串流（4K）: 15.0 ↓ / 0.5 ↑ Mbps
  • 視訊通話: 3.0 ↓ / 3.0 ↑ Mbps
  • 線上遊戲: 3.0 ↓ / 1.0 ↑ Mbps
  • 雲端備份: 1.0 ↓ / 5.0 ↑ Mbps
  • 瀏覽與訊息: 1.0 ↓ / 0.5 ↑ Mbps
  • 智慧家庭裝置: 0.5 ↓ / 0.5 ↑ Mbps

方案速度 0.5 至 10000 Mbps、最多一位小數；每列 1 至 50 台；最多 20 列。Wi‑Fi 涵蓋、延遲與電信商實際到府速度不在本表範圍。

  • 方案下載速度（Mbps） / 方案上傳速度（Mbps）: 0.5 ≤ x ≤ 10000 Mbps
  • 裝置數: 1 ≤ n ≤ 50
  • 購買項目: 1 ≤ n ≤ 20
