公式與限制

每月磨耗＝(100－容量)÷機齡月數，以 ±25% 帶寬呈現。距 80% 月數＝(容量－80)÷磨耗率，下界用高磨耗率、上界用低磨耗率。每月循環＝循環次數÷機齡。

裝置 1: (100 − 88) ÷ 24 = 0.50 %/機齡（月） → ±25% → 0.38–0.63; (88 − 80) ÷ 每月磨耗 % → 12–22
裝置 2: (100 − 100) ÷ 1 = 0.00 %/機齡（月） → ±25% → 0.00–0.00; (100 − 80) ÷ 每月磨耗 % → 尚無可量測的磨耗
裝置 3: (100 − 79) ÷ 66 = 0.32 %/機齡（月） → ±25% → 0.24–0.40; (79 − 80) ÷ 每月磨耗 % → 已達或低於 80%

容量 60 至 100 的整數百分比；循環次數 0 至 3000；購買月份介於 2007 與 2099、機齡 1 至 240 個月；最多 10 台。月份格式 YYYY-MM。輸入只留在本分頁，不會量測或讀取你的手機。

  • 最大容量 %: 60 ≤ x ≤ 100
  • 循環次數: 0 ≤ x ≤ 3000
  • 機齡（月）: 1 ≤ m ≤ 240
  • 裝置: 1 ≤ n ≤ 10
