公式與限制

小計＝所有人點的金額相加。稅＝小計 × 稅率。小費＝小計 × 小費比例。每個人分攤到的稅與小費＝自己點的金額 ÷ 小計，除不盡的零頭優先給小數部分最大的人，所以各人金額加起來一定等於帳單總額。

小計 = 32.40 + 18.90 + 25.00 = 76.30
稅 = 76.30 × 8.25% = 6.29
小費 = 76.30 × 15.00% = 11.45
分攤的人 1: 32.40 + 2.67 + 4.86 = 39.93
分攤的人 2: 18.90 + 1.56 + 2.84 = 23.30
分攤的人 3: 25.00 + 2.06 + 3.75 = 30.81
帳單總額 = 94.04

請使用同一貨幣，稅與小費都以小計的百分比填寫。不換匯、不套用服務費規則、不建議該給多少小費，也不經手任何付款。顯示取小數兩位，分攤計算本身以「分」為單位。

  • 他點的金額: 0 ≤ n ≤ 100,000,000
  • 稅率 % / 小費 %: 0 ≤ % ≤ 100
  • 分攤的人: 1 ≤ n ≤ 20
