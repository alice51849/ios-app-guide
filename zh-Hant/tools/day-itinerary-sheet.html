公式與限制

到達＝上一站離開＋移動。離開＝到達＋停留。合計＝所有停留＋所有移動。可用＝結束－開始；結束時間早於開始時視為隔天。超出＝合計－可用；大於零即超時。純分鐘加法，不處理時區。

1. 地點 1: 09:00 + 120 = 11:00 + 25 →
2. 地點 2: 11:25 + 60 = 12:25 + 40 →
3. 地點 3: 13:05 + 180 = 16:05 + 30 →
合計（分） = 455; 可用（分） = 09:00–18:00 = 540
超出（分） = 455 − 540 = -85 → 塞得下

時間為 24 小時制 HH:MM；停留 5 至 720 分鐘；移動 0 至 600 分鐘；最多 25 站。營業時間、實際路況、地圖、路線規劃與訂位不在本表範圍。

  • 開始時間 / 結束時間: HH:MM
  • 停留（分）: 5 ≤ m ≤ 720
  • 移動到下一站（分）: 0 ≤ m ≤ 600
  • 地點: 1 ≤ n ≤ 25
