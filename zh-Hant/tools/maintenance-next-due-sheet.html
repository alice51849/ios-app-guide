公式與限制

下次到期＝上次完成＋間隔。以月為單位時保留同一日，該月沒有這天則取月底（含閏年）。剩餘天數＝下次到期－今天；小於 0 為已逾期，0 至 7 為即將到期。

2026-06-01 + 3 個月 = 2026-09-01; 2026-09-01 − 2026-09-05 = -4
2026-08-31 + 1 週 = 2026-09-07; 2026-09-07 − 2026-09-05 = 2
2025-11-30 + 12 個月 = 2026-11-30; 2026-11-30 − 2026-09-05 = 86

間隔為 1 至 3650 天、週或個月；日期介於 1900-01-01 與 2999-12-31；最多 30 個項目。不提醒、不推播、不同步行事曆，資料不會離開本頁。

  • 間隔: 1 ≤ x ≤ 3650
  • 上次完成: 1900-01-01 ≤ x ≤ 2999-12-31
  • 項目: 1 ≤ n ≤ 30
