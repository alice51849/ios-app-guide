公式與限制

本表原樣保留你的文字：先標題，再依你輸入的順序列重點，接著下一步行動，最後指標。它只計算重點數並去掉前後空白；不改寫、不摘要、不評分。

標題 ≤ 80 · 重點 × 3 ≤ 160 · 下一步行動 ≤ 160 · 指標 ≤ 60
區塊: 標題 → 重點 1…3 → 下一步行動 → 指標

標題最多 80 字元；重點 3 到 12 個、每個最多 160 字元；下一步行動最多 160 字元；指標最多 60 字元。每一行都必須是單行文字。本表不會讀取檔案、錄音或行事曆。

  • 標題: ≤ 80
  • 重點: 3 ≤ n ≤ 12, ≤ 160
  • 下一步行動: ≤ 160
  • 指標: ≤ 60
