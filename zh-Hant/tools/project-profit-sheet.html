公式與限制

毛利＝收入合計－支出合計。毛利率＝毛利÷收入合計。每小時淨收入＝毛利÷投入時數。金額以最小單位整數相加，合計不會漂移。

收入合計 = 1500.00
支出合計 = 400.39
毛利 = 1500.00 − 400.39 = 1099.61
毛利率 = 1099.61 ÷ 1500.00 = 73.3%
每小時淨收入 = 1099.61 ÷ 12.5 = 87.97

金額 0 至 100,000,000、最多兩位小數；收入與支出各最多 20 列；時數 0.25 至 2000，以 0.25 小時為單位。同幣別、不換匯，不提供稅務或會計建議。

  • 金額: 0 ≤ x ≤ 100,000,000
  • 投入時數: 0.25 ≤ h ≤ 2000
  • 收入 / 支出: 1 ≤ n ≤ 20
