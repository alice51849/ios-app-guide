公式與限制

合計＝數量 × 含稅單價。所需工時＝合計 ÷ 實領時薪。工作天數＝所需工時 ÷ 每天工作時數。

1 × 120 + 2 × 45 + 3 × 30 = 300.00
300.00 ÷ 20 = 15.00
15.00 ÷ 8 ≈ 1.88

請輸入含稅價格。不換匯、不試算薪資、不預測存款，也不建議是否購買。顯示取小數兩位，合計使用未四捨五入的數值。

  • 每小時實領收入: 0 < x ≤ 100000000
  • 含稅單價: 0 ≤ x ≤ 100000000
  • 每天工作時數: 0 < x ≤ 24
  • 數量: 1 ≤ x ≤ 999
