Mask My File 怎麼用 — iPhone 文件個資遮蔽教學

1
匯入文件

開啟 Mask My File 並點選匯入，從「檔案」、照片或任何 App 選取 PDF 或圖片。

2
執行自動偵測

應用程式會掃描文件中的電話號碼、電子郵件、身分證字號和地址。

3
審查偵測到的項目

查看偵測到的個資清單，取消勾選您希望在共享版本中保留顯示的項目。

4
套用遮蔽

點選遮蔽，在選定的個資欄位上套用黑色色塊。

5
匯出並分享遮蔽後的文件

點選匯出，透過電子郵件、AirDrop 或「檔案」應用程式儲存或分享已遮蔽的文件。

常見問題

Mask My File 支援哪些格式？

支援 PDF 和常見圖片格式。文字型 PDF（非掃描圖片型）的偵測準確度最佳。

Mask My File 能偵測手寫的個人資料嗎？

偵測基於文字辨識，掃描文件中的手寫文字可能無法可靠偵測。

遮蔽後的文件能復原嗎？

不能。匯出的遮蔽文件中，被黑色色塊覆蓋的資料無法從該檔案還原，這是刻意的安全設計。
