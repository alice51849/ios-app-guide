Zafe 私人相片保險箱怎麼用 — iPhone 完整教學

1
下載並開啟 Zafe

從 App Store 下載 Zafe。首次啟動時設定 Face ID 或 PIN 碼以保護保險箱。

2
從相機膠卷匯入照片

點選 + 按鈕，從 iPhone 相機膠卷選取要移入的照片。照片將被複製到加密保險箱中。

3
確認後刪除相機膠卷的原始檔案

確認照片已安全存入 Zafe 後，再從相機膠卷刪除原始照片。請先確認 Zafe 中的照片正常，再進行刪除。

4
存取保險箱

鎖定 iPhone 後重新開啟 Zafe，每次都需要 Face ID 或 PIN 碼才能進入保險箱。

5
需要時匯出照片

若要分享或還原某張照片，點選後使用「分享」按鈕匯出到相機膠卷或其他應用程式。

常見問題

忘記 Zafe PIN 碼還能找回照片嗎？

如果忘記 PIN 且 Face ID 無法使用，保險箱內的照片將無法存取，沒有後門可以重設。請設定一個不會忘記的 PIN 碼，或確保 Face ID 啟用。

Zafe 的照片會備份到 iCloud 嗎？

不會。Zafe 刻意不連接 iCloud 或任何雲端服務，保險箱照片只存在於您的 iPhone 上。

可以一次把所有私人照片從相機膠卷移到 Zafe 嗎？

可以。點選 + 選取所有想移入的照片，在 Zafe 確認無誤後，再從相機膠卷刪除原始檔案。建議分批操作以避免誤刪。
